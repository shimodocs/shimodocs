# 部署与 MySQL 8

[← ShimoDocs Suite 部署文档](../../README.md)

本文说明如何禁用内置 MySQL 在 ShimoDocs 安装程序并配置您自己的 MySQL 作为第三方关系数据库。配置完成后，安装程序将检查数据库登录、网络连接以及表创建权限。检查完成后，可以继续部署。 

# 1. 配置前的准备 
在开始之前，请确认： 
- MySQL 8.0 已安装并正常运行。 
- 部署节点可以访问 MySQL 数据库主机和端口。 
- 数据库主机、端口， USERNAME和 PASSWORD 已准备好。 
- 数据库账户具有登录、连接、创建表和删除表的权限。 

> [!TIP]
>
> 本文中的 IP、端口和账户仅为示例。请使用您的实际环境信息进行配置；不要在外部 PASSWORD 文档或截图中记录真实信息。 
>

# 2. 进入高级配置 
在安装程序的“配置”步骤中，完成网络、目标环境和节点信息配置后，展开页面底部的“高级配置”部分。 

# 3. 取消内置安装 MySQL
在“中间件服务”区域，取消勾选 MySQL.

取消勾选后，安装程序将不再安装内置 MySQL，而会使用后续准备好的外部 MySQL 稍后将使用已准备好的 8.0。是否使用其他中间件的内置服务应根据实际部署方案选择。

# 4. 打开第三方中间件配置
在“第三方中间件”部分，单击“配置”。

# 5. 进行配置 MySQL 数据库
1. 选择"RDB 左侧的“关系型数据库”。
2. 启用“使用第三方关系型数据库”。
3. 在“方言”下选择“标准”。 MySQL 
4. 填写数据库连接信息。
5. 验证并保存。

# 6. 确认验证结果
安装程序将检查以下内容：

- 登录：数据库账户是否可以正常登录。
- 连接性：部署环境是否可以访问数据库。
- 创建表权限：数据库账户是否具有创建和删除表的权限。

当所有检查项显示“成功”后，关闭配置窗口并返回安装程序的“配置”页面。

如果有任何失败，请根据页面上的提示检查：
- 主机和端口是否填写正确。
- 部署节点与数据库之间的网络是否连接。
- 是否 USERNAME 以及 PASSWORD 是否正确。
- 数据库账户是否具有所需权限。

# 7. 继续初始化部署
返回“配置”页面后，确保 MySQL 如果仍未检查，请点击“初始化部署”以继续完成部署概览、检查和执行步骤。

> [!TIP]
>
> 在初始化部署之前，请再次确认 MySQL 8.0 配置已保存且所有验证项均已通过。
