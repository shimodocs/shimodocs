# MySQL 8 要求

[← ShimoDocs Suite 部署文档](../../README.md)

本文件旨在指导实施、运维或集成人员逐步完成 ShimoDocs 到 MySQL 8 数据库初始化连接，以及服务启动和连接验证。


## 1. 运营前确认

## MySQL 实例规格确认

| 推荐版本 | 用户数少于3000 | 用户数超过3000 | 
| --- | --- | --- |
| MySQL 8.0 | 4核 8G 200G SSD | 8核 16G 200G SSD | 

## MySQL 配置和高可用性要求
支持主从高可用切换
字符集：utf8mb4 
时区：亚洲/上海 或 UTC 
连接数：最大_连接数 ≥ 1000
连接用户：管理员权限

> [!TIP]
>
> 必须配置单独 MySQL 实例；
> 1. 为了实现故障隔离、权限安全以及独立备份与恢复，确保文档系统的稳定高效运行。
> 2. 系统当前不支持自定义数据库名称和表前缀，因此必须在部署前完成单独实例的规划和准备。





## 网络连通性 
连接 k8s 业务集群网络到 MySQL 实例的端口需要开放 

```js
telnet IP 3306
```
## 用户认证
用户为 MySQL 用户在连接到 MySQL 服务器时需要进行身份验证

# 说明： 
- 用户为 MySQL 文档中的配置都是推荐设置，用于项目早期阶段的容量评估和资源规划，并非最终生产配置。实际最终配置将在售前评估后确定
- 在使用国产 CPU 架构的服务器时，建议按标准规格的两倍估算整体资源
- 建议在正式生产环境中预留扩展容量，并优先考虑高可用性部署
