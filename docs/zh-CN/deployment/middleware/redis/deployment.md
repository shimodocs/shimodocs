# 部署与 Redis

[← ShimoDocs Suite 部署文档](../../README.md)

本文说明如何在安装程序中禁用内置 Redis 在 ShimoDocs 安装程序并配置客户自己的 Redis 作为第三方缓存数据库。配置完成后，安装程序将检查 Redis 网络连接性、连接、认证、命令执行、发布/订阅权限等。一旦检查通过，部署即可继续。 

# 1. 配置前的准备 
在开始之前，请确认： 
- 用户为 Redis 服务器已安装并正常运行。 
- 部署节点可以访问 Redis 服务器的主机和端口。 
- 认证用户信息和 PASSWORD 用于连接到 Redis 服务器的信息已准备好。 

> [!TIP] 
> 
> 本文中的 IP、端口和账户为示例。请使用实际环境信息进行配置，并且不要在公开文档或截图中记录真实密码。 
> 

# 2. 进入高级配置 
在安装程序的“配置”步骤中，完成网络、目标环境和节点信息设置后，展开页面底部的“高级配置”。 

# 3. 取消安装内置 Redis
在“中间件服务”部分，取消勾选 Redis

取消勾选后，安装程序将不再安装内置 Redis，将使用准备好的外部 Redis 替代。其他中间件是否使用内置服务，应根据实际部署方案选择。

# 4. 打开第三方中间件配置
在“第三方中间件”区域，点击“配置”。

# 5. 进行配置 Redis 缓存中间件
## Redis 服务器单节点
1. 选择 ""Redis 左侧的“缓存”。
2. 启用“使用第三方 Redis".
3. 点击“单节点”
4. 输入主机、端口, PASSWORD
5. 验证并保存

## Redis 服务器哨兵集群
1. 在左侧选择“Redis 缓存”。
2. 启用“使用第三方 Redis'.
3. 点击“哨兵集群”。
4. 输入“主节点名称， SENTINEL PASSWORD, SENTINEL 节点”。
5. 验证并保存

# 6. 确认验证结果
安装程序将检查以下内容：
- 登录：该账户可以正常通过认证
- 连接性：部署环境可以访问 Redis
- 权限：该账户具有连接、认证、执行命令、发布/订阅等权限。

当所有检查项显示“成功”后，关闭配置窗口并返回安装程序的“配置”页面。

如果有任何失败，请根据页面上的提示检查：
- 主机和端口是否填写正确。
- 部署节点与...之间的网络是否 Redis 服务器已连接。
- 是否 USERNAME 以及 PASSWORD 是否正确。
- 账户是否具有所需权限（连接和认证、命令权限、发布/订阅权限等）。

# 7. 继续初始化部署
返回“配置”页面后，确保 Redis 保持未选中状态，然后点击“初始化部署”以继续进行部署概述、检查和执行步骤。

> [!TIP]
>
> 在初始化部署之前，请再次确认 Redis 配置已保存且所有验证项均已通过。
