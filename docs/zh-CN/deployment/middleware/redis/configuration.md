# Redis 配置

[← ShimoDocs Suite 部署文档](../../README.md)

本文档旨在指导实施人员、运维人员或集成商逐步完成集成。 ShimoDocs 有外部 Redis 它通常用于会话管理、分布式锁、限流计数器和消息队列等核心场景。

## 1. 运营前确认

## Redis 实例要求


| 中间件 | 推荐版本 | 适用于少于3000个用户 | 适用于超过3000个用户 |
| --- | --- | --- | --- |
| Redis | Redis 6.2.21 | 2C 4G 100G SSD | 2C 8G 100G SSD |


## 集群配置要求
- 支持主从/哨兵高可用
- 数据持久化
- 不支持集群模式
- 数据库数量必须>=64





## 网络连接

用于连接的端口 K8s 业务集群网络到 Redis 实例必须开放

```js
telnet IP 6379
```

## 身份验证和授权
- 在生产环境中，建议启用 PASSWORD 身份验证（requirepass / ACL).


## 其他要求
- 内部网络 P99 延迟应小于 10 毫秒
- 时钟同步： Redis 集群节点和 ShimoDocs 应用服务器必须 NTP 保持同步
- 定期完整备份
