# 部署与 MongoDB

[← ShimoDocs Suite 部署文档](../../README.md)

本文介绍如何禁用内置的 MongoDB 在 ShimoDocs 安装程序并配置客户自己的 MongoDB 作为第三方 MongoDB 文档数据库。配置完成后，安装程序将检查 MongoDB 网络连接和连接及认证等权限。一旦检查通过，即可继续部署。 

# 1. 配置前的准备工作 
在开始之前，请确认： 
- MongoDB 服务器已安装并正常运行。 
- 部署节点可以访问 MongoDB 服务器。 
- 连接信息以及 PASSWORD 用于认证 MongoDB 服务器的信息已准备好。 

> [!TIP] 
> 
> 本文中的IP、端口和账号仅作示例。请使用实际环境信息进行配置，并且不要在公开文档或截图中记录真实信息。 PASSWORD  
> 

# 2. 进入高级配置 
在安装程序的“配置”步骤中，完成网络、目标环境和节点信息配置后，展开页面底部的“高级配置”。 

# 3. 取消内置安装 MongoDB
在“中间件服务”区域，取消勾选 MongoDB

取消勾选后，安装程序将不再安装内置 MongoDB，并将使用外部准备的 MongoDB 而是。对于其他中间件，是否使用内置服务应根据实际部署方案选择。

# 4. 打开第三方中间件配置
在“第三方中间件”区域，点击“配置”。

# 5. 进行配置 MongoDB 文档数据库
1. 选择 ""MongoDB 左侧的“文档数据库”。
2. 启用“使用第三方 MongoDB 文档数据库.
3. 输入主机、端口, USERNAME, PASSWORD，连接字符串覆盖
4. 验证并保存

> [!WARNING]
>
> 注意：如果是第三方 MongoDB 为该应用程序创建一个专用账户，并遵循“最小权限原则”，即账户仅具有访问指定数据库的权限，有必要为每个业务数据库分配一个用户和 PASSWORD 

# 6. 确认验证结果
安装程序将检查以下内容：
- 登录：该账户可以正常通过认证
- 连接性：部署环境可以访问 MongoDB
- 权限：该账户具有连接、认证、执行命令等权限。

当所有检查项显示“成功”后，关闭配置窗口并返回安装程序的“配置”页面。

如果有任何失败，请根据页面上的提示检查：
- 主机和端口是否填写正确。
- 部署节点与...之间的网络是否 MongoDB 服务器已连接。
- 是否 USERNAME 以及 PASSWORD 是否正确。
- 账户是否具有所需权限（连接和认证、命令权限等）。

# 7. 继续初始化部署
返回“配置”页面后，确保 MongoDB 保持未检查状态，然后点击“初始化部署”以继续完成部署概览、检查和执行步骤。

> [!TIP]
>
> 在初始化部署之前，请再次确认 MongoDB 配置已保存，且所有验证项均已通过。
