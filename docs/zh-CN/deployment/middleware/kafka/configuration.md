# Kafka 配置

[← ShimoDocs Suite 部署文档](../../README.md)

本文件旨在指导实施、运维或集成人员完成 ShimoDocs 与外部消息中间件的集成 Kafka 逐步操作，适用于异步任务处理、消息通知、数据同步及审计日志传送等场景。 


## 1. 操作前确认 

## Kafka 实例要求 


| 中间件 | 推荐版本 | 用户少于 3000 | 用户多于 3000 | 
| --- | --- | --- | --- | 
| Kafka | Kafka 3.5 | 2 核 4G 300G SSD | 4 核 8G 300G SSD | 


## 配置要求 
- Broker >= 3 
- 副本因子：默认副本数为 3，生产环境必须 ≥ 3 以确保高可用性 
- 消息保留：72 小时（可根据业务需求调整） 
- 每个主题的最大单条消息大小：10 MB 
- 认证：支持 SASL 加密访问（PLAIN, SCRAM-SHA-256, SCRAM-SHA-512) 





## 网络连通性 

访问 Kafka 实例的端口必须从 K8s 业务集群开放 

```js
telnet IP 9092
```



## 其他要求
- 内网 RTT 建议延迟 < 5ms；跨数据中心/跨区域建议 < 20ms。
- 带宽必须满足峰值吞吐量，以避免因网络饱和造成消息积压。
- 确保 Kafka Broker 与 ShimoDocs 应用服务器时间同步NTP)，因为时间偏差可能影响消息排序和 TTL 计算。
