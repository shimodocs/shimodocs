# 部署与 Dameng V8

[← ShimoDocs Suite 部署文档](../../README.md)

本文说明如何在安装程序中禁用内置 MySQL 在 ShimoDocs 安装程序中并配置 Dameng DM8 作为第三方关系型数据库。配置完成后，安装程序将检查数据库登录、网络连通性和表创建权限。检查通过后，即可继续部署。

## 1. 配置前准备

开始前，请确认：

- Dameng DM8 已安装并正常运行。
- 部署节点可以访问 Dameng 数据库的主机和端口。
- 数据库主机、端口、 USERNAME和 PASSWORD 已准备就绪。
- 数据库账号具有登录、连接、创建表和删除表的权限。
- Dameng 数据库已完成根据要求的 MySQL 兼容模式配置。有关详细说明，请参阅 ["Dameng 数据库集成配置指南](requirements.md).

> [!TIP]
>
> 本文中的 IP、端口和账号均为示例，请使用实际环境信息进行配置，并且不要在外部文档或截图中记录真实信息。 PASSWORD 

## 2. 进入高级设置

在安装程序的“配置”步骤中，完成网络、目标环境和节点信息配置后，展开页面底部的“高级配置”。

## 3. 取消选择安装内置组件 MySQL

在“中间件服务”部分，取消选择 **MySQL**.

取消选择后，安装程序将不再安装内置组件 MySQL，并将使用预先准备的 Dameng 数据库。对于其他中间件，是否使用内置服务应根据实际部署计划选择。

## 4. 打开第三方中间件配置

在“第三方中间件”区域，点击“配置”。

## 5. 进行配置 Dameng 数据库

1. 选择 ""RDB 关系型数据库”。
2. 启用“使用第三方关系数据库。”
3. 在“方言”部分，选择 **DM (Dameng)**.
4. 填写数据库连接信息。

| 配置项 | 说明 |
| --- | --- |
| 主机 | 该的IP地址或可访问的主机名 Dameng 数据库 |
| 端口 | 的监听端口 Dameng 数据库，通常默认是5236，具体取决于实际配置 |
| USERNAME | 用于连接数据库的账户 |
| PASSWORD | 该 PASSWORD 对应于数据库账户 |
| DSN | 由安装程序根据上述信息自动生成，无需手动输入 |

5. 确认信息无误后，点击“验证并保存”。

## 6. 确认验证结果

安装程序将检查以下项目：

- **登录**：数据库账户可以正常登录。
- **连接性**：部署环境可以访问数据库。
- **创建表权限**：数据库账户具有创建和删除表的权限。

所有检查显示“成功”后，关闭配置窗口并返回安装程序的“配置”页面。

如果有失败项，请根据页面提示检查：

- 主机和端口是否填写正确。
- 部署节点与数据库之间的网络是否连通。
- 是否 USERNAME 以及 PASSWORD 是否正确。
- 数据库账户是否具有所需权限。
- 是否 Dameng 数据库服务和 MySQL 兼容性配置是否正常生效。

## 7. 继续初始化部署

返回“配置”页面后，确认 MySQL 保持未选中状态，然后点击“初始化部署”以继续完成部署概览、检查和执行步骤。

> [!TIP]
>
> 在初始化部署之前，请再次确认 Dameng 配置已保存且所有验证项已通过。
