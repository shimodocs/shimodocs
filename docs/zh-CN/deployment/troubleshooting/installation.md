# 安装故障排查

[← ShimoDocs Suite 部署文档](../README.md)

> [!TIP]
>
> 安装阶段的常见问题通常属于以下类别。

## 1 时间不同步

问题症状：

* 登录失败

* 身份验证错误

* 服务调用异常

处理要求：

* 首先检查所有节点的时间偏差

* 修复 /time 同步服务后， NTP继续进行安装或验收

调查命令：

```plain
timedatectl status
date
```


## 2 数据磁盘路径配置错误

现象：

* 安装后，磁盘很快就会被填满

* 数据写入失败

* 持久目录位于系统驱动器上

处理要求：

* 持久目录必须明确指向数据盘

* 业务数据不存储在系统磁盘目录中

故障排除命令：

```plain
findmnt -n -o TARGET -T /data
df -Th|egrep -v "overlay|tmpfs"
```


## 3 依赖服务连接失败

现象：

* 安装过程中服务检查失败

* 连接数据库、缓存、消息队列或对象存储失败

处理要求：

* 首先检查地址、端口、账户，以及 PASSWORD 已正确输入

* 然后检查网络连接和安全策略

* 最后，检查目标服务本身是否可用

故障排除命令：

```plain
nc -zv <MYSQL_HOST> 3306
nc -zv <REDIS_HOST> 6379
nc -zv <MONGO_HOST> 27017
nc -zv <KAFKA_HOST> 9092
```


## 离线包不匹配

现象：

* 镜像加载失败

* 安装过程中报告服务无法启动且版本不匹配

* 安装包与离线镜像包不对应

处理要求：

* 确认安装包、离线镜像包和产品版本一致

* 确认安装包是否匹配 CPU 架构

* 确认不同项目或不同日期的材料未混合

## 安装程序页面无法打开

现象：

* 无法访问 Web UI 页面

* 端口 18080 未监听

* 安装程序进程已退出

故障排除命令：

```plain
ps -ef | grep mdp | grep -v grep
ss -lntp | grep 18080
tail -n 100 /root/nohup.out
```


## 6. 推荐的故障排除顺序

按照以下顺序排查安装问题：

1. 首先，确认是否为环境问题：系统、时间、磁盘、端口、网络

2. 再次确认是否为配置问题：域名、目录、依赖地址、账户 PASSWORD

3. 再次确认是否为材料问题：安装包、离线包、架构兼容性

4. 最后，检查安装程序日志和服务运行状态

说明：

* 如果先决条件未满足，请勿重复安装

* 不要重复执行具有相同明确失败原因的命令

## 7. 何时应停止安装

如果出现以下情况，请先停止安装，解决根本问题后再继续：

* 所有节点时间不同步

* 数据盘未独立挂载

* 外部依赖服务不可访问

* 离线物料版本不一致

* 安装服务未正常启动
