# 平台用户管理

[← ShimoDocs Suite 部署文档](../../../README.md)

## 功能概览

系统用户管理用于在管理后台维护用户账户，包括创建用户、编辑基本信息、重置 MDP 、管理双因素认证以及删除用户。 PASSWORD

## 访问页面

使用系统管理员账户登录后，选择 **系统用户管理** 在左侧导航中访问该页面。

此菜单仅限指定的系统管理员账户访问。如果您看不到此菜单，请联系您的系统管理员。

## 查看用户

页面显示用户昵称、用户名、角色、电子邮件地址、联系方式、上次登录时间和注册时间，并提供总用户数、最近活跃用户和管理员账户等概览信息。

您可以通过列表分页查看所有用户。

## 创建新用户

点击 **创建新用户** 并填写以下信息：

- **昵称**：必填，用于页面显示。
- **USERNAME**：必填，用于登录系统。
- **电子邮件**：必填，必须提供有效的电子邮件地址。
- **联系信息**：可选。
- **角色**：选择普通用户或管理员。

创建后，系统将生成初始密码 PASSWORD。请立即复制并通过安全方式提供给用户，因为 PASSWORD 关闭此窗口后可能无法再次查看。

### 用户角色描述

- 管理员
  - 可以根据全局权限使用所有页面
    - ShimoDocs Suite
    - 文档中心
    - 系统服务
- 普通用户
  - 页面使用范围基于全局权限
    - ShimoDocs Suite
    - 文档中心
    - 系统服务（隐藏）

## 编辑用户信息

点击用户右侧的编辑按钮以修改其昵称、电子邮件和联系方式。 USERNAME 创建后无法在此页面修改。

## 重置 PASSWORD

点击重置后 PASSWORD 按钮并确认操作，系统将生成新的 PASSWORD。原始 PASSWORD 将立即失效。

请复制并妥善保存新的 PASSWORD，通过可信渠道将其交付给相应用户，并提醒用户尽快登录并更改 PASSWORD 。

## 管理双因素认证

- **启用或禁用 2FA**：在用户所在行使用开关，并在确认窗口中继续操作。
- **重置 2FA**：系统将生成新的二维码和秘钥，原验证信息将失效。

重置后，用户应使用 Authenticator 等认证器重新扫描并绑定。二维码和秘钥属于敏感凭证，不应通过公共渠道传输。 

绑定 2FA

通过 Authenticator 扫描添加，并使用动态 6 位 2FA 进行后续登录

## 删除用户

点击删除按钮并确认后，用户账号将被移除。删除操作无法撤销，请确保账号不再使用，并在执行前完成必要的数据和权限交接。

## 常见情况

- **无法创建用户**：请检查是否 USERNAME 已重复，电子邮件格式正确，所有必填字段已完整。
- **用户无法登录**：请验证是否正确；如有必要，请重置 USERNAME 以及 PASSWORD  PASSWORD.
- **用户无法完成双因素认证（2FA）验证**：确保系统时间正确，或为用户重置2FA并重新绑定。
- **用户管理菜单不可见**：当前账户可能不是指定的系统管理员账户。
- **意外删除用户**：删除操作无法直接撤销；需要重新创建账户并重新配置相关权限。

> 在创建、重置 PASSWORD和重置2FA时生成的凭证应及时保存，仅提供给账户持有人。
