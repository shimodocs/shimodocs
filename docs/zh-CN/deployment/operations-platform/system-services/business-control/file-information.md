# 文件信息搜索

[← ShimoDocs Suite 部署文档](../../../README.md)

## 功能概览

文件信息查询用于根据内部文件 GUID 或客户侧文件 ID 查询系统中文件的基本记录，方便验证文件标识、关联应用、文件类型、状态和内容大小。

此页面为只读，不会修改文件内容或状态。

## 访问页面

登录管理后台后，选择 **文件信息查询** 在左侧导航中访问该页面。

## 查询文件

页面支持以下查询条件：

- **内部文件 GUID**：文件的 `history_guid`.
- **客户文件提供者 GUID**：客户侧 `provider_file_id`.
- **应用 ID**：可选，建议与提供方一起填写 GUID 以指定关联的应用程序。

至少有一个内部文件 GUID 或客户文件提供者 GUID ，然后点击 **查询**.

如果只有提供者 GUID 已填写而应用程序ID未填写，系统将返回所有匹配提供者的记录 GUID，所以可能会出现多个结果。 

### 获取文件 GUID 
1. 在 ShimoDocs Suite的情况下，您只需要在浏览器中使用套件的地址作为 **客户文件提供者 GUID**. 

## 查询结果

查询结果主要包括：

- **ID**：文件记录的主键ID。
- **应用_ID**：关联应用的ID。
- **提供者_文件_ID**：客户端文件ID。
- **历史_全局唯一标识符**：内部系统历史文件 GUID.
- **创建_时间**：记录创建时间。
- **类型**：文件类型，例如文档、电子表格、演示文稿、 PDF、图片或视频。
- **创建_创建者**：创建者用户ID。
- **状态**: 文件的当前状态值。
- **文件_内容_大小**: 文件内容的大小，单位为字节。

结果中的文件类型将同时显示类型编号和对应名称，以便于识别。

## 常见情况

- **提示：必须输入查询条件**: 请至少填写内部文件 GUID 或提供商 GUID.
- **未找到文件**: 请检查标识是否完整，或确认该文件是否属于当前环境。
- **返回多条记录**: 提供商 GUID 可能在多个应用中重复；请添加应用 ID 后再次搜索。
- **文件类型显示为未知**: 当前记录的类型编号可能尚未配置对应名称。您可以将编号提供给技术支持确认。
- **无法确定状态值**: 状态字段是底层记录值，需要结合具体业务现象和日志进一步分析。

> 文件标识符属于业务数据；请避免在公共聊天或外部工单中直接分享。
