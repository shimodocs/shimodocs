# 高级设置

[← ShimoDocs Suite 部署文档](../../../README.md)

## 功能概览

高级设置用于管理系统的自定义 `pd-config` 通过 YAML直接操作。这适用于处理标准设置页面未提供的高级参数或批量配置。

系统将自定义配置与出厂默认配置合并。相同路径上的自定义值将覆盖默认值，而未填写的配置将继续使用出厂默认值。

## 进入页面

登录管理后台后，选择 **高级设置** 在左侧导航中访问该页面。

高级设置仅对管理员开放。本页面可能影响整个系统，因此应由熟悉系统的人员操作 MDP 配置结构。

## 页面描述

页面分为两部分：

- **出厂默认 pd-config**：安装包提供的默认配置，只读。
- **自定义 pd-config**：当前保存的客户自定义配置，可以编辑。

自定义配置不需要复制所有默认内容；通常只保留需要覆盖或添加的配置项。

## 修改和发布配置

建议按照以下步骤操作：

1. 点击 **刷新** 以确保加载最新的自定义配置。
2. 将其与左侧的出厂默认配置进行比较，并进行修改 YAML 右侧的内容。
3. 点击 **发布**.
4. 在差异确认窗口中检查已添加、已删除和已修改的内容。
5. 使用上一个/下一个差异按钮逐项检查更改。
6. 确认无误后，点击 **确认发布**.

发布成功后，系统将创建一个配置应用任务，并在新窗口中打开任务日志。根据更改和系统设置，相关服务可能会自动重启。

## 配置历史

点击 **历史** 查看之前发布的自定义配置，包括记录ID、创建时间以及 MD5.

- 点击 **查看** 查看完整 YAML 历史版本内容。
- 选择两条记录后，可以执行差异对比。

当前页面不提供一键恢复按钮。要恢复历史配置，请检查对应版本，验证内容，手动复制到编辑区，并重新发布。

## 注意事项

- YAML 语法必须保持正确；注意缩进、冒号和数据类型。
- 不要随意删除不理解的配置项。
- 发布前请充分检查差异，以避免覆盖其他管理员最近提交的更改。
- 建议在非高峰营业时间执行重要更改，并应提前记录原始配置。
- 发布后，请检查任务日志以确保配置应用和服务状态检查已完成。

## 常见情况

- **发布失败**：请检查 YAML 格式、字段名称和配置值类型。
- **发布后服务重启**：配置更改可能需要重启相关服务，这是正常的。
- **发布后页面暂时无法访问**: MDP 或相关服务可能正在重启；请稍等后刷新。
- **配置未达到预期效果**：请确认配置路径是否正确，并检查最终合并结果和任务日志。
- **错误的配置修改**：从历史记录中找到正确版本，复制内容并重新发布。

> 高级设置会影响系统级配置和服务运行，不要将未经验证的配置直接发布到生产环境。
