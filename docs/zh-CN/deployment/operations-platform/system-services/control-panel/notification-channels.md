# 通知渠道

[← ShimoDocs Suite 部署文档](../../../README.md)

## 功能概览

通知通道用于集中管理系统警报消息的接收方式，允许中间件检查和其他功能发送故障及恢复通知。

当前支持的通道包括企业微信、钉钉、飞书和自定义 Webhooks。

## 访问页面

登录管理控制台后，选择 **通知渠道** 在左侧导航中访问该页面。

通知通道仅对管理员可用。如果您看不到此菜单，请联系系统管理员确认您的账户权限。

## 创建新的通知通道

点击 **创建通道**输入通道名称，并选择通道类型：

- **企业微信**：输入机器人 Webhook 密钥。
- **钉钉**：输入完整的 Webhook URL，并根据机器人配置可选输入签名密钥。
- **飞书**：输入完整的 Webhook URL，并根据机器人配置可选输入签名密钥。
- **自定义 Webhook**：输入请求 URL, HTTP 方法和正文模板。

确认是否启用该通道，然后点击 **保存**.

## 自定义 Webhook

自定义 Webhook 的正文模板支持以下变量： 

```text
{{title}}
{{body}}
{{level}}
```

默认模板示例： 

```json
{"title":"{{title}}","body":"{{body}}","level":"{{level}}"}
```

当系统发送通知时，会将变量替换为实际的标题、内容和告警级别。 

## 测试频道 

保存后，点击 **测试** 在频道右侧。系统将发送测试消息以验证 Webhook 地址、签名和网络连接是否正确。 

建议在创建或修改频道后立即进行测试，然后再将其绑定到中间件检查或其他业务功能。 

## 启用、编辑和删除 

- **启用/禁用**：编辑频道时调整启用状态。禁用后，频道将不会接收业务通知。 
- **编辑**：您可以修改频道名称、类型和 Webhook 配置。 
- **删除**：删除不再使用的频道。被中间件检查引用的频道必须先解绑才能删除。 

## 常见情况

- **测试发送失败**：请检查 Webhook 地址、Key、Secret, HTTP 方法，及网络访问权限。
- **保存失败**：请确保所有必填字段已完成，并且Webhook URL 格式正确。
- **未收到业务提醒**：请确认该渠道已启用，并已在相应的业务页面上选择。
- **无法删除渠道**：该渠道可能仍被中间件检查使用。请先移除关联并保存检查配置。
- **自定义 Webhook 接收到的内容格式不正确**：请检查 Body 模板是否符合目标系统的要求。

> Webhook 地址和签名 Secret 是敏感信息。请限制访问，并避免通过截图、日志或聊天工具公开共享。
