# 配置中心

[← ShimoDocs Suite 部署文档](../../../README.md)

## 功能概览 

配置中心用于查看和修改各种服务的应用配置。页面同时显示工厂模板配置和当前正在使用的配置，使您能够轻松了解配置差异，并以可控的方式发布修改。 

配置发布后，系统会保存此修改，并可根据您的选择自动重启相关服务以应用新配置。 

## 访问页面 

登录管理后台后，选择左侧导航中的 **配置中心** 以访问该页面。 

配置中心仅对管理员开放。如果您没有看到此菜单，请联系系统管理员确认您的账户权限。 

## 页面说明 

页面主要分为三个区域： 

- **应用及文件列表**：按应用显示可配置文件，并支持按应用名称搜索。 
- **工厂模板配置**：显示安装包中提供的原始配置，仅供查看和参考。 
- **当前活动配置**：显示环境当前使用的配置，可以直接编辑。 

配置文件通常为 JSON, YAML, 或 TOML 格式。请保持正确的文件语法和数据结构。 

## 修改和发布配置 

建议按以下步骤操作： 

1. 在左侧选择需要修改的应用程序和配置文件。
2. 参考工厂模板，在 **有效配置** 区域修改配置内容。
3. 修改后，页面将显示状态 **已修改但未发布**.
4. 点击 **已修改但未发布**，或者使用 `Ctrl S` （Windows）/ `Command S` （macOS）打开确认窗口。
5. 检查字段路径、修改类型和要发布的新值。
6. 根据需要选择是否启用 **发布配置后重启相关服务** 。
7. 点击 **发布配置** 以完成修改。

如果配置内容存在格式错误，系统将提示错误并阻止发布。请进行更正后再试。

## 更改确认

发布前的确认窗口将显示此修改的差异：

- **路径**：已更改的配置路径。
- **操作**：更改类型，例如新增、修改或删除。
- **值**：更改后的配置值。

建议确认每个差异，以避免意外删除配置或修改错误的服务参数。

## 服务重启

某些配置仅在服务重启后生效。默认情况下，页面启用 **发布配置后重启相关服务**，发布成功后，与应用相关的服务将自动重启。

如果关闭此选项，配置仍会发布，但相关服务可能需要稍后手动重启才能应用新设置。

在服务重启期间，相关功能可能会有短暂波动；建议在非高峰业务时间进行重要配置更改。

## 常见情况

- **未找到应用**：请清除搜索条件或确认目标应用程序已正确部署。
- **配置文件无法加载**：请在重试前检查服务状态和当前账户权限。
- **配置格式错误**：请检查缩进、括号、引号和字段格式 JSON, YAML, 或 TOML.
- **没有要发布的更改**：实际配置内容未发生有效变化，无需发布。
- **发布后更改未生效**：请确认相关服务是否已重启，如有必要，请手动重启并再次验证。
- **发布失败**：请根据页面提示检查配置内容或服务状态，并处理后重新发布。 

> 配置更改可能影响服务启动及业务功能，请在完全确认更改后再发布。
