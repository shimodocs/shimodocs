# 服务日志

[← ShimoDocs Suite 部署文档](../../../README.md)

## 功能概览 
服务日志功能是一个类似 Kibana 的日志检索平台，可以收集来自各种 Pod 的日志，并提供日志搜索、查询和比例分析功能。 ShimoDocs  

## 入口与导航
左侧菜单：系统服务 --> 服务操作 --> 服务日志

## SQL 模式
输入框支持 ClickHouse SQL 语法查询。输入完成后 SQL，可以在 ClickHouse 原生模式下执行查询。

如下面图所示，输入

``` sql
`_raw_log_` like '%access%'
```

可以用于查询包含 access 的所有日志。

如下面图所示，点击行记录中某字段旁的图标以打开下拉菜单。选择“Top 值”后，可以在右上角查看该字段在当前时间范围内的比例。

## 字段描述

| 内置字段 | 说明 |
| --- | --- |
| 级别 | 日志的错误级别，包括信息、错误、警告 |
| 容器名称 | CONTAINER_NAME |
| 方法 | 访问日志中的方法； gRPC 打印 gRPC 方法， HTTP 打印 API 路径 |
| 对等 IP | 对等 IP |
| 对等名称 | 对等体的名称，例如服务名称等。 |
| 组件 | 访问日志中的组件，例如 server.begin |
| 耗时 | 访问日志中消耗的时间，以毫秒为单位 |
