# 实时日志

[← ShimoDocs Suite 部署文档](../../../README.md)

## 功能概览

实时日志用于在线查看集群中服务的操作日志， Kubernetes 帮助您快速定位服务异常、请求失败和执行延迟。

主要使用场景：
- 快速过滤实时触发的日志
- 在未部署完整日志系统时的轻量级替代方案

注意：实时日志通过 Kubernetes API获取，日志数据可能会受到影响 Kubernetes 滚动更新。

## 访问页面

登录管理控制台后，选择 **实时日志** 从左侧导航进入页面。

实时日志仅在部署模式下受支持。 Kubernetes 如果您看不到此菜单，请联系您的系统管理员以确认部署模式以及您当前账户的访问权限。

## 查询日志

建议按照以下步骤操作：

1. 选择该 **集群** 以及 **NAMESPACE** 您想要查询的。
2. 选择日志目标，支持 Deployment、StatefulSet 或 Pod，同时可以选择多个目标。
3. 选择日志范围，可以查询最近 100 行、1000 行、5000 行，或过去 1 分钟至 24 小时的日志。
4. 要缩小查询结果，可以填写行级过滤条件。
5. 点击 **开始** 页面将加载所选范围内的日志，并持续显示新生成的日志。

点击 **停止** 以结束实时拉取。重新启动查询时，当前页面的日志将被清除，并加载新的查询结果。

## 日志过滤

行级过滤对英文字母不区分大小写。输入条件后按回车键应用。常见用法如下：

```text
error
error AND timeout
error OR warning
error NOT health
error AND (timeout OR deadline)
"connection refused"
```

- `AND`：同时包含多个条件。 
- `OR`：包含任意条件。 
- `NOT`：排除指定内容。 
- `()`：组合多个过滤条件。 
- `""`：搜索包含空格的完整短语。 

您可以点击输入框右侧的帮助按钮查看完整的语法示例。您也可以使用 **常用查询** 快速填写预设的日志目标和过滤条件。 

## 查看日志 

日志列表显示日志时间， POD_NAME和日志内容。 

- 点击 POD_NAME 复制完整名称。 
- 当内容较长时，您可以展开以查看完整日志。 
- 日志已以 JSON 格式显示，可展开为格式化内容，并支持一键复制。 
- 当日志较多时，页面会自动分页，您可以使用列表顶部的按钮快速跳转到顶部或底部。 

## 日志量分布 

页面上的日志量分布图显示不同时间段的日志数量，并显示日志行总数及过滤后的匹配行数。 

您可以在分布图上拖动选择时间范围，日志列表将仅显示该时间范围内的内容，这适合快速关注日志突增或异常的时间段。 

## 页面操作 

- **开始**：根据当前条件拉取日志并持续接收新日志。 
- **停止**：停止接收新日志；已加载的日志将保留在页面上。
- **清除**：清除当前显示的日志；如果实时拉取继续，新日志将持续出现。

## 常见情况

- **暂无日志**：请确保目标服务正在运行，并尝试扩大日志时间范围。
- **未选择目标**：请至少选择一个 Deployment、StatefulSet 或 Pod。
- **目标过多**：单次查询最多支持 20 个实际 Pod；请减少选择后重试。
- **过滤条件无效**：请检查 `AND`, `OR`, `NOT`、括号或引号是否完整。
- **日志获取中断**：这可能由服务重启、网络变化或权限不足导致。您可以点击 **开始** 再次尝试。

> 页面最多保留 500,000 行日志。一旦超过限制，较旧的日志将被自动移除。
