# 通用工具

[← ShimoDocs Suite 部署文档](../../../README.md)

## 1. 页面概览

通用工具页面包括7个常用功能： JSON 格式化、格式转换、 JWT 解码、时间戳转换、机器时间检查、二维码解析和Base64编码/解码。

1. 点击任意功能卡即可进入操作页面。
2. 进入后，可直接从左侧功能列表切换到其他工具。
3. 点击“返回功能菜单”可返回卡片主页。

## 2. JSON 格式化

此功能用于格式化、压缩和验证 JSON 内容。

1. 点击 "JSON 格式化。
2. 在“输入 JSON”区域输入要处理的内容，例如：

   ```json
   {"name":"MDP","enabled":true,"items":[1,2]}
   ```

3. 点击“格式”，然后缩进 JSON 将会在右侧生成。
4. 点击“压缩”，并进行压缩 JSON 没有空格和换行的内容将在右侧生成。
5. 点击“复制”以复制处理后的结果。
6. 点击“清除”以删除输入和输出内容。

测试结果：字符串、布尔值和数组均被正确保留，格式和压缩功能也正常工作。

## 3. 格式转换

此功能支持不同格式之间的转换和格式化。 JSON, YAML和 TOML 。

1. 点击“格式转换”。
2. 在“源格式”中选择输入内容的格式。
3. 在“目标格式”中选择所需的输出格式。
4. 在左侧输入要转换的内容。
5. 点击“转换”，结果将显示在右侧。
6. 点击“交换格式”以切换源格式和目标格式。
7. 点击“格式化”以调整当前内容的缩进和布局。
8. 点击“复制”以复制输出结果。

这次我们使用 JSON 转换为 YAML，输入：

```json
{"name":"MDP","ports":[80,443],"enabled":true}
```

转换结果： 

```yaml
name: MDP
ports:
  - 80
  - 443
enabled: true
```

测量结果：字段、数组和布尔值均正确转换。

## 4. JWT 解码

此功能用于解析 JWT 令牌的 Header、Payload 和 Signature。

1. 点击 "JWT 解码。
2. 将 JWT 令牌粘贴到输入框中。
3. 点击“解码”。
4. 在 Header 中查看签名算法和 Token 类型。
5. 在 Payload 中查看用户、角色和到期时间等信息。
6. 查看 Signature 的原始内容。
7. 点击每个部分的复制按钮以复制解析结果。
8. 点击 "清除" 删除当前 Token 和解析结果。

测试结果：测试 Token 成功解析了用户、角色和到期时间等字段。 `HS256`, `JWT`

> JWT 解码仅用于查看 Token 结构，不能替代服务器端的签名有效性验证。

## 5. 时间戳转换 

此功能支持 Unix 时间戳与日期时间之间的双向转换。 

### 5.1 时间戳转换为日期/时间 

1. 点击 "时间戳转换"。 
2. 在 "时间戳（秒或毫秒）" 中输入 10 位秒或 13 位毫秒时间戳。 
3. 点击顶部的 "转换"。 
4. 在 "转换结果" 中查看日期和时间。 
5. 点击结果旁边的复制按钮以复制内容。 

### 5.2 日期时间转时间戳 

1. 输入 'YYYY-MM-DD HH:mm:ss' 或者 ISO 在“日期时间”字段中格式化时间。 
2. 点击下方“转换”。 
3. 在“转换结果（秒）”中查看 Unix 时间戳。 
4. 点击“当前时间”以快速填写当前时间戳和日期。 
5. 点击“清除”以清空所有内容。 

测试结果：'1704067200' 已成功转换为日期时间，并且日期时间也可以正确转换为秒级时间戳。 

> 在检查跨时区数据时，首先明确业务时间使用的是 UTC 还是本地时区。 

## 6. 机器时间检查

此功能用于检查当前 `app=ws-gateway` 中所有 Pod 的时间 NAMESPACE 并突出显示时间偏差超过 30 秒的实例。

1. 点击“机器时间检查”。
2. 点击右上角的“刷新”。
3. 检查当前 NAMESPACE 并查询标签。
4. 查看系统计算的参考时间，即所有 Pod 的中位时间。
5. 查看每个 Pod 所在的节点、Unix 时间戳及可读时间。
6. 检查“与参考的差异”和“状态”。
7. 如果偏差超过30秒，请检查节点的 NTP/Chrony、虚拟机时间和时区设置。

测试结果：1 `ws-gateway` Pod 返回，参考时间偏差为 `0s` 状态为“正常”。

## 7. 二维码分析

此功能用于上传二维码图片并提取其中的文字、链接或其他内容。

1. 点击“二维码分析”。
2. 点击“选择文件”。
3. 从本地设备选择清晰的二维码图片。
4. 页面显示图片预览后，查看下方的“分析结果”。
5. 将结果与二维码的预期内容进行比较以确认一致性。
6. 点击“复制”以复制分析内容。
7. 点击“清除”以删除图片和分析结果。

测试结果：测试二维码可以成功上传、预览并正确分析。

## 8. Base64 编码和解码

此功能用于明文与 Base64 内容之间的双向转换。

### 8.1 Base64 编码

1. 点击“Base64 编码和解码”。
2. 在左侧输入纯文本。
3. 点击“编码”。
4. 在右侧查看 Base64 编码结果。

### 8.2 Base64 解码

1. 在左侧输入 Base64 内容。
2. 点击“解码”。
3. 在右侧查看恢复的文本。
4. 点击“复制”以复制结果。
5. 点击“清除”以清除输入和输出。

测试结果：

```text
MDPTEST → TURQ5rWL6K+V
TURQ5rWL6K+V → MDPTEST
```

中文 UTF-8 内容可以正常来回转换。
