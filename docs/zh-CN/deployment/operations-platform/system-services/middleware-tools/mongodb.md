# MongoDB 工具

[← ShimoDocs Suite 部署文档](../../../README.md)

> [!TIP]
>
> MongoDB 用于在运维平台查看 MongoDB 数据库、集合和文档内容。它适用于排查基于文档的数据、中间状态、任务记录以及具有灵活结构的业务数据。
>
> 该页面支持按数据库或集合进行搜索，选择集合后， MongoDB JSON 可以使用条件查询。

## 1. 访问 MongoDB

1. 登录至 **MDP 运维平台**.
2. 选择 **系统服务** 在左侧导航栏中
3. 展开 **中间件工具** 。
4. 选择 **MongoDB**.

页面左侧显示数据库和集合树，右侧显示查询条件和查询结果。

## 2. 搜索数据库或集合

1. 输入 DATABASE_NAME 在左上角的搜索框中输入数据库或集合名称的关键字。
2. 查看过滤后的树列表。
3. 清空搜索框以恢复显示所有数据库。

## 3. 展开数据库并选择集合

1. 在左侧树中找到目标数据库。
2. 点击数据库左侧的展开图标以加载集合列表。
3. 选择目标集合。
4. 右侧页面会自动使用默认条件执行一次查询。 `{}`.

> 仅选择数据库不会执行集合查询；您需要先选择一个特定的集合，然后查询区域才会显示在右侧。

## 4. 填写查询条件

1. 填写 MongoDB JSON 在右侧查询输入框中填写查询条件。
2. 选择要返回的结果数量，支持 `limit: 10`, `limit: 20`, `limit: 50`.
3. 点击 **查询**.

查询示例： 

```json
{
  "_id": "task-123"
}
```

按字段查询示例：

```json
{
  "status": "running"
}
```

## 5. 查看查询结果

1. 查询完成后，在右侧结果区域查看返回的文档。
2. 默认情况下，结果显示为 JSON 格式。
3. 点击 **展开** 以展开当前文档。
4. 点击 **收起** 以收起当前文档。
5. 点击 **复制** 以复制当前文档 JSON.

## 6. 常见故障排查场景

| 场景 | 操作建议 |
| --- | --- |
| 确认文档是否存在 | 选择集合后，使用 `_id` 或业务ID进行查询。 |
| 检查任务状态 | 通过任务ID查询并检查状态字段和更新时间字段。 |
| 查找一种记录 | 使用状态、类型和创建时间等字段的组合进行查询。 |
| 结果为空 | 检查是否选择了正确的数据库、集合、字段名称和字段类型。 |
| 需要移除故障排查结果 | 点击 **复制** 单个结果。 |
