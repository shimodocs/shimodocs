# gRPC 工具

[← ShimoDocs Suite 部署文档](../../../README.md)

> [!TIP]
>
> 用户为 gRPC 该工具用于连接内部 gRPC 服务，查看服务和方法，并发起 Unary 方法调试调用。
>
> 该页面支持三种方式选择目标：手动输入地址，通过选择 Kubernetes 服务，或按 Pod 选择。

## 1. 访问 gRPC

1. 登录到 **MDP 运维平台**.
2. 选择 **系统服务** 在左侧导航栏中
3. 展开 **中间件工具** 。
4. 选择 **gRPC**.

页面首先显示用于选择要连接的服务的“目标”区域。 gRPC 

## 2. 目标选择方法

页面提供三种目标模式：

| 模式 | 说明 |
| --- | --- |
| 手动 | 手动输入 gRPC 地址，例如， `svc-user:50051`. |
| 服务 | 按集群、命名空间、服务和端口选择目标。 |
| Pod | 按集群、命名空间、Pod 和端口选择目标。 |

## 3. 手动连接 

1. 选择 **手动**. 
2. 输入 gRPC 在地址输入框中输入服务地址。 **地址** 输入框。 
3. 点击 **连接**. 
4. 连接成功后，页面将进入服务/方法调试工作区。 

## 4. 按服务连接

1. 选择 **服务**.
2. 选择目标集群和命名空间。
3. 在 **服务/端口** 下拉列表中，选择目标服务和端口。
4. 如果服务列表未更新，请点击 **刷新**.
5. 点击 **连接**.

## 5. 按 Pod 连接

1. 选择 **Pod**.
2. 选择目标集群和命名空间。
3. 在 **Pod/端口** 下拉菜单，选择目标 Pod 和端口。
4. 如果 Pod 列表没有更新，点击 **刷新**.
5. 点击 **连接**.

## 6. 选择服务和方法

连接成功后，页面分为服务列表、方法列表、请求区域和响应区域。

1. 从左侧的服务列表中选择目标服务。
2. 您可以使用服务搜索框来过滤服务。
3. 从方法列表中选择目标方法。
4. 可切换的方法过滤选项： `Unary`, `Streaming`, `All`.
5. 您可以使用方法搜索框来过滤方法。

> 当前页面仅支持调用单次方法。流式方法将显示为不可用。

## 7. 填写请求参数

请求区域支持两种填写方式：

| 方法 | 说明 |
| --- | --- |
| 表单模式 | 页面根据方法输入字段生成表单。 |
| JSON 模式 | 当 **JSON 模式** 启用时，可直接编辑完整的 JSON 请求体。 |

使用表单模式的步骤：

1. 选择目标方法。
2. 逐字段填写请求参数。
3. 使用下拉菜单选择枚举字段。
4. 选择 `true` 或 `false` 用于布尔字段。
5. 对于重复字段，请按照页面指示使用逗号。

使用步骤 JSON 模式：

1. 打开 **JSON 模式** 开关。
2. 在文本框中填写完整的 JSON 。
3. 确保 JSON 格式有效。

## 8. 填写元数据

1. 展开 **元数据** 在请求区域中。
2. 填写键和值。
3. 要添加多个元数据条目，请点击 **添加**.
4. 要删除一行，请点击删除图标。

元数据通常用于传递认证信息、请求 ID 或业务上下文。

## 9. 发起调用并查看响应

1. 确认目标、服务、方法、请求正文和元数据。
2. 点击 **调用** 在页面右上角。
3. 在响应区域查看状态、耗时、响应元数据和响应 JSON 。
4. 如果调用失败，响应区域将显示错误状态和错误内容。

## 10. 切换或重新连接目标

1. 点击 **连接** 在顶部重新加载当前目标的服务定义。
2. 点击 **更改目标** 返回目标选择页面。
3. 切换目标后，需要重新连接并再次选择服务/方法。

## 11. 常见故障排除场景

| 场景 | 操作建议 |
| --- | --- |
| 检查服务是否可连接 | 选择目标并点击 **连接** 查看服务列表是否可以加载。 |
| 查找接口方法 | 使用服务搜索和方法搜索进行过滤。 |
| 调试查询接口 | 选择一个单点方法，填写请求参数，并点击 **调用**. |
| 需要传递上下文 | 展开元数据并填写对应的键和值。 |
| 响应为空或失败 | 检查响应状态、错误内容和元数据。 |
