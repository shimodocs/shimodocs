# Kafka 工具

[← ShimoDocs Suite 部署文档](../../../README.md)

> [!TIP]
>
> 用户为 Kafka 工具允许您查看 Kafka 通过 Redpanda 控制台查看集群状态、主题、消息、消费者组及分区信息，常用于排查消息写入、消费者积压和异步链路问题。
>
> 页面加载成功后，Redpanda 控制台将被嵌入其中 MDP.

## 1. 访问 Kafka

1. 登录到 **MDP 运维平台**.
2. 选择 **系统服务** 在左侧导航栏中
3. 展开 **中间件工具** 。
4. 选择 **Kafka**.
5. 等待 Redpanda 控制台完成加载。

如果控制台尚未准备好，页面将提示正在启动或启动失败，并显示错误信息。

## 2. 查看集群概览

进入后 Kafka, **默认显示概览** 。

您可以查看以下信息：

| 信息 | 说明 |
| --- | --- |
| 集群状态 | 集群运行状态。 |
| 集群存储容量 | 当前集群存储大小。 |
| 集群版本 | 集群版本信息。 |
| 在线代理 | 在线代理数量。 |
| 主题 | 主题数量。 |
| 副本 | 副本数量。 |
| 代理详情 | 代理ID、状态和大小。 |

## 3. 查看主题

1. 在Redpanda控制台的左侧导航中，选择 **主题**.
2. 在主题列表中找到目标主题。
3. 点击主题以进入详情页。
4. 查看主题的分区、消息和配置等信息。

主题故障排除通常关注：

| 信息 | 说明 |
| --- | --- |
| 分区 | 主题的分区状态。 |
| 消息 | 主题中的消息列表。 |
| 配置 | 主题配置，例如保留策略。 |

## 4. 查看消息

1. 进入目标主题。
2. 打开消息查看区域。
3. 使用页面提供的过滤器选择分区、位置或时间范围。
4. 查看消息的键、值、头信息、分区、偏移量和时间戳。

> 消息内容可能包含业务字段。排查问题时优先按业务ID、键、偏移量和时间戳定位。

## 5. 查看消费者组

1. 在Redpanda控制台中，选择 **消费者组** 从左侧导航。
2. 搜索或选择目标消费者组。
3. 进入消费者组详情。
4. 查看消费者组关联的主题、分区、当前偏移量、日志末尾偏移量和滞后。

## 6. 确定消费者积压

| 状态 | 说明 |
| --- | --- |
| 滞后为0 | 当前消费者组没有积压。 |
| 滞后持续增加 | 消费速度低于生产速度。 |
| 滞后不会改变，但不是0。 | 可能存在已停止的消费者、分区阻塞或消费失败。 |
| 单个分区的滞后显著偏高。 | 可能是由于热点键或该分区的异常消费导致。 |

## 7. 查看 Broker

1. 在概览页面，找到 **Broker 详情**.
2. 查看 Broker ID、运行状态和存储大小。
3. 点击 **查看** 以查看 broker 详情。

## 8. 常见故障排除场景

| 场景 | 操作建议 |
| --- | --- |
| 确认是否 Kafka 正常运行 | 在概览中检查集群状态和在线 Brokers。 |
| 确认是否有消息被写入 | 进入 Topic 并检查消息。 |
| 排查消费者延迟 | 进入消费者组并检查滞后。 |
| 定位单条消息 | 可按 Topic、分区、偏移量、Key 或时间戳搜索。 |
| 确认 Topic 配置 | 进入 Topic 详情并检查配置。 |
