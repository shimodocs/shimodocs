# Redis 工具

[← ShimoDocs Suite 部署文档](../../../README.md)

> [!TIP]
>
> Redis 用于在运维平台查看 Redis 实例、数据库、一组Key及Key详情。通常用于排查缓存、会话、分布式锁、限流计数器和短期状态。
>
> 页面支持按Key或Key前缀搜索，并显示Key类型、 TTL以及当前值。

## 1. 访问 Redis

1. 登录至 **MDP 运维平台**.
2. 选择 **系统服务** 在左侧导航栏中
3. 展开 **中间件工具** 。
4. 选择 **Redis**.

页面左侧为Key查询区域，右侧为Key详情区域。

## 2. 选择 Redis 实例和数据库

1. 在左上角的第一个下拉菜单中，选择 Redis 实例。
2. 在第二个下拉菜单中，选择数据库，例如 `db0`.
3. 页面将根据当前实例和数据库加载密钥列表。

如果数据库列表为空或页面报告错误，请首先检查是否 Redis 实例配置正常。

## 3. 搜索键

1. 在搜索框中输入键名或键前缀。
2. 点击搜索按钮或按回车键执行查询。
3. 在左侧查看键列表。
4. 如果您需要在当前条件下重新加载列表，请点击刷新图标。

搜索框提示为“请输入键名，支持模糊搜索。”页面将显示匹配的键类型和 TTL.

## 4. 查看键列表

键列表包含以下信息：

| 信息 | 说明 |
| --- | --- |
| 类型 | 该 Redis 键的类型，例如 `string`, `hash`, `list`, `set`, `zset`. |
| 键名 | 当前匹配的完整键。 |
| TTL | 键的剩余过期时间；如果当前键没有过期，页面显示“永久”。 |

## 5. 查看键详情

1. 在左侧的键列表中点击目标键。
2. 右侧的详细信息区域显示键名、类型， TTL以及具体值。
3. 要刷新当前键的详细信息，请点击详细信息标题区域的刷新按钮。

不同类型的显示方法如下：

| 类型 | 显示方法 |
| --- | --- |
| `string` | 在文本框中显示完整的值。 |
| `hash` | 在表格中显示字段键和值。 |
| `list` / `set` | 在表格中显示元素列表。 |
| `zset` | 在表格中显示分数和成员。 |

## 6. 复制字段值

1. 在键详细信息表中找到要复制的字段或值。
2. 点击对应的内容。
3. 页面会将该内容复制到剪贴板。

> `string` 类型显示在文本框中，可通过选择文本直接复制；表格类型支持点击值进行复制。

## 7. 常见故障排除场景

| 场景 | 建议操作 |
| --- | --- |
| 确认缓存是否存在 | 选择实例和数据库后，通过完整键或前缀搜索。 |
| 检查缓存是否已过期 | 检查 TTL 在键列表或详细信息中。 |
| 查看哈希字段 | 点击键以查看右侧表中的字段和值。 |
| 查看 ZSet 排序数据 | 点击 `zset` 键以查看分数和成员。 |
| 查看相同键的最新状态 | 点击详细信息区域的刷新按钮。 |
