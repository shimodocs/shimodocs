# 品牌定制

[← ShimoDocs Suite 部署文档](../../README.md)

> [!TIP]
>
> 品牌定制用于统一 ShimoDocs Suite的品牌标识和界面风格。在这里可以设置公司标志、浏览器图标、标签页品牌扩展、主题颜色、按钮圆角、页面入口和系统水印。 
>
> 使用该功能时，建议先确认配置的有效范围，然后按品牌标识、界面风格、入口和水印的顺序完成配置。 

> 当未选择租户时，配置将全局生效于 ShimoDocs Suite。同一配置项的优先级为： ** 租户配置 > 全局配置**. 

## 1. 进入品牌定制 

1. 登录至 **MDP 运维平台**. 
2. 在顶部，选择 **ShimoDocs Suite**. 
3. 在左侧导航栏中选择 **品牌定制**. 

## 2. 选择配置的有效范围 

品牌定制支持全球、租户或用户范围。在配置之前，请根据您的实际需求选择相应的范围。 

| 配置范围 | 如何选择 | 效果 |
| --- | --- | --- |
| 全局配置 | 不选择租户或用户。 | 对全局生效 ShimoDocs Suite. |
| 租户配置 | 选择指定租户。 | 仅对所选租户生效。 |
| 用户配置 | 选择指定用户。 | 仅对所选用户生效。 |

例如：如果全局主题颜色设置为蓝色，而某个租户的主题颜色设置为绿色，则该租户将使用绿色，而未单独配置的其他租户仍使用蓝色。

## 3. 配置品牌标识

### 1. 公司Logo

通过配置“修改主站公司Logo”，可以控制在“企业管理 > 公司基本信息”页面上是否显示更改公司Logo的选项。 **企业管理 > 公司基本信息** 页面中 ShimoDocs Suite.

启用后，管理员可以在公司基本信息页面修改公司Logo。

### 2. 浏览器图标

通过“修改页面浏览器图标”设置，您可以替换浏览器标签页上显示的图标（Icon）。 ShimoDocs Suite 浏览器标签页

配置后，您可以在浏览器标签页上查看实际显示效果。

### 3. 浏览器标签页品牌后缀

通过“浏览器标签页品牌后缀”配置，您可以设置显示的品牌名称后缀 ShimoDocs Suite 在浏览器标签中。

配置完成后，您可以在浏览器标签标题中查看效果。

## 4. 配置界面风格

### 1. 主题颜色

通过“主题颜色”配置，您可以统一调整主按钮、选中状态和高亮内容的颜色 ShimoDocs Suite.

更改颜色后，您可以预览主题颜色在页面中的实际应用效果。

### 2. 按钮圆角

调整按钮的圆角效果 ShimoDocs Suite 通过“圆角半径配置”。

调整数值后，按钮的圆角形状将相应改变。

## 5. 配置页面入口和品牌信息

### 1. 官方网站入口

通过配置“启用主站官方网站入口”，您可以控制是否在个人名片上显示 ShimoDocs 官方网站入口。

启用后，用户可以在个人资料中看到官方网站入口。

### 2.“关于”入口

通过“启用主站关于入口”设置，可以控制个人资料中是否显示“关于”入口。

启用后，用户可以在个人资料中查看“关于”入口。

### 3. 品牌信息

通过“是否显示品牌信息”设置，您可以控制在相关页面上是否向用户显示品牌信息。

## 6. 配置系统水印

### 1. 协作者水印

通过配置“启用系统内置协作者水印”，您可以控制用户编辑或预览文件时显示的水印内容。

水印内容会根据访问者是否匿名以及“是否显示用户信息”的选择而有所不同。 

#### 非匿名访问 

| 配置选项 | 水印显示内容 |
| --- | --- |
| 显示/隐藏 | 显示系统内置水印，包括基本授权信息和用户信息。 |
| 自定义 | 根据企业中设置的协作者水印内容显示 ShimoDocs Suite 企业。 |

#### 匿名访问

| 配置选项 | 水印显示内容 |
| --- | --- |
| 显示/隐藏 | 显示系统内置水印，包括基本授权信息和用户信息。 |
| 自定义 | 仅显示为匿名用户配置的自定义文本。 |

启用内置协作者水印后，用户在编辑或预览文件时将永久显示相应水印。

### 2. 编辑器底部栏水印

通过“修改系统内置编辑器底部栏水印”配置，您可以调整编辑器底部显示的系统内置水印。

配置完成后，可以在编辑器底部查看实际显示效果。

## 7. 检查配置结果

配置完成后，建议按以下顺序检查：

1. 确认当前选择的配置范围是全局还是租户。
2. 打开 ShimoDocs Suite 在相应范围内的页面。
3. 刷新页面并检查徽标、浏览器图标、标签名称、主题颜色以及入口的显示状态。
4. 使用非匿名和匿名方法打开文件，并确认水印内容按预期显示。
5. 如果实际效果与预期不符，请首先检查是否存在优先级更高的租户配置。
