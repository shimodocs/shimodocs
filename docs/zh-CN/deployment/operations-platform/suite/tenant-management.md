# 租户管理

[← ShimoDocs Suite 部署文档](../../README.md)

> [!TIP]
>
> 租户管理用于集中管理租户。 ShimoDocs Suite.
> 管理员可以在此查看租户数量和席位使用情况，获取第三方集成凭证，管理AI配置，以及创建、编辑、启用或禁用租户。
>

## 1. 进入租户管理

1. 登录至 **MDP 运维平台**.
2. 选择 **ShimoDocs Suite** 在左侧导航栏中
3. 选择 **租户管理** 。

## 2. 了解租户管理页面

页面顶部显示当前系统的总体信息：

| 区域 | 说明 |
| --- | --- |
| API-KEY | 查看并复制 `AppID` 以及 `AppSecret` 。 |
| AI 设置 | 检查 AI 功能是否已启用，并访问 AI 模型和搜索配置。 |
| 租户总数 | 当前系统中已创建的租户数量。 |
| 启用的租户 | 当前启用的租户数量。 |
| 座位使用情况 | 已使用座位数、系统中的总座位数以及使用比例。 |

下面的租户列表显示租户名称、激活时间、租户管理员、座位使用情况和当前状态。在“操作”列中，您可以编辑或禁用相应的租户。

## 3. 查看 API 密钥

`AppID` 以及 `AppSecret` 用于认证当 ShimoDocs Suite 与第三方系统集成时。

### 操作步骤

1. 找到 **API-KEY** 在租户管理页面上选择卡片。
2. 点击复制图标。
3. 系统将复制当前环境的 `AppID` 以及 `AppSecret`.
4. 将凭据输入到相应的第三方集成配置中。

> `AppSecret` 是一个敏感凭证。请妥善保管，不要将其写入公共文档、聊天记录或公开可访问的代码仓库。

## 4. 管理 AI 配置

AI 配置卡显示当前 AI 能力的激活状态。

点击 AI 配置卡后，您可以在“AI 模型与搜索配置”页面查看或编辑以下内容： 

### 1. 基本模型配置

用于配置通用大型语言模型（LLM）及其可用模型。在此页面上，您可以查看提供者、请求等信息 URL, API 密钥、默认模型、模型 ID、上下文窗口和输入功能。

### 2. 图像模型配置

用于配置图像生成或图像编辑模型。在页面上，您可以查看提供商、模型名称、基础 URL, API 密钥以及支持的图像功能。

### 3. 网络搜索引擎配置

用于配置 AI 网络搜索服务。在页面上，您可以查看服务提供商、接口地址， API 密钥和超时。

### 4. 嵌入式供应商配置

用于配置文本向量化服务。在页面上，您可以查看基础 URL, API 密钥、嵌入模型和向量维度。

> 在修改 AI 配置之前，请首先确认服务地址、 API 密钥、模型 ID 和能力参数均正确。修改后，建议使用少量测试内容来验证模型调用是否正常。

### 5. 使用 AI ShimoDocs Suite
配置完成后，您可以在内使用 AI 功能 ShimoDocs Suite.

## 5. 管理现有租户

在租户列表中，您可以查看每个租户的基本信息和座位使用情况。

### 编辑租户

1. 找到需要调整的租户。
2. 点击“操作”列中的“编辑”。
3. 根据页面提示修改租户信息或座位数量。
4. 保存更改并返回列表以确认信息已更新。

### 禁用或恢复租户

- 对于当前已启用的租户，您可以在“操作”列中点击“禁用”。
- 要恢复已禁用的租户，请在对应租户的操作项中重新启用它。

> 禁用租户将影响对该租户的正常访问。请在继续操作前确认目标租户是否正确，并根据实际使用情况安排操作时间。

## 6. 激活新租户

在激活租户之前，请先检查页面顶部的座位使用情况，以确认仍有可分配的座位。

### 操作步骤

1. 点击页面右上角的“激活新租户”。
2. 在“租户名称”中输入用于识别该租户的名称。
3. 确认系统生成的租户管理员邮箱。租户成功创建后，请保存此管理员账户及初始密码，并尽快记录。 PASSWORD 
4. 查看“可分配座位”以了解当前最多可分配给新租户的座位数量。
5. 在“租户分配座位”中输入分配给该租户的座位数量。
6. 确认信息无误后，点击“保存”。

### 席位字段说明

| 字段 | 说明 |
| --- | --- |
| 可分配席位 | 系统当前可以分配给租户的最大席位数。 |
| 分配给租户的席位 | 分配给该租户的席位总数。此数字不能少于租户已使用的席位数。 |
| 租户使用的席位 | 该租户中活跃企业成员的数量。每个活跃成员占用一个席位。 |

> 创建租户时需要分配一定数量的席位。席位数量可以根据实际使用情况稍后调整。

## 7. 首次登录及修改初始密码 PASSWORD

租户创建成功后，请使用系统生成的默认账户或管理员账户登录 ShimoDocs Suite 并立即修改初始密码 PASSWORD.

### 1. 打开 ShimoDocs Suite

在浏览器中访问：

```text
http://<ACCESS_DOMAIN>/
```

如果 HTTPS 已配置，请访问： 

```text
https://<ACCESS_DOMAIN>/
```

### 2. 登录 ShimoDocs Suite

输入管理员账户和初始密码 PASSWORD 在设置租户时创建，以完成登录。

### 3. 更改初始设置 PASSWORD

首次登录后，请按照页面指示或账户安全设置更改初始密码。 PASSWORD一旦设置了新的 PASSWORD ，请妥善保管。
