- 1. 访问顶部的许可证管理
## 。

1. 登录到 **MDP 运维平台**.
2. 选择 **ShimoDocs Suite** 在左侧导航栏中
3. 选择 **许可证管理** 。

该页面包含许可证激活、许可证信息、机器码对比和机器信息区域。

## 2. 申请 ShimoDocs Suite 许可证

在申请授权之前，请先确保 ShimoDocs Suite 服务器节点是稳定的，并且在短期内不会添加、移除或更换节点。 

### 1. 复制所有机器码 

1. 在“授权激活”区域，点击“一键复制所有机器码”。 
2. 确认页面显示复制成功提示。 
3. 将机器码保存在授权申请材料中。 

### 2. 提交授权申请信息

将所有机器码和授权要求提交给 ShimoDocs 服务人员以生成 ShimoDocs Suite 许可证。

建议在申请时确认以下信息：

| 信息 | 说明 |
| --- | --- |
| 授权产品 | ShimoDocs Suite. |
| 许可证名称和公司 | 将在许可证上显示的许可证名称和公司。 |
| 座位数 | 可以使用许可证的最大座位数。 |
| 使用期间 | 产品许可证的开始和到期时间。 |
| 售后服务期 | 售后服务的开始和到期时间。 |
| 可用套件 | 需要启用的文档类型或功能套件。 |
| 人工智能功能 | 是否需要启用人工智能功能。 |
| 机器码 | 当前运行的所有服务器机器码 ShimoDocs Suite. |

## 3. 写入和验证授权

收到新许可证后，请按照以下步骤将其写入系统。

### 1. 写入许可证

1. 点击“授权激活”区域中的“写入授权”。
2. 将收到的完整许可证内容粘贴到输入框中。
3. 确保许可证内容完整，没有缺失字符或多余空格。
4. 点击“临时保存”。

### 2. 检查许可证验证结果

临时保存后，系统将验证新许可证并显示以下结果：

| 验证结果 | 说明 | 建议操作 |
| --- | --- | --- |
| 不匹配 | 新许可证的关键信息与当前环境不匹配。 | 检查机器码、应用类型、版本和授权范围。确认无误后，再次获取许可证。 |
| 已更改 | 新许可证中的某些信息与当前许可证不同。 | 请在页面上检查原始值、新值和判定结果，以确认更改与本次申请一致。 |
| 通过 | 对应的验证项已通过。 | 继续检查其他授权信息。 |

如果页面上有任何“已更改”的项目，并且这些更改符合本次授权申请，请点击“确认临时保存”。

> 如果出现意外的“不匹配”或“已更改”，请先停止发布并重新检查申请信息和当前操作环境。

## 4. 发布授权

验证并临时保存完成后，页面将显示待发布的许可证信息。

### 发布前检查

仔细核对以下项目：

- 许可证名称。
- 数量限制。
- 开始时间和到期时间。
- 申请ID。
- 服务器机器码。

确认信息无误后，点击“发布许可证”。

发布完成后，刷新页面以查看更新后的授权状态和授权信息。

## 5. 查看授权信息

“授权信息”部分显示当前有效的许可内容。

### 授权信息字段说明

| 字段 | 说明 |
| --- | --- |
| 授权名称 | 当前许可的授权名称。 |
| 被授权公司 | 许可所属的公司。 |
| 产品版本 | 当前授权适用的产品版本。 |
| 发布版本 | 当前授权的发布类型。 |
| 应用类型 | 当前许可适用的产品类型。 |
| 租户数量 | 当前许可允许的最大租户数量。 |
| 座位数 | 当前许可允许的最大席位数。 |
| 产品使用周期 | 产品授权的起始和到期日期。 |
| 售后服务期 | 售后服务的起始和到期日期。 |
| 机器数量 | 许可绑定的服务器数量。 |
| AI 功能 | 当前许可证是否启用 AI 功能。 |
| 可用套件 | 当前许可证允许的文档类型或套件。 |

## 6. 检查机器码比较结果

在授权信息下方，将显示许可证中的机器码与当前运行服务器的比较结果。

| 结果 | 说明 |
| --- | --- |
| 证书中的机器 | 当前许可证中已绑定的服务器数量。 |
| 实际机器 | 当前系统检测到的正在运行的服务器数量。 |
| 匹配 | 许可证中的机器码与当前服务器匹配。 |
| 不匹配 | 当前存在未绑定到许可证的服务器，或许可证中的机器已更改。 |
| 缺失 | 许可证中绑定的机器当前未被系统检测到。 |

如果证书中的机器数量与实际机器数量不符，或者页面显示“未匹配”或“缺失”，请点击“复制机器码”，并使用当前机器码重新申请许可证。

> 如果页面顶部出现倒计时提示，显示机器码不一致，请在提示时间内完成服务器信息验证或许可证更换，以确保授权连续性。

## 7. 查看机器信息

“机器信息”部分显示当前运行的服务器节点。

### 机器信息字段说明

| 字段 | 说明 |
| --- | --- |
| 服务器 | 当前服务器节点的名称或地址。 |
| 操作系统 | 服务器当前使用的操作系统。 |
| CPU | 服务器的处理器型号。 |
| 核心数 | 服务器的核心数量。 CPU  |
| 内存 | 服务器当前识别的内存容量。 |
| 架构 | 服务器的系统架构。 |
| 机器码 | 用于生成和绑定许可证的服务器唯一标识符。 |

## 8. 检查授权更新结果

完成许可证释放后，建议按以下顺序检查：

1. 刷新授权管理页面，确认授权状态是否正常。
2. 验证授权名称、席位数量、使用期限、可用套件和AI功能。
3. 确认证书中的机器数量与实际机器数量匹配。
4. 确认机器码对比中没有意外的“匹配错误”或“缺失”结果。
5. 登录至 ShimoDocs Suite 验证授权的文档类型和功能能否正常使用。

> 在更换、增加或移除服务器节点后，建议及时返回此页面检查机器码对比结果。如果机器码发生变化，需要使用所有新的机器码重新申请并发布许可证。
