# 编辑器配置

[← ShimoDocs Suite 部署文档](../../../README.md)

## 1. 手册说明

本手册介绍了“编辑器配置”功能 ShimoDocs Suite，适用于首次使用此功能的系统管理员和实施人员。您可以按照本文档中的步骤查找配置项、修改功能开关或配额、验证其是否生效，并在必要时恢复原始设置。

**最重要的范围规则** 当团队ID留空时，将查询并修改默认应用配置；当输入团队ID时，将查询并修改相应团队的配置。修改默认应用配置可能会影响多个团队，因此在保存前请再次确认配置范围。

### 1.1 访问入口

管理员后台 > ShimoDocs Suite > 配置管理 > 编辑器配置

### 1.2 使用前的准备

- 确认您的登录账户具有查看和修改权限 ShimoDocs Suite 编辑器配置。
- 首先确认目标范围是默认应用程序还是特定团队，并获取准确的团队ID。
- 请根据配置要求或附录 A 确认配置项名称。配置项名称是唯一标识符；不要仅根据中文功能名称猜测。
- 在修改之前记录来源、有效值和限制状态；对于重要配置，还应准备回滚值。
- 默认的应用配置影响范围广；建议在业务低峰期进行修改，并提前通知相关责任人。

## 2. 配置范围和优先级

编辑器配置支持两个范围：应用默认和团队。在进行更改之前，您必须检查页面顶部的团队ID和“当前维度”。

| **功能区域** | **应用默认范围** | **团队范围** | **页面识别指示器** |
| --- | --- | --- | --- |
| 编辑器配置 | 留空团队ID | 输入正整数团队ID | 当前维度显示“应用默认”或“团队” |

*图1 团队ID与当前维度的对应关系*

### 2.1 应用默认范围

- 保持团队ID为空。
- 页面顶部显示“当前维度：应用默认”。
- 应用默认值是在未设置团队覆盖时的基础值；修改它可能会影响多个团队。
- 保存前，请再次确认团队ID确实为空，以避免错误地将团队需求写入应用默认设置。

### 2.2 团队范围

- 在团队ID字段中输入目标团队的正整数ID，然后点击“查询”。
- 页面顶部显示“当前维度：团队”。
- 团队级配置仅影响对应输入的团队ID的团队，不会直接更改其他团队的配置。
- 当配置项有团队级设置时，团队有效值优先于应用默认值。

### 2.3 覆盖、继承与恢复

- 如果当前团队没有自定义覆盖，将使用应用程序默认配置或系统默认值。
- 列表中的“来源”可以帮助确定当前值是来自系统默认、应用程序覆盖，还是团队覆盖。
- 删除当前层覆盖后，配置通常会重新继承上级值；在删除前请确认继承结果。
- 修改或恢复后，请重新查询相同的团队 ID 和配置项，以确认来源和生效值符合预期。

**风险提示** 在未确认当前维度前，请勿直接保存。当团队 ID 为空时，操作将写入应用程序默认范围，可能影响多个团队。 

## 3. 编辑器配置 

编辑器配置用于查看和调整功能开关、使用配额以及编辑器的结构化配置。 ShimoDocs Suite 您可以按类型筛选，或展开“高级筛选”，在“名称白名单”中输入配置项名称以进行精确搜索。 

### 3.1 页面字段 

| **字段** | **描述** | 
| --- | --- | 
| 应用程序ID | 当前 ShimoDocs Suite 应用程序标识符，仅用于确认上下文。 | 
| 当前维度 | 当团队ID为空时为“应用程序默认值”；在填写团队ID后为“团队”。 | 
| 团队ID | 团队标识符；仅接受正整数。 | 
| 类型 | 选项包括全部、功能、单值配额、范围配额或 JSON 配置。 | 
| 高级筛选 | 展开输入框以输入配置项名称。 | 
| 名称白名单 | 输入配置项名称；支持每行一个或用英文逗号分隔。 | 
| 来源 | 指示当前值是来自系统默认、应用覆盖还是团队覆盖。 | 
| 生效值 | 当前范围内使用的实际开关、配额或结构化配置。 | 
| 操作 | 铅笔图标用于编辑；删除图标用于移除当前层覆盖。 | 

*图2 编辑器配置查询区域、结果列表及操作列*

### 3.2 精确搜索

1. 根据配置范围决定是否填写团队ID：留空表示使用应用的默认范围，或填写对应团队。
2. 根据需要选择“类型”；如果不确定类型，请保持“全部”。
3. 点击“高级筛选”以展开“名称白名单”。
4. 输入完整的配置项名称。多个名称请每行输入一个或用逗号分隔。
5. 点击“查询”以在结果中验证名称、类型、来源及有效值。
6. 点击目标行最右侧的铅笔图标以打开编辑弹窗。

*图3 点击“高级筛选”后填写名称白名单*

*图4 精确搜索后单条结果用于编辑_限制_mosheet_大小*

**操作提示** 如果看不到操作图标，请水平滚动列表至最右侧或扩大浏览器可见区域。

### 3.3 在列表中直接搜索

- 首先确认团队 ID 和类型筛选器是否正确，然后滚动浏览查询结果。
- 使用“名称”和“类型”来确认目标配置；不要仅仅依赖当前值。
- 页面上显示的记录数量可能会根据部署版本和当前应用支持的配置项而变化。
- 找到目标行后，点击最右侧的铅笔图标进入编辑模式。

### 3.4 编辑配置

#### 3.4.1 功能

功能类型用于控制某个功能是否可用。打开编辑弹窗后，从“有效值”下拉框中选择页面提供的状态，如“支持”或“隐藏”，然后点击“保存”。某些配置项名称包含反向语义，如不支持或禁用，请根据项名称和描述判断实际含义。

*图 5 功能类型配置项的有效值设置*

#### 3.4.2 单值配额

单值配额通常包括一个“限制验证”开关和一个“最大值”。当启用限制验证时，系统将根据最大值进行验证；当禁用时，通常显示为“无限制”。最大值必须在参数允许的范围内，并与参数名称中的单位一致，例如MB、GB、页、项或字符。

*图6 单值配额验证及最大值设置*

#### 3.4.3 范围配额

- 范围配额通常提供最小值和最大值。
- 最小值不能大于最大值，输入值应在页面或附录提供的允许范围内。
- 如果页面提供“无验证”或“无限制”选项，首先确认当前功能是否支持此设置。
- 保存后，在实际业务功能中验证边界值，以避免仅检查配置后台的显示。

#### 3.4.4 JSON 配置

- JSON 配置必须保持有效的结构，包括成对的引号、逗号、括号以及正确的数据类型。
- 在进行更改前保存完整的原始值；不要只记录单个字段。
- 当字段含义不明确时，不要随意添加、删除或重命名字段。

### 3.5 保存与删除

- 保存前，请重新确认当前维度、团队ID、配置项名称、类型、单位及新值。
- 保存后，再次查询相同范围和相同配置项，以确认源值和生效值已更新。
- 删除图标通常用于移除当前范围的覆盖记录，而不是删除配置项本身。
- 本手册仅列出当前页面可查询和修改的配置项；实际显示的项目可能因部署版本和当前应用支持能力而异。

### 3.6 配置项说明

附录A仅包含当前页面上可查询和修改的编辑器配置项；具体可见范围取决于当前部署版本和页面的实际显示。

## 4. 效果验证与回滚

### 4.1 保存后的验证

- 在编辑器配置页面，重新查询相同的团队ID和相同的配置项，以确认来源、生效值及限制状态。
- 进入实际使用该配置的编辑器或功能页面，验证功能是否可见、配额是否生效或限制是否解除。
- 应用默认配置时，至少验证一个没有设置团队级配置的团队；对于团队级配置，仅验证目标团队ID。
- 如有必要，刷新页面、重新进入编辑器、重新登录或等待缓存更新。
- 记录修改时间、操作人、配置范围、团队ID、配置项名称、修改前后数值及验证结果。

### 4.2 回滚

- 如果原始值已被记录，请重新编辑并写回原始值。
- 如果只需要移除当前范围的覆盖，请使用删除图标，并在删除后确认上级的继承值。
- 回滚后，重新查询源值和生效值，并进入业务页面再次验证。
- 如果应用默认配置修改导致异常，先恢复默认值，然后检查是否有团队有独立覆盖。

**重要提示** 删除当前覆盖后，继承值可能会立即在页面上显示。删除前必须确认上级配置符合预期，并保留修改前状态的记录。

## 5. 常见问题

| **问题** | **解决方案** |
| --- | --- |
| 找不到配置项名称输入框 | 点击“高级筛选”展开“名称白名单”。 |
| 找不到编辑或删除图标 | 水平滚动列表到最右侧，或扩大浏览器视口。 |
| 精确搜索未返回结果 | 检查名称的大小写、下划线、团队ID和类型筛选器；清除过于严格的筛选条件后重试搜索。 |
| 输入团队ID后，仍未在团队维度中显示 | 团队ID必须是有效的正整数；输入后请再次点击“查询”，并查看页面顶部的“当前维度”。 |
| 保存后，业务页面没有改变 | 检查是否选择了错误的范围，是否被团队覆盖，是否需要刷新或重新登录，以及配置项是否适用于当前功能。 |
| 删除图标不可用 | 当前范围可能没有自定义覆盖，正在使用系统默认值或继承自更高层级的值。 |
| 配额保存失败 | 检查数值范围、单位、最小值与最大值的关系，并确认是否允许“无限制”。 |
| JSON 配置保存失败 | 使用有效 JSON；检查引号、逗号、括号和字段类型；如不确定，请在修改前恢复完整原始值。 |

## 附录 B：术语与页面字段对应关系

| **术语** | **含义** |
| --- | --- |
| 配置项名称 / 名称白名单 | 配置项的唯一名称，例如 rdoc_通知、编辑_限制_mosheet_大小 |
| 团队ID | 团队标识符；输入正整数以进入团队级配置范围。 |
| 应用默认值 | 未填写团队 ID 时的配置范围；本手册中称为全局配置。 |
| 团队级配置 | 仅对指定团队 ID 生效的覆盖配置。 |
| 系统默认值 | 当此级别没有覆盖时，使用产品内置默认值。 |
| 应用覆盖 / 团队覆盖 | 当前层存在自定义配置，优先于上级值。 |
| 功能开关 | 开关或状态类型参数。 |
| 单值配额 | 最大值和可选的限制验证开关。 |
| 范围配额 | 包含最小值和最大值的范围参数。 |
| JSON 配置 | 必须保持有效的结构化参数 JSON；某些配置项未显示在当前页面。 |
| 无验证 / 无限制 | 不根据输入的最大值执行限制验证。 |
