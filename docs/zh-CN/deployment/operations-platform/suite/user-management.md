# 套件用户管理

[← ShimoDocs Suite 部署文档](../../README.md)

> [!TIP]
>
> 用户管理用于查看每个租户中的用户 ShimoDocs Suite 并批量启用或禁用用户账户。 
>
> 使用此功能，您需要先选择用户所在的租户，然后进入相应的用户列表进行管理。 

> 用户管理页面使用“团队”名称显示用户所在的租户范围。 

## 1. 进入用户管理 

1. 登录至 **MDP 运维平台**. 
2. 在顶部，选择 **ShimoDocs Suite**. 
3. 在左侧导航栏中选择 **用户管理**. 

## 2. 选择要管理的团队（租户） 

进入用户管理页面后，系统首先显示团队列表。请从列表中选择用户所属的团队（租户）。 

### 查找团队（租户）

1. 在页面顶部的搜索框中输入团队名称、创建者或ID。 
2. 在搜索结果中，确认团队名称、创建者、激活人数、容量及到期日期。 
3. 点击团队名称进入该团队的用户列表。 

### 团队列表字段说明

| 字段 | 说明 |
| --- | --- |
| ID | 系统中团队的唯一标识符。 |
| 团队名称 | 团队的名称。点击以进入该团队的用户列表。 |
| 创建者 | 创建此团队的账户。 |
| 激活 / 容量 | 团队当前已激活的用户数量和可用席位。 |
| 到期日期 | 该团队当前服务的到期日期。 |

> 如果列表内容未及时更新，可以点击搜索框右侧的“刷新”。

## 3. 查看租户用户

点击租户名称后，页面将显示该租户内的用户列表。

### 用户列表字段说明

| 字段 | 说明 |
| --- | --- |
| ID | 系统中用户的唯一标识符。 |
| USERNAME | 用户显示的名称 ShimoDocs Suite. |
| 电子邮件 | 绑定到用户账户的电子邮件。 |
| 角色 | 用户在当前租户中的角色，如管理员或成员。 |
| 状态 | 用户账户当前是否启用。 |

## 4. 搜索用户

当租户中有许多用户时，您可以使用搜索功能快速找到目标用户。

1. 输入 USERNAME在用户列表上方的搜索框中输入姓名、邮箱或用户ID。
2. 验证搜索结果中的 USERNAME姓名、邮箱和角色，以确保您找到了目标用户。
3. 要重新加载列表，请点击搜索框右侧的“刷新”。

## 5. 批量启用用户

当用户账户被禁用且需要恢复时，您可以批量启用用户。

### 步骤

1. 确认当前页面显示的是目标租户。
2. 在用户列表左侧勾选一个或多个需要启用的用户。
3. 确认页面右上角显示的“已选”数量是否正确。
4. 点击“批量启用”。
5. 根据页面提示确认操作。
6. 操作完成后，刷新列表并确认用户状态已更改为“已启用”。

## 6. 批量禁用用户

当用户暂时不需要使用时 ShimoDocs Suite，可以批量禁用其账户。

### 步骤

1. 确认当前页面显示的是目标租户。
2. 在用户列表左侧勾选一个或多个要禁用的用户。
3. 确认页面右上角“已选”显示的数量是否正确。
4. 点击“批量禁用”。
5. 根据页面提示确认操作。
6. 操作完成后，刷新列表并确认用户状态已更新。

> 禁用用户将影响该账户的正常使用。 ShimoDocs Suite 请在操作前检查租户、 USERNAME电子邮件和角色，以避免误操作影响其他用户。

## 7. 返回租户列表

如果需要切换到其他租户：

1. 点击页面左上角的“返回团队列表”。
2. 在租户列表中再次搜索并选择目标租户。
