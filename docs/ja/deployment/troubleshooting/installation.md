# インストール時のトラブルシューティング

[← ShimoDocs Suite デプロイメント文書](../README.md)

> [!TIP]
>
> インストールフェーズ中の一般的な問題は通常、以下のカテゴリに分類されます。

## 1 時間の非同期

問題の症状:

* ログイン失敗

* 認証エラー

* サービスコール例外

対応要件:

* すべてのノードの時刻のずれを最初に確認する

* 修正後 NTP/時刻同期サービス、インストールまたは受け入れを続行

調査コマンド：

```plain
timedatectl status
date
```


## 2 データディスクパス構成エラー

現象:

* インストール後、ディスクがすぐにいっぱいになる

* データ書き込みに失敗しました

* 永続ディレクトリはシステムドライブにあります

処理要件:

* 永続ディレクトリは明示的にデータディスクを指す必要があります

* 業務データはシステムディスクのディレクトリに保存されません

トラブルシューティングコマンド:

```plain
findmnt -n -o TARGET -T /data
df -Th|egrep -v "overlay|tmpfs"
```


## 3 依存サービス接続失敗

現象:

* インストール中にサービス検査が失敗しました

* データベース、キャッシュ、メッセージキュー、またはオブジェクトストレージへの接続に失敗しました

取扱要件:

* まず、アドレス、ポート、アカウントを確認してください、そして PASSWORD は正しく入力されました

* 次にネットワーク接続とセキュリティポリシーを確認します

* 最後に、対象のサービス自体が利用可能かどうかを確認します

トラブルシューティングコマンド:

```plain
nc -zv <MYSQL_HOST> 3306
nc -zv <REDIS_HOST> 6379
nc -zv <MONGO_HOST> 27017
nc -zv <KAFKA_HOST> 9092
```


## オフラインパッケージの不一致

現象:

* ミラーの読み込みに失敗しました

* インストールプロセスは、サービスを起動できず、バージョンが一致しないことを報告します

* インストールパッケージがオフラインミラーパッケージに対応していません

処理要件:

* インストールパッケージ、オフラインイメージパッケージ、および製品バージョンが一致していることを確認してください

* インストールパッケージが一致しているかどうか確認してください CPU アーキテクチャ

* 異なるプロジェクトや異なる日付の材料が混ざっていないことを確認してください

## インストーラーページを開けません

現象:

* Web UI ページにアクセスできません

* ポート18080がリッスンしていません

* インストーラープロセスが終了しました

トラブルシューティングコマンド:

```plain
ps -ef | grep mdp | grep -v grep
ss -lntp | grep 18080
tail -n 100 /root/nohup.out
```


## 6. 推奨トラブルシューティングの順序

インストールの問題を次の順序でトラブルシュートしてください:

1. まず、環境の問題かどうかを確認してください: システム、時間、ディスク、ポート、ネットワーク

2. 次に、構成の問題かどうかを再確認してください: ドメイン名、ディレクトリ、依存関係のアドレス、アカウント PASSWORD

3. さらに、材料の問題かどうかを再確認してください: インストールパッケージ、オフラインパッケージ、アーキテクチャの互換性

4. 最後に、インストーラーログとサービスの稼働状況を確認してください

説明:

* 前提条件が満たされていない場合は、インストールを繰り返さないでください

* 同じ明示的な失敗理由でコマンドを繰り返し実行しないでください

## 7. インストールを停止すべき場合

次の状況が発生した場合は、まずインストールを停止し、基礎的な問題を修正した後にのみ続行してください:

* すべてのノードの時刻が同期していない

* データディスクが独立してマウントされていない

* 外部依存サービスに接続できない

* オフラインマテリアルのバージョンが一致しない

* インストーラーサービスが正常に起動しなかった
