# プラットフォームユーザー管理

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

## 機能概要

システムユーザー管理は、管理バックエンドでのユーザーアカウントの維持に使用されます。 MDP ユーザーの作成、基本情報の編集、リセット、 PASSWORD二要素認証の管理、ユーザーの削除を含みます。

## ページへのアクセス

システム管理者アカウントでログインした後、選択します **システムユーザー管理** を選択してページにアクセスします。

このメニューは指定されたシステム管理者アカウントのみがアクセス可能です。見えない場合は、システム管理者に連絡してください。

## ユーザーを表示

ページにはユーザーのニックネーム、USERNAME、役割、メールアドレス、連絡先情報、最終ログイン時間、登録時間が表示され、総ユーザー数、最近アクティブなユーザー、管理者アカウントなどの概要情報も提供されます。

リストのページネーションを通じて全ユーザーを表示できます。

## 新規ユーザー作成

クリック **新規ユーザー作成** 次の情報を入力してください：

- **ニックネーム**：必須項目で、ページ表示に使用されます。
- **USERNAME**：必須項目で、システムへのログインに使用されます。
- **メール**：必須項目で、有効なメールアドレスを提供する必要があります。
- **連絡先情報**：任意です。
- **役割**：一般ユーザーか管理者のいずれかを選択してください。

作成後、システムは初期 PASSWORDを生成します。すぐにコピーし、安全な方法でユーザーに提供してください。ウィンドウを閉じると PASSWORD は再度表示できない場合があります。

### ユーザー役割の説明

- 管理者
  - グローバル権限に基づきすべてのページを使用できます
    - ShimoDocs Suite
    - ドキュメントセンター
    - システムサービス
- 一般ユーザー
  - グローバル権限に基づくページ使用範囲
    - ShimoDocs Suite
    - ドキュメントセンター
    - システムサービス（非表示）

## ユーザー情報の編集

ユーザーの右側にある編集ボタンをクリックして、ニックネーム、メール、および連絡先情報を変更します。 USERNAME 作成後、このページで変更することはできません。

## リセット PASSWORD

リセットをクリックした後 PASSWORD ボタンを押して操作を確認すると、システムは新しい PASSWORDを生成します。元の PASSWORD は直ちに無効になります。

新しいものをコピーして正しく保存し、 PASSWORD信頼できるチャネルを通じて該当ユーザーに届け、ユーザーに速やかにログインして PASSWORD を変更するように促してください。

## 二要素認証を管理

- **2FAの有効化または無効化**: ユーザー行のスイッチを使用し、確認ウィンドウで続行してください。
- **2FAのリセット**: システムは新しいQRコードとシークレットを生成し、元の認証情報は無効になります。

リセット後、ユーザーはAuthenticatorなどの認証アプリを使用して再スキャンし、バインドしてください。QRコードとシークレットは機密情報であり、公共のチャネルを通じて送信してはいけません。 

2FAをバインド

Authenticatorでスキャンして追加し、その後のログインに動的な6桁の2FAを使用します。

## ユーザーを削除

削除ボタンをクリックして確認すると、ユーザーアカウントは削除されます。削除操作は元に戻せないため、アカウントが使用されていないことを確認し、必要なデータおよび権限の引き継ぎを完了してから実行してください。

## 一般的な状況

- **ユーザーを作成できません**: 確認してください USERNAME は重複しています。メール形式は正しく、すべての必須項目が入力されています。
- **ユーザーがログインできません**: 確認してください USERNAME および PASSWORD が正しいかどうか。必要に応じて PASSWORD.
- **ユーザーが2FA認証を完了できません**: システム時刻が正しいことを確認するか、ユーザーの2FAをリセットして再バインドしてください。
- **ユーザー管理メニューが表示されません**: 現在のアカウントが指定されたシステム管理者アカウントでない可能性があります。
- **誤ってユーザーを削除**: 削除操作は直接元に戻せません。アカウントを再作成し、関連する権限を再設定する必要があります。

> 作成時、リセット時に生成される資格情報 PASSWORDおよび2FAのリセットは、速やかに保存し、アカウント保持者のみに提供する必要があります。
