# 一般ツール

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

## 1. ページ概要

一般ツールページには、7つの一般的に使用される機能が含まれています： JSON フォーマット、フォーマット変換、 JWT デコード、タイムスタンプ変換、マシン時間チェック、QRコード解析、Base64エンコード/デコード。

1. 任意の機能カードをクリックして、操作ページに入ります。
2. 一度入ると、左側の機能リストから他のツールに直接切り替えることができます。
3. 「機能メニューに戻る」をクリックすると、カードのホームページに戻ります。

## 2. JSON フォーマット

この機能は、フォーマット、圧縮、検証に使用されます JSON コンテンツ。

1. クリック "JSON 書式設定。
2. 処理する内容を「入力」に入力してください JSON」エリア:

   ```json
   {"name":"MDP","enabled":true,"items":[1,2]}
   ```

3. 「フォーマット」をクリックすると、右側にインデント付きの内容が生成されます。 JSON 右側に生成されます。
4. 「圧縮」をクリックすると、スペースや改行のないコンパクトな内容が右側に生成されます。 JSON 右側に生成されます。
5. 「コピー」をクリックすると、処理された結果をコピーできます。
6. 「クリア」をクリックすると、入力と出力の内容が削除されます。

テスト結果：文字列、ブール値、および配列はすべて正しく保持されており、フォーマットおよび圧縮機能も正常に動作します。

## 3. フォーマット変換

この機能はフォーマット間の変換および整形をサポートしています。 JSON, YAML、および TOML フォーマット間での変換および整形をサポートします。

1. 「フォーマット変換」をクリックします。
2. 「ソースフォーマット」で入力内容のフォーマットを選択します。
3. 「ターゲットフォーマット」で出力したいフォーマットを選択します。
4. 左側に変換する内容を入力します。
5. 「変換」をクリックすると、結果が右側に表示されます。
6. 「フォーマットを入れ替え」をクリックして、ソースとターゲットのフォーマットを切り替えます。
7. 「フォーマット」をクリックして、現在の内容のインデントとレイアウトを調整します。
8. 「コピー」をクリックして、出力結果をコピーします。

今回は JSON を使用して YAMLに変換します、入力：

```json
{"name":"MDP","ports":[80,443],"enabled":true}
```

変換結果： 

```yaml
name: MDP
ports:
  - 80
  - 443
enabled: true
```

測定結果：フィールド、配列、およびブール値が正しく変換されました。

## 4. JWT デコード

この機能は、トークンのヘッダー、ペイロード、および署名を解析するために使用されます。 JWT トークン.

1. クリック "JWT デコード。
2. 貼り付ける JWT トークンを入力してください。
3. 「デコード」をクリックしてください。
4. ヘッダーで署名アルゴリズムとトークンタイプを確認します。
5. ペイロードでユーザー、役割、期限などの情報を確認します。
6. 署名の生の内容を確認します。
7. 各セクションのコピー ボタンをクリックして、解析結果をコピーします。
8. 「クリア」をクリックして、現在のトークンと解析結果を削除します。

テスト結果: テスト用トークンは、ユーザー、役割、期限などのフィールドを正常に解析しました。 `HS256`, `JWT`

> JWT デコードはトークン構造の確認用であり、サーバー側の署名検証の代替にはなりません。

## 5. タイムスタンプ変換 

この機能は、Unixタイムスタンプと日付時刻の双方向変換をサポートしています。 

### 5.1 タイムスタンプの日時への変換 

1. 「タイムスタンプ変換」をクリックします。 
2. 「タイムスタンプ（秒またはミリ秒）」に10桁の秒または13桁のミリ秒のタイムスタンプを入力します。 
3. 上部の「変換」をクリックします。 
4. 「変換結果」で日付と時刻を表示します。 
5. 結果の横にあるコピー ボタンをクリックして内容をコピーします。 

### 5.2 日時をタイムスタンプに変換 

1. ' を入力しますYYYY-MM-DD HH:mm:ss' または ISO 「日付時刻」フィールドで時間をフォーマットします。 
2. 下の「変換」をクリックします。 
3. 「変換結果（秒）」でUnixタイムスタンプを確認します。 
4. 「現在時刻」をクリックして、現在のタイムスタンプと日付を素早く入力します。 
5. 「クリア」をクリックして、すべての内容を消去します。 

テスト結果: '1704067200' が正常に日付時刻に変換され、日付時刻も正しく秒単位のタイムスタンプに変換できることを確認しました。 

> クロス時間帯データを確認する場合、まず業務時間が UTC またはローカル時間帯を使用しているかを確認してください。 

## 6. マシン時間チェック

この機能は、現在の `app=ws-gateway` で全Podの時間を確認するために使用されます。 NAMESPACE 30秒以上の時間偏差があるインスタンスをハイライトします。

1. 「マシン時間チェック」をクリックします。
2. 右上の「更新」をクリックします。
3. 現在の NAMESPACE およびクエリラベルを確認します。
4. システム計算された参照時間（全Podの中央値時間）を確認します。
5. 各Podが配置されているノード、Unixタイムスタンプ、および可読時間を確認します。
6. 「参照との差」と「ステータス」を確認します。
7. 偏差が30秒を超える場合は、ノードの NTP/Chrony、仮想マシンの時間、およびタイムゾーン設定を確認してください。

テスト結果: 1 `ws-gateway` ポッドが返され、参照時間からの偏差は `0s` およびステータスは「正常」です。

## 7. QRコード分析

この機能は、QRコードの画像をアップロードし、含まれるテキスト、リンク、またはその他の内容を抽出するために使用されます。

1. 「QRコード分析」をクリックします。
2. 「ファイルを選択」をクリックします。
3. ローカルデバイスから鮮明なQRコード画像を選択してください。
4. ページに画像プレビューが表示されたら、下の「分析結果」を確認してください。
5. 結果をQRコードの期待される内容と比較して、一致しているか確認します。
6. 「コピー」をクリックして、解析された内容をコピーします。
7. 「クリア」をクリックして、画像と解析結果を削除します。

テスト結果: テスト用QRコードを正常にアップロード、プレビューし、正確に解析することができます。

## 8. Base64 エンコードとデコード

この機能は、プレーンテキストとBase64コンテンツ間の双方向変換に使用されます。

### 8.1 Base64 エンコード

1. 「Base64 エンコードとデコード」をクリックしてください。
2. 左側にプレーンテキストを入力します。
3. 「エンコード」をクリックします。
4. 右側にBase64でエンコードされた結果が表示されます。

### 8.2 Base64デコード

1. 左側にBase64の内容を入力します。
2. 「デコード」をクリックしてください。
3. 右側に復元されたテキストが表示されます。
4. 結果をコピーするには「コピー」をクリックします。
5. 入力と出力をクリアするには「クリア」をクリックします。

テスト結果:

```text
MDPTEST → TURQ5rWL6K+V
TURQ5rWL6K+V → MDPTEST
```

中国語 UTF-8 コンテンツは通常通りに相互に変換できます。
