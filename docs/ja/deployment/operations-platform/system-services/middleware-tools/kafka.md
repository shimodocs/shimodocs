# Kafka ツール

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

> [!TIP]
>
>  Kafka ツールにより、次の内容を確認できます Kafka Redpandaコンソールを通じてクラスタの状態、トピック、メッセージ、コンシューマグループ、パーティション情報を表示でき、メッセージ書き込み、コンシューマのバックログ、非同期リンクの問題のトラブルシューティングに一般的に使用されます。
>
> ページが正常に読み込まれると、Redpandaコンソールが組み込まれます。 MDP.

## 1. アクセス Kafka

1. にログインし、 **MDP 操作プラットフォーム**.
2. 選択 **システムサービス** 上部にあります。
3. 展開 **ミドルウェアツール** 左のナビゲーションバーにあります。
4. 選択 **Kafka**.
5. Redpandaコンソールが読み込みを完了するまで待ちます。

コンソールが準備できていない場合、ページは起動中であるか起動に失敗したことを通知し、エラー情報を表示します。

## 2. クラスター概要の表示

に入った後 Kafka, **概要** がデフォルトで表示されます。

次の情報を確認できます:

| 情報 | 説明 |
| --- | --- |
| クラスターのステータス | クラスターの稼働状況。 |
| クラスターのストレージサイズ | 現在のクラスターのストレージサイズ。 |
| クラスターのバージョン | クラスターのバージョン情報。 |
| オンラインブローカー | オンラインのブローカー数。 |
| トピック | トピックの数。 |
| レプリカ | レプリカの数。 |
| ブローカーの詳細 | ブローカーID、ステータス、サイズ。 |

## 3. トピックの表示

1. Redpandaコンソールの左ナビゲーションで、 **トピック**.
2. トピック一覧から対象のトピックを探します。
3. トピックをクリックして詳細ページに入ります。
4. トピックのパーティション、メッセージ、設定などの情報を確認します。

トピックのトラブルシューティングは通常、以下に焦点を当てます:

| 情報 | 説明 |
| --- | --- |
| パーティション | トピックのパーティション状況。 |
| メッセージ | トピック内のメッセージの一覧。 |
| 構成 | 保持ポリシーなどのトピック構成。 |

## 4. メッセージの表示

1. 対象のトピックに入る。
2. メッセージ表示エリアを開く。
3. ページ上のフィルターを使ってパーティション、位置、または時間範囲を選択する。
4. メッセージのキー、値、ヘッダー、パーティション、オフセット、およびタイムスタンプを確認する。

> メッセージ内容にはビジネスフィールドが含まれている場合がある。トラブルシューティング時は、ビジネスID、キー、オフセット、タイムスタンプを優先的に探す。

## 5. コンシューマグループの表示

1. Redpandaコンソールで、 **コンシューマグループ** を左のナビゲーションから選択する。
2. 対象のコンシューマグループを検索または選択する。
3. コンシューマグループの詳細に入る。
4. コンシューマグループに関連するトピック、パーティション、現在のオフセット、ログ末尾オフセット、ラグを確認する。

## 6. コンシューマのバックログ確認

| ステータス | 説明 |
| --- | --- |
| ラグは0 | 現在のコンシューマグループにバックログはない。 |
| ラグが継続的に増加している | 消費速度は生産速度よりも遅いです。 |
| 遅延は変わらないが、0ではありません。 | 消費者が停止している、パーティションがブロックされている、または消費に失敗している可能性があります。 |
| 単一パーティションの遅延が著しく高い | そのパーティションでホットキーや異常な消費が原因である可能性があります。 |

## 7. ブローカーの確認

1. 概要ページで、 **ブローカ詳細**.
2. ブローカーID、稼働状況、およびストレージサイズを確認します。
3. クリック **表示** ブローカーの詳細を見るには。

## 8. 一般的なトラブルシューティングのシナリオ

| シナリオ | 運用上の提案 |
| --- | --- |
| 以下を確認します Kafka が正常に機能しているか | 概要でクラスタステータスとオンラインのブローカーを確認します。 |
| メッセージが書き込まれているか確認します | トピックに移動してメッセージを確認します。 |
| 消費者の遅延をトラブルシューティングする | 消費者グループに移動して遅延を確認します。 |
| 単一のメッセージを特定する | トピック、パーティション、オフセット、キー、またはタイムスタンプで検索します。 |
| トピックの設定を確認する | トピックの詳細に移動して設定を確認します。 |
