# Redis ツール

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

> [!TIP]
>
> Redis は、運用プラットフォームで表示するために使用されます Redis インスタンス、DB、キーの一覧およびキーの詳細。キャッシュ、セッション、分散ロック、レート制限カウンター、短期状態のトラブルシューティングによく使用されます。
>
> ページはキーまたはキーのプレフィックスで検索でき、キーの種類を表示します。 TTL、および現在の値。

## 1. アクセス Redis

1. にログイン **MDP 操作プラットフォーム**.
2. 選択 **システムサービス** 上部にあります。
3. 展開 **ミドルウェアツール** 左のナビゲーションバーにあります。
4. 選択 **Redis**.

ページの左側はキーのクエリエリアで、右側はキーの詳細エリアです。

## 2. 選択 Redis インスタンスとDB

1. 左上の最初のドロップダウンで、を選択します Redis インスタンス。
2. 2つ目のドロップダウンで、DBを選択します。例えば `db0`.
3. ページは現在のインスタンスとDBに基づいてキーのリストを読み込みます。

DBリストが空である場合、またはページにエラーが表示される場合は、まずインスタンスの構成が正常かどうかを確認してください。 Redis インスタンス構成が正常かどうかを確認してください。

## 3. 検索キー

1. 検索ボックスにキー名またはキーの接頭辞を入力してください。
2. 検索ボタンをクリックするか、Enterキーを押してクエリを実行してください。
3. 左側でキーリストを表示します。
4. 現在の条件でリストを再読み込みする必要がある場合は、リフレッシュアイコンをクリックしてください。

検索ボックスのプロンプトは「キー名を入力してください。あいまい検索が可能です。」です。ページには一致するキーの種類が表示されます。 TTL.

## 4. キーリストを見る

キーリストには以下の情報が含まれます:

| 情報 | 説明 |
| --- | --- |
| タイプ |  Redis キーの種類、例えば `string`, `hash`, `list`, `set`, `zset`. |
| キー名 | 現在一致している完全なキー。 |
| TTL | キーの残り有効期限。現在のキーに有効期限がない場合、ページには「永久」と表示されます。 |

## 5. キーの詳細を見る

1. 左側のキー一覧で対象のキーをクリックします。
2. 右側の詳細エリアには、キー名、タイプ、 TTLおよび具体的な値が表示されます。
3. 現在のキー詳細を更新するには、詳細タイトルエリアの更新ボタンをクリックします。

表示方法の種類は以下の通りです：

| タイプ | 表示方法 |
| --- | --- |
| `string` | テキストボックスに完全な値を表示します。 |
| `hash` | フィールドのキーと値を表形式で表示します。 |
| `list` / `set` | 要素のリストを表形式で表示します。 |
| `zset` | スコアとメンバーを表形式で表示します。 |

## 6. フィールド値のコピー

1. キー詳細テーブルでコピーしたいフィールドまたは値を探します。
2. 対応する内容をクリックします。
3. ページはその内容をクリップボードにコピーします。

> `string` typeはテキストボックスに表示され、テキストを選択することで直接コピーできます。テーブルタイプは値をクリックしてコピーをサポートします。

## 7. 一般的なトラブルシューティングシナリオ

| シナリオ | 推奨アクション |
| --- | --- |
| キャッシュが存在するか確認します。 | インスタンスとDBを選択した後、フルキーまたはプレフィックスで検索します。 |
| キャッシュが期限切れか確認します。 | キー一覧または詳細で TTL を確認します。 |
| ハッシュフィールドを見る | キーをクリックして、右側のテーブルのフィールドと値を表示します。 |
| ZSetのソート済みデータを表示 | クリック `zset` キーをクリックして、スコアとメンバーを表示します。 |
| 同じキーの最新の状態を確認 | 詳細画面の更新ボタンをクリックします。 |
