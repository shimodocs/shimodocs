# MongoDB ツール

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

> [!TIP]
>
> MongoDB は、運用プラットフォームで表示するために使用されます MongoDB データベース、コレクション、およびドキュメントの内容。これは、ドキュメントベースのデータ、中間状態、タスク記録、および柔軟な構造のビジネスデータのトラブルシューティングに適しています。
>
> このページでは、データベースまたはコレクションごとの検索がサポートされており、コレクションを選択した後は MongoDB JSON 条件付きクエリを使用できます。

## 1. アクセス MongoDB

1. にログイン **MDP 操作プラットフォーム**.
2. 選択 **システムサービス** 上部にあります。
3. 展開 **ミドルウェアツール** 左のナビゲーションバーにあります。
4. 選択 **MongoDB**.

ページの左側にはデータベースとコレクションのツリーが表示され、右側にはクエリ条件とクエリ結果が表示されます。

## 2. データベースまたはコレクションの検索

1. 入力してください DATABASE_NAME 左上の検索ボックスにデータベースまたはコレクション名のキーワードを入力します。
2. フィルタリングされたツリーリストを表示します。
3. 検索ボックスをクリアすると、すべてのデータベースの表示が元に戻ります。

## 3. データベースを展開してコレクションを選択

1. 左側のツリーで対象のデータベースを見つけます。
2. データベースの左側にある展開アイコンをクリックして、コレクションのリストを読み込みます。
3. 対象のコレクションを選択します。
4. 右側のページはデフォルト条件で自動的に一度クエリを実行します。 `{}`.

> データベースのみを選択してもコレクションのクエリは実行されません。まず特定のコレクションを選択する必要があり、その後、右側にクエリエリアが表示されます。

## 4. クエリ条件を入力する

1. 入力してください MongoDB JSON 右側のクエリ入力ボックスにクエリ条件を入力します。
2. 返される結果の数を選択します、サポートされています `limit: 10`, `limit: 20`, `limit: 50`.
3. クリック **をクリックしてください**.

クエリ例: 

```json
{
  "_id": "task-123"
}
```

フィールドによるクエリの例:

```json
{
  "status": "running"
}
```

## 5. クエリ結果の表示

1. クエリが完了したら、右側の結果エリアで返されたドキュメントを確認します。
2. デフォルトでは、結果は以下の形式で表示されます JSON フォーマット。
3. クリック **展開** 現在のドキュメントを展開する。
4. クリック **折りたたむ** 現在のドキュメントを折りたたむ。
5. クリック **コピー** 現在のドキュメントをコピーする JSON.

## 6. 一般的なトラブルシューティングシナリオ

| シナリオ | 操作上の提案 |
| --- | --- |
| ドキュメントが存在するか確認する | コレクションを選択した後、次を使用してクエリを実行する `_id` またはビジネスID。 |
| タスクの状態を確認する | タスクIDでクエリを実行し、状態フィールドと更新時間フィールドを確認する。 |
| レコードの種類を見つける | ステータス、タイプ、作成時間などのフィールドを組み合わせてクエリを実行します。 |
| 結果が空です | 正しいデータベース、コレクション、フィールド名、およびフィールドタイプが選択されているか確認してください。 |
| トラブルシューティング結果を削除する必要があります | クリック **コピー** 単一の結果で。 |
