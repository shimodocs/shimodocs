# サービスログ

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

## 機能概要 
サービスログ機能は、Kibanaのようなログ取得プラットフォームであり、さまざまな ShimoDocs サービスからPodログを収集し、ログ検索、クエリ、および割合分析の機能を提供します。 

## エントリとナビゲーション
左側のメニュー：システムサービス --> サービス操作 --> サービスログ

## SQL モード
入力ボックスはClickHouse SQL 構文クエリをサポートします。入力後 SQL、ClickHouseのRawモードでクエリを実行できます。

下の図のように、入力

``` sql
`_raw_log_` like '%access%'
```

はアクセスを含むすべてのログを検索するために使用できます。 

## 条件フィルタリング
下の図のように、「条件を追加」ボタンをクリックして新しいフィルタ条件を追加します。

## 割合分析
下の図のように、行レコード内のフィールド横のアイコンをクリックしてドロップダウンメニューを開きます。「上位値」を選択すると、現在の時間範囲内でそのフィールドの割合を右上で確認できます。

## フィールドの説明

| 組み込みフィールド | 説明 |
| --- | --- |
| レベル | ログのエラーレベル。info、error、warnを含む |
| コンテナ名 | CONTAINER_NAME |
| メソッド | アクセスログ内のメソッド gRPC メソッドを出力します gRPC メソッド HTTP メソッドを出力します API パス |
| ピアIP | ピアIPアドレス |
| ピア名 | ピアの名前、例えばサービス名など |
| コンプ | アクセスログ内のコンポーネント、例えば server.begin |
| コスト | アクセスログで消費された時間（ミリ秒単位） |
