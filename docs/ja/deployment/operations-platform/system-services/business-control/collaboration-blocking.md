# 共同作業のブロック

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

## 機能の説明

でバックログが発生した場合、 Kafka、特定のファイルによって異常なバックログが発生していることが確認された場合、この禁止機能を使用してそのファイルの編集を禁止することで、 Kafka バックログの問題を解決することができます。

## 使用例

1. 共同編集禁止を選択 

2. ファイル GUID を入力してください。強調：これは ShimoDocs内の GUID を指し、顧客のファイル ID ではありません。 

入力 ShimoDocs ファイル GUID 「ブロックに追加」をクリックします。ファイルは3分以内に編集禁止になります。 

「ブロック解除」ボタンをクリックして、ファイルの編集機能を復元します。 

### 取得方法 GUID 

1. ブラウザのデベロッパーツールを開きます。 

2. プルリクエストをフィルターします。 

3. リクエスト内で、rp3OMYnMrdcQJZkmからの16文字の文字列が該当します。 GUID 

### 禁止の影響を確認する方法

ドキュメントを正常に保存できません。ファイル編集後、2分でオフラインのポップアップが表示され、ページを更新するとデータは失われます。

### ブロック解除のタイミング

ブロック解除は推奨されません。一般的に、これはファイルが大きすぎてサーバーが編集をサポートできないためです。禁止後は読み取り専用になります。ファイル内容を新しいファイルに手動でコピーすることを推奨します。
