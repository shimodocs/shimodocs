# ファイル情報検索

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

## 機能概要

ファイル情報検索は、システム内のファイルの基本レコードを内部ファイル GUID または顧客側のファイル ID に基づいて検索し、ファイル識別子、関連アプリケーション、ファイルタイプ、ステータス、コンテンツサイズの確認を容易にします。

このページは読み取り専用であり、ファイルの内容やステータスを変更することはありません。

## ページへのアクセス

管理バックエンドにログイン後、左側ナビゲーションで **ファイル情報検索** を選択してページにアクセスします。

## ファイルの検索

このページは以下の検索条件をサポートしています:

- **内部ファイル GUID**: ファイルの `history_guid`.
- **顧客ファイルプロバイダ GUID**: 顧客側 `provider_file_id`.
- **アプリID**: 任意、プロバイダーと一緒に記入することが推奨されます GUID 関連するアプリケーションを指定するために。

内部ファイルの少なくとも1つ GUID または顧客ファイル提供者 GUID を入力したら、次に **をクリックしてください**.

もしプロバイダーだけでも GUID が入力され、App IDが入力されていない場合、システムはProviderに一致するすべてのレコードを返します GUID、そのため複数の結果が表示される場合があります。

## クエリ結果

クエリ結果には主に以下が含まれます：

- **ID**: ファイルレコードの主キーID。
- **アプリ_ID**: 関連アプリケーションのID。
- **プロバイダー_ファイル_ID**: クライアント側のファイルID。
- **履歴_GUID**: 内部システムの履歴ファイル GUID.
- **作成_日**: レコード作成時間。
- **タイプ**: ファイルタイプ（文書、スプレッドシート、プレゼンテーション、 PDF、画像、または動画）。
- **作成_作成者**: 作成者ユーザーID。
- **ステータス**: ファイルの現在の状態値。
- **ファイル_content_サイズ**: ファイル内容のサイズ（バイト単位）。

検索結果のファイルタイプは、識別しやすいようにタイプ番号と対応する名前の両方が表示されます。

## 一般的な状況

- **プロンプト: 検索条件を入力する必要があります**: 少なくとも内部ファイルを入力してください GUID または提供者 GUID.
- **ファイルが見つかりません**: 識別子が完全であるかを確認するか、そのファイルが現在の環境に属しているかを確認してください。
- **複数のレコードが返されました**: 提供者 GUID は複数のアプリケーションで重複している可能性があります。App ID を追加して再検索してください。
- **ファイルタイプが不明と表示される**: 現在のレコードのタイプ番号には、まだ対応する名前が設定されていない場合があります。番号を技術サポートに提供して確認できます。
- **ステータス値を判断できません**: ステータスフィールドは基礎レコードの値であり、特定のビジネス現象やログと組み合わせてさらなる分析が必要です。

> ファイル識別子はビジネスデータに属するため、公開チャットや外部チケットで直接共有しないでください。
