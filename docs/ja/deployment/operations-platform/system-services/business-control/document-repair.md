# 文書修復

[← ShimoDocs Suite デプロイメント文書](../../../README.md)

ファイルが異常に破損している症状には、ドキュメントが正常に開かない、読み込み中にエラーポップアップが表示される、内容が表示されないことなどがあります。

ドキュメントが開けない場合、この機能を使用してファイルを修復します。

# 使用例

修復方法は2つあります。

## 準備

### ファイルタイプのクイックリファレンス

|**fileType**|**ファイル URL アドレス機能**|**備考**|
|:----|:----|:----|
|rdoc(richdoc)|/**ドキュメント**/{fileguid}|ライトドキュメント|
|mosheet(modoc)|/**シート**/{fileguid}|テーブル|
|modoc(modoc)|/**docx**/{fileguid}|プロフェッショナルドキュメント|

### 運用リスク警告

修復失敗にはリスクなし

## 暗号化データからの復元

テーブル型ファイルの修復のみサポートします。他のタイプのファイルの場合は[履歴データから修復]を選択してください

これは推奨方法です。ファイルを直接入力して GUID 修復を行うことができます。この GUID は…です ShimoDocs ファイル GUID.

修復の原則は、オブジェクトストレージ内の暗号化されたファイルデータを暗号化されていないファイルコンテンツデータに変換することであり、ほとんどのシナリオに適用可能です。

この方法で修復できない場合は、別の方法を選択してください。

### ファイル GUID

1. ブラウザの開発者ツールを開く

2. プルリクエストをフィルター

3. リクエスト内の rp3OMYnMrdcQJZkm という16文字の文字列がguidです

## 履歴データから復元

履歴記録から復元

1. 顧客ファイルID

2. ファイルタイプ

   1. 従来のドキュメント／スプレッドシート／プレゼンテーションの場合は modoc を選択してください

   2. 軽量なドキュメントの場合は、richdoc を選択してください

1. データソースを選択

### 顧客ファイルID

顧客が使用している場合 ShimoDocs サイト全体では、ブラウザ内のドキュメントのファイルアドレスです。例えば、次の m8AZMoYMrRsYbOkb

### データソースの確認方法 

svc-edit サービスの設定を確認する 

設定項目: history.driver 

mysql の場合、「Mongo データソースを使用」スイッチはオフです 

mongo の場合、「Mongo データソースを使用」スイッチはオンです
