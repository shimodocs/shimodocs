# 運用プラットフォーム概要

[← ShimoDocs Suite デプロイメント文書](../README.md)

## 機能概要

- **ShimoDocs Suite**: 認可、テナント、ユーザー、ブランディング、およびAI構成に関連する管理に使用されます。 ShimoDocs Suite.
- **システムサービス**: グローバル設定、クラスタ管理、ログ表示、機能検査、問題の照会、ドキュメントの修復などの一般的な運用および保守作業に使用されます。 **システムアップグレード**.

> **注意**: 表示される具体的な機能は、現在の展開バージョンおよび有効化された機能によって異なります。

## オペレーションプラットフォームへのログイン

ブラウザで以下のアドレスにアクセスしてください:
> **ブラウザ要件**: オペレーションプラットフォームにアクセスするには、Google Chrome バージョン111以上を使用してください。まず最新の安定バージョンにアップグレードすることを推奨します。

```text
http(s)://<OPERATIONS_PLATFORM IP OR_DOMAIN_NAME>/mdp/user/login
```

管理者アカウントを入力し PASSWORD、次に「ログイン」をクリックしてください。

## オペレーションプラットフォームのホームページの理解

ログイン後、ページ左側のメニューから対応する管理機能にアクセスできます。表示されるメニューは、現在の環境で展開および認可されている製品とバージョンに依存します。

## 管理者のリセット PASSWORD 忘れた場合

オペレーションプラットフォームの管理者を PASSWORD 忘れた場合、展開ノードにログインして以下のコマンドを実行することでリセットできます。

```bash
kubectl exec -it $(kubectl get pods -l app=mdp -o jsonpath='{.items[0].metadata.name}') -- reset-admin-password Aa1234567.
```

上記の例では PASSWORD から `Aa1234567.`をリセットします。実際の操作では、例を置き換えてください。 PASSWORD を PASSWORD 。

リセットが完了したら、ログインページに戻り、新しいものでログインしてください PASSWORD、そしてメニューに通常通りアクセスできることを確認してください。
