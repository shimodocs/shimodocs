# テナント管理

[← ShimoDocs Suite デプロイメント文書](../../README.md)

> [!TIP]
>
> テナント管理は、テナントを集中管理するために使用されます。 ShimoDocs Suite.
> 管理者はここで、テナント数や座席使用状況を確認し、サードパーティ統合の認証情報を取得し、AI構成を管理し、テナントの作成、編集、有効化、無効化を行うことができます。
>

## 1. テナント管理にアクセスする

1. にログイン **MDP 操作プラットフォーム**.
2. 選択 **ShimoDocs Suite** 上部にあります。
3. 選択 **テナント管理** 左のナビゲーションバーにあります。

## 2. テナント管理ページの理解

現在のシステムの全体情報がページ上部に表示されます：

| リージョン | 説明 |
| --- | --- |
| API-KEY | 表示してコピーする `AppID` および `AppSecret` サードパーティ統合に必要なもの。 |
| AI設定 | AI機能が有効になっているか確認し、AIモデルおよび検索設定にアクセスします。 |
| テナントの総数 | 現在のシステムで作成されたテナントの数。 |
| 有効テナント | 現在有効なテナントの数。 |
| シート使用状況 | 使用されているシート数、システム内の総シート数、および使用比率。 |

以下のテナントリストには、テナント名、有効化時間、テナント管理者、シート使用状況、および現在のステータスが表示されます。「操作」列では、対応するテナントの編集または無効化が可能です。

## 3. 表示 API キー

`AppID` および `AppSecret` は ShimoDocs Suite サードパーティシステムと統合する際の認証に使用されます。

### 操作手順

1. 次を見つけます **API-KEY** テナント管理ページのカード。
2. コピーアイコンをクリックします。
3. システムは現在の環境の `AppID` および `AppSecret`.
4. 対応するサードパーティ統合設定に認証情報を入力します。

> `AppSecret` は機密性の高い資格情報です。安全に保管し、公開文書、チャット記録、または公開可能なコードリポジトリに書き込まないでください。

## 4. AI構成の管理

AI構成カードは、現在のAI機能の有効化状況を表示します。

AI構成カードをクリックすると、「AIモデルと検索構成」ページで以下の内容を表示または編集できます: 

### 1. 基本モデル構成

一般的な大規模言語モデル（LLM）とその利用可能なモデルを構成するために使用されます。このページでは、プロバイダーやリクエストなどの情報を確認できます URL, API キー、デフォルトモデル、モデルID、コンテキストウィンドウ、および入力機能。

### 2. 画像モデル構成

画像生成または画像編集モデルを構成するために使用されます。ページでは、プロバイダー、モデル名、基本 URL, API キー、およびサポートされている画像機能を確認できます。

### 3. ネットワーク検索エンジン構成

AIネットワーク検索サービスを構成するために使用されます。ページでは、サービスプロバイダー、インターフェースアドレスを確認できます。 API キー、およびタイムアウト。

### 4. 埋め込みベンダー構成

テキストのベクトル化サービスを構成するために使用します。ページ上で、ベースキー、埋め込みモデル、およびベクトル次元を確認できます。 URL, API キー、埋め込みモデル、およびベクトル次元。

> AI構成を変更する前に、サービスアドレス、キー、モデルID、および機能パラメータがすべて正しいことをまず確認してください。変更後は、少量のテストコンテンツを使用してモデル呼び出しが正常に動作するか確認することを推奨します。 API 

### 5. AIの使用 ShimoDocs Suite
構成が完了したら、内部でAI機能を使用できます ShimoDocs Suite.

## 5. 既存テナントの管理

テナントリストで、各テナントの基本情報や席の使用状況を確認できます。

### テナントの編集

1. 調整が必要なテナントを探します。
2. '操作'列の『編集』をクリックします。
3. ページ上の指示に従って、テナント情報または席数を変更します。
4. 変更を保存し、リストに戻って情報が更新されたことを確認します。

### テナントを無効化または復元

- 現在有効になっているテナントについては、「操作」列の「無効化」をクリックできます。
- 無効にしたテナントを復元するには、対応するテナントの操作項目で再有効化してください。

> テナントを無効化すると、そのテナントへの通常アクセスに影響があります。対象のテナントが正しいことを確認してから操作を実行し、実際の使用状況に応じて操作のスケジュールを調整してください。

## 6. 新しいテナントの有効化

テナントを有効化する前に、ページ上部のシート使用状況を確認し、割り当て可能なシートがまだあることを確認してください。

### 操作手順

1. ページの右上隅にある「新しいテナントを有効化」をクリックします。
2. 「テナント名」に、このテナントを識別するために使用する名前を入力します。
3. システム生成のテナント管理者のメールを確認します。テナントが正常に作成されたら、この管理者アカウントと初期情報を PASSWORD 速やかに保存してください。
4. 「割り当て可能な席」を確認して、新しいテナントに現在割り当て可能な最大席数を把握します。
5. 「テナント割り当て席数」に、このテナントに割り当てる席数を入力します。
6. 情報が正しいことを確認したら、「保存」をクリックしてください。

### シート欄の説明

| フィールド | 説明 |
| --- | --- |
| 割り当て可能なシート | システムが現在このテナントに割り当てることができる最大のシート数。 |
| テナントに割り当てられたシート | このテナントに割り当てられたシートの合計数。この数は既にテナントが使用しているシート数より少なくすることはできません。 |
| テナントが使用しているシート | このテナント内のアクティブな企業メンバーの数。各アクティブメンバーが1つのシートを使用します。 |

> テナントを作成する際に、一定数の席を割り当てる必要があります。席の数は使用状況に応じて後で調整できます。
