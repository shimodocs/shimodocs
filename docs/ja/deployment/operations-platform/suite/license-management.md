# ライセンス管理

[← ShimoDocs Suite デプロイメント文書](../../README.md)

> [!TIP]
>
> ライセンス管理は、サーバーのマシンコードを取得するために使用され、 ShimoDocs Suiteライセンスの書き込みと公開、および現在のライセンス状況、ライセンススコープ、稼働中マシン情報の表示に使用されます。初めてのアクティベーションの場合、 
> ライセンスの有効期限が切れた場合、またはサーバーノードが変更された場合は、このページから ShimoDocs Suite ライセンスを更新できます。

> ライセンスを書き込んだ後は、ライセンスを公開する前に必ず検証結果を確認してください。書き込むだけ、または一時的に保存するだけではライセンスは正式に有効になりません。
- もし有料のお客様であれば、コピーしたマシンコードを次に送ってください ShimoDocs テクニカルサポートチーム。マシンコードに基づいて対応するライセンスを生成し、ライセンス情報をお送りします。
- 無料トライアルをご希望の場合は、以下にアクセスしてください **ShimoDocs 公式ウェブサイトライセンス申請**: https://shimo.net/license 申請情報を記入し、マシンコードを貼り付けます。
- 送信後、システムは自動的にトライアルライセンスを生成します。生成後10分以内にコピーして記入を完了してください。期限切れの場合は、再申請してください。
## 1. ライセンス管理にアクセスします。

1. にログインし、 **MDP 操作プラットフォーム**.
2. 選択 **ShimoDocs Suite** 上部にあります。
3. 選択 **ライセンス管理** 左のナビゲーションバーにあります。

ページには、ライセンスの有効化、ライセンス情報、マシンコード比較、マシン情報の領域が含まれています。

## 2. ライセンスを申請します。 ShimoDocs Suite ライセンス

認可を申請する前に、まず次のことを確認してください ShimoDocs Suite サーバーノードは安定しており、一時的にノードが追加、削除、または交換されることはありません。 

### 1. すべてのマシンコードをコピーする 

1. 「認証アクティベーション」エリアで、「ワンクリックですべてのマシンコードをコピー」をクリックします。 
2. ページにコピー成功のメッセージが表示されることを確認します。 
3. 機械コードを認証申請資料に保存してください。 

### 2. 認証申請情報を提出する

すべての機械コードと認証要件を ShimoDocs サービス担当者に提出して ShimoDocs Suite ライセンスを発行してもらいます。

申請時には、以下の情報を確認することをお勧めします：

| 情報 | 説明 |
| --- | --- |
| 認可された製品 | ShimoDocs Suite. |
| ライセンス名および会社 | ライセンスに表示されるライセンス名および会社。 |
| 利用可能な席数 | ライセンスを使用できる最大席数。 |
| 使用期間 | 製品ライセンスの開始および終了時刻。 |
| アフターサービス期間 | アフターサービスの開始および終了時刻。 |
| 利用可能なスイート | 有効にする必要があるドキュメントの種類または機能スイート。 |
| AI機能 | AI機能を有効にする必要があるかどうか。 |
| マシンコード | 現在稼働中のすべてのサーバーマシンコード ShimoDocs Suite. |

## 3. 認証の書き込みと確認

新しいライセンスを受け取った後、以下の手順に従ってシステムに書き込みます。

### 1. ライセンスの書き込み

1. 「認証アクティベーション」エリアの「認証書き込み」をクリックします。
2. 受け取ったライセンス内容を入力ボックスに貼り付けます。
3. ライセンス内容が完全であることを確認し、文字が欠けたり余分なスペースがないことを確認します。
4. 「一時保存」をクリックします。

### 2. ライセンス検証結果の確認

一時保存後、システムは新しいライセンスを検証し、以下の結果を表示します。

| 検証結果 | 説明 | 推奨アクション |
| --- | --- | --- |
| 不一致 | 新しいライセンスのキー情報が現在の環境と一致しません。 | マシンコード、アプリケーションの種類、バージョン、認証範囲を確認します。正しいことを確認した後、再度ライセンスを取得します。 |
| 変更済み | 新しいライセンスの情報は、現在のライセンスと異なる場合があります。 | 変更がこの申請に一致していることを確認するために、ページ上の元の値、新しい値、および判定結果を確認してください。 |
| 合格 | 該当する検証項目は合格しました。 | 他の認証情報の確認を続けてください。 |

ページ上に「変更あり」の項目があり、その変更がこの認証申請に準拠している場合、「一時保存を確認」をクリックしてください。

> 予期しない「不一致」や「変更あり」が発生した場合は、まずリリースを停止し、申請情報と現在の運用環境を再確認してください。

## 4. リリース認証

確認と一時保存が完了した後、リリースされるライセンス情報がページに表示されます。

### リリース前の確認

以下の項目を注意深く確認してください：

- ライセンス名
- 座席制限
- 開始時刻および有効期限
- 申請ID
- サーバー機械コード

情報が正しいことを確認したら、「ライセンスを公開」をクリックしてください。

リリースが完了したら、ページをリフレッシュして更新された認証ステータスおよび認証情報を確認してください。

| リリースバージョン | 現在の認証のリリースタイプ。 |

| 製品使用期間 | 製品認証の開始日と有効期限。 |

## 6. マシンコード比較結果の確認

認証情報の下に、ライセンス内のマシンコードと現在稼働中のサーバーとの比較結果が表示されます。

| 結果 | 説明 |
| --- | --- |
| 証明書内のマシン | 現在のライセンスにすでにバインドされているサーバーの数。 |
| 実際のマシン | 現在のシステムで検出された稼働中のサーバーの数。 |
| 一致 | ライセンス内のマシンコードが現在のサーバーと一致しています。 |
| 不一致 | 現在、ライセンスにバインドされていないサーバーがあるか、ライセンス内のマシンが変更されています。 |
| 不足 | ライセンスにバインドされたマシンが現在システムで検出されていません。 |

証明書内のマシンの数が実際のマシンの数と一致しない場合、またはページに「不一致」や「不足」と表示されている場合は、「マシンコードのコピー」をクリックし、現在のマシンコードを使用して再度ライセンスを申請してください。

> ページの上部にマシンコード不一致を示すカウントダウンプロンプトが表示された場合は、継続的な認証を確実にするために、プロンプト期間内にサーバー情報の確認またはライセンスの交換を完了してください。

## 8. 認証更新結果の確認

ライセンスリリースを完了した後は、以下の順序で確認することをお勧めします。

1. 認証管理ページを更新して、認証状態が正常であることを確認します。
2. 承認名、座席数、使用期間、利用可能なスイート、およびAI機能を確認してください。
3. 証明書内のマシン数が実際のマシン数と一致することを確認してください。
4. マシンコードの比較で、予期しない「不一致」や「欠落」の結果がないことを確認してください。
5. にログイン ShimoDocs Suite 承認されたドキュメントの種類および機能が正常に使用できることを確認してください。

> サーバーノードを交換、追加、または削除した後は、このページに promptly 戻ってマシンコードの比較結果を確認することを推奨します。マシンコードが変わった場合は、すべての新しいマシンコードを使用してライセンスを再申請およびリリースする必要があります。
