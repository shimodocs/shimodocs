# オブジェクトストレージで展開

[← ShimoDocs Suite デプロイメント文書](../../README.md)

この記事では、組み込みの機能を無効にする方法を説明します。 MinIO インストーラー内の ShimoDocs 顧客自身の設定方法について説明します S3 サードパーティとしてのオブジェクトストレージ S3 オブジェクトストレージ。設定が完了すると、インストーラーは確認します S3 オブジェクトストレージのネットワーク接続、認証情報、およびバケットの読み書き権限。チェックが通過したら、デプロイメントを続行できます。 

# 1. 構成前の準備 
開始する前に、以下を確認してください: 
- S3 オブジェクトストレージは正常にインストールされ、稼働しています。 
- K8s クラスタノードはオブジェクトストレージのホストおよびポートにアクセスできます。 S3  
- 接続用のオブジェクトストレージ認証 AK/SK が準備できています。 S3  
- S3 ストレージはクライアントブラウザからのアクセスをサポートする必要があります。 
- 別のインスタンスを使用することを推奨します。 S3  
- 標準 S3 内部ネットワークおよび外部ネットワーク用の標準プロトコルアクセスアドレスを提供する必要があります。 
- ShimoDocs ビジネス標準 S3 バケットは事前に作成しておく必要があります。 
- S3 ストレージはディスクを使用する必要があります。 SSD

## バケット構成手順
- 公開_ヘッダーは、ヘッダー名を指定することを推奨します。 記号を使用しないでください * 記号、一部のベンダーはサポートしていない場合があります * 記号、例えばHuawei Cloud OBS、Alibaba OSS
- バケット名は重複を避けるために、会社のニーズに応じて接頭辞を設定できます

# 2. 詳細設定の入力
インストーラーの「構成」ステップで、ネットワーク、ターゲット環境、ノード情報の構成を完了した後、ページ下部の「詳細構成」を展開します。

# 3. 組み込み MinIO
「ミドルウェアサービス」エリアでチェックを外します MinIO

チェックを外すと、インストーラーは組み込みインストールを行わなくなります MinIO、および外部 S3 準備されたオブジェクトストレージは後で使用されます。他のミドルウェアが組み込みサービスを使用するかどうかは、実際の展開計画に応じて選択する必要があります。

# 4. サードパーティミドルウェアの設定を開く
「サードパーティミドルウェア」領域で「設定」をクリックします。

# 5. 設定 S3 オブジェクトストレージ
1. 左側で「S3 左側の「オブジェクトストレージ」
2. 有効化MinIO オブジェクトストレージ。
3. メインサービス／エディタ相互作用の場合、それぞれ次の情報を入力してください：AK/SK、内部エンドポイント、公開エンドポイント、ホスト、ポート、 SSLおよびその他の情報
4. 確認して保存してください

> [!TIP]
>
> メインサービス：共同編集以外のサービスで使用されるオブジェクトストレージインスタンス
> エディタ相互作用：共同編集サービスで使用されるオブジェクトストレージインスタンス
>
> 注意：メインサービスとエディタ相互作用は同じオブジェクトストレージインスタンスを使用できますが、エディタ相互作用専用のインスタンスを提供すると、共同編集のパフォーマンスが向上する可能性があります

# 6. 確認結果の確認
インストーラーは次の内容をチェックします：
- ログイン: アカウントは正常に認証できます
- 接続性: デプロイ環境はオブジェクトストレージにアクセスできます S3 オブジェクトストレージ
- 権限: アカウントには接続、認証、バケットの読み書きなどの権限があります

すべての検査項目が「成功」を示した後、設定ウィンドウを閉じ、インストーラーの「構成」ページに戻ります

失敗した項目がある場合は、ページの指示に従って確認してください:
- ホストとポートが正しく入力されているか
- デプロイメントノードと...の間のネットワークが S3 オブジェクトストレージが接続されています
- かどうか USERNAME および PASSWORD 正しいです 
- アカウントが必要な権限（接続および認証、バケット読み書き権限など）を持っているかどうか 

# 7. デプロイの初期化を続行 
「構成」ページに戻った後、 S3 オブジェクトストレージが未チェックのままであることを確認し、「デプロイの初期化」をクリックしてデプロイの概要、チェック、実行ステップの完了を続行します 

> [!TIP] 
> 
> 展開を初期化する前に、もう一度 S3 オブジェクトストレージの構成が保存され、すべての検証項目が合格しています
