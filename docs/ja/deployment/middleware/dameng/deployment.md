# で展開 Dameng V8

[← ShimoDocs Suite デプロイメント文書](../../README.md)

この記事では、組み込みの機能を無効にする方法を説明します。 MySQL インストーラー内の ShimoDocs を無効にして第三者のリレーショナルデータベースとして設定します。 Dameng DM8 設定完了後、インストーラーはデータベースのログイン、ネットワーク接続、およびテーブル作成権限を確認します。確認が通過すると、展開を続行できます。

## 1. 設定前の準備

開始前に確認してください：

- Dameng DM8 が正常にインストールされ、稼働していること。
- 展開ノードが、ホストとポートにアクセスできること Dameng データベース。
- データベースのホスト、ポート、 USERNAME、および PASSWORD が準備完了です。
- データベースアカウントには、ログイン、接続、テーブル作成、テーブル削除の権限があります。
- Dameng データベースは、要求に応じて MySQL 互換モードの構成を完了しました。詳細な手順については ["Dameng データベース統合構成ガイドを参照してください。](requirements.md).

> [!TIP]
>
> この記事にあるIP、ポート、およびアカウントはすべて例です。設定には実際の環境情報を使用し、実際の PASSWORD を外部の文書やスクリーンショットに記録しないでください。

## 2. 詳細設定の入力

インストーラーの「構成」ステップで、ネットワーク、ターゲット環境、ノード情報の構成を完了した後、ページ下部の「詳細構成」を展開します。

## 3. 組み込みのインストールの選択解除 MySQL

「ミドルウェアサービス」セクションで、 **MySQL**.

選択解除すると、インストーラーは組み込みの MySQLをインストールせず、準備したものを使用します。 Dameng 今後のデータベース。その他のミドルウェアについては、組み込みサービスを使用するかどうかは、実際の展開計画に従って選択してください。

## 4. サードパーティミドルウェアの設定を開く

「サードパーティミドルウェア」領域で「設定」をクリックします。

## 5. 設定 Dameng データベース

1. 左側で「RDB リレーショナルデータベース」を選択
2. 「サードパーティリレーショナルデータベースを使用」を有効にする。
3. 「方言」セクションで選択 **DM（Dameng)**.
4. データベース接続情報を入力してください。

| 構成項目 | 説明 |
| --- | --- |
| ホスト | アクセス可能なIPアドレスまたはホスト名 Dameng データベース |
| ポート | リッスンポート Dameng データベース、通常はデフォルトで5236、実際の構成による |
| USERNAME | データベースに接続するために使用するアカウント |
| PASSWORD |  PASSWORD データベースアカウントに対応する |
| DSN | 上記の情報に基づきインストーラーによって自動生成され、手動入力は不要 |

5. 情報が正しいことを確認したら、「確認して保存」をクリック

## 6. 確認結果の確認

インストーラーは以下の項目をチェックします:

- **ログイン**: データベースアカウントが正常にログインできること
- **接続性**: 展開環境がデータベースにアクセスできること
- **テーブル作成権限**: データベースアカウントにテーブル作成および削除の権限があること

すべてのチェック項目が「成功」と表示されたら、設定ウィンドウを閉じ、インストーラーの「設定」ページに戻ります

失敗した項目がある場合は、ページの指示に従って確認してください:

- ホストとポートが正しく入力されているか
- 展開ノードとデータベース間のネットワークが接続されているか
- かどうか USERNAME および PASSWORD 正しいかどうか
- データベースアカウントに必要な権限があるか
- かどうか Dameng データベースサービスおよび MySQL 互換性設定が正常に適用されているか

## 7. 展開の初期化を続行

「設定」ページに戻った後、 MySQL が未チェックであることを確認し、「展開の初期化」をクリックして、展開の概要、確認、実行ステップの完了を続行します

> [!TIP]
>
> 展開を初期化する前に、もう一度 Dameng 設定が保存され、すべての確認項目に合格していることを確認してください。
