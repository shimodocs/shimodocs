# で展開 MySQL 8

[← ShimoDocs Suite デプロイメント文書](../../README.md)

この記事では、組み込みインストーラーを無効にし、 MySQL インストーラー内の ShimoDocs インストーラーを使用して自分で設定する MySQL サードパーティのリレーショナルデータベースとして。構成後、インストーラーはデータベースのログイン、ネットワーク接続、およびテーブル作成権限を確認します。確認が完了したら、デプロイを進めることができます。 

# 1. 構成前の準備 
開始する前に、以下を確認してください: 
- MySQL 8.0がインストールされ、正常に動作しています。 
- デプロイノードが MySQL データベースのホストとポート。 
- データベースホスト、ポート、 USERNAME、および PASSWORD が準備されています。 
- データベースアカウントには、ログイン、接続、テーブル作成、テーブル削除の権限があります。 

> [!TIP]
>
> この記事のIP、ポート、アカウントは例です。実際の環境情報を使って設定してください。実際のものを記録しないでください。 PASSWORD 。 
>

# 2. 高度な構成を入力する 
インストーラーの「構成」ステップで、ネットワーク、ターゲット環境、ノード情報の構成を完了した後、ページ下部の「高度な構成」セクションを展開します。 

# 3. 組み込み MySQL
「ミドルウェアサービス」エリアでチェックを外します MySQL.

チェックを外すと、インストーラーは組み込みインストールを行わなくなります MySQL、および外部 MySQL 後で使用するために、既に準備されている8.0を使用します。他のミドルウェアが組み込みのサービスを使用するかどうかは、実際のデプロイ計画に従って選択してください。

# 4. サードパーティミドルウェアの設定を開く
「サードパーティミドルウェア」セクションで、"設定"をクリックします。

# 5. 設定 MySQL データベース
1. 左側で 'RDB リレーショナルデータベース' を選択します。
2. 'サードパーティリレーショナルデータベースを使用' を有効にします。
3. '方言' の下で Standard を選択します。 MySQL 確認して保存します。
4. データベース接続情報を入力してください。
5. 

# 6. 確認結果の確認
インストーラーは次の内容をチェックします：

- ログイン: データベースアカウントが正常にログインできるかどうか。
- 接続性: 展開環境がデータベースにアクセスできるかどうか。
- テーブル作成権限: データベースアカウントがテーブルの作成および削除権限を持っているか。

すべてのチェック項目が「成功」と表示されたら、設定ウィンドウを閉じ、インストーラーの「設定」ページに戻ります。

もし障害が発生した場合は、ページの指示に従って確認してください：
- ホストとポートが正しく入力されているか
- 展開ノードとデータベース間のネットワークが接続されているかどうか。
- かどうか USERNAME および PASSWORD 正しいかどうか
- データベースアカウントに必要な権限があるか

# 7. デプロイの初期化を続行
「設定」ページに戻ったら、確認してください MySQL チェックされていない場合は、'展開を初期化' をクリックして、展開概要、確認、および実行手順の完了を続行します。

> [!TIP]
>
> 展開を初期化する前に、もう一度 8.0 の設定が保存され、すべての検証項目が合格していることを確認してください。 MySQL
