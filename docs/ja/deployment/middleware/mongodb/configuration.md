# MongoDB 構成

[← ShimoDocs Suite デプロイメント文書](../../README.md)

この記事は、実装、運用、または統合担当者が外部との統合を完了するためのガイドを目的としています。 ShimoDocs 外部との MongoDB ステップバイステップ

## 1. 操作前の確認

## MongoDB インスタンスの要件


| ミドルウェア | 推奨バージョン | 3000ユーザー未満 | 3000ユーザー以上 |
| --- | --- | --- | --- |
| MongoDB | MongoDB 4.4 | 2C 8G 100G SSD | 4C 16G 100G SSD |


## クラスタ構成要件
- レプリカセットの高可用性クラスタをサポートし、本番環境では少なくとも3ノードが必須
- 有効にすることを推奨 SCRAM-SHA-256 認証





## ネットワーク接続

ポートは K8s ビジネスクラスターにアクセスする MongoDB オープンでなければならない

```js
telnet IP 27017
```

## 認証と認可
- 本番環境では、次の実施を推奨 SCRAM-SHA-256 認証


## その他の要件
- 内部ネットワーク P99 読み取り遅延 < 5ms、書き込み遅延 < 10ms
- ディスク IOPS ピーク書き込み要件を満たす必要があります; SSD 必須です
- クロック同期: MongoDB クラスタノードおよび ShimoDocs アプリケーションサーバーは NTP 同期されている必要があります
- 定期のフルバックアップと継続的なOplogバックアップ
