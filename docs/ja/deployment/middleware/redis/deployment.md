# で展開 Redis

[← ShimoDocs Suite デプロイメント文書](../../README.md)

この記事では、組み込みの機能を無効にする方法を説明します。 Redis インストーラー内の ShimoDocs 顧客自身の設定方法について説明します Redis 。構成後、インストーラーは Redis ネットワーク接続、接続、認証、コマンド実行、公開/購読権限などを確認します。チェックが通過すると、展開を続行できます。 

# 1. 構成前の準備 
開始する前に、以下を確認してください: 
-  Redis サーバーがインストールされており、正常に稼働していること。 
- 展開ノードは Redis サーバーのホストおよびポートにアクセスできます。 
- 認証ユーザー情報および PASSWORD 接続用 Redis サーバーが準備されています。 

> [!TIP] 
> 
> この記事のIP、ポート、およびアカウントは例です。設定には実際の環境情報を使用し、実際のパスワードを公開文書やスクリーンショットに記録しないでください。 
> 

# 2. 高度な構成を入力する 
インストーラーの「構成」ステップで、ネットワーク、ターゲット環境、およびノード情報の設定が完了した後、ページ下部の「高度な構成」を展開します。 

# 3. 組み込みのインストールをキャンセル Redis
「ミドルウェアサービス」セクションで、チェックを外します Redis

チェックを外すと、インストーラーは組み込みインストールを行わなくなります Redis、そして事前に準備した外部を使用します Redis 代わりに。他のミドルウェアが組み込みサービスを使用するかどうかは、実際の展開計画に従って選択してください。

# 4. サードパーティミドルウェアの設定を開く
「サードパーティミドルウェア」領域で「設定」をクリックします。

# 5. 設定 Redis キャッシュミドルウェア
## Redis サーバー単一ノード
1. 左側で「Redis 左の「キャッシュ」を選択します。
2. 「サードパーティのメッセージキューを使用」を有効にします。 Redis".
3. 「単一ノード」をクリックします
4. ホスト、ポート、 PASSWORD
5. 確認して保存してください

## Redis サーバー Sentinel クラスター
1. 左側で「キャッシュ」を選択します。Redis 「キャッシュ」。
2. 「サードパーティを使用」を有効にします Redis'.
3. 「Sentinel クラスター」をクリックします。
4. 「マスタ名」を入力します。 SENTINEL PASSWORD, SENTINEL ノード。
5. 確認して保存してください

# 6. 確認結果の確認
インストーラーは次の内容をチェックします：
- ログイン: アカウントは正常に認証できます。
- 接続性：デプロイ環境がアクセス可能か Redis
- 権限: このアカウントは接続、認証、コマンド実行、パブリッシュ/サブスクライブなどの権限を持っています。

すべてのチェック項目が「成功」と表示されたら、設定ウィンドウを閉じ、インストーラーの「設定」ページに戻ります。

もし障害が発生した場合は、ページの指示に従って確認してください：
- ホストとポートが正しく入力されているか
- デプロイメントノードと...の間のネットワークが Redis サーバーが接続されています。
- かどうか USERNAME および PASSWORD 正しいかどうか
- アカウントが必要な権限（接続および認証、コマンド権限、公開/購読権限など）を持っているかどうか。

# 7. デプロイの初期化を続行
「設定」ページに戻ったら、確認してください Redis 未確認の場合は、「デプロイの初期化」をクリックして、デプロイの概要、確認、および実行手順を続行してください。

> [!TIP]
>
> 展開を初期化する前に、もう一度 8.0 の設定が保存され、すべての検証項目が合格していることを確認してください。 Redis 設定が保存され、すべての検証項目が合格しました。
