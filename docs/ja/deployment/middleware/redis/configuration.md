# Redis 構成

[← ShimoDocs Suite デプロイメント文書](../../README.md)

本書は、導入担当者、運用担当者、またはインテグレーターが統合を完了するためのガイドを目的としています ShimoDocs 外部との Redis ステップバイステップ。通常、セッション管理、分散ロック、レート制限カウンター、メッセージキューなどのコアシナリオで使用されます

## 1. 操作前確認

## Redis インスタンスの要件


| ミドルウェア | 推奨バージョン | 3000ユーザー未満の場合 | 3000ユーザー以上の場合 |
| --- | --- | --- | --- |
| Redis | Redis 6.2.21 | 2C 4G 100G SSD | 2C 8G 100G SSD |


## クラスタ構成要件
- マスター-スレーブ/センチネル高可用性をサポート
- データ永続性
- クラスタモードはサポートされていません
- DBの数は64以上でなければなりません





## ネットワーク接続

ビジネスクラスタネットワークに接続するためのポート K8s に対して Redis インスタンスは開いている必要があります

```js
telnet IP 6379
```

## 認証と認可
- 本番環境では、有効にすることを推奨します PASSWORD 認証 (requirepass / ACL).


## その他の要件
- 内部ネットワーク P99 レイテンシは10ms未満であるべき
- クロック同期: Redis クラスタノードおよび ShimoDocs アプリケーションサーバーは NTP 同期されている必要があります
- 定期的なフルバックアップ
