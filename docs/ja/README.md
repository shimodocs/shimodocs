# ShimoDocs ドキュメント

ShimoDocs は、プライベートクラウドでドキュメント、文書作成、スプレッドシート、プレゼンテーション、フォーム、テーブルを提供し、すべての製品にプライベート設定可能な AI Agent を内蔵したセルフホスト型文書コラボレーションスイートです。

## ドキュメント

- [ShimoDocs Suite の導入・運用](deployment/README.md)

このリポジトリには ShimoDocs Suite のドキュメントが含まれています。開発者プラットフォームとの連携ドキュメントは含まれていません。
