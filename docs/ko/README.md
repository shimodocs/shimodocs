# ShimoDocs 문서

ShimoDocs는 프라이빗 클라우드에서 문서, 워드 프로세싱, 스프레드시트, 프레젠테이션, 양식, 테이블을 제공하며 모든 제품에 비공개로 구성 가능한 AI Agent가 내장된 셀프 호스팅 문서 협업 제품군입니다.
