# 와 함께 배포 Kafka

[← ShimoDocs Suite 배포 문서](../../README.md)

이 문서에서는 내장 Kafka 을 비활성화하는 방법을 설명합니다. ShimoDocs 설치 프로그램을 비활성화하고 고객의 자체 Kafka 제3자 메시지 큐로 사용됩니다. 구성 후 설치 관리자는 Kafka의 네트워크 연결 및 주제를 생성할 수 있는 권한을 확인합니다. 확인이 완료되면 배포를 진행할 수 있습니다. 

# 1. 구성 전 준비 사항 
시작하기 전에 다음을 확인하십시오: 
- Kafka 서버가 설치되어 정상적으로 실행 중인지. 
- 배포 노드가 Kafka 서버 호스트 및 포트에 접근할 수 있는지. 
- 연결을 위해 준비된 인증 사용자 정보 및 PASSWORD 서버 주제에 연결 Kafka (외부 경우 Kafka 클러스터가 보안 인증을 사용하도록 설정되었습니다). 
- 인증된 계정은 관리자 사용자여야 하며, Topic을 생성, 삭제, 승인, 읽기 및 쓰기 권한을 가져야 합니다(외부일 경우). Kafka 클러스터가 보안 인증을 사용하도록 설정되었습니다). 

> [!TIP]
>
> 이 문서의 IP, 포트 및 계정은 예시입니다. 실제 환경 정보를 사용하여 구성하십시오; 실제 정보를 외부 문서나 스크린샷에 기록하지 마십시오. PASSWORD 외부 문서나 스크린샷에 기록하지 마십시오. 
>

# 2. 고급 구성 입력 
설치 관리자의 '구성' 단계에서 네트워크, 대상 환경 및 노드 정보 구성을 완료한 후, 페이지 하단의 '고급 구성' 섹션을 확장합니다. 

# 3. 내장 설치 취소 Kafka
'미들웨어 서비스' 영역에서 선택을 해제합니다 Kafka.

선택을 해제하면 설치 관리자가 더 이상 내장된 Kafka및 외부를 설치하지 않습니다 Kafka 준비된 것은 나중에 사용됩니다. 다른 미들웨어의 경우, 내장 서비스를 사용할지 여부는 실제 배포 계획에 따라 선택해야 합니다.

# 선택 해제
"서드파티 미들웨어" 영역에서 "구성"을 클릭합니다.

# 타사 미들웨어 구성 열기 Kafka 메시징 미들웨어
## Kafka 서버 SASL 인증 비활성화
1. 데이터베이스Kafka 왼쪽의 "메시지 큐".
2. "서드파티 사용"을 활성화합니다 Kafka "메시지 큐".
3. 서버 연결 정보를 입력하세요. Kafka 서버 연결 정보를 입력하세요.
5. 확인 및 저장

## 활성화 중 SASL 서버에서 인증을 활성화합니다 Kafka 서버 
설치 중 Kafka 서버가 인증을 활성화했으며, Web UI에서도 동시에 활성화해야 합니다: 브로커가 인증된 액세스를 요구할 때만 활성화 버튼 SASL 인증 활성화 
1. 활성화 SASL 인증 
2. 체크 메커니즘 
3. 입력 USERNAME 그리고 PASSWORD 
4. 검증 후 저장 

# 6. 검증 결과 확인
설치 프로그램은 다음을 확인합니다:
- 로그인: 계정을 정상적으로 인증할 수 있습니다 ( SASL 가 활성화된 경우).
- 연결성: 배포 환경에서 접근할 수 있습니다. Kafka.
- 주제 생성 권한: 계정에 주제를 생성하고, 권한을 부여하며, 읽기/쓰기할 수 있는 권한이 있습니다.

모든 확인 항목이 '성공'으로 표시되면 구성 창을 닫고 설치 프로그램의 '구성' 페이지로 돌아갑니다.

실패가 발생하면, 페이지의 안내에 따라 확인해 주십시오:
- 호스트와 포트가 올바르게 입력되어 있는지
- 배포 노드와의 네트워크가 Kafka 서버가 연결되었습니다.
- 여부 USERNAME 그리고 PASSWORD 맞습니다 (Kafka 서버가 활성화되었습니다 SASL 인증).
- 계정에 필요한 권한이 있는지 여부 (Kafka 서버가 인증을 활성화했으며, Web UI에서도 동시에 활성화해야 합니다: 브로커가 인증된 액세스를 요구할 때만 활성화 버튼 SASL 인증 활성화됨).

# 7. 배포 초기화 계속
'구성' 페이지로 돌아간 후, 다음을 확인 Kafka 확인이 되지 않은 채로 남아 있으면 '배포 초기화'를 클릭하여 배포 개요, 확인 및 실행 단계를 계속 진행하십시오.

> [!TIP]
>
> 배포를 초기화하기 전에 다시 한 번 확인해 주십시오. Kafka 설정이 저장되었으며 모든 검증 항목이 통과되었습니다.
