## 1. 작업 전 확인

## MongoDB 인스턴스 요구 사항


| 미들웨어 | 권장 버전 | 3000명 이하 사용자 | 3000명 이상의 사용자 |
| --- | --- | --- | --- |
| MongoDB | MongoDB 4.4 | 2C 8G 100G SSD | 4C 16G 100G SSD |


## 클러스터 구성 요구사항
- 복제본 세트 고가용성 클러스터 지원, 운영 환경에서는 최소 3개의 노드가 필수
- 다음 설정을 권장합니다 SCRAM-SHA-256 인증





## 네트워크 연결

포트 K8s 비즈니스 클러스터 접근용 MongoDB 열려 있어야 함

```js
telnet IP 27017
```

## 인증 및 권한 부여
- 운영 환경에서는 -256 인증을 적용하는 것이 권장됨 SCRAM-SHA-256 인증


## 기타 요구 사항
- 내부 네트워크 P99 읽기 지연 < 5ms, 쓰기 지연 < 10ms
- 디스크 IOPS 최대 쓰기 요구 사항을 충족해야 함; SSD 필수임
- 시계 동기화: MongoDB 클러스터 노드 및 ShimoDocs 애플리케이션 서버는 NTP 동기화되어야 함
- 정기 전체 백업 및 연속 Oplog 백업
