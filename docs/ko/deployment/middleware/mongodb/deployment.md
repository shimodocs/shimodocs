시작하기 전에 다음을 확인하십시오: 
- MongoDB 서버가 설치되어 정상적으로 실행 중인지. 
- 배포 노드는 MongoDB 서버 
- 연결 정보 및 PASSWORD 서버 인증을 위해 MongoDB 서버가 준비되었습니다.

# 2. 고급 구성 입력 
설치 프로그램의 "구성" 단계에서 네트워크, 대상 환경 및 노드 정보 구성을 완료한 후, 페이지 하단의 "고급 구성"을 확장합니다. 

# 3. 내장 설치 취소 MongoDB
'미들웨어 서비스' 영역에서 선택을 해제합니다 MongoDB

선택을 해제하면 설치 관리자가 더 이상 내장된 MongoDB하고 외부에서 준비된 MongoDB 를 대신 사용합니다. 다른 미들웨어의 경우 내장 서비스를 사용할지 여부는 실제 배포 계획에 따라 선택해야 합니다.

# 선택 해제
"서드파티 미들웨어" 영역에서 "구성"을 클릭합니다.

# 타사 미들웨어 구성 열기 MongoDB 문서 데이터베이스

2. "서드파티 사용"을 활성화합니다 MongoDB 문서 데이터베이스.
3. 호스트, 포트 입력, USERNAME, PASSWORD, 연결 문자열 재정의
4. 확인 및 저장

> [!WARNING]
>
> 주의: 타사에서 MongoDB 응용프로그램 전용 계정을 생성하고 계정이 지정된 데이터베이스에만 접근할 수 있는 '최소 권한 원칙'을 따르는 경우, 사용자와 PASSWORD 각 비즈니스 데이터베이스에 대해

# 6. 검증 결과 확인
설치 프로그램은 다음을 확인합니다:
- 로그인: 계정을 정상적으로 인증할 수 있음
- 연결성: 배포 환경에서 접근할 수 있습니다. MongoDB
- 권한: 연결, 인증, 명령 실행 등의 권한이 있음

모든 확인 항목이 '성공'으로 표시되면 구성 창을 닫고 설치 프로그램의 '구성' 페이지로 돌아갑니다.

실패가 발생하면, 페이지의 안내에 따라 확인해 주십시오:
- 호스트와 포트가 올바르게 입력되어 있는지
- 배포 노드와의 네트워크가 MongoDB 서버가 연결되었습니다.
- 여부 USERNAME 그리고 PASSWORD 가 올바른지
- 계정이 필요한 권한(연결 및 인증, 명령 권한 등)을 가지고 있는지 여부.

# 7. 배포 초기화 계속
'구성' 페이지로 돌아간 후, 다음을 확인 MongoDB 체크되지 않은 상태이면, '배포 초기화'를 클릭하여 배포 개요, 검사 및 실행 단계를 계속 완료합니다.

> [!TIP]
>
> 배포를 초기화하기 전에 다시 한 번 확인해 주십시오. MongoDB 구성이 저장되었으며 모든 검증 항목을 통과했습니다.
