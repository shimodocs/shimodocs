# 와 함께 배포 Dameng V8

[← ShimoDocs Suite 배포 문서](../../README.md)

이 문서에서는 내장된 MySQL 을 비활성화하는 방법을 설명합니다. ShimoDocs 설치 프로그램에서 Dameng DM8 를 타사 관계형 데이터베이스로 구성합니다. 구성이 완료되면 설치 프로그램이 데이터베이스 로그인, 네트워크 연결, 테이블 생성 권한을 확인합니다. 확인이 통과되면 배포를 계속할 수 있습니다.

## 1. 구성 전 준비 사항

시작하기 전에 다음을 확인하십시오:

- Dameng DM8 가 설치되어 있고 정상적으로 실행 중입니다.
- 배포 노드는 Dameng 데이터베이스의 호스트와 포트에 접근할 수 있습니다.
- 데이터베이스 호스트, 포트, USERNAME, 및 PASSWORD 가 준비되었습니다.
- 데이터베이스 계정은 로그인, 연결, 테이블 생성 및 테이블 삭제 권한을 가지고 있습니다.
- Dameng 데이터베이스는 요구 사항에 따라 MySQL 호환성 모드 구성을 완료했습니다. 자세한 지침은 ["Dameng 데이터베이스 통합 구성 가이드를 참조하세요.](requirements.md).

> [!TIP]
>
> 이 문서의 IP, 포트 및 계정은 모두 예시입니다. 실제 환경 정보를 사용하여 구성하고, 실제 PASSWORD 정보를 외부 문서나 스크린샷에 기록하지 마세요.

## 2. 고급 설정 입력

설치 프로그램의 '구성' 단계에서 네트워크, 대상 환경 및 노드 정보 구성을 완료한 후, 페이지 하단의 '고급 구성'을 확장합니다.

## 3. 내장 설치 선택 해제 MySQL

"미들웨어 서비스" 섹션에서 **MySQL**.

선택 해제 후, 설치 프로그램은 더 이상 내장 MySQL를 설치하지 않으며, 준비된 Dameng 데이터베이스를 사용합니다. 다른 미들웨어의 경우, 내장 서비스를 사용할지 여부는 실제 배포 계획에 따라 선택해야 합니다.

## 선택 해제

4. 타사 미들웨어 구성 열기

## 타사 미들웨어 구성 열기 Dameng 5. 구성

1. 데이터베이스RDB 왼쪽에서 "관계형 데이터베이스"를 선택합니다.
2. "타사 관계형 데이터베이스 사용"을 활성화합니다.
3. "방언" 섹션에서 **DM (Dameng)**.
4. 데이터베이스 연결 정보를 입력합니다.

| 구성 항목 | 설명 |
| --- | --- |
| 호스트 | 데이터베이스의 IP 주소 또는 접근 가능한 호스트 이름 Dameng 데이터베이스 |
| 포트 | 청취 포트 Dameng 데이터베이스, 기본값은 일반적으로 5236이며 실제 구성에 따라 다름 |
| USERNAME | 데이터베이스에 연결하는 데 사용되는 계정 |
| PASSWORD | 그 PASSWORD 데이터베이스 계정에 해당하는 |
| DSN | 위 정보를 기반으로 설치 관리자가 자동 생성하며, 수동 입력 필요 없음 |

5. 정보가 정확한지 확인한 후 "검증 및 저장"을 클릭합니다.

## 6. 검증 결과 확인

설치 관리자가 다음 항목을 확인합니다:

- **로그인**: 데이터베이스 계정이 정상적으로 로그인할 수 있습니다.
- **연결성**: 배포 환경이 데이터베이스에 접근할 수 있습니다.
- **테이블 생성 권한**: 데이터베이스 계정이 테이블을 생성하고 삭제할 수 있는 권한을 가지고 있습니다.

모든 확인 항목이 "성공"으로 표시되면, 구성 창을 닫고 설치 관리자의 "구성" 페이지로 돌아갑니다.

실패한 항목이 있는 경우, 페이지 안내에 따라 확인하십시오:

- 호스트와 포트가 올바르게 입력되어 있는지
- 배포 노드와 데이터베이스 간의 네트워크가 연결되어 있는지
- 여부 USERNAME 그리고 PASSWORD 가 올바른지
- 데이터베이스 계정에 필요한 권한이 있는지
- 여부 Dameng 데이터베이스 서비스 및 MySQL 호환성 구성이 정상적으로 적용되었는지

## 7. 배포 초기화 계속

"구성" 페이지로 돌아온 후, MySQL 체크 해제 상태로 남아 있는지 확인하고 "배포 초기화"를 클릭하여 배포 개요, 확인 및 실행 단계를 계속 완료합니다.

> [!TIP]
>
> 배포를 초기화하기 전에 다시 한 번 Dameng 구성이 저장되었고 모든 검증 항목이 통과했는지 확인하십시오.
