# 와 함께 배포 MySQL 8

[← ShimoDocs Suite 배포 문서](../../README.md)

이 문서에서는 내장 MySQL 을 비활성화하는 방법을 설명합니다. ShimoDocs 설치 프로그램을 실행하고 직접 구성 MySQL 서드파티 관계형 데이터베이스로서. 구성 후, 설치 프로그램은 데이터베이스 로그인, 네트워크 연결, 테이블 생성 권한을 확인합니다. 확인이 완료되면 배포를 진행할 수 있습니다. 

# 1. 구성 전 준비 
시작하기 전에 다음을 확인하십시오: 
- MySQL 8.0이 설치되어 정상적으로 실행 중입니다. 
- 배포 노드가 MySQL 데이터베이스 호스트와 포트. 
- 데이터베이스 호스트, 포트, USERNAME, 및 PASSWORD 준비되었습니다. 
- 데이터베이스 계정은 로그인, 연결, 테이블 생성 및 삭제 권한이 있습니다. 

> [!TIP]
>
> 이 문서의 IP, 포트 및 계정은 예시입니다. 실제 환경 정보를 사용하여 구성하십시오; 실제 정보를 외부 문서나 스크린샷에 기록하지 마십시오. PASSWORD 외부 문서나 스크린샷에 기록하지 마십시오. 
>

# 2. 고급 구성 입력 
설치 관리자의 '구성' 단계에서 네트워크, 대상 환경 및 노드 정보 구성을 완료한 후, 페이지 하단의 '고급 구성' 섹션을 확장합니다. 

# 3. 내장 설치 취소 MySQL
'미들웨어 서비스' 영역에서 선택을 해제합니다 MySQL.

선택을 해제하면 설치 관리자가 더 이상 내장된 MySQL및 외부를 설치하지 않습니다 MySQL 나중에 사용할 이미 준비된 8.0이 사용됩니다. 다른 미들웨어가 내장 서비스를 사용할지 여부는 실제 배포 계획에 따라 선택해야 합니다.

# 선택 해제
"서드파티 미들웨어" 섹션에서 "구성"을 클릭합니다.

# 타사 미들웨어 구성 열기 MySQL 5. 구성
1. 선택 'RDB 왼쪽의 '관계형 데이터베이스'.
2. '타사 관계형 데이터베이스 사용'을 활성화합니다.
3. 표준 선택 MySQL '방언' 아래에.
4. 데이터베이스 연결 정보를 입력합니다.
5. 확인하고 저장합니다.

# 6. 검증 결과 확인
설치 프로그램은 다음을 확인합니다:

- 로그인: 데이터베이스 계정이 정상적으로 로그인할 수 있는지 여부.
- 연결성: 배포 환경이 데이터베이스에 접근할 수 있는지 여부.
- 테이블 생성 권한: 데이터베이스 계정이 테이블을 생성하고 삭제할 권한이 있는지 여부.

모든 확인 항목이 '성공'으로 표시되면 구성 창을 닫고 설치 프로그램의 '구성' 페이지로 돌아갑니다.

실패가 발생하면, 페이지의 안내에 따라 확인해 주십시오:
- 호스트와 포트가 올바르게 입력되어 있는지
- 배포 노드와 데이터베이스 간의 네트워크가 연결되어 있는지 여부.
- 여부 USERNAME 그리고 PASSWORD 가 올바른지
- 데이터베이스 계정에 필요한 권한이 있는지

# 7. 배포 초기화 계속
'구성' 페이지로 돌아간 후, 다음을 확인 MySQL 체크되지 않은 상태로 두면 '배포 초기화'를 클릭하여 배포 개요를 완료하고, 검사 및 실행 단계를 진행합니다.

> [!TIP]
>
> 배포를 초기화하기 전에, 다시 한 번 확인해 주십시오. MySQL 8.0 설정이 저장되었으며 모든 검증 항목이 통과되었는지 여부.
