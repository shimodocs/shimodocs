## MySQL 구성 및 고가용성 요구 사항
마스터-슬레이브 고가용성 전환 지원
문자 집합: utf8mb4 
시간대: Asia/Shanghai 또는 UTC 
연결: 최대_연결 수 ≥ 1000
연결 사용자: 관리자 권한

> [!TIP]
>
> 별도로 구성해야 합니다 MySQL 인스턴스;
> 1. 문서 시스템의 안정적이고 효율적인 운영을 보장하기 위해, 장애 격리, 권한 보안, 독립적인 백업 및 복구를 달성합니다.
> 2. 현재 시스템은 사용자 정의 데이터베이스 이름과 테이블 접두사를 지원하지 않으므로, 배포 전에 별도의 인스턴스 계획 및 준비를 완료해야 합니다.





## 네트워크 연결 
k8s 비즈니스 클러스터 네트워크를 MySQL 인스턴스에 연결하기 위한 포트를 열어야 합니다 

```js
telnet IP 3306
```
## 사용자 인증
사용자는 MySQL 서버에 연결할 때 제공된 사용자를 인증해야 합니다 MySQL 서버

# 설명: 
- 사용자는 MySQL 문서의 설정들은 모두 권장 설정으로, 초기 단계 프로젝트 용량 평가 및 자원 계획을 위해 사용되며, 최종 운영 환경 설정이 아닙니다. 실제 최종 설정은 사전 판매 평가 후에 결정됩니다.
- 국산 아키텍처 서버를 사용할 경우, CPU 표준 사양의 두 배로 전체 자원을 추정하는 것이 권장됩니다.
- 정식 운영 환경에서는 확장을 위한 용량을 확보하고 고가용성 배포를 우선시하는 것이 권장됩니다.
