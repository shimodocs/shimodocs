# Redis 구성

[← ShimoDocs Suite 배포 문서](../../README.md)

이 문서는 구현자, 운영 담당자 또는 통합자가 완전한 통합을 완료할 수 있도록 안내하기 위한 것입니다. ShimoDocs 외부와 함께 Redis 단계별. 일반적으로 세션 관리, 분산 잠금, 속도 제한 카운터, 메시지 큐와 같은 핵심 시나리오에 사용됩니다.

## 1. 사전 작업 확인

## Redis 인스턴스 요구 사항


| 미들웨어 | 권장 버전 | 3000명 이하의 사용자용 | 3000명 이상의 사용자용 |
| --- | --- | --- | --- |
| Redis | Redis 6.2.21 | 2C 4G 100G SSD | 2C 8G 100G SSD |


## 클러스터 구성 요구사항
- 마스터-슬레이브/센티넬 고가용성 지원
- 데이터 지속성
- 클러스터 모드는 지원되지 않음
- DB 수는 64 이상이어야 함





## 네트워크 연결

비즈니스 클러스터 네트워크를 인스턴스에 연결하는 포트는 개방되어야 함 K8s  Redis 

```js
telnet IP 6379
```

## 인증 및 권한 부여
- 운영 환경에서는 인증 활성화 권장 (requirepass /) PASSWORD  ACL).


## 기타 요구 사항
- 내부 네트워크 P99 지연 시간은 < 10ms이어야 함
- 시계 동기화: Redis 클러스터 노드 및 ShimoDocs 애플리케이션 서버는 NTP 동기화되어야 함
- 정기적인 전체 백업
