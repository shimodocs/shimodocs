# 협업 차단

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 설명

에서 백로그가 발생하고, Kafka특정 파일로 인해 비정상적인 백로그가 발생한 것이 확인되면, 이 차단 기능을 사용하여 해당 파일의 편집을 금지하고, 이를 통해 Kafka 백로그 문제를 해결할 수 있습니다.

## 사용 예시

1. 협업 차단 선택 

2. 파일 GUID 입력, 강조: 이는 ShimoDocs고객 파일 ID가 아닌 내부의 GUID를 의미합니다. 

입력하십시오 ShimoDocs 파일 GUID 그리고 '차단에 추가'를 클릭하면, 파일 편집이 3분 내에 금지됩니다. 

파일 편집 기능을 복원하려면 '차단 해제' 버튼을 클릭하세요. 

### 획득 방법 GUID 

1. 브라우저 개발자 도구를 엽니다. 

2. 풀 리퀘스트 필터링 

3. 요청에서 rp3OMYnMrdcQJZkm에서 16자리 문자열은 GUID 

### 차단 영향 확인 방법

문서를 성공적으로 저장할 수 없습니다; 파일 편집 후 2분 뒤 오프라인 팝업이 나타나고, 페이지 새로고침 후 데이터가 손실됩니다.

### 차단 해제 시기

차단 해제는 추천되지 않습니다. 일반적으로 파일이 서버 편집을 지원하기에 너무 크기 때문입니다. 차단 후 읽기 전용이 되며, 파일 내용을 새 파일에 수동으로 복사하는 것을 권장합니다.
