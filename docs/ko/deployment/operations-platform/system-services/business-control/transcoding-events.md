# 트랜스코딩 이벤트 검색

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 개요 
트랜스코딩 이벤트 조회 기능은 최근 트랜스코딩 이벤트를 빠르게 확인하는 데 사용됩니다 MDP 백엔드, 트랜스코딩 과정 중 문제를 찾고 해결하는 데 도움을 줍니다. 

기본적으로 목록에는 가장 최근의 트랜스코딩 이벤트가 표시됩니다. 

## 작업_ID 획득
작업_ID는 가져오기 및 내보내기 작업 중에 생성됩니다

브라우저의 개발자 모드를 엽니다. 내보낼 때 작업을 얻을 수 있습니다_아래 그림과 같이 이 인터페이스를 확인하여 ID

## 작업별 조회_id
작업 입력_해당 작업과 관련된 트랜스코딩 이벤트를 신속하게 필터링하려면 taskID 입력란에 ID를 입력합니다.

## 링크 보기
아래 그림과 같이 행 기록에서 "링크 보기" 아이콘을 클릭하여 해당 작업과 관련된 모든 이벤트를 확인합니다._ID, 이는 이 트랜스코딩 작업의 시작부터 완료까지 전체 프로세스를 분석하는 데 도움이 됩니다.

## 예외 위치 확인

### gRPC 성공, 콜백 수신되지 않음
설치 중 gRPC 이 성공적으로 전송되고 응답이 성공적으로 수신되면, 이는 트랜스코딩 작업이 트랜스코딩 서비스로 전달되었음을 나타냅니다. 이 경우, 트랜스코딩 서비스가 시간 초과로 인해 콜백을 제때 수신하지 못하면, 트랜스코딩 서비스를 조사해야 합니다.

### 콜백 수신됨
작업 ID에 대한 콜백이 있는 것을 확인할 수 있다면_일반적으로 이는 호환되지 않는 형식이나 기타 예외와 같은 트랜스코딩 실패로 간주됩니다.
