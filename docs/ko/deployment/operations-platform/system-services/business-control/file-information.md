# 파일 정보 검색

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 개요

파일 정보 조회는 내부 파일 또는 GUID 고객 측 파일 ID를 기반으로 시스템 내 파일의 기본 기록을 조회하여, 파일 식별자, 연결된 애플리케이션, 파일 유형, 상태 및 내용 크기를 확인하는 데 도움을 줍니다.

이 페이지는 읽기 전용이며 파일 내용이나 상태를 수정하지 않습니다.

## 페이지 접근 방법

관리 백엔드에 로그인한 후, **왼쪽 탐색 메뉴에서 파일 정보 조회를 선택하여** 페이지에 접근하세요.

## 파일 조회

이 페이지는 다음 조회 조건을 지원합니다:

- **내부 파일 GUID**: 파일의 `history_guid`.
- **고객 파일 제공자 GUID**: 고객 측 `provider_file_id`.
- **앱 ID**: 선택 사항, 제공자와 함께 입력하는 것이 권장됨 GUID 연관된 애플리케이션을 지정하기 위해.

내부 파일 또는 GUID 고객 파일 제공자 중 적어도 하나는 입력되어야 하며, 그 다음 GUID 조회 버튼을 클릭하십시오 **조회**.

만약 제공자라면 GUID 이 입력되고 앱 ID가 입력되지 않으면 시스템은 제공자와 일치하는 모든 레코드를 반환합니다 GUID, 따라서 여러 결과가 나타날 수 있습니다. 

### 파일 가져오기 GUID 
1. 의 경우, ShimoDocs Suite브라우저에서 스위트의 주소만 사용하면 됩니다. **고객 파일 제공자 GUID**. 

## 쿼리 결과

쿼리 결과에는 주로 다음이 포함됩니다:

- **id**: 파일 기록의 기본 키 ID.
- **앱_id**: 관련 애플리케이션의 ID.
- **제공자_파일_id**: 클라이언트 측 파일 ID.
- **기록_GUID**: 내부 시스템의 역사적 파일 GUID.
- **생성됨_시간**: 기록 생성 시간.
- **유형**: 문서, 스프레드시트, 프레젠테이션, PDF, 이미지 또는 비디오와 같은 파일 유형.
- **생성됨_작성자**: 작성자 사용자 ID.
- **상태**: 파일의 현재 상태 값입니다.
- **파일_내용_크기**: 파일 내용의 크기(바이트 단위)입니다.

결과의 파일 유형은 식별하기 쉽게 유형 번호와 해당 이름을 모두 표시합니다.

## 일반 상황

- **프롬프트: 조회 조건을 입력해야 합니다**: 최소한 내부 파일을 입력해 주세요 GUID 또는 제공자를 입력해 주세요 GUID.
- **파일을 찾을 수 없습니다**: 식별자가 완전한지 확인하거나 파일이 현재 환경에 속하는지 확인해 주세요.
- **여러 레코드 반환**: 제공자가 GUID 여러 애플리케이션에 중복될 수 있습니다. App ID를 추가하고 다시 검색해 주세요.
- **파일 유형이 알 수 없음으로 표시됨**: 현재 레코드의 유형 번호에 해당 이름이 아직 구성되지 않았을 수 있습니다. 번호를 기술 지원에 제공하여 확인할 수 있습니다.
- **상태 값을 확인할 수 없음**: 상태 필드는 기본 레코드 값이며, 특정 비즈니스 현상과 로그를 결합하여 추가 분석이 필요합니다.

> 파일 식별자는 비즈니스 데이터에 속하므로, 공개 채팅이나 외부 티켓에서 직접 공유하지 마세요.
