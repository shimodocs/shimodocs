# 구성 센터

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 개요 

구성 센터는 다양한 서비스의 애플리케이션 구성을 조회하고 수정하는 데 사용됩니다. 이 페이지는 공장 템플릿 구성과 현재 활성화된 구성을 모두 표시하여 구성 차이와 릴리스 수정을 쉽게 이해하고 통제된 방식으로 확인할 수 있습니다. 

구성이 게시되면 시스템은 이 수정을 저장하고 선택에 따라 관련 서비스를 자동으로 재시작하여 새 구성을 적용할 수 있습니다. 

## 페이지 접근 

관리 백엔드에 로그인한 후, 왼쪽 탐색에서 **구성 센터** 를 선택하여 페이지에 접근할 수 있습니다. 

구성 센터는 관리자만 사용할 수 있습니다. 이 메뉴가 보이지 않는 경우, 시스템 관리자에게 문의하여 계정 권한을 확인하십시오. 

## 페이지 설명 

페이지는 주로 세 가지 영역으로 나뉩니다: 

- **애플리케이션 및 파일 목록**: 애플리케이션별 구성 가능한 파일을 표시하며, 애플리케이션 이름으로 검색할 수 있습니다. 
- **공장 템플릿 구성**: 설치 패키지에서 제공된 원래 구성을 표시하며, 보기와 참고용으로만 사용됩니다. 
- **현재 활성 구성**: 환경에서 현재 사용 중인 구성을 표시하며, 직접 편집할 수 있습니다. 

구성 파일은 일반적으로 JSON, YAML, 또는 TOML 형식입니다. 올바른 파일 구문과 데이터 구조를 유지하십시오. 

## 구성 수정 및 게시 

다음 단계를 따르는 것이 권장됩니다: 

1. 왼쪽에서 수정하려는 애플리케이션과 구성 파일을 선택합니다.
2. 공장 템플릿을 참조하여 **유효한 구성** 영역에서 구성 내용을 수정합니다.
3. 수정 후 페이지에 상태가 **수정되었지만 게시되지 않음**.
4. 클릭 **수정되었지만 게시되지 않음**으로 표시되거나 확인 창을 열기 위해 `Ctrl S` (Windows) / `Command S` (macOS)를 사용합니다.
5. 게시할 필드 경로, 변경 유형 및 새 값을 확인합니다.
6. 필요에 따라 **구성 게시 후 관련 서비스 재시작** 을 활성화할지 선택합니다.
7. 클릭 **구성 게시** 로 수정을 완료합니다.

구성 내용에 형식 오류가 있으면 시스템이 오류를 알리고 게시를 방지합니다. 수정 후 다시 시도하십시오.

## 변경 확인

게시 전에 확인 창에 이 변경 사항의 차이가 표시됩니다:

- **경로**: 변경된 구성 경로입니다.
- **작업**: 추가, 수정 또는 삭제와 같은 변경 유형입니다.
- **값**: 변경 후 구성 값입니다.

구성을 실수로 삭제하거나 잘못된 서비스 매개변수를 수정하지 않도록 각 차이를 확인하는 것이 좋습니다.

## 서비스 재시작

일부 구성은 서비스 재시작 후에만 적용됩니다. 기본적으로 페이지는 이 옵션을 활성화하며 **구성 게시 후 관련 서비스 재시작**게시가 성공하면 애플리케이션과 관련된 서비스가 자동으로 재시작됩니다.

이 옵션을 끈 경우에도 구성은 게시되지만, 관련 서비스는 새 설정을 적용하기 위해 나중에 수동으로 재시작해야 할 수 있습니다.

서비스 재시작 중 관련 기능이 잠시 변동될 수 있으므로 중요한 구성 변경은 비업무 시간에 수행하는 것이 좋습니다.

## 일반 상황

- **애플리케이션을 찾을 수 없습니다**: 검색 기준을 지우거나 대상 애플리케이션이 올바르게 배포되었는지 확인하십시오.
- **구성 파일을 로드할 수 없습니다**: 서비스를 확인하고 현재 계정 권한을 다시 시도하기 전에 확인하십시오.
- **구성 형식 오류**: 들여쓰기, 괄호, 따옴표 및 필드 형식을 확인하십시오 JSON, YAML, 또는 TOML.
- **게시할 변경 사항이 없습니다**: 실제 구성 내용이 효과적으로 변경되지 않았으므로 게시가 필요하지 않습니다.
- **게시 후 변경 사항이 적용되지 않음**: 관련 서비스가 재시작되었는지 확인하고, 필요한 경우 수동으로 재시작한 후 다시 확인하십시오.
- **배포 실패**: 페이지의 안내에 따라 구성 내용이나 서비스 상태를 확인하고 처리한 후 다시 게시하십시오. 

> 구성 변경은 서비스 시작 및 비즈니스 기능에 영향을 줄 수 있으므로 변경 내용을 충분히 확인한 후 게시하십시오.
