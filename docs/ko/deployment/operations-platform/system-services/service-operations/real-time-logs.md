# 실시간 로그

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 개요

실시간 로그는 클러스터에서 서비스의 운영 로그를 온라인으로 확인할 수 있어 Kubernetes 서비스 이상, 요청 실패, 실행 지연을 신속하게 찾을 수 있습니다.

주요 사용 사례:
- 실시간으로 발생한 로그를 빠르게 필터링
- 전체 로깅 시스템이 배치되지 않은 경우 가벼운 대안

참고: 실시간 로그는 를 통해 얻을 수 있으며, Kubernetes API로그 데이터는 에 의해 영향을 받을 수 있습니다 Kubernetes 롤링 업데이트.

## 페이지 접근 방법

관리 콘솔에 로그인한 후, 선택 **실시간 로그** 왼쪽 내비게이션에서 페이지로 들어갑니다.

실시간 로그는 배포 모드에서만 지원됩니다. Kubernetes 이 메뉴가 보이지 않는 경우, 배포 모드와 현재 계정의 접근 권한을 확인하기 위해 시스템 관리자에게 문의하십시오.

## 로그 조회

다음 단계를 따르는 것이 좋습니다:

1. 선택 **클러스터** 그리고 **NAMESPACE** 조회하려는
2. 로그 대상을 선택하세요. Deployment, StatefulSet 또는 Pod를 지원하며, 여러 대상을 동시에 선택할 수 있습니다.
3. 로그 범위를 선택하세요. 최근 100줄, 1000줄, 5000줄 또는 최근 1분에서 24시간까지의 로그를 조회할 수 있습니다.
4. 조회 결과를 좁히려면 행 수준 필터 조건을 입력할 수 있습니다.
5. 클릭 **시작** 선택한 범위 내의 로그가 로드되고 새로 생성된 로그가 지속적으로 표시됩니다.

클릭 **중지** 실시간 가져오기를 종료합니다. 조회를 다시 시작하면 현재 페이지의 로그가 지워지고 새 조회 결과가 로드됩니다.

## 로그 필터링

행 수준 필터링은 영어 문자의 대소문자를 구분하지 않습니다. 조건 입력 후 Enter를 눌러 적용합니다. 일반적인 사용법은 다음과 같습니다:

```text
error
error AND timeout
error OR warning
error NOT health
error AND (timeout OR deadline)
"connection refused"
```

- `AND`: 여러 조건을 동시에 포함합니다. 
- `OR`: 조건 중 하나 이상을 포함합니다. 
- `NOT`: 지정한 내용을 제외합니다. 
- `()`: 여러 필터 조건을 조합합니다. 
- `""`: 공백이 포함된 전체 문구를 검색합니다. 

입력 상자 오른쪽에 있는 도움말 버튼을 클릭하면 완전한 구문 예제를 볼 수 있습니다. 또한 **자주 사용하는 쿼리** 를 사용하여 미리 설정된 로그 대상과 필터 조건을 빠르게 채울 수 있습니다. 

## 로그 보기 

로그 목록에는 로그 시간, POD_NAME및 로그 내용이 표시됩니다. 

- 을 클릭하면 POD_NAME 전체 이름을 복사할 수 있습니다. 
- 내용이 길 경우 전체 로그를 확장하여 볼 수 있습니다. 
- 형식의 로그는 포맷된 내용으로 확장할 수 있으며, 원클릭 복사를 지원합니다. JSON 로그가 많을 경우, 페이지는 자동으로 페이지를 나누며, 목록 상단의 버튼을 사용하여 위 또는 아래로 빠르게 이동할 수 있습니다.

## 로그 볼륨 분포 

페이지의 로그 볼륨 분포 차트는 서로 다른 기간 동안의 로그 수를 보여주며, 필터링 후 총 로그 라인 수와 일치하는 라인 수를 표시합니다. 

분포 차트에서 시간을 드래그하여 선택하면, 로그 목록은 해당 시간 범위 내의 내용만 표시되며, 이는 갑작스러운 로그 급증이나 이상이 발생한 기간에 빠르게 집중할 때 적합합니다. 

## 페이지 작업 

- **시작**: 현재 조건에 따라 로그를 가져오고 새 로그를 계속 수신합니다. 
- **중지**: 새 로그 수신을 중지합니다; 이미 로드된 로그는 페이지에 남아 있습니다.
- **: 지우기**: 현재 표시된 로그를 지웁니다; 실시간 가져오기가 계속되면 새 로그가 계속 나타납니다.

## 일반 상황

- **: 아직 로그가 없습니다**: 대상 서비스가 실행 중인지 확인하고 로그 시간 범위를 확장해 보세요.
- **: 대상이 선택되지 않음**: 최소 한 개의 Deployment, StatefulSet 또는 Pod를 선택하세요.
- **: 대상이 너무 많음**: 단일 쿼리는 최대 20개의 실제 Pod를 지원합니다; 선택을 줄이고 다시 시도하세요.
- **: 잘못된 필터 조건**: 다음을 확인하세요 `AND`, `OR`, `NOT`: 괄호 또는 따옴표가 완전히 닫혔는지 확인하세요.
- **: 로그 가져오기 중단됨**: 이는 서비스 재시작, 네트워크 변경 또는 권한 부족으로 인해 발생할 수 있습니다. 다시 클릭할 수 있습니다 **시작** .

> : 페이지는 최대 50만 줄의 로그를 유지합니다. 한도를 초과하면 오래된 로그가 자동으로 제거됩니다.
