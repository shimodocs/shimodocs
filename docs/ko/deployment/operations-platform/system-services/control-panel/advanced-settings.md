# 고급 설정

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 개요

고급 설정은 시스템의 사용자 정의를 관리하는 데 사용됩니다 `pd-config` 을 통해 직접 YAML. 이는 표준 설정 페이지에서 제공되지 않는 고급 매개변수 처리 또는 대량 구성에 적합합니다.

시스템은 사용자 정의 구성을 공장 기본 구성과 병합합니다. 동일한 경로의 사용자 정의 값은 기본 값을 덮어쓰며, 채워지지 않은 구성은 계속해서 공장 기본 값을 사용합니다.

## 페이지 진입

관리 백엔드에 로그인한 후, **고급 설정** 왼쪽 탐색에서 페이지에 접근합니다.

고급 설정은 관리자만 사용할 수 있습니다. 이 페이지는 시스템 전체에 영향을 줄 수 있으므로, 구성 구조를 잘 아는 담당자가 운영해야 합니다. MDP 

## 페이지 설명

이 페이지는 두 부분으로 나뉩니다:

- **공장 기본 pd-config**: 설치 패키지에서 제공되는 기본 구성으로, 읽기 전용입니다.
- **사용자 정의 pd-config**: 현재 저장된 고객 맞춤 구성이며, 편집할 수 있습니다.

사용자 정의 구성은 모든 기본 내용을 복사할 필요가 없으며, 일반적으로 재정의하거나 추가해야 하는 구성 항목만 남깁니다.

## 구성 수정 및 게시

다음 단계를 따르는 것이 좋습니다:

1. 클릭 **새로 고침** 최신 사용자 정의 구성이 로드되었는지 확인하려면.
2. 왼쪽에 있는 공장 기본 구성과 비교하고 수정하십시오 YAML 오른쪽의 내용입니다.
3. 클릭 **게시**.
4. 차이 확인 창에서 추가, 삭제 및 수정된 내용을 확인합니다.
5. 이전/다음 차이 버튼을 사용하여 항목별로 변경 사항을 확인합니다.
6. 오류가 없는 것을 확인한 후, 클릭 **게시 확인**.

성공적으로 게시된 후, 시스템은 구성 응용 프로그램 작업을 생성하고 새 창에서 작업 로그를 엽니다. 변경 내용과 시스템 설정에 따라 관련 서비스가 자동으로 다시 시작될 수 있습니다.

## 구성 이력

클릭 **이력** 기록 ID, 생성 시간 등을 포함하여 이전에 게시된 맞춤 구성을 보려면 MD5.

- 클릭 **보기** 전체 내용을 보려면 YAML 이력 버전을 확인하십시오.
- 두 개의 기록을 선택한 후에는 차이 비교를 수행할 수 있습니다.

현재 페이지에는 원클릭 복원 버튼이 제공되지 않습니다. 과거 구성을 복원하려면 해당 버전을 확인하고, 내용을 검토한 후, 편집 영역에 수동으로 복사하여 다시 게시하십시오.

## 주의 사항

- YAML 구문이 올바르게 유지되어야 하며, 들여쓰기, 콜론, 데이터 유형에 주의하십시오.
- 이해하지 못하는 구성 항목을 임의로 삭제하지 마십시오.
- 게시하기 전에 다른 관리자가 최근에 제출한 변경 사항을 덮어쓰지 않도록 차이점을 충분히 확인하십시오.
- 주요 변경 사항은 비업무 시간에 수행하는 것이 권장되며, 원래 구성은 사전에 기록해야 합니다.
- 게시 후, 구성 적용 및 서비스 상태 확인이 완료되었는지 작업 로그를 확인하십시오.

## 일반 상황

- **게시 실패**: 다음을 확인하십시오 YAML 형식, 필드 이름 및 구성 값 유형.
- **게시 후 서비스 재시작**: 구성 변경 사항은 관련 서비스 재시작이 필요할 수 있으며, 이는 정상입니다.
- **게시 후 페이지가 일시적으로 접근 불가**: MDP 또는 관련 서비스가 재시작 중일 수 있습니다; 잠시 후 새로고침하십시오.
- **구성이 예상한 효과를 내지 못함**: 구성 경로가 올바른지 확인하고 최종 병합 결과 및 작업 로그를 확인하십시오.
- **잘못된 구성 수정**: 히스토리에서 올바른 버전을 찾아 내용을 복사한 후 다시 게시하십시오.

> 고급 설정은 시스템 수준 구성 및 서비스 운영에 영향을 미치므로, 검증되지 않은 구성을 프로덕션 환경에 직접 게시하지 마십시오.
