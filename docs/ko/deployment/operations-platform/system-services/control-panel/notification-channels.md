# 알림 채널

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 개요

알림 채널은 시스템 경고 메시지 수신 방식을 중앙에서 관리하는 데 사용되며, 미들웨어 검수 및 기타 기능이 장애 및 복구 알림을 전송할 수 있도록 합니다.

현재 지원되는 채널에는 WeCom, DingTalk, Feishu, 그리고 사용자 정의 Webhook이 포함됩니다.

## 페이지 접근 방법

관리자 콘솔에 로그인한 후 선택합니다 **알림 채널** 페이지에 접근하세요.

알림 채널은 관리자만 사용할 수 있습니다. 이 메뉴가 보이지 않는 경우, 계정 권한을 확인하려면 시스템 관리자에게 문의하십시오.

## 새 알림 채널 생성

클릭 **채널 생성**채널 이름을 입력하고 채널 유형을 선택합니다:

- **WeCom**: 로봇 웹훅 키를 입력하세요.
- **딩톡**: 전체 Webhook을 입력하세요 URL, 선택적으로 로봇 설정에 따라 시그니처 시크릿을 입력하세요.
- **Feishu**: 전체 Webhook을 입력하세요 URL, 선택적으로 로봇 설정에 따라 시그니처 시크릿을 입력하세요.
- **커스텀 웹훅**: 요청 입력 URL, HTTP 메서드 및 본문 템플릿.

채널을 활성화할지 확인한 후 클릭 **저장**.

## 커스텀 웹훅

커스텀 Webhook의 본문 템플릿은 다음 변수를 지원합니다: 

```text
{{title}}
{{body}}
{{level}}
```

기본 템플릿 예시: 

```json
{"title":"{{title}}","body":"{{body}}","level":"{{level}}"}
```

시스템이 알림을 전송할 때, 변수를 실제 제목, 내용 및 경고 수준으로 대체합니다. 

## 테스트 채널 

저장 후, 클릭 **테스트** 채널 오른쪽에서. 시스템이 테스트 메시지를 보내 Webhook 주소, 서명 및 네트워크 연결이 올바른지 확인합니다. 

채널을 생성하거나 수정한 직후, 이를 미들웨어 검사 또는 다른 비즈니스 기능에 바인딩하기 전에 즉시 테스트하는 것이 권장됩니다. 

## 활성화, 수정, 삭제 

- **활성화/비활성화**: 채널을 수정할 때 활성화 상태를 조정합니다. 비활성화되면 채널은 비즈니스 알림을 받지 않습니다. 
- **수정**: 채널 이름, 유형 및 Webhook 설정을 수정할 수 있습니다. 
- **삭제**: 더 이상 사용하지 않는 채널을 삭제합니다. 미들웨어 검사에서 참조하는 채널은 삭제 전에 반드시 바인딩 해제해야 합니다. 

## 일반 상황

- **테스트 전송 실패**: Webhook 주소, Key, Secret을 확인하세요, HTTP 메서드 및 네트워크 액세스 권한.
- **저장 실패**: 모든 필수 필드가 완료되었는지 확인하고 Webhook URL 형식이 올바른지 확인하십시오.
- **비즈니스 알림을 받지 못함**: 해당 비즈니스 페이지에서 채널이 활성화되어 선택되었는지 확인하십시오.
- **채널 삭제 불가**: 이 채널은 여전히 미들웨어 검사용으로 사용될 수 있습니다. 먼저 연결을 제거하고 검사 구성을 저장하십시오.
- **사용자 정의 웹후크 수신 콘텐츠 형식이 올바르지 않습니다.**: 본문의 템플릿이 대상 시스템의 요구 사항을 충족하는지 확인하십시오.

> 웹후크 주소 및 서명 비밀은 민감한 정보입니다. 액세스를 제한하고 스크린샷, 로그 또는 채팅 도구를 통한 공개 공유를 피하십시오.
