# 일반 도구

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 1. 페이지 개요

일반 도구 페이지에는 7개의 일반적으로 사용되는 기능이 포함되어 있습니다: JSON 포맷팅, 형식 변환, JWT 디코딩, 타임스탬프 변환, 장치 시간 확인, QR 코드 파싱, Base64 인코딩/디코딩.

1. 작업 페이지로 이동하려면 기능 카드 중 하나를 클릭하십시오.
2. 진입 후 왼쪽의 기능 목록에서 다른 도구로 직접 전환할 수 있습니다.
3. '기능 메뉴로 돌아가기'를 클릭하면 카드 홈 페이지로 돌아갑니다.

## 2. JSON 포맷팅

이 기능은 포맷, 압축 및 검증에 사용됩니다 JSON 내용.

1. 클릭JSON 서식.
2. "입력 JSON" 영역에 처리할 내용을 입력합니다, 예를 들어:

   ```json
   {"name":"MDP","enabled":true,"items":[1,2]}
   ```

3. '형식'을 클릭하면 들여쓰기가 JSON 오른쪽에 생성됩니다.
4. '압축'을 클릭하면 공백과 줄 바꿈 없이 JSON 간결한 내용이 오른쪽에 생성됩니다.
5. '복사'를 클릭하여 처리된 결과를 복사합니다.
6. '지우기'를 클릭하여 입력과 출력 내용을 제거합니다.

테스트 결과: 문자열, 불리언 값, 배열이 모두 올바르게 보존되었으며, 포맷 및 압축 기능도 정상적으로 작동합니다.

## 3. 포맷 변환

이 기능은 서로 다른 포맷 간의 변환 및 포맷팅을 지원합니다. JSON, YAML, 및 TOML 포맷 간 변환을 지원합니다.

1. "포맷 변환"을 클릭하세요.
2. "소스 포맷"에서 입력 내용의 포맷을 선택하세요.
3. "타겟 포맷"에서 원하는 출력 포맷을 선택하세요.
4. 변환할 내용을 왼쪽에 입력하세요.
5. "변환"을 클릭하면 오른쪽에 결과가 표시됩니다.
6. "포맷 교환"을 클릭하여 소스와 대상 포맷을 전환하세요.
7. "포맷"을 클릭하여 현재 내용의 들여쓰기와 레이아웃을 조정하세요.
8. "복사"를 클릭하여 출력 결과를 복사하세요.

이번에는 JSON 을(를) YAML로 변환하며, 입력:

```json
{"name":"MDP","ports":[80,443],"enabled":true}
```

변환 결과: 

```yaml
name: MDP
ports:
  - 80
  - 443
enabled: true
```

측정 결과: 필드, 배열, 불리언 값이 올바르게 변환되었습니다.

## 4. JWT 디코드

이 기능은 토큰의 헤더, 페이로드 및 서명을 파싱하는 데 사용됩니다. JWT 토큰의 헤더, 페이로드 및 서명을 파싱하는 데 사용됩니다.

1. 클릭JWT 디코드.
2. 토큰을 입력 상자에 붙여넣으세요. JWT 토큰을 입력 상자에 붙여넣으세요.
3. "디코드"를 클릭하세요.
4. 헤더에서 서명 알고리즘과 토큰 유형을 확인하세요.
5. 페이로드에서 사용자, 역할, 만료 시간 등의 정보를 확인하세요.
6. 서명의 원본 내용을 확인하세요.
7. 각 섹션의 복사 버튼을 클릭하여 파싱 결과를 복사하세요.
8. "지우기"를 클릭하여 현재 토큰과 파싱 결과를 삭제하세요.

테스트 결과: 테스트 토큰이 사용자, 역할, 만료 시간 등의 필드를 성공적으로 파싱했습니다. `HS256`, `JWT`사용자, 역할, 만료 시간.

> JWT 디코드는 토큰 구조를 보기 위한 용도이며 서버 측 서명 유효성 검사를 대체할 수 없습니다.

## 5. 타임스탬프 변환 

이 기능은 유닉스 타임스탬프와 날짜-시간 간의 양방향 변환을 지원합니다. 

### 5.1 타임스탬프를 날짜/시간으로 변환 

1. "타임스탬프 변환"을 클릭하세요. 
2. "타임스탬프(초 또는 밀리초)"에 10자리 초 또는 13자리 밀리초 타임스탬프를 입력하세요. 
3. 상단의 "변환"을 클릭하세요. 
4. "변환 결과"에서 날짜와 시간을 확인하세요. 
5. 결과 옆의 복사 버튼을 클릭하여 내용을 복사하세요. 

### 5.2 날짜/시간을 타임스탬프로 변환 

1. '를 입력하세요YYYY-MM-DD HH:mm:ss' 또는 ISO "날짜 시간" 필드에서 시간 형식을 지정합니다. 
2. 아래의 "변환"을 클릭합니다. 
3. "변환 결과(초)"에서 유닉스 타임스탬프를 확인합니다. 
4. "현재 시간"을 클릭하여 현재 타임스탬프와 날짜를 빠르게 입력합니다. 
5. "지우기"를 클릭하여 모든 내용을 삭제합니다. 

테스트 결과: '1704067200'이 날짜 시간으로 성공적으로 변환되었으며, 날짜 시간도 초 단위 타임스탬프로 올바르게 변환될 수 있습니다. 

> 교차 시간대 데이터를 확인할 때 먼저 업무 시간이 UTC 또는 현지 시간대를 사용하는지 명확히 확인합니다. 

## 6. 기계 시간 확인

이 기능은 현재 `app=ws-gateway` 에서 모든 Pod의 시간을 확인하고 NAMESPACE 시간 편차가 30초 이상인 인스턴스를 강조 표시하는 데 사용됩니다.

1. "기계 시간 확인"을 클릭합니다.
2. 오른쪽 상단의 "새로 고침"을 클릭합니다.
3. 현재 NAMESPACE 및 쿼리 레이블을 확인합니다.
4. 시스템에서 계산한 기준 시간을 확인하며, 이는 모든 Pods의 중간 시간입니다.
5. 각 Pod가 위치한 노드, 유닉스 타임스탬프 및 읽을 수 있는 시간을 확인합니다.
6. "기준과의 차이"와 "상태"를 확인합니다.
7. 편차가 30초를 초과하면, 노드의 NTP/Chrony, 가상 머신 시간 및 시간대 설정을 확인하십시오.

테스트 결과: 1 `ws-gateway` Pod가 반환되었으며, 기준 시간과의 편차는 `0s` 이며 상태는 "정상"입니다.

## 7. QR 코드 분석

이 기능은 QR 코드 이미지를 업로드하고 그 안에 포함된 텍스트, 링크 또는 기타 콘텐츠를 추출하는 데 사용됩니다.

1. "QR 코드 분석"을 클릭하십시오.
2. "파일 선택"을 클릭하십시오.
3. 로컬 장치에서 선명한 QR 코드 이미지를 선택하십시오.
4. 페이지에 이미지 미리보기가 표시된 후, 아래의 "분석 결과"를 확인하십시오.
5. 결과를 QR 코드의 예상 내용과 비교하여 일치하는지 확인하십시오.
6. "복사"를 클릭하여 분석된 콘텐츠를 복사하십시오.
7. "지우기"를 클릭하여 이미지와 분석 결과를 삭제하십시오.

테스트 결과: 테스트 QR 코드를 성공적으로 업로드하고, 미리보기하며, 올바르게 분석할 수 있습니다.

## 8. Base64 인코딩 및 디코딩

이 기능은 일반 텍스트와 Base64 콘텐츠 간 양방향 변환에 사용됩니다.

### 8.1 Base64 인코딩

1. "Base64 인코딩 및 디코딩"을 클릭하십시오.
2. 왼쪽에 일반 텍스트를 입력합니다.
3. "인코드"를 클릭합니다.
4. 오른쪽에서 Base64 인코딩된 결과를 확인합니다.

### 8.2 Base64 디코딩

1. 왼쪽에 Base64 내용을 입력합니다.
2. "디코드"를 클릭하세요.
3. 오른쪽에서 복원된 텍스트를 확인합니다.
4. 결과를 복사하려면 "복사"를 클릭합니다.
5. 입력과 출력을 지우려면 "지우기"를 클릭합니다.

테스트 결과:

```text
MDPTEST → TURQ5rWL6K+V
TURQ5rWL6K+V → MDPTEST
```

중국어 UTF-8 내용을 정상적으로 상호 변환할 수 있습니다.
