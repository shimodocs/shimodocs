# MongoDB 도구

[← ShimoDocs Suite 배포 문서](../../../README.md)

> [!TIP]
>
> MongoDB 은 운영 플랫폼에서 보기를 위해 사용됩니다. MongoDB 데이터베이스, 컬렉션 및 문서 내용. 문서 기반 데이터, 중간 상태, 작업 기록 및 유연한 구조를 가진 비즈니스 데이터를 문제 해결하는 데 적합합니다.
>
> 이 페이지는 데이터베이스 또는 컬렉션별 검색을 지원하며, 컬렉션을 선택한 후 MongoDB JSON 조건부 쿼리를 사용할 수 있습니다.

## 1. 접근 MongoDB

1. <서비스 이름>에 로그인 **MDP 운영 플랫폼**.
2. 선택 **시스템 서비스** 상단에 있습니다.
3. 확장 **미들웨어 도구** 왼쪽 탐색 막대에 있습니다.
4. 선택 **MongoDB**.

페이지의 왼쪽에는 데이터베이스 및 컬렉션 트리가 표시되고, 오른쪽에는 쿼리 조건과 쿼리 결과가 표시됩니다.

## 2. 데이터베이스 또는 컬렉션 검색

1. 입력 DATABASE_NAME 왼쪽 상단의 검색 상자에 데이터베이스 또는 컬렉션 이름 키워드를 입력합니다.
2. 필터링된 트리 목록을 확인합니다.
3. 검색 상자를 지우면 모든 데이터베이스 표시가 복원됩니다.

## 3. 데이터베이스를 확장하고 컬렉션 선택

1. 왼쪽 트리에서 대상 데이터베이스를 찾습니다.
2. 데이터베이스 왼쪽의 확장 아이콘을 클릭하여 컬렉션 목록을 로드합니다.
3. 대상 컬렉션을 선택합니다.
4. 오른쪽 페이지는 기본 조건으로 한 번 자동 쿼리를 수행합니다. `{}`.

> 데이터베이스만 선택하면 컬렉션 쿼리가 실행되지 않습니다; 먼저 특정 컬렉션을 선택해야 하며, 그러면 오른쪽에 쿼리 영역이 표시됩니다.

## 4. 쿼리 조건 입력

1. 서버 연결 정보를 입력하세요. MongoDB JSON 오른쪽의 쿼리 입력 상자에 쿼리 조건을 입력합니다.
2. 반환할 결과 수를 선택합니다, 지원 `limit: 10`, `limit: 20`, `limit: 50`.
3. 클릭 **조회**.

쿼리 예시: 

```json
{
  "_id": "task-123"
}
```

필드별 쿼리 예시:

```json
{
  "status": "running"
}
```

## 5. 쿼리 결과 확인

1. 쿼리가 완료되면 오른쪽 결과 영역에서 반환된 문서를 확인합니다.
2. 기본적으로 결과는 JSON 형식으로 표시됩니다.
3. 클릭 **확장** 현재 문서를 확장합니다.
4. 클릭 **축소** 현재 문서를 축소합니다.
5. 클릭 **복사** 현재 문서를 복사합니다. JSON.

## 6. 일반적인 문제 해결 시나리오

| 시나리오 | 운영 제안 |
| --- | --- |
| 문서가 존재하는지 확인합니다. | 컬렉션을 선택한 후, `_id` 또는 비즈니스 ID로 쿼리합니다. |
| 작업 상태 확인 | 작업 ID로 쿼리하고 status 필드와 update time 필드를 확인합니다. |
| 기록 유형 찾기 | 상태, 유형, 생성 시간과 같은 필드 조합을 사용하여 쿼리합니다. |
| 결과가 없습니다. | 올바른 데이터베이스, 컬렉션, 필드 이름 및 필드 유형이 선택되었는지 확인하세요. |
| 문제 해결 결과를 제거해야 합니다. | 클릭 **복사** 단일 결과에서. |
