# Redis 도구

[← ShimoDocs Suite 배포 문서](../../../README.md)

> [!TIP]
>
> Redis 은 운영 플랫폼에서 보기를 위해 사용됩니다. Redis 인스턴스, DB, 키 목록 및 키 세부 정보가 있습니다. 캐시, 세션, 분산 잠금, 속도 제한 카운터 및 단기 상태를 문제 해결할 때 일반적으로 사용됩니다.
>
> 이 페이지는 키 또는 키 접두사로 검색을 지원하며, 키 타입, TTL및 현재 값을 표시합니다.

## 1. 접근 Redis

1. <서비스 이름>에 로그인 **MDP 운영 플랫폼**.
2. 선택 **시스템 서비스** 상단에 있습니다.
3. 확장 **미들웨어 도구** 왼쪽 탐색 막대에 있습니다.
4. 선택 **Redis**.

페이지 왼쪽은 키 조회 영역이고, 오른쪽은 키 세부 정보 영역입니다.

## 2. 선택하기 Redis 인스턴스 및 DB

1. 왼쪽 상단의 첫 번째 드롭다운에서 선택하세요 Redis 인스턴스.
2. 두 번째 드롭다운에서 DB를 선택하세요, 예를 들어 `db0`.
3. 페이지가 현재 인스턴스와 DB를 기반으로 키 목록을 불러옵니다.

DB 목록이 비어 있거나 페이지에 오류가 보고되면 먼저 다음 사항을 확인해 주십시오 Redis 인스턴스 구성은 정상입니다.

## 3. 검색 키

1. 검색 상자에 키 이름이나 키 접두어를 입력하십시오.
2. 검색 버튼을 클릭하거나 Enter 키를 눌러 쿼리를 실행하십시오.
3. 왼쪽에서 키 목록을 확인하십시오.
4. 현재 조건에서 목록을 다시 불러와야 하는 경우, 새로 고침 아이콘을 클릭하세요.

검색 상자 안내 문구는 "키 이름을 입력하세요, 퍼지 검색 지원"입니다. 페이지에는 일치하는 키 유형이 표시됩니다. TTL.

## 4. 키 목록 보기

키 목록에는 다음 정보가 포함됩니다:

| 정보 | 설명 |
| --- | --- |
| 유형 | 그 Redis 키의 유형, 예를 들어 `string`, `hash`, `list`, `set`, `zset`. |
| 키 이름 | 현재 일치하는 전체 키. |
| TTL | 키의 남은 만료 시간; 현재 키에 만료가 없는 경우 페이지에는 "영구"로 표시됩니다. |

## 5. 키 세부 정보 보기

1. 왼쪽 키 목록에서 대상 키를 클릭합니다.
2. 오른쪽 세부 영역에는 키 이름, 유형, TTL및 특정 값이 표시됩니다.
3. 현재 키 세부 정보를 새로 고치려면 세부 제목 영역의 새로 고침 버튼을 클릭합니다.

다음은 다양한 표시 방법입니다:

| 유형 | 표시 방법 |
| --- | --- |
| `string` | 텍스트 상자에 전체 값을 표시합니다. |
| `hash` | 테이블에 필드 키와 값을 표시합니다. |
| `list` / `set` | 테이블에 요소 목록을 표시합니다. |
| `zset` | 테이블에 점수와 멤버를 표시합니다. |

## 6. 필드 값 복사

1. 키 세부 정보 테이블에서 복사하려는 필드나 값을 찾습니다.
2. 해당 내용을 클릭합니다.
3. 페이지가 해당 내용을 클립보드로 복사합니다.

> `string` 유형은 텍스트 상자에 표시되며 텍스트를 선택하여 직접 복사할 수 있으며, 테이블 유형은 값을 클릭하여 복사할 수 있습니다.

## 7. 일반적인 문제 해결 시나리오

| 시나리오 | 제안된 조치 |
| --- | --- |
| 캐시가 존재하는지 확인 | 인스턴스 및 DB를 선택한 후 전체 키 또는 접두사로 검색합니다. |
| 캐시가 만료되었는지 확인 | 키 목록 또는 세부 정보에서 확인합니다. TTL  |
| 해시 필드 보기 | 오른쪽 테이블의 필드와 값을 보려면 키를 클릭하세요. |
| ZSet 정렬 데이터를 보기 | 클릭 `zset` 키를 클릭하여 점수(Scores)와 멤버를 확인하세요. |
| 같은 키의 최신 상태를 검토하세요 | 세부 영역에서 새로 고침 버튼을 클릭하세요. |
