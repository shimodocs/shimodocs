# Kafka 도구

[← ShimoDocs Suite 배포 문서](../../../README.md)

> [!TIP]
>
> 사용자는 Kafka 도구를 통해 볼 수 있음 Kafka Redpanda 콘솔을 통해 클러스터 상태, 토픽, 메시지, 컨슈머 그룹 및 파티션 정보를 확인할 수 있으며, 메시지 작성, 컨슈머 백로그 및 비동기 링크 문제를 해결할 때 일반적으로 사용됩니다.
>
> 페이지가 성공적으로 로드되면 Redpanda 콘솔이 내장됩니다. MDP.

## 1. 접근 Kafka

1. 운영 플랫폼에 로그인하고, **MDP 운영 플랫폼**.
2. 선택 **시스템 서비스** 상단에 있습니다.
3. 확장 **미들웨어 도구** 왼쪽 탐색 막대에 있습니다.
4. 선택 **Kafka**.
5. Redpanda 콘솔이 로드될 때까지 기다리세요.

콘솔이 준비되지 않은 경우, 페이지에서 시작 중임을 알리거나 시작 실패를 알리고 오류 정보를 표시합니다.

## 2. 클러스터 개요 보기

입력한 후 Kafka, **기본적으로 개요가 표시됩니다.** 기본적으로 개요가 표시됩니다.

다음 정보를 확인할 수 있습니다:

| 정보 | 설명 |
| --- | --- |
| 클러스터 상태 | 클러스터 실행 상태. |
| 클러스터 저장 용량 | 현재 클러스터 저장 용량. |
| 클러스터 버전 | 클러스터 버전 정보. |
| 온라인 브로커 | 온라인 브로커 수. |
| 토픽 | 토픽 수. |
| 복제본 | 복제본 수. |
| 브로커 세부 정보 | 브로커 ID, 상태 및 크기. |

## 3. 토픽 보기

1. Redpanda 콘솔의 왼쪽 탐색에서 선택 **토픽**.
2. 토픽 목록에서 대상 토픽을 찾습니다.
3. 토픽을 클릭하여 세부 정보 페이지로 들어갑니다.
4. 토픽의 파티션, 메시지 및 구성과 같은 정보를 확인합니다.

토픽 문제 해결은 일반적으로 다음에 중점을 둡니다:

| 정보 | 설명 |
| --- | --- |
| 파티션 | 토픽의 파티션 상태입니다. |
| 메시지 | 토픽의 메시지 목록입니다. |
| 구성 | 보존 정책과 같은 토픽 구성입니다. |

## 4. 메시지 보기

1. 대상 토픽에 들어갑니다.
2. 메시지 보기 영역을 엽니다.
3. 페이지에 제공된 필터를 사용하여 파티션, 위치 또는 시간 범위를 선택합니다.
4. 메시지 키, 값, 헤더, 파티션, 오프셋 및 타임스탬프를 확인합니다.

> 메시지 내용에는 비즈니스 필드가 포함될 수 있습니다. 문제 해결 시 비즈니스 ID, 키, 오프셋 및 타임스탬프를 기준으로 먼저 찾아보세요.

## 5. 컨슈머 그룹 보기

1. Redpanda 콘솔에서 선택합니다 **컨슈머 그룹** 왼쪽 내비게이션에서.
2. 대상 컨슈머 그룹을 검색하거나 선택합니다.
3. 컨슈머 그룹 세부 정보로 들어갑니다.
4. 컨슈머 그룹과 연결된 토픽, 파티션, 현재 오프셋, 로그 끝 오프셋 및 지연(Lag)을 확인합니다.

## 6. 컨슈머 백로그 확인

| 상태 | 설명 |
| --- | --- |
| 지연(Lag)이 0입니다. | 현재 컨슈머 그룹에는 백로그가 없습니다. |
| 지연(Lag)이 지속적으로 증가하고 있습니다. | 소비 속도가 생성 속도보다 낮습니다. |
| 지연은 변하지 않지만 0은 아닙니다. | 중지된 소비자, 파티션 차단, 또는 소비 실패가 있을 수 있습니다. |
| 단일 파티션의 지연이 현저히 높습니다. | 이는 해당 파티션에서 핫 키나 비정상적 소비 때문일 수 있습니다. |

## 7. 브로커 보기

1. 개요 페이지에서 찾기 **브로커 세부정보**.
2. 브로커 ID, 실행 상태, 저장소 크기를 확인합니다.
3. 클릭 **보기** 브로커 세부정보를 보려면.

## 8. 일반적인 문제 해결 시나리오

| 시나리오 | 운영 제안 |
| --- | --- |
| 정상적으로 작동하는지 확인합니다. Kafka 정상적으로 작동하는지 확인합니다. | 개요에서 클러스터 상태와 온라인 브로커를 확인합니다. |
| 메시지가 기록되고 있는지 확인합니다. | 주제로 이동하여 메시지를 확인합니다. |
| 소비자 지연 문제 해결 | 소비자 그룹으로 이동하여 지연(Lag)을 확인합니다. |
| 단일 메시지 찾기 | 주제, 파티션, 오프셋, 키 또는 타임스탬프로 검색합니다. |
| 주제 구성 확인 | 주제 세부정보로 이동하여 구성을 확인합니다. |
