# gRPC 도구

[← ShimoDocs Suite 배포 문서](../../../README.md)

> [!TIP]
>
> 사용자는 gRPC 도구는 내부 서비스에 연결하고, gRPC 서비스 및 메서드를 조회하며, 단항(Unary) 메서드 디버그 호출을 시작하는 데 사용됩니다.
>
> 이 페이지는 대상을 선택하는 세 가지 방법을 지원합니다: 주소를 수동으로 입력, 선택 Kubernetes 서비스, 또는 Pod로 선택하세요.

## 1. 접근 gRPC

1. 운영 플랫폼에 로그인하고, **MDP 운영 플랫폼**.
2. 선택 **시스템 서비스** 상단에 있습니다.
3. 확장 **미들웨어 도구** 왼쪽 탐색 막대에 있습니다.
4. 선택 **gRPC**.

페이지는 먼저 연결할 서비스를 선택할 수 있는 "대상" 영역을 표시합니다. gRPC 

## 2. 대상 선택 방법

페이지는 세 가지 대상 모드를 제공합니다:

| 모드 | 설명 |
| --- | --- |
| 수동 | 주소를 수동으로 입력합니다, 예: gRPC  `svc-user:50051`. |
| 서비스 | 클러스터, 네임스페이스, 서비스 및 포트로 대상을 선택합니다. |
| Pod | 클러스터, 네임스페이스, Pod 및 포트로 대상을 선택합니다. |

## 3. 수동 연결 

1. 선택 **수동**. 
2. 입력하십시오 gRPC 주소 입력 상자에 서비스 주소를 입력합니다. **주소** 입력 상자 
3. 클릭 **연결**. 
4. 연결이 성공하면 페이지가 서비스 / 메소드 디버깅 작업 공간으로 들어갑니다. 

## 4. 서비스로 연결

1. 선택 **서비스**.
2. 대상 클러스터와 네임스페이스를 선택합니다.
3.  **서비스 / 포트** 드롭다운에서 대상 서비스와 포트를 선택합니다.
4. 서비스 목록이 업데이트되지 않으면 클릭하세요 **새로 고침**.
5. 클릭 **연결**.

## 5. Pod로 연결

1. 선택 **Pod**.
2. 대상 클러스터와 네임스페이스를 선택합니다.
3.  **Pod / 포트** 드롭다운에서 대상 Pod와 포트를 선택합니다.
4. Pod 목록이 업데이트되지 않으면 클릭하십시오 **새로 고침**.
5. 클릭 **연결**.

## 6. 서비스 및 메서드 선택

연결이 성공하면 페이지가 서비스 목록, 메서드 목록, 요청 영역, 응답 영역으로 나뉩니다.

1. 왼쪽의 서비스 목록에서 대상 서비스를 선택합니다.
2. 서비스 검색 상자를 사용하여 서비스를 필터링할 수 있습니다.
3. 메서드 목록에서 대상 메서드를 선택합니다.
4. 전환 가능한 메서드 필터 옵션: `Unary`, `Streaming`, `All`.
5. 메서드 검색 상자를 사용하여 메서드를 필터링할 수 있습니다.

> 현재 페이지는 단항(Unary) 메서드 호출만 지원합니다. 스트리밍 메서드는 사용할 수 없는 것으로 표시됩니다.

## 7. 요청 파라미터 입력

요청 영역은 두 가지 입력 방식을 지원합니다:

| 방법 | 설명 |
| --- | --- |
| 폼 모드 | 페이지는 메서드 입력 필드를 기반으로 폼을 생성합니다. |
| JSON 모드 | 언제 **JSON 모드** 가 활성화되면 전체 요청 본문을 직접 편집할 수 있습니다. JSON  |

폼 모드 사용 단계:

1. 대상 메서드를 선택합니다.
2. 요청 파라미터를 필드별로 입력합니다.
3. 열거된 필드를 선택하려면 드롭다운을 사용하세요.
4. 선택 `true` 또는 `false` 부울 필드의 경우.
5. 반복 필드에는 페이지에 표시된 대로 쉼표를 사용하세요.

사용 단계 JSON 모드:

1. 스위치를 켭니다. **JSON 모드** 스위치를 켭니다.
2. 텍스트 상자에 전체를 입력하세요. JSON 텍스트 상자에 전체 내용을 입력하세요.
3. 형식이 유효한지 확인하세요. JSON 형식이 유효한지 확인합니다.

## 8. 메타데이터 입력

1. 확장 **메타데이터** 요청 영역에 입력하세요.
2. 키와 값을 입력하세요.
3. 여러 메타데이터 항목을 추가하려면 클릭하세요. **추가**.
4. 행을 삭제하려면 삭제 아이콘을 클릭하세요.

메타데이터는 일반적으로 인증 정보, 요청 ID 또는 비즈니스 컨텍스트를 전달하는 데 사용됩니다.

## 9. 호출을 시작하고 응답 보기

1. 대상, 서비스, 메서드, 요청 본문 및 메타데이터를 확인하세요.
2. 클릭 **호출** 페이지 오른쪽 상단에서 호출하세요.
3. 응답 영역에서 상태, 경과 시간, 응답 메타데이터 및 응답을 확인하세요. JSON 응답 영역에서 상태, 경과 시간, 응답 메타데이터 및 응답을 보세요.
4. 호출이 실패하면 응답 영역에 오류 상태 및 오류 내용이 표시됩니다.

## 10. 대상 전환 또는 재연결

1. 클릭 **연결** 현재 대상의 서비스 정의를 다시 로드하려면 상단에서.
2. 클릭 **대상 변경** 대상 선택 페이지로 돌아가려면.
3. 대상을 전환한 후에는 다시 연결하고 서비스 / 메소드를 다시 선택해야 합니다.

## 11. 일반적인 문제 해결 시나리오

| 시나리오 | 작업 제안 |
| --- | --- |
| 서비스 연결 가능 여부 확인 | 대상을 선택하고 클릭 **연결** 서비스 목록이 로드되는지 확인합니다. |
| 인터페이스 메소드 찾기 | 서비스 검색 및 메소드 검색 필터링 사용. |
| 쿼리 인터페이스 디버그 | Unary 메소드를 선택하고 요청 매개변수를 입력한 후 클릭 **호출**. |
| 컨텍스트를 통과해야 함 | 메타데이터를 확장하고 해당 키와 값을 입력합니다. |
| 응답이 비어 있거나 실패 | 응답 상태, 오류 내용 및 메타데이터 확인. |
