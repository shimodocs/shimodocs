# 플랫폼 사용자 관리

[← ShimoDocs Suite 배포 문서](../../../README.md)

## 기능 개요

시스템 사용자 관리는 관리 백엔드에서 사용자 계정을 유지 관리하는 데 사용됩니다 MDP 사용자 생성, 기본 정보 편집, 재설정, PASSWORD이중 인증 관리 및 사용자 삭제를 포함합니다.

## 페이지 접근 방법

시스템 관리자 계정으로 로그인한 후, 선택하십시오 **시스템 사용자 관리** 페이지에 접근하세요.

이 메뉴는 지정된 시스템 관리자 계정에서만 접근할 수 있습니다. 이 메뉴가 보이지 않는 경우 시스템 관리자에게 문의하십시오.

## 사용자 보기

이 페이지에서는 사용자 닉네임, USERNAME, 역할, 이메일 주소, 연락처 정보, 마지막 로그인 시간 및 등록 시간을 표시하며, 총 사용자 수, 최근 활동 사용자, 관리자 계정 등의 개요 정보를 제공합니다.

목록 페이지네이션을 통해 모든 사용자를 볼 수 있습니다.

## 새 사용자 생성

클릭 **새 사용자 생성** 다음 정보를 입력하세요:

- **닉네임**: 필수 항목, 페이지 표시용입니다.
- **USERNAME**: 필수 항목, 시스템 로그인용입니다.
- **이메일**: 필수 항목, 유효한 이메일 주소를 제공해야 합니다.
- **연락처 정보**: 선택 사항입니다.
- **역할**: 일반 사용자 또는 관리자 중 선택하세요.

생성 후 시스템에서 초기 PASSWORD를 생성합니다. 이 값은 즉시 복사하여 안전한 방법으로 사용자에게 제공하세요. 이 창을 닫으면 PASSWORD 를 다시 볼 수 없을 수도 있습니다.

### 사용자 역할 설명

- 관리자
  - 글로벌 권한을 기반으로 모든 페이지 사용 가능
    - ShimoDocs Suite
    - 문서 센터
    - 시스템 서비스
- 일반 사용자
  - 글로벌 권한을 기반으로 한 페이지 사용 범위
    - ShimoDocs Suite
    - 문서 센터
    - 시스템 서비스 (숨김)

## 사용자 정보 편집

사용자의 오른쪽에 있는 편집 버튼을 클릭하여 별명, 이메일 및 연락처 정보를 수정합니다. USERNAME 생성 후에는 이 페이지에서 수정할 수 없습니다.

## 재설정 PASSWORD

재설정 버튼을 클릭하고 작업을 확인하면, 시스템이 새로운 PASSWORD 을 생성합니다. PASSWORD원본 PASSWORD 즉시 무효가 됩니다.

새로운 것을 복사하여 제대로 저장하고, PASSWORD신뢰할 수 있는 채널을 통해 해당 사용자에게 전달하며, 사용자가 가능한 빨리 로그인하여 변경하도록 알리십시오. PASSWORD 

## 이중 인증 관리

- **2FA 활성화 또는 비활성화**: 사용자의 행에서 스위치를 사용하고 확인 창에서 계속 진행하십시오.
- **2FA 재설정**: 시스템이 새로운 QR 코드와 시크릿을 생성하며, 원래의 인증 정보는 무효가 됩니다.

재설정 후 사용자는 Authenticator와 같은 인증기를 사용하여 QR 코드와 시크릿을 다시 스캔하고 연결해야 합니다. QR 코드와 시크릿은 민감한 자격 증명이므로 공개 채널로 전송하지 마십시오. 

2FA 연결

Authenticator로 스캔하여 추가하고, 이후 로그인 시 동적 6자리 2FA를 사용하십시오.

## 사용자 삭제

삭제 버튼을 클릭하고 확인하면 사용자 계정이 제거됩니다. 삭제 작업은 되돌릴 수 없으므로, 계정이 더 이상 사용되지 않는지 확인하고 필요한 데이터 및 권한 인수인계를 완료한 후 실행하십시오.

## 일반 상황

- **사용자 생성 불가**: 다음을 확인하십시오. USERNAME 가 중복되었습니다. 이메일 형식은 올바르며, 모든 필수 항목이 완전합니다.
- **사용자가 로그인할 수 없습니다.**: 다음을 확인하십시오. USERNAME 그리고 PASSWORD 이 올바른지 확인하십시오. 필요하다면 PASSWORD.
- **사용자가 2FA 인증을 완료할 수 없습니다.**: 시스템 시간이 올바른지 확인하거나, 사용자의 2FA를 재설정하고 다시 연결하십시오.
- **사용자 관리 메뉴가 보이지 않습니다.**: 현재 계정이 지정된 시스템 관리자 계정이 아닐 수 있습니다.
- **사용자가 실수로 삭제되었습니다.**: 삭제 작업은 바로 되돌릴 수 없습니다. 계정을 다시 생성하고 관련 권한을 재설정해야 합니다.

> 생성, 재설정 시 생성된 자격 증명 PASSWORD, 그리고 2FA 재설정 시 생성된 자격 증명은 즉시 저장하고 계정 소유자에게만 제공해야 합니다.
