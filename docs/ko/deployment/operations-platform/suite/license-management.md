# 라이선스 관리

[← ShimoDocs Suite 배포 문서](../../README.md)

> [!TIP]
>
> 라이선스 관리는 서버 기계 코드를 얻고, ShimoDocs Suite라이선스를 작성 및 발행하며, 현재 라이선스 상태, 라이선스 범위 및 실행 중인 머신 정보를 확인하는 데 사용됩니다. 처음 활성화 시, 
> 라이선스 만료 시 또는 서버 노드가 변경될 때 갱신할 수 있습니다, 업데이트할 수 있습니다 ShimoDocs Suite 이 페이지를 통해 라이선스를 취득하세요.

> 라이선스를 작성한 후에는 라이선스를 공개하기 전에 검증 결과를 확인해야 합니다. 작성만 하거나 임시로 저장하는 것만으로는 라이선스가 공식적으로 효력을 갖지 않습니다.
- 유료 고객인 경우, 복사한 기계 코드를 기술 지원 팀에 보내주십시오. ShimoDocs 기계 코드를 기반으로 해당 라이선스를 생성하고 라이선스 정보를 보내드리겠습니다.
- 무료 체험을 원하시면, 공식 웹사이트 라이선스 신청으로 가주세요 **ShimoDocs **: https://shimo.net/license 신청 정보를 입력하고 기계 코드를 붙여 넣으십시오.
- 제출 후 시스템이 자동으로 체험용 라이선스를 생성합니다. 생성된 후 10분 이내에 복사하여 작성하십시오. 만료되면 다시 신청하십시오.
## 1. 라이선스 관리에 접근

1. 운영 플랫폼에 로그인하고, **MDP 운영 플랫폼**.
2. 선택 **ShimoDocs Suite** 상단에 있습니다.
3. 선택 **라이선스 관리** 왼쪽 탐색 막대에 있습니다.

페이지에는 라이선스 활성화, 라이선스 정보, 기계 코드 비교 및 기계 정보 영역이 포함되어 있습니다.

## 2. 신청 ShimoDocs Suite 라이선스

승인 신청을 하기 전에 먼저 서버 노드가 안정적인지 확인하고, 임시로 노드가 추가되거나 제거되거나 교체되지 않도록 해주십시오. ShimoDocs Suite  

### 1. 모든 기계 코드를 복사합니다 

1. '권한 활성화' 영역에서 '한 번에 모든 기계 코드 복사'를 클릭합니다. 
2. 페이지에 복사가 성공했다는 메시지가 표시되는지 확인합니다. 
3. 기계 코드를 승인 신청 자료에 저장합니다. 

### 2. 승인 신청 정보 제출

모든 기계 코드 및 승인 요구 사항을 제출합니다 ShimoDocs 라이선스를 생성하기 위해 ShimoDocs Suite 서비스 담당자에게 제출합니다.

신청 시 다음 정보를 확인하는 것이 권장됩니다:

| 정보 | 설명 |
| --- | --- |
| 승인된 제품 | ShimoDocs Suite. |
| 라이선스 이름 및 회사 | 라이선스에 표시될 이름과 회사 |
| 좌석 수 | 라이선스를 사용할 수 있는 최대 좌석 수 |
| 사용 기간 | 제품 라이선스의 시작 및 만료 시간 |
| 판매 후 서비스 기간 | 판매 후 서비스의 시작 및 만료 시간 |
| 사용 가능한 스위트 | 활성화해야 하는 문서 또는 기능 모음의 유형. |
| AI 기능 | AI 기능을 활성화해야 하는지 여부. |
| 머신 코드 | 현재 실행 중인 모든 서버 머신 코드 ShimoDocs Suite. |

## 3. 권한 작성 및 확인

새 라이선스를 받은 후, 아래 단계를 따라 시스템에 작성하십시오.

### 1. 라이선스 작성

1. "권한 작성"을 "권한 활성화" 영역에서 클릭합니다.
2. 받은 전체 라이선스 내용을 입력 상자에 붙여넣습니다.
3. 라이선스 내용이 완전하고, 누락되거나 여분의 공백이 없는지 확인합니다.
4. "임시 저장"을 클릭합니다.

### 2. 라이선스 확인 결과 확인

임시 저장 후, 시스템이 새 라이선스를 검증하고 다음 결과를 표시합니다:

| 검증 결과 | 설명 | 제안된 조치 |
| --- | --- | --- |
| 불일치 | 새 라이선스의 핵심 정보가 현재 환경과 일치하지 않습니다. | 머신 코드, 애플리케이션 유형, 버전 및 권한 범위를 확인합니다. 올바른지 확인한 후, 라이선스를 다시 받으십시오. |
| 변경됨 | 새 라이선스의 일부 정보가 현재 라이선스와 다릅니다. | 원래 값, 새 값 및 판단 결과를 페이지에서 확인하여 변경 사항이 이 신청과 일치하는지 확인하십시오. |
| 통과 | 해당 검증 항목이 통과되었습니다. | 다른 권한 정보를 계속 확인하십시오. |

페이지에 "변경됨" 항목이 있고 변경 사항이 이 권한 신청과 일치하면 "임시 저장 확인"을 클릭하십시오.

> 예상치 못한 '불일치' 또는 '변경됨'이 발생하면 먼저 릴리스를 중지하고 신청 정보와 현재 운영 환경을 다시 확인하십시오.

## 4. 권한 해제

검증 및 임시 저장이 완료되면 페이지에 해제할 라이선스 정보가 표시됩니다.

### 사전 릴리스 확인

다음 항목을 주의 깊게 확인하십시오:

- 라이선스 이름
- 사용자 수 제한
- 시작 시간 및 만료 시간
- 신청 ID
- 서버 머신 코드

정보가 정확함을 확인한 후 "라이선스 발행"을 클릭하십시오.

배포가 완료된 후, 업데이트된 권한 상태 및 권한 정보를 보려면 페이지를 새로 고치십시오.

## 5. 권한 정보 보기

'권한 정보' 섹션에는 현재 활성화된 라이선스 내용이 표시됩니다.

### 권한 정보 필드 설명

| 필드 | 설명 |
| --- | --- |
| 권한 이름 | 현재 라이선스의 권한 이름입니다. |
| 권한 부여 회사 | 라이선스가 속한 회사입니다. |
| 제품 버전 | 현재 권한에 적용되는 제품 버전입니다. |
| 배포 버전 | 현재 권한의 배포 유형입니다. |
| 애플리케이션 유형 | 현재 라이선스에 적용되는 제품 유형입니다. |
| 테넌트 수 | 현재 라이선스로 허용되는 최대 테넌트 수입니다. |
| 좌석 수 | 현재 라이선스로 허용되는 최대 좌석 수입니다. |
| 제품 사용 기간 | 제품 권한의 시작 및 만료 날짜입니다. |
| 판매 후 서비스 기간 | 사후 서비스의 시작 및 만료 날짜입니다. |
| 서버 수 | 라이선스에 바인딩된 서버 수입니다. |
| AI 기능 | 현재 라이선스가 AI 기능을 활성화했는지 여부. |
| 사용 가능한 스위트 | 현재 라이선스에서 허용된 문서 유형 또는 스위트. |

## 6. 기계 코드 비교 결과 확인

권한 정보 아래에 라이선스에 있는 기계 코드와 현재 실행 중인 서버 간의 비교 결과가 표시됩니다.

| 결과 | 설명 |
| --- | --- |
| 인증서의 머신 | 현재 라이선스에 이미 등록된 서버 수. |
| 실제 머신 | 현재 시스템에서 감지한 실행 중인 서버 수. |
| 일치 | 라이선스의 기계 코드가 현재 서버와 일치합니다. |
| 불일치 | 현재 라이선스에 등록되지 않은 서버가 있거나, 라이선스에 있는 기계가 변경되었습니다. |
| 누락 | 라이선스에 등록된 기계가 현재 시스템에서 감지되지 않습니다. |

인증서의 기계 수가 실제 기계 수와 일치하지 않거나, 페이지에 '불일치' 또는 '누락'이 표시되면 '기계 코드 복사'를 클릭하고 현재 기계 코드를 사용하여 라이선스를 다시 신청하십시오.

> 페이지 상단에 기계 코드 불일치를 나타내는 카운트다운 프롬프트가 표시되면, 연속적인 권한 부여를 위해 프롬프트 기간 내에 서버 정보 확인 또는 라이센스 교체를 완료하십시오.

## 7. 기계 정보 보기

'기계 정보' 섹션에서는 현재 실행 중인 서버 노드를 표시합니다.

### 기계 정보 필드 설명

| 필드 | 설명 |
| --- | --- |
| 서버 | 현재 서버 노드의 이름 또는 주소. |
| 운영 체제 | 서버가 현재 사용하는 운영 체제. |

| 아키텍처 | 서버의 시스템 아키텍처. |
| 기계 코드 | 라이센스를 생성하고 바인딩하는 데 사용되는 서버의 고유 식별자. |

## 8. 권한 업데이트 결과 확인

라이센스 해제를 완료한 후, 다음 순서로 확인하는 것이 권장됩니다:

1. 권한 관리 페이지를 새로고침하여 권한 상태가 정상인지 확인합니다.
2. 인가 이름, 좌석 수, 사용 기간, 사용 가능한 스위트, 그리고 AI 기능을 확인합니다.
3. 인증서의 기기 수가 실제 기기 수와 일치하는지 확인합니다.
4. 기기 코드 비교에서 예상치 못한 '불일치' 또는 '누락' 결과가 없는지 확인합니다.
5. <서비스 이름>에 로그인 ShimoDocs Suite 권한이 부여된 문서 유형과 기능을 정상적으로 사용할 수 있는지 확인합니다.

> 서버 노드를 교체, 추가 또는 제거한 후에는 이 페이지로 돌아와 기기 코드 비교 결과를 확인하는 것이 좋습니다. 기기 코드가 변경되면 모든 새로운 기기 코드를 사용하여 라이선스를 다시 신청하고 해제해야 합니다.
