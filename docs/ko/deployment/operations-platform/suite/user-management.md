# 스위트 사용자 관리

[← ShimoDocs Suite 배포 문서](../../README.md)

> [!TIP]
>
> 사용자 관리는 각 테넌트의 사용자를 조회하고 ShimoDocs Suite 사용자 계정을 일괄적으로 활성화하거나 비활성화하는 데 사용됩니다. 
>
> 이 기능을 사용하려면 먼저 사용자가 있는 테넌트를 선택한 다음, 관리할 해당 사용자 목록을 입력해야 합니다. 

> 사용자 관리 페이지는 사용자가 속한 테넌트 범위를 '팀' 이름을 사용하여 표시합니다. 

## 1. 사용자 관리 입력 

1. <서비스 이름>에 로그인 **MDP 운영 플랫폼**. 
2. 상단에서 선택 **ShimoDocs Suite**. 
3. 왼쪽 탐색 바에서 선택 **사용자 관리**. 

## 2. 관리할 팀(테넌트) 선택 

사용자 관리 페이지에 들어가면 시스템에서 먼저 팀 목록을 표시합니다. 목록에서 사용자가 속한 팀(테넌트)을 선택하세요. 

### 팀(테넌트) 찾기

1. 페이지 상단의 검색 상자에 팀 이름, 생성자 또는 ID를 입력하세요. 
2. 검색 결과에서 팀 이름, 생성자, 활성 사용자 수, 용량 및 만료 날짜를 확인하세요. 
3. 팀 이름을 클릭하여 해당 팀의 사용자 목록에 들어갑니다. 

### 팀 목록 필드 설명

| 필드 | 설명 |
| --- | --- |
| ID | 시스템에서 팀의 고유 식별자입니다. |
| 팀 이름 | 팀의 이름입니다. 클릭하면 해당 팀의 사용자 목록으로 이동합니다. |
| 생성자 | 이 팀을 생성한 계정입니다. |
| 활성화 / 수용 인원 | 팀에 대해 현재 활성화된 사용자 수와 사용 가능한 좌석 수입니다. |
| 만료 날짜 | 이 팀의 현재 서비스 만료 날짜입니다. |

> 목록 내용이 제때 업데이트되지 않으면, 검색 상자 오른쪽의 "새로 고침"을 클릭할 수 있습니다.

## 3. 테넌트 사용자 보기

테넌트 이름을 클릭하면 해당 테넌트 내 사용자 목록이 페이지에 표시됩니다.

### 사용자 목록 필드 설명

| 필드 | 설명 |
| --- | --- |
| ID | 시스템에서 사용자의 고유 식별자입니다. |
| USERNAME | 사용자에게 표시되는 이름입니다. ShimoDocs Suite. |
| 이메일 | 사용자 계정에 연결된 이메일입니다. |
| 역할 | 현재 테넌트에서 사용자의 역할, 예를 들어 관리자(Admin) 또는 구성원(Member)입니다. |
| 상태 | 사용자 계정이 현재 활성화되어 있는지 여부입니다. |

## 4. 사용자 검색

테넌트에 사용자가 많은 경우 검색 기능을 사용하여 대상 사용자를 빠르게 찾을 수 있습니다.

1. 입력하십시오 USERNAME사용자 목록 위의 검색 상자에서 이름, 이메일 또는 사용자 ID를 입력합니다.
2. 검색 결과에서 이름, 이메일 및 역할을 확인하여 대상 사용자를 찾았는지 확인합니다. USERNAME목록을 다시 로드하려면 검색 상자 오른쪽의 “새로 고침”을 클릭합니다.

## 5. 사용자 일괄 활성화

사용자 계정이 비활성화되었고 복원이 필요한 경우 사용자를 일괄 활성화할 수 있습니다.

### 단계

1. 현재 페이지가 대상 테넌트를 표시하는지 확인합니다.
2. 사용자 목록 왼쪽에서 활성화할 하나 이상의 사용자를 선택합니다.
3. 페이지 오른쪽 상단에 표시된 “선택됨” 수가 올바른지 확인합니다.
4. “일괄 활성화”를 클릭합니다.
5. 페이지 안내에 따라 작업을 확인합니다.
6. 작업 완료 후 목록을 새로 고치고 사용자 상태가 "활성화됨"으로 변경되었는지 확인합니다.

## 6. 사용자 일괄 비활성화

사용자가 일시적으로 사용하지 않아야 할 경우 ShimoDocs Suite계정을 일괄 비활성화할 수 있습니다.

### 단계

1. 현재 페이지가 대상 테넌트를 표시하는지 확인합니다.
2. 사용자 목록의 왼쪽에서 사용 중지할 하나 이상의 사용자를 선택합니다.
3. 페이지 오른쪽 상단의 '선택됨'에 표시된 숫자가 올바른지 확인합니다.
4. "일괄 사용 중지"를 클릭합니다.
5. 페이지 안내에 따라 작업을 확인합니다.
6. 작업이 완료되면 목록을 새로 고치고 사용자 상태가 업데이트되었는지 확인합니다.

> 사용자를 사용 중지하면 해당 계정의 정상적인 사용에 영향을 미칩니다. ShimoDocs Suite 작업하기 전에 테넌트, USERNAME이메일, 역할을 확인하여 다른 사용자에게 실수로 영향을 주지 않도록 하세요.

## 7. 테넌트 목록으로 돌아가기

다른 테넌트로 전환해야 하는 경우:

1. 페이지 왼쪽 상단의 "팀 목록으로 돌아가기"를 클릭합니다.
2. 테넌트 목록에서 대상 테넌트를 다시 검색하고 선택합니다.
