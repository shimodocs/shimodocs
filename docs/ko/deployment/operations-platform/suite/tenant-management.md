# 테넌트 관리

[← ShimoDocs Suite 배포 문서](../../README.md)

> [!TIP]
>
> 테넌트 관리는 테넌트를 중앙에서 관리하는 데 사용됩니다. ShimoDocs Suite.
> 관리자는 여기에서 테넌트 수와 좌석 사용 현황을 확인하고, 타사 통합 자격 증명을 획득하며, AI 구성을 관리하고, 테넌트를 생성, 편집, 활성화 또는 비활성화할 수 있습니다.
>

## 1. 테넌트 관리 접근

1. <서비스 이름>에 로그인 **MDP 운영 플랫폼**.
2. 선택 **ShimoDocs Suite** 상단에 있습니다.
3. 선택 **테넌트 관리** 왼쪽 탐색 막대에 있습니다.

## 2. 테넌트 관리 페이지 이해

현재 시스템의 전체 정보가 페이지 상단에 표시됩니다:

| 지역 | 설명 |
| --- | --- |
| API-KEY | 보기 및 복사 `AppID` 그리고 `AppSecret` 타사 통합에 필요한 정보를 복사합니다. |
| AI 설정 | AI 기능이 활성화되어 있는지 확인하고 AI 모델 및 검색 구성을 액세스합니다. |
| 총 테넌트 수 | 현재 시스템에서 생성된 테넌트 수입니다. |
| 활성화된 테넌트 | 현재 활성화된 테넌트 수입니다. |
| 좌석 사용량 | 사용된 좌석 수, 시스템의 총 좌석 수 및 사용 비율입니다. |

아래 테넌트 목록에는 테넌트 이름, 활성화 시간, 테넌트 관리자, 좌석 사용량 및 현재 상태가 표시됩니다. '작업' 열에서 해당 테넌트를 편집하거나 비활성화할 수 있습니다.

## 3. 보기 API 키

`AppID` 그리고 `AppSecret` 는 타사 시스템과 통합될 때 인증에 사용됩니다. ShimoDocs Suite 타사 시스템과 통합될 때 사용됩니다.

### 작업 단계

1. 다음을 찾습니다 **API-KEY** 테넌트 관리 페이지에서 카드를 클릭합니다.
2. 복사 아이콘을 클릭합니다.
3. 시스템이 현재 환경의 정보를 복사합니다. `AppID` 그리고 `AppSecret`.
4. 해당 자격 증명을 해당 타사 통합 구성에 입력합니다.

> `AppSecret` 은 민감한 자격 증명입니다. 안전하게 보관하고 공개 문서, 채팅 기록 또는 공개적으로 접근 가능한 코드 저장소에 작성하지 마십시오.

## 4. AI 구성 관리

AI 구성 카드는 현재 AI 기능 활성화 상태를 표시합니다.

AI 구성 카드를 클릭한 후, "AI 모델 및 검색 구성" 페이지에서 다음 내용을 조회하거나 편집할 수 있습니다: 

### 1. 기본 모델 구성

일반 대규모 언어 모델(LLM)과 사용 가능한 모델을 구성하는 데 사용됩니다. 이 페이지에서 제공자, 요청과 같은 정보를 확인할 수 있습니다. URL, API 키, 기본 모델, 모델 ID, 컨텍스트 창, 입력 기능.

### 2. 이미지 모델 구성

이미지 생성 또는 이미지 편집 모델을 구성하는 데 사용됩니다. 페이지에서 제공자, 모델 이름, 기본 URL, API 키 및 지원되는 이미지 기능을 확인할 수 있습니다.

### 3. 네트워크 검색 엔진 구성

AI 네트워크 검색 서비스를 구성하는 데 사용됩니다. 페이지에서 서비스 제공자, 인터페이스 주소를 확인할 수 있습니다. API 키 및 시간 초과.

### 4. 임베딩 공급자 구성

텍스트 벡터화 서비스를 구성하는 데 사용됩니다. 페이지에서 Base URL, API 키, 임베딩 모델 및 벡터 차원을 확인할 수 있습니다.

> AI 구성을 수정하기 전에 서비스 주소, API 키, 모델 ID 및 기능 매개변수가 모두 정확한지 먼저 확인하세요. 수정 후에는 소량의 테스트 콘텐츠를 사용하여 모델 호출이 정상적으로 작동하는지 확인하는 것이 권장됩니다.

### 5. AI 사용 ShimoDocs Suite
구성이 완료되면 ShimoDocs Suite 내에서 AI 기능을 사용할 수 있습니다.

## 5. 기존 테넌트 관리

테넌트 목록에서 각 테넌트의 기본 정보와 좌석 사용 현황을 확인할 수 있습니다.

### 테넌트 편집

1. 조정이 필요한 테넌트를 찾습니다.
2. '작업' 열에서 '편집'을 클릭합니다.
3. 페이지의 안내에 따라 테넌트 정보나 좌석 수를 수정합니다.
4. 변경 사항을 저장하고 목록으로 돌아가 정보가 업데이트되었는지 확인합니다.

### 테넌트 사용 중지 또는 복원

- 현재 활성화된 테넌트의 경우 '작업' 열에서 '비활성화'를 클릭할 수 있습니다.
- 비활성화된 테넌트를 복원하려면 해당 테넌트의 작업 항목에서 다시 활성화하십시오.

> 테넌트를 비활성화하면 해당 테넌트에 대한 정상적인 접근에 영향을 미칩니다. 진행하기 전에 대상 테넌트가 정확한지 확인하고 실제 사용에 따라 작업 일정을 계획하십시오.

## 6. 새로운 테넌트 활성화

테넌트를 활성화하기 전에 페이지 상단에서 좌석 사용량을 먼저 확인하여 할당 가능한 좌석이 남아 있는지 확인하십시오.

### 운영 단계

1. 페이지 우측 상단의 '새로운 테넌트 활성화'를 클릭하십시오.
2. '테넌트 이름'에 이 테넌트를 식별하는 이름을 입력하십시오.
3. 시스템에서 생성된 테넌트 관리자 이메일을 확인하십시오. 테넌트가 성공적으로 생성된 후, 이 관리자 계정과 초기 비밀번호를 반드시 저장하십시오. PASSWORD 즉시 저장하십시오.
4. '할당 가능 좌석'을 확인하여 새 테넌트에 현재 할당할 수 있는 최대 좌석 수를 파악하십시오.
5. '테넌트 할당 좌석'에 이 테넌트에 할당할 좌석 수를 입력하십시오.
6. 정보가 정확한지 확인한 후 '저장'을 클릭하십시오.

### 좌석 필드 설명

| 필드 | 설명 |
| --- | --- |
| 할당 가능한 좌석 | 시스템에서 현재 테넌트에 할당할 수 있는 최대 좌석 수입니다. |
| 테넌트에 할당된 좌석 | 이 테넌트에 할당된 총 좌석 수입니다. 이 수치는 이미 테넌트가 사용한 좌석 수보다 적을 수 없습니다. |
| 테넌트가 사용한 좌석 | 이 테넌트의 활성 기업 구성원 수입니다. 각 활성 구성원은 한 좌석을 차지합니다. |

> 테넌트를 생성할 때 일정 수의 좌석을 할당해야 합니다. 좌석 수는 실제 사용량에 따라 나중에 조정할 수 있습니다.
