# 브랜드 맞춤화

[← ShimoDocs Suite 배포 문서](../../README.md)

> [!TIP]
>
> 브랜드 맞춤화는 브랜드 정체성과 인터페이스 스타일을 통일하는 데 사용됩니다. ShimoDocs Suite여기서 기업 로고, 브라우저 아이콘, 탭 브랜드 확장, 테마 색상, 버튼 둥근 모서리, 페이지 진입 및 시스템 워터마크를 설정할 수 있습니다. 
>
> 이 기능을 사용할 때는 먼저 설정의 유효 범위를 확인한 후 브랜드 정체성, 인터페이스 스타일, 진입, 워터마크 순서로 설정을 완료하는 것이 권장됩니다. 

> 테넌트를 선택하지 않으면 설정은 전역적으로 적용됩니다. ShimoDocs Suite같은 설정 항목의 우선순위는 다음과 같습니다: ** 테넌트 설정 > 전역 설정**. 

## 1. 브랜드 맞춤화에 들어가기 

1. <서비스 이름>에 로그인 **MDP 운영 플랫폼**. 
2. 상단에서 선택 **ShimoDocs Suite**. 
3. 왼쪽 탐색 바에서 선택 **브랜드 맞춤화**. 

## 2. 설정의 유효 범위 선택 

브랜드 맞춤화는 전역, 테넌트 또는 사용자 범위를 지원합니다. 설정하기 전에 실제 필요에 따라 해당 범위를 선택하십시오. 

| 구성 범위 | 선택 방법 | 효과 |
| --- | --- | --- |
| 전체 구성 | 테넌트나 사용자를 선택하지 마십시오. | 전체에 적용 ShimoDocs Suite. |
| 테넌트 구성 | 지정된 테넌트를 선택하십시오. | 선택된 테넌트에만 적용 |
| 사용자 구성 | 지정된 사용자를 선택하십시오. | 선택된 사용자에만 적용 |

예를 들어: 전체 테마 색상이 파란색으로 설정되어 있고 특정 테넌트의 테마 색상이 녹색으로 설정된 경우, 해당 테넌트는 녹색을 사용하고 개별적으로 구성되지 않은 다른 테넌트는 여전히 파란색을 사용합니다.

## 3. 브랜드 아이덴티티 구성

### 1. 회사 로고

"주 사이트 회사 로고 수정"을 구성하면 회사 로고 변경 옵션이 다음 페이지에 표시되는지 여부를 제어할 수 있습니다. **기업 관리 > 회사 기본 정보** 페이지에서 ShimoDocs Suite.

활성화된 후, 관리자는 회사 기본 정보 페이지에서 회사 로고를 수정할 수 있습니다.

### 2. 브라우저 아이콘

"페이지 브라우저 아이콘 수정" 설정을 통해 브라우저 탭에 표시되는 아이콘(Icon)을 교체할 수 있습니다. ShimoDocs Suite 

구성 후 브라우저 탭에서 실제 표시 효과를 확인할 수 있습니다.

### 3. 브라우저 탭 브랜드 접미사

"브라우저 탭 브랜드 접미사" 구성을 통해 브라우저 탭에 표시되는 브랜드 이름 접미사를 설정할 수 있습니다. ShimoDocs Suite 

구성 후 브라우저 탭 제목에서 효과를 확인할 수 있습니다.

## 4. 구성 인터페이스 스타일

### 1. 테마 색상

"테마 색상" 구성을 통해 주요 버튼, 선택 상태 및 강조 표시된 콘텐츠의 색상을 일괄적으로 조정할 수 있습니다. ShimoDocs Suite.

색상을 변경한 후 페이지에서 테마 색상의 실제 적용 효과를 미리 볼 수 있습니다.

### 2. 버튼 모서리 반경

"모서리 반경 구성"을 통해 버튼의 모서리 반경 효과를 조정할 수 있습니다. ShimoDocs Suite 모서리 반경 구성

값을 조정하면 버튼 모서리의 모양이 그에 따라 변경됩니다.

## 5. 페이지 진입 및 브랜드 정보 구성

### 1. 공식 웹사이트 진입

"메인 사이트 공식 웹사이트 진입 활성화"를 구성하면 ShimoDocs 개인 명함에서 공식 웹사이트 진입 표시 여부를 제어할 수 있습니다.

활성화되면 사용자는 개인 프로필에서 공식 웹사이트 진입을 확인할 수 있습니다.

### 2. "소개" 진입

"메인 사이트 소개 진입 활성화" 설정을 통해 개인 프로필에서 "소개" 진입 표시 여부를 제어할 수 있습니다.

활성화되면 사용자는 개인 프로필에서 '소개' 진입을 확인할 수 있습니다.

### 3. 브랜드 정보

"브랜드 정보 표시 여부" 설정을 통해 관련 페이지에서 사용자에게 브랜드 정보 표시 여부를 제어할 수 있습니다.

## 6. 시스템 워터마크 구성

### 1. 협업자 워터마크

"시스템 내장 협업자 워터마크 사용"을 구성하면 사용자가 파일을 편집하거나 미리 볼 때 표시되는 워터마크 내용을 제어할 수 있습니다.

워터마크 내용은 방문자가 익명인지 여부와 '사용자 정보 표시 여부' 선택에 따라 달라집니다. 

#### 익명이 아닌 액세스 

| 구성 옵션 | 워터마크 표시 내용 |
| --- | --- |
| 표시/숨기기 | 기본 권한 정보와 사용자 정보를 포함한 시스템 내장 워터마크를 표시합니다. |
| 사용자 정의 | 에 설정된 협업자 워터마크 내용에 따라 표시합니다. ShimoDocs Suite 기업. |

#### 익명 액세스

| 구성 옵션 | 워터마크 표시 내용 |
| --- | --- |
| 표시/숨기기 | 기본 권한 정보와 사용자 정보를 포함한 시스템 내장 워터마크를 표시합니다. |
| 사용자 정의 | 익명 사용자에게는 구성된 사용자 정의 텍스트만 표시합니다. |

내장된 공동작업자 워터마크를 활성화하면 사용자가 파일을 편집하거나 미리보기할 때 해당 워터마크가 영구적으로 표시됩니다.

### 2. 편집기 하단 바 워터마크

"시스템 내장 편집기 하단 바 워터마크 수정" 설정을 통해 편집기 하단에 표시되는 시스템 내장 워터마크를 조정할 수 있습니다.

설정 후 편집기 하단에서 실제 표시 효과를 확인할 수 있습니다.

## 7. 설정 결과 확인

설정을 완료한 후에는 다음 순서로 확인하는 것이 좋습니다:

1. 현재 선택된 설정 범위가 전체(global) 또는 테넌트(tenant)인지 확인합니다.
2. 열기 ShimoDocs Suite 해당 범위 내 페이지.
3. 페이지를 새로 고치고 로고, 브라우저 아이콘, 탭 이름, 테마 색상 및 항목 표시 상태를 확인합니다.
4. 익명 및 비익명 방식 모두로 파일을 열어 워터마크 내용이 예상대로 표시되는지 확인합니다.
5. 실제 효과가 기대와 일치하지 않는 경우, 먼저 우선순위가 더 높은 테넌트 구성이 있는지 확인하십시오.
