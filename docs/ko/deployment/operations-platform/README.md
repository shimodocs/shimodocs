# 운영 플랫폼 개요

[← ShimoDocs Suite 배포 문서](../README.md)

## 기능 개요

- **ShimoDocs Suite**: 권한, 테넌트, 사용자, 브랜딩 및 AI 구성과 관련된 관리를 위해 사용됩니다. ShimoDocs Suite.
- **시스템 서비스**: 전역 구성, 클러스터 관리, 로그 보기, 기능 점검, 문제 조회, 문서 복구 및 일반 운영 및 유지 보수 작업에 사용됩니다. **시스템 업그레이드**.

> **참고**: 표시되는 구체적 기능은 현재 배포 버전과 활성화된 기능에 따라 달라집니다.

## 운영 플랫폼 로그인

브라우저에서 다음 주소로 접속하세요:
> **브라우저 요구 사항**: 운영 플랫폼에 접속하려면 Google Chrome 버전 111 이상을 사용하십시오. 먼저 최신 안정 버전으로 업그레이드하는 것이 권장됩니다.

```text
http(s)://<OPERATIONS_PLATFORM IP OR_DOMAIN_NAME>/mdp/user/login
```

관리자 계정을 입력하고 PASSWORD, 그런 다음 "로그인"을 클릭하십시오.

## 운영 플랫폼 홈페이지 알아보기

로그인한 후에는 페이지 왼쪽 메뉴를 통해 해당 관리 기능에 접근할 수 있습니다. 표시되는 메뉴는 현재 환경에 배포되고 승인된 제품과 버전에 따라 달라집니다.

## 관리자 재설정 PASSWORD 비밀번호를 잊었을 때

운영 플랫폼 관리자를 PASSWORD 잊어버린 경우, 배포 노드에 로그인하여 다음 명령어를 실행하여 재설정할 수 있습니다.﻿

```bash
kubectl exec -it $(kubectl get pods -l app=mdp -o jsonpath='{.items[0].metadata.name}') -- reset-admin-password Aa1234567.
```

위 예제는 PASSWORD 부터 `Aa1234567.`를 재설정합니다. 실제 운영에서는 예제를 대체하여 사용하시기 바랍니다. PASSWORD 명령어 끝에 보안 요구사항을 충족하는 새로운 PASSWORD 을 입력합니다.

리셋이 완료되면 로그인 페이지로 돌아가 새로운 PASSWORD로 로그인하고 메뉴에 정상적으로 접근할 수 있는지 확인합니다.
