# 설치 문제 해결

[← ShimoDocs Suite 배포 문서](../README.md)

> [!TIP]
>
> 설치 단계 동안의 일반적인 문제는 보통 다음과 같은 범주에 속합니다.

## 1 시간 비동기화

문제 증상:

* 로그인 실패

* 인증 오류

* 서비스 호출 예외

처리 요구 사항:

* 먼저 모든 노드의 시간 편차를 확인합니다

* /time synchronization 서비스를 수정한 후 NTP설치 또는 승인 절차를 계속 진행합니다

조사 명령어:

```plain
timedatectl status
date
```


## 2 데이터 디스크 경로 구성 오류

현상:

* 설치 후, 디스크가 빠르게 가득 찹니다

* 데이터 쓰기 실패

* 영속 디렉터리는 시스템 드라이브에 위치합니다

처리 요구 사항:

* 영속 디렉터리는 명시적으로 데이터 디스크를 가리켜야 합니다

* 비즈니스 데이터는 시스템 디스크 디렉터리에 저장되지 않습니다

문제 해결 명령:

```plain
findmnt -n -o TARGET -T /data
df -Th|egrep -v "overlay|tmpfs"
```


## 3 종속 서비스 연결 실패

현상:

* 설치 중 서비스 점검 실패

* 데이터베이스, 캐시, 메시지 큐 또는 객체 저장소와의 연결 실패

처리 요구 사항:

* 먼저 주소, 포트, 계정이 올바르게 입력되었는지 확인하세요 PASSWORD 

* 그런 다음 네트워크 연결 및 보안 정책을 확인하세요

* 마지막으로 대상 서비스 자체가 사용 가능한지 확인하세요

문제 해결 명령어:

```plain
nc -zv <MYSQL_HOST> 3306
nc -zv <REDIS_HOST> 6379
nc -zv <MONGO_HOST> 27017
nc -zv <KAFKA_HOST> 9092
```


## 4 오프라인 패키지 불일치

현상:

* 미러 로딩 실패

* 설치 과정에서 서비스가 시작할 수 없고 버전이 일치하지 않음

* 설치 패키지가 오프라인 미러 패키지와 일치하지 않음

처리 요구 사항:

* 설치 패키지, 오프라인 이미지 패키지 및 제품 버전이 일치하는지 확인

* 설치 패키지가 일치하는지 확인 CPU 아키텍처

* 다른 프로젝트 또는 다른 날짜의 자료가 혼합되지 않았는지 확인

## 설치 프로그램 페이지를 열 수 없음

현상:

* 웹 UI 페이지에 접속할 수 없음

* 포트 18080이 수신 대기 중이 아님

* 설치 프로그램 프로세스가 종료됨

문제 해결 명령:

```plain
ps -ef | grep mdp | grep -v grep
ss -lntp | grep 18080
tail -n 100 /root/nohup.out
```


## 6. 권장 문제 해결 순서

설치 문제를 다음 순서로 해결:

1. 먼저 환경 문제인지 확인: 시스템, 시간, 디스크, 포트, 네트워크

2. 구성 문제인지 재확인: 도메인 이름, 디렉토리, 종속 주소, 계정 PASSWORD

3. 자료 문제인지 재확인: 설치 패키지, 오프라인 패키지, 아키텍처 호환성

4. 마지막으로 설치 로그와 서비스 실행 상태를 확인

설명:

* 전제 조건이 충족되지 않으면 설치를 반복하지 마세요

* 명백한 실패 이유가 있는 명령을 반복 실행하지 마세요

## 7. 설치를 중단해야 하는 경우

다음 상황이 발생하면 먼저 설치를 중단하고 기본 문제를 해결한 후에만 계속 진행:

* 모든 노드 시간이 동기화되지 않음

* 데이터 디스크가 독립적으로 마운트되지 않았습니다

* 외부 종속 서비스에 접근할 수 없습니다

* 오프라인 자료 버전이 일치하지 않습니다

* 설치 서비스가 제대로 시작되지 않았습니다
