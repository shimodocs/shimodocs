# การจัดการใบอนุญาต

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

> [!TIP]
>
> การจัดการใบอนุญาตใช้เพื่อรับรหัสเครื่องเซิร์ฟเวอร์สำหรับ ShimoDocs Suite, เขียนและเผยแพร่ใบอนุญาต และดูสถานะใบอนุญาตปัจจุบัน ช่วงใบอนุญาต และข้อมูลเครื่องที่ทำงาน สำหรับการเปิดใช้งานครั้งแรก 
> การต่ออายุใบอนุญาตเมื่อหมดอายุ หรือเมื่อโหนดเซิร์ฟเวอร์เปลี่ยนแปลง คุณสามารถอัปเดต ShimoDocs Suite ใบอนุญาตผ่านหน้านี้

> หลังจากเขียนใบอนุญาตแล้ว คุณต้องตรวจสอบผลการยืนยันก่อนที่จะเผยแพร่ใบอนุญาต การเขียนหรือบันทึกชั่วคราวเพียงอย่างเดียวไม่ได้ทำให้ใบอนุญาตมีผลทางกฎหมายอย่างเป็นทางการ
- หากคุณเป็นลูกค้าที่ชำระเงิน กรุณาส่งรหัสเครื่องที่คัดลอกไปยังทีมสนับสนุนทางเทคนิค ShimoDocs เรา sẽ สร้างใบอนุญาตที่สอดคล้องกับรหัสเครื่องและส่งข้อมูลใบอนุญาตให้คุณ
- หากคุณต้องการทดลองใช้ฟรี กรุณาไปที่ **ShimoDocs การสมัครใบอนุญาตเว็บไซต์ทางการ**: https://shimo.net/license กรอกข้อมูลใบสมัครและวางรหัสเครื่อง
- หลังจากส่ง ระบบจะสร้างใบอนุญาตทดลองโดยอัตโนมัติ กรุณาคัดลอกและกรอกข้อมูลให้เสร็จภายใน 10 นาทีหลังจากสร้าง หากหมดเวลา กรุณายื่นสมัครใหม่
## 1. เข้าถึงการจัดการใบอนุญาต

1. เข้าสู่ระบบไปยัง **MDP แพลตฟอร์มปฏิบัติการ**.
2. เลือก **ShimoDocs Suite** ที่ด้านบน
3. เลือก **การจัดการใบอนุญาต** ในแถบนำทางด้านซ้าย

หน้าประกอบด้วยพื้นที่สำหรับการเปิดใช้งานใบอนุญาต ข้อมูลใบอนุญาต การเปรียบเทียบรหัสเครื่อง และข้อมูลเครื่อง

## 2. ยื่นขอ ShimoDocs Suite ใบอนุญาต

ก่อนที่จะยื่นขออนุญาต โปรดตรวจสอบให้แน่ใจก่อนว่า ShimoDocs Suite โหนดเซิร์ฟเวอร์มีความเสถียรและจะไม่มีการเพิ่ม ลบ หรือแทนที่โหนดชั่วคราว 

### 1. คัดลอกรหัสเครื่องทั้งหมด 

1. ในพื้นที่ 'การเปิดใช้งานการอนุญาต' คลิก 'คัดลอกรหัสเครื่องทั้งหมดด้วยคลิกเดียว' 
2. ยืนยันว่าหน้าจอแสดงข้อความคัดลอกสำเร็จ 
3. บันทึกรหัสเครื่องในเอกสารขออนุญาตใช้งาน 

### 2. ส่งข้อมูลคำขออนุญาต

ส่งรหัสเครื่องทั้งหมดและข้อกำหนดการอนุญาตไปยัง ShimoDocs เจ้าหน้าที่บริการเพื่อสร้าง ShimoDocs Suite ใบอนุญาต

แนะนำให้ยืนยันข้อมูลต่อไปนี้เมื่อทำการสมัคร:

| ข้อมูล | คำอธิบาย |
| --- | --- |
| ผลิตภัณฑ์ที่ได้รับอนุญาต | ShimoDocs Suite. |
| ชื่อใบอนุญาตและบริษัท | ชื่อใบอนุญาตและบริษัทที่จะปรากฏบนใบอนุญาต |
| จำนวนผู้ใช้ | จำนวนผู้ใช้สูงสุดที่สามารถใช้ใบอนุญาตได้ |
| ระยะเวลาการใช้งาน | วันเริ่มต้นและวันหมดอายุของใบอนุญาตผลิตภัณฑ์ |
| ระยะเวลาการให้บริการหลังการขาย | วันเริ่มต้นและวันหมดอายุของการให้บริการหลังการขาย |
| ชุดโปรแกรมที่ใช้งานได้ | ประเภทของเอกสารหรือชุดคุณสมบัติที่จำเป็นต้องเปิดใช้งาน |
| ความสามารถของ AI | ว่าความสามารถของ AI จำเป็นต้องเปิดใช้งานหรือไม่ |
| รหัสเครื่อง | รหัสเครื่องเซิร์ฟเวอร์ทั้งหมดที่กำลังทำงานอยู่ในปัจจุบัน ShimoDocs Suite. |

## 3. เขียนและตรวจสอบการอนุญาต

หลังจากได้รับใบอนุญาตใหม่ กรุณาทำตามขั้นตอนด้านล่างเพื่อเขียนลงในระบบ

### 1. เขียนใบอนุญาต

1. คลิก "เขียนใบอนุญาต" ในพื้นที่ "การเปิดใช้งานใบอนุญาต"
2. วางเนื้อหาใบอนุญาตที่ได้รับทั้งหมดลงในกล่องป้อนข้อมูล
3. ตรวจสอบให้แน่ใจว่าเนื้อหาใบอนุญาตครบถ้วน ไม่ขาดตัวอักษรหรือมีช่องว่างเกิน
4. คลิก "บันทึกชั่วคราว"

### 2. ตรวจสอบผลการยืนยันใบอนุญาต

หลังจากการบันทึกชั่วคราว ระบบจะทำการตรวจสอบใบอนุญาตใหม่และแสดงผลลัพธ์ดังต่อไปนี้

| ผลการตรวจสอบ | คำอธิบาย | คำแนะนำในการดำเนินการ |
| --- | --- | --- |
| ไม่ตรงกัน | ข้อมูลสำคัญของใบอนุญาตใหม่ไม่ตรงกับสภาพแวดล้อมปัจจุบัน | ตรวจสอบรหัสเครื่อง ประเภทแอปพลิเคชัน เวอร์ชัน และขอบเขตการอนุญาต หลังจากยืนยันว่าถูกต้องแล้ว ให้ขอใบอนุญาตใหม่อีกครั้ง |
| เปลี่ยนแปลง | ข้อมูลบางอย่างในใบอนุญาตใหม่แตกต่างจากใบอนุญาตปัจจุบัน | ตรวจสอบค่าต้นฉบับ ค่าที่เปลี่ยนใหม่ และผลการพิจารณาบนหน้าเพื่อตรวจสอบว่าการเปลี่ยนแปลงตรงตามคำขอนี้หรือไม่ |
| ผ่าน | รายการตรวจสอบที่เกี่ยวข้องผ่านแล้ว | ดำเนินการตรวจสอบข้อมูลการอนุญาตอื่นต่อ |

หากมีรายการ "เปลี่ยนแปลง" ในหน้า และการเปลี่ยนแปลงเป็นไปตามคำขออนุญาตนี้ ให้คลิก "ยืนยันการบันทึกชั่วคราว"

> หากเกิด 'ไม่ตรง' หรือ 'เปลี่ยนแปลง' ที่ไม่คาดคิด กรุณาหยุดการปล่อยก่อน และตรวจสอบข้อมูลคำขอและสภาพแวดล้อมการทำงานปัจจุบันอีกครั้ง

## 4. การอนุญาตให้ปล่อย

หลังจากตรวจสอบและบันทึกชั่วคราวเสร็จ หน้าเพจจะแสดงข้อมูลใบอนุญาตที่ต้องปล่อย

### การตรวจสอบก่อนปล่อย

ตรวจสอบรายการต่อไปอย่างรอบคอบ

- ชื่อใบอนุญาต
- ข้อจำกัดของที่นั่ง
- เวลาเริ่มและเวลาหมดอายุ
- รหัสคำขอ
- รหัสเครื่องเซิร์ฟเวอร์

หลังจากยืนยันข้อมูลถูกต้อง ให้คลิก "เผยแพร่ใบอนุญาต"

หลังจากการปล่อยใช้งานเสร็จสมบูรณ์ ให้รีเฟรชหน้ากระดาษเพื่อดูสถานะการอนุญาตและข้อมูลการอนุญาตที่อัปเดตแล้ว

## 5. การดูข้อมูลการอนุญาต

ส่วน 'ข้อมูลการอนุญาต' จะแสดงเนื้อหาใบอนุญาตที่กำลังใช้งานอยู่ในปัจจุบัน

### คำอธิบายของช่องข้อมูลการอนุญาต

| ช่องข้อมูล | คำอธิบาย |
| --- | --- |
| ชื่อการอนุญาต | ชื่อของการอนุญาตสำหรับใบอนุญาตปัจจุบัน |
| บริษัทที่ได้รับอนุญาต | บริษัทที่เป็นเจ้าของใบอนุญาต |
| เวอร์ชันผลิตภัณฑ์ | เวอร์ชันผลิตภัณฑ์ที่ใช้กับการอนุญาตปัจจุบัน |
| เวอร์ชันการปล่อย | ประเภทการปล่อยของสิทธิ์ปัจจุบัน |
| ประเภทแอปพลิเคชัน | ประเภทผลิตภัณฑ์ที่ใช้ได้กับใบอนุญาตปัจจุบัน |
| จำนวนผู้เช่า | จำนวนผู้เช่าสูงสุดที่ใบอนุญาตปัจจุบันอนุญาต |
| จำนวนผู้ใช้ | จำนวนที่นั่งสูงสุดที่ใบอนุญาตปัจจุบันอนุญาต |
| ระยะเวลาใช้งานผลิตภัณฑ์ | วันที่เริ่มต้นและวันหมดอายุของสิทธิ์ใช้งานผลิตภัณฑ์ |
| ระยะเวลาการให้บริการหลังการขาย | วันที่เริ่มต้นและวันหมดอายุของบริการหลังการขาย |
| จำนวนเครื่อง | จำนวนเซิร์ฟเวอร์ที่เชื่อมโยงกับใบอนุญาต |
| ความสามารถของ AI | ว่ายังมีการเปิดใช้งานความสามารถ AI ในใบอนุญาตปัจจุบันหรือไม่ |
| ชุดที่มีให้ใช้งาน | ประเภทของเอกสารหรือชุดโปรแกรมที่ได้รับอนุญาตตามใบอนุญาตปัจจุบัน |

## 6. ตรวจผลการเปรียบเทียบรหัสเครื่อง

ด้านล่างของข้อมูลการอนุญาต จะแสดงผลการเปรียบเทียบระหว่างรหัสเครื่องในใบอนุญาตกับเซิร์ฟเวอร์ที่กำลังทำงานอยู่ในปัจจุบัน

| ผลลัพธ์ | คำอธิบาย |
| --- | --- |
| เครื่องในใบรับรอง | จำนวนเซิร์ฟเวอร์ที่ผูกกับใบอนุญาตปัจจุบันแล้ว |
| เครื่องจริง | จำนวนเซิร์ฟเวอร์ที่ระบบปัจจุบันตรวจพบว่ากำลังทำงาน |
| ตรงกัน | รหัสเครื่องในใบอนุญาตตรงกับเซิร์ฟเวอร์ปัจจุบัน |
| ไม่ตรงกัน | ขณะนี้มีเซิร์ฟเวอร์ที่ยังไม่ผูกกับใบอนุญาต หรือเครื่องในใบอนุญาตมีการเปลี่ยนแปลง |
| หายไป | เครื่องที่ผูกกับใบอนุญาตไม่ถูกตรวจพบโดยระบบในขณะนี้ |

หากจำนวนเครื่องในใบรับรองไม่ตรงกับจำนวนเครื่องจริง หรือหากหน้าจอแสดง 'ไม่ตรงกัน' หรือ 'หายไป' โปรดคลิก 'คัดลอกรหัสเครื่อง' แล้วขอใบอนุญาตใหม่โดยใช้รหัสเครื่องปัจจุบัน

> หากมีข้อความนับถอยหลังแจ้งรหัสเครื่องไม่ตรงกันปรากฏที่ด้านบนของหน้า กรุณาทำการยืนยันข้อมูลเซิร์ฟเวอร์หรือเปลี่ยนใบอนุญาตภายในระยะเวลาที่กำหนดเพื่อให้การอนุญาตดำเนินต่อไปอย่างต่อเนื่อง

## 7. ดูข้อมูลเครื่อง

ส่วน 'ข้อมูลเครื่อง' จะแสดงโหนดเซิร์ฟเวอร์ที่กำลังทำงานอยู่ในปัจจุบัน

### คำอธิบายฟิลด์ข้อมูลเครื่อง

| ช่องข้อมูล | คำอธิบาย |
| --- | --- |
| เซิร์ฟเวอร์ | ชื่อหรือที่อยู่ของโหนดเซิร์ฟเวอร์ปัจจุบัน |
| ระบบปฏิบัติการ | ระบบปฏิบัติการที่เซิร์ฟเวอร์ใช้งานอยู่ในปัจจุบัน |
| CPU | รุ่นโปรเซสเซอร์ของเซิร์ฟเวอร์ |
| จำนวนคอร์ | จำนวน CPU คอร์ของเซิร์ฟเวอร์ |
| หน่วยความจำ | ปริมาณหน่วยความจำที่เซิร์ฟเวอร์รับรู้ในปัจจุบัน |
| สถาปัตยกรรม | สถาปัตยกรรมระบบของเซิร์ฟเวอร์ |
| รหัสเครื่อง | รหัสประจำเครื่องของเซิร์ฟเวอร์ที่ใช้ในการสร้างและผูกสิทธิ์การใช้งาน |

## 8. ตรวจสอบผลลัพธ์การอัปเดตสิทธิ์

หลังจากทำการปล่อยสิทธิ์การใช้งานเสร็จสิ้น ควรตรวจสอบตามลำดับดังนี้

1. รีเฟรชหน้าการจัดการสิทธิ์เพื่อยืนยันว่าสถานะสิทธิ์ปกติ
2. ตรวจสอบชื่อผู้ได้รับอนุญาต จำนวนที่นั่ง ระยะเวลาใช้งาน ห้องชุดที่สามารถใช้ได้ และความสามารถด้าน AI
3. ยืนยันว่าจำนวนเครื่องในใบรับรองตรงกับจำนวนเครื่องจริง
4. ยืนยันว่าไม่มีผลลัพธ์ที่ไม่คาดคิดเช่น "ไม่ตรงกัน" หรือ "ขาดหาย" ในการเปรียบเทียบรหัสเครื่อง
5. เข้าสู่ระบบที่ ShimoDocs Suite เพื่อยืนยันว่าประเภทเอกสารและฟังก์ชันที่ได้รับอนุญาตสามารถใช้งานได้ตามปกติ

> หลังจากเปลี่ยน เพิ่ม หรือเอาโหนดเซิร์ฟเวอร์ออก ควรกลับมาที่หน้านี้โดยรวดเร็วเพื่อตรวจสอบผลลัพธ์การเปรียบเทียบรหัสเครื่อง ถ้ารหัสเครื่องเปลี่ยน จำเป็นต้องยื่นขอและออกใบอนุญาตใหม่โดยใช้รหัสเครื่องทั้งหมดใหม่
