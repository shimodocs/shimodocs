# การกำหนดค่าระบบ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## 1. คำแนะนำ

คู่มือนี้แนะนำฟีเจอร์ "การกำหนดค่าระบบ" ของ ShimoDocs Suiteเหมาะสำหรับผู้ดูแลระบบและผู้ใช้งานที่ใช้ฟีเจอร์นี้เป็นครั้งแรก คุณสามารถทำตามขั้นตอนในเอกสารนี้เพื่อค้นหารายการกำหนดค่า แก้ไขการกำหนดค่า ตรวจสอบว่าการเปลี่ยนแปลงมีผลหรือไม่ และคืนค่าการตั้งค่าเดิมหากจำเป็น

> [!TIP]
>
> หากคุณไม่แน่ใจเกี่ยวกับความหมายหรือผลกระทบของรายการการกำหนดค่า โปรดติดต่อ ShimoDocs ฝ่ายสนับสนุนทางเทคนิคเพื่อยืนยันก่อนทำการเปลี่ยนแปลงใดๆ

**กฎขอบเขตที่สำคัญที่สุด** เมื่อเว้นว่างรหัส Enterprise ID การค้นหาและการแก้ไขจะใช้กับการกำหนดค่าระดับโลก; เมื่อเลือก Enterprise ID การค้นหาและการแก้ไขจะใช้กับการกำหนดค่าขององค์กรที่เลือก การแก้ไขการกำหนดค่าระดับโลกอาจส่งผลกระทบต่อหลายองค์กร ดังนั้นโปรดยืนยันขอบเขตของการกำหนดค่าก่อนบันทึก

### 1.1 การเข้าถึงเมนู

Admin Backend > ShimoDocs Suite > การจัดการการกำหนดค่า > การกำหนดค่าระบบ

### 1.2 การเตรียมก่อนใช้งาน

- ยืนยันว่าบัญชีที่เข้าสู่ระบบมีสิทธิ์ในการดูและแก้ไขสำหรับ ShimoDocs Suite การกำหนดค่าระบบ
- ยืนยันก่อนว่าขอบเขตเป้าหมายเป็นระดับโลกหรือเฉพาะองค์กร และรับรหัสองค์กรที่ถูกต้อง
- ยืนยันชื่อคีย์การตั้งค่าจากข้อกำหนดการตั้งค่าหรือภาคผนวก A ชื่อคีย์การตั้งค่าเป็นตัวระบุเฉพาะ อย่าเดาจากชื่อภาษาจีนเท่านั้น
- บันทึกแหล่งที่มา สถานะ และค่าที่มีผลก่อนการแก้ไข สำหรับการตั้งค่าที่สำคัญควรเตรียมค่ากู้คืนด้วย
- การตั้งค่าระดับโลกที่มีผลกระทบมากควรแก้ไขในช่วงเวลาที่ธุรกิจน้อย และแจ้งบุคลากรที่เกี่ยวข้องล่วงหน้า

## 2. ขอบเขตและลำดับความสำคัญของการกำหนดค่า

การกำหนดค่าระบบรองรับทั้งขอบเขตแบบทั่วโลกและแบบองค์กร ก่อนการแก้ไข ต้องตรวจสอบช่องระบุรหัสองค์กรและข้อความแจ้งขอบเขตที่ด้านล่างของหน้า

| **พื้นที่การทำงาน** | **ขอบเขตทั่วโลก** | **ขอบเขตองค์กร** | **สัญญาณระบุหน้า** |
| --- | --- | --- | --- |
| การกำหนดค่าระบบ | เว้นว่างรหัสองค์กร | เลือก รหัสองค์กร | ข้อความด้านล่าง “Global version override” หรือ “ผลลัพธ์สุดท้ายที่มีผลขององค์กร” |

*รูปที่ 1 ตำแหน่งสำหรับเลือก Enterprise ID ในการตั้งค่าระบบ*

### 2.1 การตั้งค่าระดับโลก

- ปล่อยให้ Enterprise ID ไม่ถูกเลือก
- หน้าจอจะแจ้งว่าการค้นหาและแก้ไขปัจจุบันเป็นสำหรับ 'Global Version Override'
- ค่าระดับโลกเป็นค่าพื้นฐานที่ใช้เมื่อไม่มีการตั้งค่า override ขององค์กร; การแก้ไขค่าเหล่านี้อาจมีผลต่อหลายองค์กร
- ก่อนบันทึก ตรวจสอบอีกครั้งอย่างน้อยหนึ่งครั้งเพื่อให้แน่ใจว่าช่อง Enterprise ID ว่างจริง

### 2.2 การตั้งค่าระดับองค์กร

- เลือกองค์กรเป้าหมายจากรายการดรอปดาวน์ Enterprise ID
- หน้าจอจะแสดงผลลัพธ์สุดท้ายที่มีผลหลังจากรวมค่าพื้นฐานกับการตั้งค่าแบบกำหนดเองขององค์กรปัจจุบัน
- การตั้งค่าระดับองค์กรมีผลเฉพาะกับองค์กรที่เลือกเท่านั้น และไม่เปลี่ยนการตั้งค่าขององค์กรอื่นโดยตรง
- เมื่อมีการตั้งค่าระดับองค์กรสำหรับรายการเดียวกัน ค่าที่มีผลสุดท้ายขององค์กรจะมีความสำคัญเหนือค่าระดับโลก

### 2.3 การเขียนทับ การสืบทอด และการฟื้นฟู

- เมื่อองค์กรปัจจุบันไม่มีการแทนค่า จะใช้ค่าการกำหนดค่าระดับโลกหรือค่าตั้งต้นของระบบ
- การปฏิบัติ เช่น 'คืนค่าเริ่มต้นของระบบ' หรือการลบการแทนค่าในปัจจุบัน โดยทั่วไปหมายถึงการลบการแทนค่าของช่วงปัจจุบันและสืบทอดค่าของระดับบนใหม่
- ข้อความแจ้งในหน้าต่าง เช่น 'ค่าเริ่มต้นของระบบ,' 'การแทนค่ารุ่นระดับโลก,' และ 'ผลลัพธ์สุดท้ายที่มีประสิทธิภาพขององค์กร' สามารถใช้เพื่อระบุชั้นที่ค่าปัจจุบันมาจาก
- ก่อนทำการคืนค่าหรือการลบ ให้บันทึกค่าปัจจุบันและยืนยันว่าผลลัพธ์ที่สืบทอดตรงตามที่คาดหวัง

**คำเตือนความเสี่ยง** อย่าบันทึกโดยตรงโดยไม่ยืนยันขอบเขตขององค์กร หาก Enterprise ID ว่าง การดำเนินการอาจเขียนทับแบบทั่วโลกและส่งผลต่อหลายองค์กร

## 3. การตั้งค่าระบบ

การตั้งค่าระบบใช้ในการดูและปรับฟังก์ชันทั่วไป โควต้า และค่าพารามิเตอร์การทำงานของ ShimoDocs Suite.

### 3.1 วิธีการค้นหาที่หนึ่ง: การค้นหาแบบตรง

- Enterprise ID: ปล่อยว่างสำหรับระดับทั่วโลก; เลือก Enterprise ID สำหรับการตั้งค่าในระดับองค์กร
- เกณฑ์การค้นหา: เลือกประเภท, ประเภทค่า และวันที่สิ้นสุดที่มีผลตามต้องการ; คงไว้เป็น "ทั้งหมด" หากไม่แน่ใจ
- ชื่อคีย์: ป้อนชื่อคีย์การกำหนดค่า; หนึ่งคีย์ต่อบรรทัด หรือใช้เครื่องหมายจุลภาคคั่นคีย์หลายตัว
- คลิก "ค้นหา" เพื่อยืนยันชื่อ, คีย์, แหล่งที่มา, สถานะ และค่าปัจจุบันในผลลัพธ์
- คลิก "แก้ไข" ที่ด้านขวาสุดของแถวเป้าหมายเพื่อเปิดหน้าต่างแก้ไข

*รูปที่ 2  พื้นที่ค้นหาการกำหนดค่าระบบอย่างแม่นยำ*

*รูปที่ 3  ผลลัพธ์เดียวหลังการค้นหาอย่างแม่นยำตามชื่อคีย์การกำหนดค่า*

**คำแนะนำช่วง** เมื่อข้อความ "เมื่อไม่ได้เลือกองค์กร ปัจจุบันการสอบถามและการแก้ไขเป็นการแทนค่าระดับโลก" ปรากฏที่ด้านล่างของหน้า นั่นแสดงว่าขอบเขตปัจจุบันเป็นระดับโลก หลังจากเลือกองค์กร หน้าแสดงผลลัพธ์สุดท้ายที่มีค่าดีฟอลต์รวมกับการกำหนดค่าแบบกำหนดเองขององค์กรปัจจุบัน

### 3.2 วิธีการค้นหาที่สอง: ค้นหาโดยตรงในรายการ

- รักษาขอบเขตขององค์กรและเงื่อนไขตัวกรองให้ถูกต้อง และใช้การเลื่อนหน้าจอเพื่อเรียกดูรายการ
- ยืนยันการตั้งค่าเป้าหมายโดยใช้ "ชื่อ" หรือ "ชื่อคีย์" อย่าตัดสินเพียงจากค่าปัจจุบันเท่านั้น
- ดูประเภท วันสิ้นสุดที่มีผล ค่าในปัจจุบัน แหล่งที่มา และสถานะในแถวเดียวกัน
- คลิก "แก้ไข" ที่ด้านขวาสุด หากคุณไม่เห็นคอลัมน์การดำเนินการ ให้เลื่อนตารางไปทางขวา หรือขยายหน้าต่างเบราว์เซอร์

### 3.3 การแก้ไขประเภทการตั้งค่าระบบต่าง ๆ

#### 3.3.1 ประเภทคีย์-ค่า (Key-Value)

ส่วนบนของหน้าต่างแก้ไขจะแสดงเมตาดาต้าแบบอ่านอย่างเดียว รวมถึงชื่อคีย์ ชื่อ คำอธิบาย ประเภท และวันสิ้นสุดที่มีผล เมื่อเปิดใช้งาน ให้กรอกค่าลงในกล่องป้อนข้อมูล เช่น "ค่าตัวอักษร" แล้วบันทึก หากสตริงนั้นมี JSON, URL, path, หรือ list ควรรักษารูปแบบเดิมไว้

*รูปที่ 4  หน้าต่างแก้ไขประเภทคีย์-ค่าของการตั้งค่าระบบ*

#### 3.3.2 ประเภทโควต้า

ป๊อปอัปโควต้ามักจะรวมถึง สถานะ ค่าเริ่มต้นต่ำสุด ค่าเริ่มต้นสูงสุด และสวิตช์ "ไม่ตรวจสอบ" หลังจากเปิดใช้งานการตั้งค่าแล้ว ให้กรอกช่วงค่าตามความต้องการทางธุรกิจ; การเปิดใช้งาน "ไม่ตรวจสอบ" หมายความว่าระบบจะไม่ทำการตรวจสอบข้อจำกัดตามช่วงค่าที่กรอก ค่าต้องสอดคล้องกับหน่วยของป๊อปอัป เช่น "ชิ้น", "MB" เป็นต้น

*รูปที่ 5 การตั้งค่าระบบ แก้ไขประเภทโควตาป๊อปอัป*

#### 3.3.3 ประเภทของฟังก์ชัน

ประเภทของฟังก์ชันขึ้นอยู่กับสวิตช์สถานะหลัก การเปิดสวิตช์หมายถึงรายการการตั้งค่าเปิดใช้งานในขอบเขตปัจจุบัน; การปิดสวิตช์หมายถึงปิดใช้งานหรือไม่ได้เปิดใช้งาน บางปุ่มมีความหมายย้อนกลับและควรกำหนดตามชื่อและคำอธิบายของรายการการตั้งค่า ตัวอย่างเช่น ปุ่มที่มีชื่อประกอบด้วยคำว่า 'unsupport' หรือ 'disable' อาจหมายถึง 'ไม่รองรับ' หรือ 'ปิดใช้งาน' เมื่อเปิดใช้งาน

### 3.4 บันทึก ลบ และกู้คืน

- ก่อนการบันทึก ให้ตรวจสอบขอบเขตขององค์กร ชื่อคีย์ ประเภท หน่วย และค่าที่แก้ไขอีกครั้ง
- หลังจากบันทึกแล้ว ให้ค้นหารายการการตั้งค่าเดียวกันอีกครั้งเพื่อยืนยันว่าแหล่งที่มา สถานะ และค่าที่ใช้งานได้มีการเปลี่ยนแปลง
- เมื่อมีการแทนค่าภายในสโคปปัจจุบัน การดำเนินการ 'ลบ' อาจสามารถทำได้; หลังจากลบค่าที่แทนที่ออก ระบบจะกลับไปใช้ค่าที่สืบทอดมาจากระดับก่อนหน้า
- เมื่อจำเป็นต้องย้อนกลับ ให้เขียนค่าสำรองที่บันทึกไว้เดิมก่อน หรือหลังจากยืนยันความสัมพันธ์การสืบทอดแล้ว ให้ลบการแทนค่าปัจจุบัน
- อย่าเข้าใจคำว่า 'ลบ' ว่าเป็นการลบรายการการตั้งค่าเอง การลบบนหน้ามักจะใช้กับบันทึกการแทนค่าในสโคปปัจจุบันเท่านั้น

## 4. การตรวจสอบประสิทธิผลและการย้อนกลับ

### 4.1 การตรวจสอบหลังจากการบันทึก

- ในหน้าการตั้งค่าระบบ ให้สืบค้นสโคปองค์กรเดียวกันและรายการการตั้งค่าเดียวกันอีกครั้งเพื่อยืนยันแหล่งที่มา สถานะ และค่าที่ใช้งานได้
- ไปที่หน้าฟังก์ชันที่ใช้การตั้งค่านี้จริง ๆ เพื่อตรวจสอบประสิทธิภาพของฟังก์ชัน ไม่ใช่เพียงแค่ดูที่หลังบ้านการตั้งค่าเท่านั้น
- สำหรับการกำหนดค่าระดับโลก ควรสุ่มตรวจสอบอย่างน้อยหนึ่งบริษัทที่ไม่มีการกำหนดค่าระดับองค์กร; การกำหนดค่าระดับองค์กรจะตรวจสอบเฉพาะกับบริษัทเป้าหมายเท่านั้น
- สำหรับบัญชี สิทธิ์ หรือการตั้งค่าที่เกี่ยวข้องกับแคช ให้รีเฟรชหน้า ล็อกอินใหม่ หรือรอให้แคชอัปเดตถ้าจำเป็น
- บันทึกเวลาที่แก้ไข ผู้ดำเนินการ ขอบเขตองค์กร ชื่อคีย์ ค่าก่อนและหลังการแก้ไข และผลการตรวจสอบ

### 4.2 ยกเลิกการเปลี่ยนแปลง

- มีค่าต้นฉบับที่แน่นอน: แก้ไขซ้ำและเขียนกลับค่าต้นฉบับ
- เพียงแค่ต้องลบการแทนที่ขอบเขตปัจจุบัน: ใช้ 'กู้คืนค่าเริ่มต้นของระบบ' หรือ ลบการแทนที่ปัจจุบัน
- หลังจากเลิกใช้งาน ให้สอบถามค่าต้นทางและค่าที่มีผลอีกครั้ง และกลับเข้าสู่หน้าธุรกิจเพื่อตรวจสอบ
- หากการเปลี่ยนแปลงระดับโลกทำให้เกิดความผิดปกติทั่วทั้งระบบ ควรให้ความสำคัญกับการกู้คืนการครอบคลุมระดับโลกก่อน จากนั้นจึงตรวจสอบความแตกต่างของการครอบคลุมระหว่างแต่ละองค์กร
