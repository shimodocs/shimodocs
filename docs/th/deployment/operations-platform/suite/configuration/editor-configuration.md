# การกำหนดค่าโปรแกรมแก้ไข

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## 1. คำแนะนำคู่มือ

คู่มือนี้จะแนะนำฟีเจอร์ "การกำหนดค่า Editor" ของ ShimoDocs Suiteเหมาะสำหรับผู้ดูแลระบบและผู้ดำเนินการที่ใช้ฟีเจอร์นี้เป็นครั้งแรก คุณสามารถทำตามขั้นตอนในเอกสารนี้เพื่อค้นหารายการการกำหนดค่า แก้ไขสวิตช์ฟีเจอร์หรือโควต้า ตรวจสอบว่ามีผลหรือไม่ และคืนค่าไปยังการตั้งค่าเดิมหากจำเป็น

**กฎขอบเขตที่สำคัญที่สุด** เมื่อช่อง Team ID ว่าง จะเป็นการสอบถามและแก้ไขการกำหนดค่าแอปพลิเคชันเริ่มต้น; เมื่อกรอก Team ID จะเป็นการสอบถามและแก้ไขการกำหนดค่าสำหรับทีมที่ตรงกัน การแก้ไขการกำหนดค่าแอปพลิเคชันเริ่มต้นอาจมีผลกระทบต่อหลายทีม ดังนั้นโปรดยืนยันขอบเขตการกำหนดค่าอีกครั้งก่อนบันทึก

### 1.1 การเข้าถึงเมนู

Admin Backend > ShimoDocs Suite > การจัดการการกำหนดค่า > การกำหนดค่า Editor

### 1.2 การเตรียมความพร้อมก่อนการใช้งาน

- ยืนยันว่าบัญชีผู้ใช้งานของคุณมีสิทธิ์ในการดูและแก้ไข ShimoDocs Suite การกำหนดค่า editor
- ยืนยันก่อนว่าขอบเขตเป้าหมายเป็นแอปพลิเคชันเริ่มต้นหรือทีมเฉพาะ และรับรหัสทีม (Team ID) ที่ถูกต้อง
- ยืนยันชื่อรายการการกำหนดค่าจากข้อกำหนดการกำหนดค่าหรือภาคผนวก A ชื่อรายการการกำหนดค่าคือรหัสประจำตัวที่ไม่ซ้ำกัน; อย่าสันนิษฐานเพียงจากชื่อฟีเจอร์ภาษาจีน
- บันทึกแหล่งที่มา ค่าที่มีผล และสถานะข้อจำกัดก่อนแก้ไข; สำหรับการกำหนดค่าที่สำคัญ ให้เตรียมค่าการย้อนกลับด้วย
- การกำหนดค่าแอปพลิเคชันเริ่มต้นมีผลกระทบกว้าง; แนะนำให้แก้ไขในช่วงเวลาที่ธุรกิจน้อยและแจ้งบุคคลที่รับผิดชอบที่เกี่ยวข้องล่วงหน้า

## 2. ขอบเขตและลำดับความสำคัญของการกำหนดค่า

การกำหนดค่าโปรแกรมแก้ไขรองรับสองขอบเขต: App Default และ Team ก่อนทำการเปลี่ยนแปลง คุณต้องตรวจสอบทั้ง Team ID และ 'Current Dimension' ที่ด้านบนของหน้า

| **พื้นที่การทำงาน** | **ขอบเขตแอปเริ่มต้น** | **ขอบเขตทีม** | **ตัวบ่งชี้การจดจำหน้า** |
| --- | --- | --- | --- |
| การกำหนดค่าโปรแกรมแก้ไข | ปล่อย Team ID ว่าง | ป้อน Team ID เป็นจำนวนเต็มบวก | Current Dimension แสดง 'App Default' หรือ 'Team' |

*รูปที่ 1 ความสอดคล้องระหว่าง Team ID และมิติปัจจุบัน*

### 2.1 ขอบเขตค่าเริ่มต้นของแอปพลิเคชัน

- เว้นว่าง Team ID ไว้
- ด้านบนของหน้าจอจะแสดงว่า “Current Dimension: Application Default”
- ค่าตั้งต้นของแอปพลิเคชันคือค่าพื้นฐานเมื่อไม่มีการกำหนดค่าทับของทีม การแก้ไขค่าอาจมีผลต่อหลายทีม
- ก่อนบันทึก ให้ยืนยันอีกครั้งว่า Team ID ว่างจริง ๆ เพื่อลดความเสี่ยงในการเขียนความต้องการของทีมเป็นการตั้งค่าเริ่มต้นของแอปพลิเคชันโดยไม่ตั้งใจ

### 2.2 ขอบเขตของทีม

- กรอก ID จำนวนเต็มบวกของทีมที่ต้องการในช่อง Team ID แล้วคลิก “Query”
- ด้านบนของหน้าจอจะแสดงว่า “Current Dimension: Team”
- การกำหนดค่าระดับทีมจะมีผลเฉพาะกับทีมที่ตรงกับ Team ID ที่กรอก และจะไม่เปลี่ยนการกำหนดค่าของทีมอื่นโดยตรง
- เมื่อรายการการกำหนดค่ามีการตั้งค่าระดับทีม ค่าที่มีผลของทีมจะได้สิทธิ์เหนือค่าตั้งต้นของแอปพลิเคชัน

### 2.3 การกำหนดค่าทับ การสืบทอด และการกู้คืน

- หากทีมปัจจุบันไม่มีการปรับค่าแบบกำหนดเอง จะใช้การกำหนดค่ามาตรฐานของแอปพลิเคชันหรือค่ามาตรฐานของระบบ
- “แหล่งที่มา” ในรายการสามารถช่วยระบุได้ว่าค่าปัจจุบันมาจากค่ามาตรฐานของระบบ การปรับค่าแอปพลิเคชัน หรือการปรับค่าทีม
- หลังจากลบการปรับค่าของชั้นปัจจุบัน การกำหนดค่ามักจะรับค่าจากระดับบนใหม่; โปรดยืนยันผลลัพธ์หลังการรับค่าก่อนลบ
- หลังจากแก้ไขหรือกู้คืน ให้สอบถามรหัสทีมและรายการการกำหนดค่าเดิมเพื่อยืนยันว่าแหล่งที่มาและค่าที่มีผลตรงตามที่คาดหวัง

**คำเตือนความเสี่ยง** อย่าบันทึกโดยตรงโดยไม่ยืนยันมิติปัจจุบัน เมื่อรหัสทีมว่าง การดำเนินการจะถูกเขียนลงในขอบเขตมาตรฐานของแอป ซึ่งอาจมีผลต่อทีมหลายทีม 

## 3. การกำหนดค่า Editor 

การกำหนดค่า Editor ใช้สำหรับดูและปรับสวิตช์ฟีเจอร์ จำนวนการใช้งาน และการกำหนดค่าเชิงโครงสร้างของ ShimoDocs Suite Editor คุณสามารถกรองตามประเภทหรือขยาย "ตัวกรองขั้นสูง" และป้อนชื่อรายการการกำหนดค่าใน "รายชื่อขาวชื่อ" เพื่อค้นหาอย่างแม่นยำ 

### 3.1 ช่องของหน้า 

| **ช่อง** | **คำอธิบาย** | 
| --- | --- | 
| รหัสแอป | ปัจจุบัน ShimoDocs Suite รหัสแอปพลิเคชันปัจจุบัน ใช้เพื่อยืนยันบริบทเท่านั้น | 
| มิติปัจจุบัน | "ค่าเริ่มต้นของแอป" เมื่อรหัสทีมว่าง; "ทีม" หลังจากกรอกรหัสทีมแล้ว | 
| รหัสทีม | รหัสทีม; รับเฉพาะจำนวนเต็มบวกเท่านั้น | 
| ประเภท | ตัวเลือกได้แก่ ทั้งหมด, ฟีเจอร์, โควต้าค่าคงที่เดียว, โควต้าช่วง, หรือ JSON การกำหนดค่า | 
| ตัวกรองขั้นสูง | ขยายกล่องป้อนข้อมูลสำหรับชื่อตัวกำหนดค่ารายการ | 
| รายชื่อที่อนุญาต | กรอกชื่อรายการการตั้งค่า; รองรับรายการเดียวต่อบรรทัดหรือคั่นด้วยเครื่องหมายจุลภาคภาษาอังกฤษ | 
| แหล่งที่มา | ระบุว่าค่าปัจจุบันมาจากค่าเริ่มต้นของระบบ, การแทนที่แอปพลิเคชัน, หรือการแทนที่ของทีม | 
| ค่าที่มีผล | สวิตช์, โควต้า หรือการตั้งค่าเชิงโครงสร้างที่ใช้ในขอบเขตปัจจุบัน | 
| การดำเนินการ | ไอคอนดินสอสำหรับแก้ไข; ไอคอนลบสำหรับลบการแทนที่เลเยอร์ปัจจุบัน | 

*รูปที่ 2 พื้นที่ค้นหาในหน้าแก้ไข, รายการผลลัพธ์ และคอลัมน์การดำเนินการ*

### 3.2 การค้นหาอย่างแม่นยำ

1. ตัดสินใจว่าจะกรอก Team ID หรือไม่ตามช่วงการกำหนดค่า: ปล่อยว่างเพื่อใช้ช่วงเริ่มต้นของแอปพลิเคชัน หรือกรอกสำหรับทีมที่เกี่ยวข้อง
2. เลือก "Type" ตามความต้องการ; หากไม่แน่ใจเกี่ยวกับประเภท ให้คงค่าเป็น "All"
3. คลิก "Advanced Filter" เพื่อขยาย "Name Whitelist"
4. ป้อนชื่อรายการกำหนดค่าเต็มรูปแบบ สำหรับหลายชื่อ ให้ป้อนทีละบรรทัดหรือคั่นด้วยเครื่องหมายจุลภาค
5. คลิก "Query" เพื่อยืนยันชื่อ ประเภท แหล่งที่มา และค่าที่มีผลในผลลัพธ์
6. คลิกไอคอนดินสอทางด้านขวาสุดของแถวเป้าหมายเพื่อเปิดหน้าต่างแก้ไข

*รูปที่ 3 กรอก name whitelist หลังคลิก 'Advanced Filter'*

*รูปที่ 4 ผลลัพธ์เดียวหลังการค้นหาอย่างแม่นยำเพื่อแก้ไข_จำกัด_mosheet_ขนาด*

**เคล็ดลับในการปฏิบัติการ** หากคุณไม่เห็นไอคอนการดำเนินการ โปรดเลื่อนรายการไปด้านขวาสุดหรือขยายพื้นที่การมองเห็นของเบราว์เซอร์

### 3.3 การค้นหาโดยตรงในรายการ

- ก่อนอื่นให้ยืนยันว่า Team ID และตัวกรองประเภทถูกต้อง จากนั้นเลื่อนดูผลลัพธ์ของการค้นหา
- ใช้ทั้ง “Name” และ “Type” เพื่อยืนยันการกำหนดค่าของเป้าหมาย; อย่าพึ่งพาเพียงค่าปัจจุบันเท่านั้น
- จำนวนระเบียนที่แสดงบนหน้าจะเปลี่ยนแปลงขึ้นอยู่กับเวอร์ชันการปรับใช้และรายการการกำหนดค่าที่แอปพลิเคชันปัจจุบันรองรับ
- หลังจากพบแถวเป้าหมาย ให้คลิกไอคอนดินสอทางด้านขวาสุดเพื่อเข้าสู่โหมดแก้ไข

### 3.4 การแก้ไขการกำหนดค่า

#### 3.4.1 ฟังก์ชัน

ประเภทฟังก์ชันถูกใช้เพื่อควบคุมว่าความสามารถนั้นมีให้ใช้งานหรือไม่ หลังจากเปิดหน้าต่างแก้ไข ให้เลือกสถานะที่มีในหน้าต่างเช่น “Support” หรือ “Hide” จากเมนูดรอปดาวน์ “Effective Value” จากนั้นคลิก “Save” บางชื่อรายการการกำหนดค่าจะมีความหมายตรงข้าม เช่น unsupport หรือ disable ดังนั้นโปรดตัดสินใจความหมายจริงตามชื่อรายการและคำอธิบาย

*รูปที่ 5 การตั้งค่า Effective Value ของรายการการกำหนดค่าประเภทฟังก์ชัน*

#### 3.4.2 โควต้าค่าเดียว

โควตาค่าหนึ่งค่าเดี่ยวมักรวมถึงสวิตช์ "การตรวจสอบขีดจำกัด" และ "ค่าสูงสุด" เมื่อเปิดใช้งานการตรวจสอบขีดจำกัด ระบบจะทำการตรวจสอบตามค่าสูงสุด; เมื่อปิดใช้งาน มักจะแสดงเป็น "ไม่จำกัด" ค่าสูงสุดจะต้องอยู่ภายในช่วงที่อนุญาตของพารามิเตอร์และสอดคล้องกับหน่วยในชื่อพารามิเตอร์ เช่น MB, GB, หน้า, รายการ หรือ ตัวอักษร

*รูปที่ 6 การตรวจสอบโควตาค่าหนึ่งค่าและการตั้งค่าค่าสูงสุด*

#### 3.4.3 โควตาช่วง

- โควตาช่วงมักจะให้ทั้งค่าน้อยสุดและค่าสูงสุด
- ค่าน้อยสุดไม่สามารถมากกว่าค่าสูงสุดได้ และค่าที่ป้อนควรอยู่ภายในช่วงที่อนุญาตที่ระบุในหน้าหรือภาคผนวก
- หากหน้ามีตัวเลือก "ไม่ตรวจสอบ" หรือ "ไม่จำกัด" ให้ยืนยันก่อนว่าฟังก์ชันปัจจุบันรองรับการตั้งค่านี้หรือไม่
- หลังจากบันทึกแล้ว ให้ตรวจสอบค่าขอบเขตในฟังก์ชันธุรกิจจริงเพื่อหลีกเลี่ยงการตรวจสอบเพียงการแสดงผลในระบบหลังบ้าน

#### 3.4.4 JSON การกำหนดค่า

- JSON การกำหนดค่าต้องรักษาโครงสร้างที่ถูกต้อง รวมถึงการจับคู่เครื่องหมายคำพูด, เครื่องหมายจุลภาค, วงเล็บ และชนิดข้อมูลที่ถูกต้อง
- บันทึกค่าต้นฉบับทั้งหมดก่อนทำการเปลี่ยนแปลง; ไม่บันทึกเพียงสนามเดียว
- เมื่อความหมายของสนามไม่ชัดเจน อย่าเพิ่ม ลบ หรือเปลี่ยนชื่อสนามโดยพลการ

### 3.5 บันทึกและลบ

- ก่อนบันทึก ยืนยันอีกครั้งถึงมิติปัจจุบัน, รหัสทีม, ชื่อรายการการกำหนดค่า, ชนิด, หน่วย, และค่าที่ใหม่
- หลังจากบันทึก ตรวจสอบช่วงเดียวกันและรายการกำหนดค่าเดียวกันอีกครั้งเพื่อยืนยันว่าค่าต้นทางและค่าที่มีผลได้รับการอัปเดต
- ไอคอนลบมักใช้สำหรับลบบันทึกการแทนที่ของช่วงปัจจุบัน ไม่ใช่เพื่อลบรายการกำหนดค่าเอง
- คู่มือฉบับนี้แสดงเฉพาะรายการกำหนดค่าที่สามารถสอบถามและแก้ไขในหน้าปัจจุบันเท่านั้น รายการที่แสดงจริงอาจแตกต่างกันไปขึ้นอยู่กับเวอร์ชันการปรับใช้และความสามารถในการสนับสนุนแอปพลิเคชันปัจจุบัน

### 3.6 คำอธิบายรายการการกำหนดค่า

ภาคผนวก A รวมถึงเฉพาะรายการการกำหนดค่าโปรแกรมแก้ไขที่สามารถสอบถามและแก้ไขได้บนหน้าปัจจุบันเท่านั้น; ช่วงการแสดงผลที่มองเห็นได้เฉพาะเจาะจงขึ้นอยู่กับเวอร์ชันการปรับใช้งานปัจจุบันและการแสดงผลจริงของหน้า

## 4. การตรวจสอบผลและการย้อนกลับ

### 4.1 การตรวจสอบหลังจากการบันทึก

- บนหน้าการกำหนดค่าโปรแกรมแก้ไข ให้สอบถาม Team ID เดิมและรายการการกำหนดค่าเดิมอีกครั้งเพื่อยืนยันแหล่งข้อมูล ค่าที่มีผล และสถานะข้อจำกัด
- เข้าสู่หน้าตัวแก้ไขหรือฟีเจอร์ที่ใช้งานการตั้งค่านี้จริง ๆ เพื่อยืนยันว่าฟังก์ชันสามารถมองเห็นได้ โควต้าใช้งานได้ หรือข้อจำกัดถูกยกเลิกแล้ว
- เมื่อใช้การตั้งค่าเริ่มต้น ให้ตรวจสอบกับทีมอย่างน้อยหนึ่งทีมที่ไม่มีการตั้งค่าระดับทีม สำหรับการตั้งค่าระดับทีม ให้ตรวจสอบเฉพาะ Team ID เป้าหมายเท่านั้น
- รีเฟรชหน้าเว็บ เข้าสู่ตัวแก้ไขอีกครั้ง ล็อกอินใหม่ หรือรอการอัปเดตแคชหากจำเป็น
- บันทึกเวลาที่มีการแก้ไข ผู้ปฏิบัติงาน ขอบเขตการกำหนดค่า รหัสทีม ชื่อรายการการกำหนดค่า ค่าก่อนและหลังการแก้ไข และผลการยืนยัน

### 4.2 ยกเลิกการเปลี่ยนแปลง

- หากมีการบันทึกค่าต้นฉบับไว้ ให้แก้ไขใหม่และเขียนค่าต้นฉบับกลับไป
- หากต้องการลบเฉพาะการแทนค่าช่วงปัจจุบัน ให้ใช้ไอคอนลบแล้วยืนยันค่าที่สืบทอดมาจากระดับบนหลังจากการลบ
- หลังจากยกเลิกการเปลี่ยนแปลง ให้สอบถามค่าแหล่งที่มาและค่าที่มีผลอีกครั้ง และเข้าสู่หน้าธุรกิจเพื่อตรวจสอบอีกครั้ง
- หากการปรับแก้ไขค่าเริ่มต้นทำให้เกิดความผิดปกติ ให้กู้คืนค่ามาตรฐานก่อน จากนั้นตรวจสอบว่ามีทีมใดที่มีการแทนค่าแยกต่างหากหรือไม่

**หมายเหตุสำคัญ** หลังจากลบการแทนค่าปัจจุบัน ค่าแบบสืบทอดอาจปรากฏทันทีบนหน้า ก่อนการลบ ต้องยืนยันการตั้งค่าระดับบนให้เป็นไปตามที่คาดหวัง และควรเก็บบันทึกสภาพก่อนการแก้ไข
