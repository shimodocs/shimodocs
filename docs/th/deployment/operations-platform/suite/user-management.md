# การจัดการผู้ใช้ชุดโปรแกรม

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

> [!TIP]
>
> การจัดการผู้ใช้ใช้สำหรับดูผู้ใช้ในแต่ละผู้เช่า ShimoDocs Suite และเพื่อเปิดหรือปิดใช้งานบัญชีผู้ใช้เป็นกลุ่ม 
>
> เพื่อใช้ฟีเจอร์นี้ คุณต้องเลือกผู้เช่าที่ผู้ใช้อยู่ก่อน จากนั้นเข้าสู่รายการผู้ใช้ที่เกี่ยวข้องเพื่อการจัดการ 

> หน้าการจัดการผู้ใช้จะแสดงช่วงของผู้เช่าที่ผู้ใช้อยู่โดยใช้ชื่อ "ทีม" 

## 1. เข้าสู่การจัดการผู้ใช้ 

1. เข้าสู่ระบบที่ **MDP แพลตฟอร์มปฏิบัติการ**. 
2. ที่ด้านบน เลือก **ShimoDocs Suite**. 
3. ในแถบนำทางด้านซ้าย เลือก **การจัดการผู้ใช้**. 

## 2. เลือกทีม (ผู้เช่า) ที่คุณต้องการจัดการ 

หลังจากเข้าสู่หน้าการจัดการผู้ใช้ ระบบจะแสดงรายการทีมก่อน โปรดเลือกทีม (ผู้เช่า) ที่ผู้ใช้อยู่จากรายการ 

### ค้นหาทีม (ผู้เช่า)

1. ในช่องค้นหาที่ด้านบนของหน้า ให้ใส่ชื่อทีม ผู้สร้าง หรือ ID 
2. ในผลลัพธ์การค้นหา ยืนยันชื่อทีม ผู้สร้าง จำนวนผู้ใช้งาน ความจุ และวันหมดอายุ 
3. คลิกที่ชื่อทีมเพื่อเข้าสู่รายชื่อผู้ใช้ของทีมนั้น 

### คำอธิบายฟิลด์รายการทีม

| ช่องข้อมูล | คำอธิบาย |
| --- | --- |
| รหัสประจำตัว | ตัวระบุเฉพาะของทีมในระบบ |
| ชื่อทีม | ชื่อของทีม คลิกเพื่อเข้าสู่รายการผู้ใช้ของทีมนี้ |
| ผู้สร้าง | บัญชีที่สร้างทีมนี้ |
| เปิดใช้งาน / ความจุ | จำนวนผู้ใช้ที่เปิดใช้งานในปัจจุบันและที่นั่งที่ใช้ได้สำหรับทีม |
| วันหมดอายุ | วันหมดอายุของบริการปัจจุบันสำหรับทีมนี้ |

> หากเนื้อหารายการไม่ได้รับการอัปเดตทันที คุณสามารถคลิก "รีเฟรช" ที่ด้านขวาของกล่องค้นหา

## 3. ดูผู้ใช้เช่า

หลังจากคลิกชื่อเช่า หน้าจอจะแสดงรายการผู้ใช้ภายในเช่านั้น

### คำอธิบายฟิลด์รายการผู้ใช้

| ช่องข้อมูล | คำอธิบาย |
| --- | --- |
| รหัสประจำตัว | ตัวระบุเฉพาะของผู้ใช้ในระบบ |
| USERNAME | ชื่อที่แสดงสำหรับผู้ใช้ ShimoDocs Suite. |
| อีเมล | อีเมลที่ผูกกับบัญชีผู้ใช้ |
| บทบาท | บทบาทของผู้ใช้ในเช่าปัจจุบัน เช่น ผู้ดูแลระบบ หรือ สมาชิก |
| สถานะ | สถานะที่บัญชีผู้ใช้นี้เปิดใช้งานอยู่หรือไม่ |

## 4. การค้นหาผู้ใช้

เมื่อมีผู้ใช้งานหลายคนในผู้เช่า คุณสามารถใช้ฟังก์ชันค้นหาเพื่อหาผู้ใช้เป้าหมายได้อย่างรวดเร็ว

1. ป้อน USERNAME, อีเมล หรือรหัสผู้ใช้ในกล่องค้นหาที่อยู่เหนือรายการผู้ใช้
2. ตรวจสอบ USERNAME, อีเมล และบทบาทในผลการค้นหาเพื่อให้แน่ใจว่าคุณพบผู้ใช้เป้าหมายแล้ว
3. ในการโหลดรายการใหม่ คลิก “รีเฟรช” ที่ด้านขวาของกล่องค้นหา

## 5. การเปิดใช้งานผู้ใช้พร้อมกันจำนวนมาก

เมื่อบัญชีผู้ใช้ถูกปิดใช้งานและต้องการกู้คืน คุณสามารถเปิดใช้งานผู้ใช้จำนวนมากได้

### ขั้นตอน

1. ยืนยันว่าหน้าปัจจุบันแสดงผู้เช่าที่ต้องการ
2. เลือกผู้ใช้หนึ่งคนหรือหลายคนที่ต้องการเปิดใช้งานทางด้านซ้ายของรายการผู้ใช้
3. ยืนยันว่าตัวเลขที่แสดงเป็น “เลือกแล้ว” ที่มุมขวาบนของหน้าถูกต้อง
4. คลิก “เปิดใช้งานพร้อมกันจำนวนมาก”
5. ยืนยันการดำเนินการตามคำแนะนำบนหน้า
6. หลังการดำเนินการเสร็จสิ้น รีเฟรชรายการและยืนยันว่าสถานะผู้ใช้เปลี่ยนเป็น "เปิดใช้งานแล้ว"

## 6. การปิดใช้งานผู้ใช้แบบกลุ่ม

เมื่อผู้ใช้ชั่วคราวไม่จำเป็นต้องใช้งาน ShimoDocs Suiteบัญชีของพวกเขาสามารถถูกปิดใช้งานแบบกลุ่มได้

### ขั้นตอน

1. ยืนยันว่าหน้าปัจจุบันแสดงผู้เช่าที่ต้องการ
2. เลือกผู้ใช้หนึ่งคนหรือมากกว่าที่ต้องการปิดใช้งานทางด้านซ้ายของรายการผู้ใช้
3. ยืนยันว่าจำนวนที่แสดงใน "ที่เลือก" ที่มุมขวาบนของหน้าเว็บถูกต้อง
4. คลิก "ปิดใช้งานแบบกลุ่ม"
5. ยืนยันการดำเนินการตามคำแนะนำบนหน้า
6. หลังจากดำเนินการเสร็จสิ้น ให้รีเฟรชรายการและยืนยันว่าสถานะผู้ใช้ได้รับการอัปเดต

> การปิดใช้งานผู้ใช้จะส่งผลต่อการใช้งานปกติของ ShimoDocs Suite สำหรับบัญชีนั้น โปรดตรวจสอบผู้เช่า USERNAME, อีเมล และบทบาทก่อนการดำเนินการเพื่อหลีกเลี่ยงผลกระทบต่อผู้ใช้อื่นโดยไม่ตั้งใจ

## 7. กลับไปที่รายการผู้เช่า

หากคุณต้องการสลับไปยังผู้เช่าอื่น:

1. คลิก "กลับไปที่รายการทีม" ที่มุมบนซ้ายของหน้าเว็บ
2. ค้นหาและเลือกผู้เช่าที่ต้องการอีกครั้งในรายการผู้เช่า
