# การจัดการผู้เช่า

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

> [!TIP]
>
> การจัดการผู้เช่าใช้สำหรับการจัดการผู้เช่าแบบรวมศูนย์ ShimoDocs Suite.
> ผู้ดูแลระบบสามารถดูจำนวนผู้เช่าและการใช้งานที่นั่งที่นี่ รับข้อมูลสำหรับการรวมกับบุคคลที่สาม จัดการการตั้งค่า AI และสร้าง แก้ไข เปิดใช้ หรือตัดการใช้งานผู้เช่าได้
>

## 1. การเข้าถึงการจัดการผู้เช่า

1. เข้าสู่ระบบที่ **MDP แพลตฟอร์มปฏิบัติการ**.
2. เลือก **ShimoDocs Suite** ที่ด้านบน
3. เลือก **การจัดการผู้เช่า** ในแถบนำทางด้านซ้าย

## 2. การทำความเข้าใจหน้าการจัดการผู้เช่า

ข้อมูลโดยรวมของระบบปัจจุบันจะแสดงอยู่ที่ด้านบนของหน้า:

| ภูมิภาค | คำอธิบาย |
| --- | --- |
| API-KEY | ดูและคัดลอก `AppID` และ `AppSecret` ที่จำเป็นสำหรับการรวมกับบุคคลที่สาม |
| การตั้งค่า AI | ตรวจสอบว่าได้เปิดใช้งานความสามารถของ AI หรือไม่ และเข้าถึงการกำหนดค่าโมเดล AI และการค้นหา |
| จำนวนผู้เช่าทั้งหมด | จำนวนผู้เช่าที่ถูกสร้างขึ้นในระบบปัจจุบัน |
| ผู้เช่าที่เปิดใช้งาน | จำนวนผู้เช่าที่เปิดใช้งานในปัจจุบัน |
| การใช้งานที่นั่ง | จำนวนที่นั่งที่ใช้งาน จำนวนที่นั่งทั้งหมดในระบบ และอัตราการใช้งาน |

รายการผู้เช่าด้านล่างจะแสดงชื่อผู้เช่า เวลาการเปิดใช้งาน ผู้ดูแลผู้เช่า การใช้งานที่นั่ง และสถานะปัจจุบัน ในคอลัมน์ 'การดำเนินการ' คุณสามารถแก้ไขหรือปิดใช้งานผู้เช่าที่เกี่ยวข้องได้

## 3. ดู API คีย์

`AppID` และ `AppSecret` ถูกใช้สำหรับการตรวจสอบสิทธิ์เมื่อ ShimoDocs Suite รวมกับระบบบุคคลที่สาม

### ขั้นตอนการดำเนินงาน

1. ค้นหา **API-KEY** การ์ดบนหน้าจัดการผู้เช่า
2. คลิกไอคอนคัดลอก
3. ระบบจะคัดลอก `AppID` และ `AppSecret`.
4. ป้อนข้อมูลรับรองเข้าสู่การกำหนดค่าการรวมกับบุคคลที่สามที่เกี่ยวข้อง

> `AppSecret` เป็นข้อมูลประจำตัวที่ละเอียดอ่อน โปรดเก็บรักษาให้ปลอดภัยและอย่าบันทึกลงในเอกสารสาธารณะ บันทึกการสนทนา หรือที่เก็บโค้ดที่เข้าถึงได้สาธารณะ

## 4. การจัดการการกำหนดค่า AI

บัตรการกำหนดค่า AI จะแสดงสถานะการเปิดใช้งานความสามารถของ AI ในปัจจุบัน

หลังจากคลิกที่บัตรการกำหนดค่า AI คุณสามารถดูหรือแก้ไขเนื้อหาต่อไปนี้ได้บนหน้า "การกำหนดค่าโมเดล AI และการค้นหา" 

### 1. การกำหนดค่าโมเดลพื้นฐาน

ใช้สำหรับการกำหนดค่าโมเดลภาษาขนาดใหญ่ทั่วไป (LLMs) และโมเดลที่มีให้บริการ บนหน้านี้ คุณสามารถดูข้อมูล เช่น ผู้ให้บริการ คำขอ URL, API คีย์ โมเดลเริ่มต้น รหัสโมเดล หน้าต่างบริบท และความสามารถในการป้อนข้อมูล

### 2. การกำหนดค่าโมเดลภาพ

ใช้สำหรับการกำหนดค่าโมเดลสร้างภาพหรือตัดต่อภาพ บนหน้านี้ คุณสามารถดูผู้ให้บริการ ชื่อโมเดล คีย์ฐาน URL, API และความสามารถด้านภาพที่รองรับ

### 3. การกำหนดค่าเครื่องมือค้นหาเครือข่าย

ใช้สำหรับการกำหนดค่าบริการการค้นหาเครือข่าย AI บนหน้านี้ คุณสามารถดูผู้ให้บริการ บริการ ที่อยู่ของอินเตอร์เฟส API คีย์ และ การหมดเวลา

### 4. การตั้งค่าผู้ให้บริการฝังข้อมูล

ใช้ในการตั้งค่าบริการแปลงข้อความเป็นเวกเตอร์ ในหน้าดังกล่าว คุณสามารถดูคีย์ฐาน URL, API โมเดลฝังข้อมูล และมิติของเวกเตอร์

> ก่อนแก้ไขการตั้งค่า AI โปรดยืนยันก่อนว่าที่อยู่บริการ API คีย์ ID โมเดล และพารามิเตอร์ความสามารถทั้งหมดถูกต้อง หลังจากแก้ไข แนะนำให้ใช้เนื้อหาทดสอบเล็กน้อยเพื่อตรวจสอบว่าเรียกใช้งานโมเดลได้อย่างถูกต้องหรือไม่

### 5. การใช้ AI ใน ShimoDocs Suite
หลังจากการตั้งค่าเสร็จสมบูรณ์ คุณสามารถใช้คุณสมบัติ AI ภายใน ShimoDocs Suite.

## 5. การจัดการผู้เช่าที่มีอยู่

ในรายการผู้เช่า คุณสามารถดูข้อมูลพื้นฐานและการใช้งานที่นั่งของผู้เช่าแต่ละราย

### แก้ไขผู้เช่า

1. ค้นหาผู้เช่าที่ต้องการปรับเปลี่ยน
2. คลิก 'แก้ไข' ในคอลัมน์ 'การกระทำ'
3. แก้ไขข้อมูลผู้เช่าหรือจำนวนที่นั่งตามคำแนะนำในหน้า
4. บันทึกการเปลี่ยนแปลงแล้วกลับไปที่รายการเพื่อยืนยันว่าข้อมูลได้รับการอัปเดต

### ปิดใช้งานหรือกู้คืนผู้เช่า

- สำหรับผู้เช่าที่เปิดใช้งานอยู่ในปัจจุบัน คุณสามารถคลิก 'ปิดใช้งาน' ในคอลัมน์ 'การดำเนินการ'
- ในการกู้คืนผู้เช่าที่ถูกปิดใช้งาน ให้เปิดใช้งานอีกครั้งในรายการการดำเนินการของผู้เช่าที่เกี่ยวข้อง

> การปิดใช้งานผู้เช่าจะส่งผลต่อการเข้าถึงปกติของผู้เช่าคนนั้น โปรดยืนยันว่าผู้เช่าที่เลือกถูกต้องก่อนดำเนินการ และกำหนดเวลาการดำเนินงานตามการใช้งานจริง

## 6. การเปิดใช้งานผู้เช่าใหม่

ก่อนเปิดใช้งานผู้เช่า โปรดตรวจสอบการใช้งานที่นั่งที่ด้านบนของหน้าเพื่อยืนยันว่ายังมีที่นั่งให้จัดสรรอยู่หรือไม่

### ขั้นตอนการดำเนินงาน

1. คลิก "เปิดใช้งานผู้เช่าใหม่" ที่มุมขวาบนของหน้า
2. ป้อนชื่อที่ใช้ระบุผู้เช่านี้ใน "ชื่อผู้เช่า"
3. ยืนยันอีเมลผู้ดูแลระบบผู้เช่าที่สร้างโดยระบบ หลังจากที่ผู้เช่าสร้างสำเร็จแล้ว โปรดบันทึกบัญชีผู้ดูแลระบบนี้และข้อมูลเริ่มต้น PASSWORD ทันที
4. ตรวจสอบ "ที่นั่งที่สามารถจัดสรรได้" เพื่อเข้าใจจำนวนที่นั่งสูงสุดที่สามารถจัดสรรให้ผู้อยู่อาศัยใหม่ได้ในปัจจุบัน
5. กรอกจำนวนที่นั่งที่จัดสรรให้กับผู้เช่านี้ใน "ที่นั่งที่ผู้เช่าได้รับจัดสรร"
6. หลังจากยืนยันว่าข้อมูลถูกต้อง ให้คลิก "บันทึก"

### คำอธิบายช่องที่นั่ง

| ช่องข้อมูล | คำอธิบาย |
| --- | --- |
| ที่นั่งที่สามารถจัดสรรได้ | จำนวนที่นั่งสูงสุดที่ระบบสามารถจัดสรรให้กับผู้เช่าได้ในขณะนี้ |
| ที่นั่งที่จัดสรรให้กับผู้เช่า | จำนวนรวมของที่นั่งที่จัดสรรให้กับผู้เช่านี้ จำนวนนี้ไม่สามารถน้อยกว่าจำนวนที่นั่งที่ผู้เช่าใช้งานแล้ว |
| ที่นั่งที่ผู้เช่าใช้งาน | จำนวนสมาชิกองค์กรที่ใช้งานอยู่ในผู้เช่านี้ สมาชิกที่ใช้งานแต่ละคนจะครองที่นั่งหนึ่งที่ |

> จำเป็นต้องจัดสรรจำนวนที่นั่งบางส่วนเมื่อสร้างผู้เช่า จำนวนที่นั่งสามารถปรับเปลี่ยนภายหลังตามการใช้งานจริง

## 7. การเข้าสู่ระบบครั้งแรกและการเปลี่ยนรหัสเริ่มต้น PASSWORD

หลังจากผู้เช่าสร้างสำเร็จ กรุณาเข้าสู่ระบบที่ ShimoDocs Suite โดยใช้บัญชีมาตรฐานที่ระบบสร้างให้หรือบัญชีผู้ดูแลระบบแล้วเปลี่ยนรหัสเริ่มต้นทันที PASSWORD.

### 1. เปิด ShimoDocs Suite

เข้าถึงผ่านเบราว์เซอร์:

```text
http://<ACCESS_DOMAIN>/
```

ถ้า HTTPS ได้กำหนดค่าแล้ว กรุณาเข้าชม: 

```text
https://<ACCESS_DOMAIN>/
```

### 2. เข้าสู่ระบบที่ ShimoDocs Suite

ป้อนบัญชีผู้ดูแลระบบและรหัสเริ่มต้น PASSWORD ที่สร้างขึ้นเมื่อกำหนดค่าผู้เช่าเพื่อเข้าสู่ระบบเสร็จสิ้น

### 3. เปลี่ยนค่าเริ่มต้น PASSWORD

หลังจากเข้าสู่ระบบครั้งแรก โปรดทำตามคำแนะนำบนหน้าเพจหรือการตั้งค่าความปลอดภัยของบัญชีเพื่อเปลี่ยนค่าเริ่มต้น PASSWORD. เมื่อกำหนดค่าใหม่เรียบร้อยแล้ว PASSWORD โปรดเก็บรักษาอย่างถูกต้อง
