# การกำหนดค่า AI

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

การตั้งค่า AI ใช้เชื่อมต่อ ShimoDocs Suite กับโมเดลฐาน โมเดลภาพ การค้นหาออนไลน์ และบริการ Embedding หลังจากทำการตั้งค่าเสร็จ ฟังก์ชันใน ShimoDocs Suite เช่น การสนทนา AI การสร้างเนื้อหา การประมวลผลภาพ และการดึงความรู้ สามารถเข้าถึงบริการที่สอดคล้องกันได้ 

## 1. ทำความเข้าใจสี่ประเภทของความสามารถก่อนการตั้งค่า 

วัตถุประสงค์ของการกำหนดค่าทั้งสี่ประเภทนั้นแตกต่างกัน และคุณอาจไม่จำเป็นต้องกำหนดค่าทั้งหมด กรุณาเลือกตาม ShimoDocs Suite คุณสมบัติที่คุณวางแผนจะเปิดใช้งาน 

| ประเภทการกำหนดค่า | วัตถุประสงค์ | จำเป็นต้องกำหนดค่า | 
| --- | --- | --- |
| รุ่นพื้นฐาน | จัดการการสนทนา การเขียน การสรุป การเขียนใหม่ การถาม-ตอบ และงานข้อความหรืองานหลายรูปแบบอื่น ๆ | มักจำเป็นเมื่อใช้ฟีเจอร์ AI |
| โมเดลภาพ | สร้างหรือแก้ไขภาพ | จำเป็นเฉพาะเมื่อใช้ฟีเจอร์สร้างหรือแก้ไขภาพ |
| ค้นหาออนไลน์ | ดึงข้อมูลจากบริการค้นหาออนไลน์ภายนอกเพื่อเสริมอ้างอิงของโมเดล | จำเป็นเฉพาะเมื่อใช้ฟีเจอร์ดึงข้อมูลออนไลน์ |
| การฝังตัว | แปลงข้อความเป็นเวกเตอร์เพื่อใช้ในการดึงข้อมูลจากฐานความรู้ การค้นหาเชิงความหมาย และคุณสมบัติที่คล้ายกัน | จำเป็นเฉพาะเมื่อใช้ฟีเจอร์ดึงข้อมูลความรู้หรือการค้นหาเวกเตอร์ |

> [!TIP]
>
> การค้นหาออนไลน์มักเป็นบริการค้นหาแยกต่างหากและไม่เหมือนกับความสามารถออนไลน์ที่ฝังอยู่ในโมเดลฐาน 

## 2. การเข้าถึงการตั้งค่า AI 

1. เข้าสู่ระบบไปยัง **MDP แพลตฟอร์มปฏิบัติการ**. 
2. ที่ด้านบน เลือก **ShimoDocs Suite**.
3. ในแถบด้านข้างซ้าย เลือก **การจัดการผู้เช่า**.
4. ค้นหา **การกำหนดค่า AI** บัตร
5. คลิกที่บัตรเพื่อเข้าสู่หน้าการ "ตั้งค่าโมเดล AI และการค้นหา"

## 3. ก่อนอื่น เลือกผู้ให้บริการโมเดลที่จะเชื่อมต่อ

กรุณายืนยันบริการโมเดลที่คุณวางแผนจะใช้ก่อน จากนั้นไปที่ส่วนที่เกี่ยวข้องเพื่อตั้งค่า

| ประเภทโมเดล | ผู้ให้บริการ |
| --- | --- |
| รุ่นพื้นฐาน | ผู้ให้บริการที่เข้ากับโปรโตคอล OpenAI Responses |
| โมเดลภาพ | ผู้ให้บริการที่เข้ากับโปรโตคอล OpenAI Image |
| โมเดลเครื่องมือค้นหาอินเทอร์เน็ต | ปัจจุบันรองรับเฉพาะ Volcengine เท่านั้น |
| โมเดลฝังตัว (Embedding Model) | ผู้ให้บริการที่เข้ากับโปรโตคอลการฝังตัวของ OpenAI |

## 4. การตั้งค่าโมเดล AI

ส่วนนี้ใช้สำหรับการตั้งค่า GPT-บริการที่เกี่ยวข้อง กรุณาให้ฝ่ายวิศวกรรมยืนยันว่าจะใช้บริการ OpenAI อย่างเป็นทางการ, Azure OpenAI, บริการพร็อกซี หรืออินเตอร์เฟซที่เข้ากันได้อื่นๆ เนื่องจากที่อยู่คำขอและรหัสโมเดลอาจแตกต่างกันขึ้นอยู่กับวิธีการเชื่อมต่อ

### 4.4 โมเดล Embedding

โมเดล embedding ใช้สำหรับการดึงฐานความรู้และการค้นหาเชิงความหมาย รหัสโมเดลและมิติการทำงานต้องตรงกับการส่งออกเวกเตอร์จริง

| รายการการกำหนดค่า | ค่าตัวอย่าง | บันทึกการพัฒนา |
| --- | --- | --- |
| ผู้ให้บริการ | OpenAI (หรือโมเดล embedding ที่เข้ากันได้กับ OpenAI) | OpenAI (หรือโมเดล embedding ที่เข้ากันได้กับ OpenAI) |
| พื้นฐาน URL | https://myai.com/v1 | เลือกที่อยู่เกตเวย์ AI ของคุณเองที่เข้ากันได้กับโปรโตคอล OpenAI Responses |
| API คีย์ | ak-•••••••• | รับจากผู้ให้บริการโมเดล embedding |

| มิติ | ค่าจำนวนเต็ม | มิติเกี่ยวข้องกับโมเดล embedding; คุณสามารถปรึกษาผู้ให้บริการสำหรับพารามิเตอร์มิติ |

| รายการยืนยันการพัฒนา | เนื้อหา |

## 5. ความหมายทางธุรกิจของแต่ละรายการการกำหนดค่า

ส่วนนี้ให้คำอธิบายรวมถึงวัตถุประสงค์ของแต่ละรายการการกำหนดค่าบนหน้า เมื่อทำการกำหนดค่าเป็นครั้งแรก สามารถกรอกตามเทมเพลตของผู้ขายที่กล่าวถึงก่อนหน้านี้ แล้วกลับมาที่ส่วนนี้เพื่อยืนยันว่าฟิลด์แต่ละรายการตรงกับความต้องการทางธุรกิจจริงหรือไม่

| --- | --- | --- | --- |
| ผู้ให้บริการ | ระบุให้ระบบทราบว่าจะใช้วิธีการปรับแต่งโมเดลแบบใด แม้ว่าสองบริการจะเข้ากันได้กับอินเทอร์เฟซที่คล้ายกัน ตัวเลือกของผู้ให้บริการอาจกำหนดรูปแบบคำขอ วิธีการตรวจสอบตัวตน และวิธีการแยกวิเคราะห์ผลลัพธ์ | อาจไม่สามารถบันทึกได้ รูปแบบคำขอไม่ตรงกัน หรือไม่สามารถแยกวิเคราะห์การตอบสนองได้ | ใช่ |

### 5.5 การตั้งค่า Embedding

โมเดล.embedding ไม่จำเป็นต้องเปิดใช้งานเสมอไป แต่ถ้าไม่เปิดใช้งาน เนื้อหาของเอกสารจะไม่สามารถทำเป็นเวกเตอร์ได้ และดังนั้น ระบบจะไม่สามารถจัดการคำถามที่เกี่ยวข้องกับฐานความรู้ของผู้ใช้ได้

| รายการการกำหนดค่า | ความหมายทางธุรกิจ | ผลลัพธ์ทั่วไปของการกรอกข้อมูลไม่ถูกต้อง | จำเป็นต้องทำหรือไม่ |
| --- | --- | --- | --- |
| พื้นฐาน URL | ที่อยู่บริการที่ส่งไปยังคำขอการเวกเตอร์ข้อความ หากที่อยู่ไม่ถูกต้อง จะไม่สามารถสร้างหรืออัปเดตข้อมูลเวกเตอร์ได้ ไม่จำเป็น |
| API คีย์ | ข้อมูลรับรองการตรวจสอบสิทธิ์ที่ใช้โดยบริการ Embedding การเวกเตอร์ล้มเหลวเนื่องจากเกิดข้อผิดพลาด หมดอายุ หรือไม่มีสิทธิ์ ไม่จำเป็น |
| โมเดลฝังตัว (Embedding Model) | รหัสโมเดลที่รับผิดชอบจริงในการแปลงข้อความเป็นเวกเตอร์ จะไม่สามารถสร้างเวกเตอร์ได้เมื่อโมเดลไม่มีหรือไม่ตรง ไม่จำเป็น |
| มิติ | ความยาวเวกเตอร์สุดท้ายที่สร้างโดยแต่ละบรรทัดข้อความต้องตรงกับผลลัพธ์จริงของโมเดลและการกำหนดค่าการเก็บเวกเตอร์ | หากมิติไม่สอดคล้องกัน การเขียนหรือการเรียกคืนมักจะไม่สามารถทำได้; หลังจากเปลี่ยนมิติ อาจต้องสร้างเวกเตอร์ที่มีอยู่ใหม่ ไม่จำเป็น |

หมายเหตุ: ขณะนี้ รองรับเฉพาะโปรโตคอล OpenAI Embedding API โปรโตคอล 

## 6. ลำดับการกำหนดค่าที่แนะนำ 

เพื่อ ลด การทำซ้ำ แนะนำให้กำหนดค่าตามลำดับดังต่อไปนี้: 

1. เริ่มแรก ให้ยืนยันคุณสมบัติ AI ใดบ้างที่จำเป็นต้องเปิดใช้งาน ShimoDocs Suite. 
2. เลือกโมเดลฐานที่ตรงตามข้อกำหนดของโปรโตคอล 
3. กำหนดค่า Provider และเพิ่มโมเดลฐานอย่างน้อยหนึ่งโมเดล 
4. ตั้งค่าโมเดลที่สามารถใช้งานและผ่านการยืนยันแล้วเป็นโมเดลเริ่มต้น 
5. กำหนดค่าโมเดลภาพตามความต้องการทางธุรกิจ 
6. กำหนดค่าโหมดค้นหาผ่านเครือข่ายตามความต้องการทางธุรกิจ 
7. หากใช้ฐานความรู้หรือการค้นหาเชิงความหมาย ให้กำหนดค่า Embedding 
8. หลังบันทึก ให้ตรวจสอบความสามารถแต่ละอย่างแยกกัน; อย่าตัดสินความสำเร็จของการกำหนดค่าเพียงจากการแสดง "Enable" บนหน้า
