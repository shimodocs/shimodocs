# ภาพรวมแพลตฟอร์มปฏิบัติการ

[← ShimoDocs Suite เอกสารการติดตั้ง](../README.md)

## ภาพรวมฟังก์ชัน

- **ShimoDocs Suite**: ใช้สำหรับการจัดการสิทธิ์, ผู้เช่า, ผู้ใช้, การสร้างแบรนด์, และการตั้งค่า AI ที่เกี่ยวข้องกับ ShimoDocs Suite.
- **บริการระบบ**: ใช้สำหรับงานปฏิบัติการและบำรุงรักษาทั่วไป เช่น การตั้งค่าระดับโลก, การจัดการคลัสเตอร์, การดูบันทึก, การตรวจสอบคุณสมบัติ, การสอบถามปัญหา, การซ่อมแซมเอกสาร และ **การอัปเกรดระบบ**.

> **หมายเหตุ**: ฟังก์ชันเฉพาะที่แสดงขึ้นอยู่กับเวอร์ชันการปรับใช้ปัจจุบันและคุณสมบัติที่เปิดใช้งาน

## การเข้าสู่แพลตฟอร์มปฏิบัติการ

เข้าถึงที่อยู่ต่อไปนี้ในเบราว์เซอร์ของคุณ:
> **ข้อกำหนดของเบราว์เซอร์**: โปรดใช้ Google Chrome เวอร์ชัน 111 หรือสูงกว่าในการเข้าถึงแพลตฟอร์มปฏิบัติการ แนะนำให้อัปเกรดเป็นเวอร์ชันเสถียรล่าสุดก่อน

```text
http(s)://<OPERATIONS_PLATFORM IP OR_DOMAIN_NAME>/mdp/user/login
```

ป้อนบัญชีผู้ดูแลระบบและ PASSWORD, จากนั้นคลิก "เข้าสู่ระบบ"

## ทำความรู้จักกับหน้าแรกของแพลตฟอร์มปฏิบัติการ

หลังจากเข้าสู่ระบบแล้ว คุณสามารถเข้าถึงฟังก์ชันการจัดการที่เกี่ยวข้องผ่านเมนูด้านซ้ายของหน้าเมนู เมนูที่แสดงขึ้นอยู่กับผลิตภัณฑ์และเวอร์ชันที่ติดตั้งและได้รับอนุญาตในสภาพแวดล้อมปัจจุบัน

## การรีเซ็ตผู้ดูแลระบบ PASSWORD เมื่อถูกลืม

หากผู้ดูแลแพลตฟอร์มปฏิบัติการ PASSWORD ถูกลืม คุณสามารถเข้าสู่ระบบโหนดการติดตั้งและเรียกใช้คำสั่งดังต่อไปนี้เพื่อรีเซ็ตมัน

```bash
kubectl exec -it $(kubectl get pods -l app=mdp -o jsonpath='{.items[0].metadata.name}') -- reset-admin-password Aa1234567.
```

ตัวอย่างด้านบนทำการรีเซ็ต PASSWORD ถึง `Aa1234567.`ในการดำเนินงานจริง โปรดแทนที่ตัวอย่าง PASSWORD ใส่ตอนท้ายของคำสั่งด้วยใหม่ PASSWORD ที่ตรงตามข้อกำหนดด้านความปลอดภัย

หลังจากรีเซ็ตเสร็จสิ้น ให้กลับไปยังหน้าล็อกอิน ลงชื่อเข้าใช้โดยใช้ PASSWORDใหม่ และยืนยันว่าเมนูสามารถเข้าถึงได้ตามปกติ
