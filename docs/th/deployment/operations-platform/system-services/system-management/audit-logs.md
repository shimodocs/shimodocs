# บันทึกการตรวจสอบ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## ภาพรวมฟังก์ชัน

บันทึกการทำงานใช้สำหรับดูและติดตามการจัดการผู้ใช้ในระบบ ซึ่งช่วยในการแก้ไขปัญหา ตรวจสอบความปลอดภัย และติดตามการเปลี่ยนแปลง

หน้านี้อ่านอย่างเดียวและไม่รองรับการแก้ไขหรือการลบบันทึก

## การเข้าถึงหน้า

หลังจากเข้าสู่ระบบด้านหลังการจัดการ ให้เลือก **บันทึกการทำงาน** ในเมนูนำทางด้านซ้ายเพื่อเข้าถึงหน้า

## การกรองบันทึก

คุณสามารถค้นหาโดยใช้การรวมเงื่อนไขดังต่อไปนี้:

- **แหล่งที่มาของเหตุการณ์**: ตัวอย่างเช่น แผงควบคุม ศูนย์การกำหนดค่าแอปพลิเคชัน โปรแกรมอัปเดต Kubernetes การจัดการทรัพยากร หรือศูนย์การจัดการผู้ใช้
- **ประเภทการดำเนินการ**: แสดงการดำเนินการที่สอดคล้องกันตามแหล่งที่มาของเหตุการณ์ เช่น การอัปเดตการกำหนดค่า การอัปเกรดเวอร์ชัน การรีสตาร์ทบริการ หรือการจัดการผู้ใช้
- **ผู้ใช้ที่ดำเนินการ**: กรองบันทึกที่สร้างโดยผู้ใช้เฉพาะ

หลังจากเลือกแหล่งที่มาของเหตุการณ์ รายการประเภทการดำเนินการจะปรับโดยอัตโนมัติ คลิก **ค้นหา** เพื่อใช้เงื่อนไขการกรอง หรือคลิกปุ่มรีเซ็ตเพื่อล้างเงื่อนไข

## การดูรายการบันทึก

รายการจะแสดงหลัก ๆ ดังนี้:

- รหัสบันทึก
- แหล่งที่มาของเหตุการณ์และประเภทการดำเนินการ
- ผู้ใช้ที่ดำเนินการ
- ประเภท ชื่อ และรหัสของวัตถุที่ถูกดำเนินการ
- เวลาการดำเนินการ 

จำนวนบันทึกทั้งหมดจะแสดงที่ด้านบนของหน้า และรายการรองรับการแบ่งหน้าและการปรับจำนวนรายการที่แสดงต่อหน้า 

## ดูรายละเอียดบันทึก 

คลิก **รายละเอียด** ทางด้านขวาของบันทึกเพื่อดูข้อมูลทั้งหมด รวมถึง: 

- ชื่อและรหัสภายในของแหล่งที่มาและประเภทการดำเนินการ 
- ผู้ใช้ที่ดำเนินการและรหัสผู้ใช้ 
- เวลาการดำเนินการ 
- ประเภทวัตถุ รหัสวัตถุ และชื่อวัตถุ 
- เมตาดาต้าเหตุการณ์ 

สำหรับการเปลี่ยนแปลงในศูนย์การกำหนดค่าแอปพลิเคชัน รายละเอียดอาจแสดงการแก้ไขการกำหนดค่า ว่าจะมีการรีสตาร์ทอัตโนมัติหลังจากการปล่อยหรือไม่ และเวิร์กโหลดที่ได้ถูกรีสตาร์ทแล้ว

## กรณีการใช้งานทั่วไป

- ตรวจสอบว่าใครเป็นผู้ดำเนินการเปลี่ยนแปลงการกำหนดค่าเฉพาะ
- ยืนยันเวลาของการอัปเกรดระบบ การรีสตาร์ทบริการ หรือการดำเนินการปรับขนาด
- ติดตามการเปลี่ยนแปลงที่เกี่ยวข้องตามชื่อวัตถุ
- ตรวจสอบความแตกต่างของการกำหนดค่าและผลลัพธ์ของการดำเนินการโดยใช้ข้อมูลเมตาเหตุการณ์
- สอบสวนการดำเนินการผิดพลาดหรือการเปลี่ยนแปลงของผู้ดูแลระบบที่ไม่คาดคิด

## สถานการณ์ทั่วไป

- **ไม่พบบันทึก**: ลองล้างเงื่อนไขตัวกรอง หรือยืนยันว่าที่มา ประเภทการดำเนินการ และผู้ใช้ที่เลือกตรงกัน
- **รายการประเภทการดำเนินการว่าง**: เลือกแหล่งที่มาของเหตุการณ์ก่อน หรือโหลดหน้าขึ้นใหม่เพื่อรับการนับรายการล่าสุด
- **ข้อมูลวัตถุว่าง**: เหตุการณ์ระบบบางอย่างอาจไม่ได้เชื่อมโยงกับวัตถุเฉพาะ ซึ่งถือเป็นเรื่องปกติ
- **ข้อมูลเมตาไม่ได้อยู่ในรูปแบบเนื้อหา**: เหตุการณ์ประวัติศาสตร์บางรายการอาจถูกเก็บเป็นข้อความธรรมดา และหน้าจะแสดงเนื้อเดิม
- **ปริมาณบันทึกไม่ตรงตามความคาดหมาย**: บันทึกจะบันทึกเฉพาะการดำเนินการที่ได้รับการตรวจสอบโดยระบบ และอาจได้รับผลกระทบจากนโยบายการเก็บรักษาของสภาพแวดล้อม

> บันทึกการดำเนินการอาจมีข้อมูลผู้ใช้ ตัวระบุวัตถุ และข้อมูลการเปลี่ยนแปลงการตั้งค่า และควรเข้าถึงได้เฉพาะบุคลากรที่ได้รับอนุญาต
