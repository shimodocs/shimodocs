# การจัดการผู้ใช้แพลตฟอร์ม

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## ภาพรวมฟังก์ชัน

การจัดการผู้ใช้ระบบใช้เพื่อบำรุงรักษาบัญชีผู้ใช้ใน MDP ส่วนหลังการจัดการ รวมถึงการสร้างผู้ใช้ แก้ไขข้อมูลพื้นฐาน การรีเซ็ต PASSWORDการจัดการการตรวจสอบสิทธิ์สองปัจจัย และการลบผู้ใช้

## การเข้าถึงหน้า

หลังจากเข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบ ให้เลือก **การจัดการผู้ใช้ระบบ** ในเมนูนำทางด้านซ้ายเพื่อเข้าถึงหน้า

เมนูนี้สามารถเข้าถึงได้เฉพาะบัญชีผู้ดูแลระบบที่กำหนด หากคุณไม่เห็นเมนูนี้ กรุณาติดต่อผู้ดูแลระบบของคุณ

## ดูผู้ใช้

หน้าจอจะแสดงชื่อเล่นผู้ใช้ USERNAME บทบาท ที่อยู่อีเมล ข้อมูลติดต่อ เวลาเข้าสู่ระบบครั้งล่าสุด และเวลาลงทะเบียน และให้ข้อมูลภาพรวม เช่น จำนวนผู้ใช้ทั้งหมด ผู้ใช้ที่เพิ่งใช้งาน และบัญชีผู้ดูแลระบบ

คุณสามารถดูผู้ใช้ทั้งหมดผ่านการแบ่งหน้ารายการ

## สร้างผู้ใช้ใหม่

คลิก **สร้างผู้ใช้ใหม่** และกรอกข้อมูลต่อไปนี้:

- **ชื่อเล่น**: จำเป็น ต้องใช้สำหรับแสดงผลบนหน้าเพจ
- **USERNAME**: จำเป็น ต้องใช้สำหรับเข้าสู่ระบบ
- **อีเมล**: จำเป็น ต้องระบุที่อยู่อีเมลที่ถูกต้อง
- **ข้อมูลการติดต่อ**: ไม่บังคับ
- **บทบาท**: เลือกผู้ใช้ทั่วไปหรือผู้ดูแลระบบ

หลังจากสร้าง ระบบจะสร้าง PASSWORDเบื้องต้น กรุณาคัดลอกทันทีและมอบให้ผู้ใช้ผ่านวิธีที่ปลอดภัย เนื่องจาก PASSWORD อาจไม่สามารถดูได้อีกเมื่อปิดหน้าต่างนี้

## แก้ไขข้อมูลผู้ใช้

คลิกปุ่มแก้ไขทางด้านขวาของผู้ใช้เพื่อแก้ไขชื่อเล่น อีเมล และข้อมูลการติดต่อ USERNAME ไม่สามารถแก้ไขได้บนหน้านี้หลังจากสร้าง

## รีเซ็ต PASSWORD

หลังจากคลิกปุ่มรีเซ็ต PASSWORD และยืนยันการปฏิบัติ ระบบจะสร้าง PASSWORDใหม่ ของเดิม PASSWORD จะหมดอายุทันที

โปรดคัดลอกและบันทึกใหม่ให้ถูกต้อง PASSWORDส่งให้ผู้ใช้ที่เกี่ยวข้องผ่านช่องทางที่เชื่อถือได้ และเตือนผู้ใช้ให้เข้าสู่ระบบและเปลี่ยน PASSWORD โดยด่วนที่สุด

## จัดการการยืนยันตัวตนสองขั้นตอน

- **เปิดหรือปิด 2FA**: ใช้สวิตช์ในแถวผู้ใช้และดำเนินการต่อในหน้าต่างยืนยัน
- **รีเซ็ต 2FA**: ระบบจะสร้างรหัส QR ใหม่และรหัสลับ (Secret) และข้อมูลการยืนยันเดิมจะหมดอายุ

หลังจากรีเซ็ต ผู้ใช้ควรใช้แอปยืนยันตัวตน เช่น Authenticator สแกนและผูกใหม่ รหัส QR และรหัสลับเป็นข้อมูลสำคัญและไม่ควรส่งผ่านช่องทางสาธารณะ 

ผูก 2FA

เพิ่มโดยการสแกนด้วย Authenticator และใช้รหัส 2FA 6 หลักแบบไดนามิกในการเข้าสู่ระบบครั้งต่อไป

## ลบผู้ใช้

หลังจากคลิกปุ่มลบและยืนยัน บัญชีผู้ใช้จะถูกลบ การลบไม่สามารถย้อนกลับได้ ดังนั้นโปรดตรวจสอบให้แน่ใจว่าบัญชีไม่ถูกใช้งานและทำการโอนข้อมูลและสิทธิ์ที่จำเป็นเรียบร้อยก่อนดำเนินการ

## สถานการณ์ทั่วไป

- **ไม่สามารถสร้างผู้ใช้ได้**: โปรดตรวจสอบว่า USERNAME ถูกทำซ้ำ รูปแบบอีเมลถูกต้อง และทุกช่องข้อมูลที่จำเป็นครบถ้วน
- **ผู้ใช้ไม่สามารถเข้าสู่ระบบได้**: ตรวจสอบว่า USERNAME และ PASSWORD ถูกต้อง หากจำเป็น ให้รีเซ็ต PASSWORD.
- **ผู้ใช้ไม่สามารถทำการยืนยัน 2FA ได้**: ตรวจสอบให้แน่ใจว่าระบบเวลาถูกต้อง หรือรีเซ็ต 2FA สำหรับผู้ใช้และผูกใหม่
- **เมนูการจัดการผู้ใช้ไม่ปรากฏ**: บัญชีปัจจุบันอาจไม่ใช่บัญชีผู้ดูแลระบบที่กำหนด
- **ผู้ใช้ถูกลบโดยอุบัติเหตุ**: การลบไม่สามารถย้อนกลับได้โดยตรง จำเป็นต้องสร้างบัญชีใหม่และกำหนดสิทธิ์ใหม่

> ข้อมูลรับรองที่สร้างขึ้นเมื่อสร้าง รีเซ็ต PASSWORDและรีเซ็ต 2FA ควรถูกบันทึกทันทีและมอบให้เฉพาะเจ้าของบัญชี
