# ศูนย์การกำหนดค่า

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## ภาพรวมฟังก์ชัน 

ศูนย์การกำหนดค่าใช้สำหรับดูและปรับเปลี่ยนการกำหนดค่าของแอปพลิเคชันสำหรับบริการต่างๆ หน้าเว็บจะแสดงทั้งการกำหนดค่าต้นแบบจากโรงงานและการกำหนดค่าที่ใช้งานอยู่ในปัจจุบัน ทำให้เข้าใจความแตกต่างของการกำหนดค่าและการปรับปรุงเวอร์ชันได้อย่างง่ายดายและควบคุมได้ 

หลังจากเผยแพร่การกำหนดค่า ระบบจะบันทึกการปรับเปลี่ยนนี้ และสามารถเริ่มต้นบริการที่เกี่ยวข้องโดยอัตโนมัติตามการเลือกของคุณเพื่อใช้การกำหนดค่าใหม่ 

## การเข้าถึงหน้าเว็บ 

หลังจากเข้าสู่ระบบของส่วนจัดการหลังบ้าน ให้เลือก **ศูนย์การกำหนดค่า** ในเมนูการนำทางด้านซ้ายเพื่อเข้าถึงหน้าเว็บ 

ศูนย์การกำหนดค่าจะสามารถใช้งานได้เฉพาะผู้ดูแลระบบ หากคุณไม่เห็นเมนูนี้ โปรดติดต่อผู้ดูแลระบบเพื่อยืนยันสิทธิ์บัญชีของคุณ 

## คำอธิบายหน้าเว็บ 

หน้าจะถูกแบ่งออกเป็นสามส่วนหลัก 

- **รายการแอปพลิเคชันและไฟล์**: แสดงไฟล์ที่สามารถกำหนดค่าได้ตามแอปพลิเคชัน พร้อมรองรับการค้นหาด้วยชื่อแอปพลิเคชัน 
- **การกำหนดค่าต้นแบบจากโรงงาน**: แสดงการกำหนดค่าเดิมที่ให้มาในแพ็กเกจติดตั้ง สำหรับการดูและอ้างอิงเท่านั้น 
- **การกำหนดค่าที่ใช้งานอยู่ขณะนี้**: แสดงการกำหนดค่าที่ใช้งานโดยสภาพแวดล้อมในปัจจุบัน ซึ่งสามารถแก้ไขได้โดยตรง 

ไฟล์การกำหนดค่ามักอยู่ใน JSON, YAML, หรือ TOML รูปแบบ กรุณารักษาไวยากรณ์ของไฟล์และโครงสร้างข้อมูลให้ถูกต้อง 

## การแก้ไขและเผยแพร่การกำหนดค่า 

แนะนำให้ทำตามขั้นตอนด้านล่าง: 

1. ทางด้านซ้าย เลือกแอปพลิเคชันและไฟล์การกำหนดค่าที่คุณต้องการแก้ไข
2. อ้างอิงจากเทมเพลตโรงงานและแก้ไขเนื้อหาการกำหนดค่าใน **การกำหนดค่าที่มีผล** พื้นที่
3. หลังจากแก้ไข หน้าเว็บจะแสดงสถานะ **แก้ไขแล้วแต่ยังไม่ได้เผยแพร่**.
4. คลิก **แก้ไขแล้วแต่ยังไม่ได้เผยแพร่**, หรือใช้ `Ctrl S` (Windows) / `Command S` (macOS) เพื่อเปิดหน้าต่างยืนยัน
5. ตรวจสอบเส้นทางฟิลด์ ประเภทการเปลี่ยนแปลง และค่าที่จะแพร่หลายใหม่
6. เลือกว่าจะเปิดใช้งานหรือไม่ **รีสตาร์ทบริการที่เกี่ยวข้องหลังจากเผยแพร่การกำหนดค่า** ตามความจำเป็น
7. คลิก **เผยแพร่การกำหนดค่า** เพื่อทำการแก้ไขให้เสร็จสมบูรณ์

หากมีข้อผิดพลาดด้านรูปแบบในเนื้อหาการกำหนดค่า ระบบจะแจ้งข้อผิดพลาดและป้องกันการเผยแพร่ โปรดแก้ไขแล้วลองใหม่อีกครั้ง

## การยืนยันการเปลี่ยนแปลง

หน้าต่างการยืนยันก่อนการเผยแพร่จะแสดงความแตกต่างสำหรับการแก้ไขนี้:

- **เส้นทาง**: เส้นทางการกำหนดค่าที่มีการเปลี่ยนแปลง
- **การดำเนินการ**: ประเภทของการเปลี่ยนแปลง เช่น เพิ่ม แก้ไข หรือ ลบ
- **ค่า**: ค่าการกำหนดค่าหลังจากการเปลี่ยนแปลง

แนะนำให้ยืนยันความแตกต่างแต่ละรายการเพื่อหลีกเลี่ยงการลบการกำหนดค่าโดยไม่ตั้งใจหรือแก้ไขพารามิเตอร์บริการผิดพลาด

## การรีสตาร์ทบริการ

การกำหนดค่าบางอย่างจะมีผลหลังจากบริการถูกรีสตาร์ท เท่านั้น โดยค่าเริ่มต้น หน้าเพจจะเปิดใช้งาน **รีสตาร์ทบริการที่เกี่ยวข้องหลังจากเผยแพร่การกำหนดค่า**และหลังจากเผยแพร่อย่างสำเร็จ บริการที่เกี่ยวข้องกับแอปพลิเคชันจะถูกรีสตาร์ทโดยอัตโนมัติ

หากปิดตัวเลือกนี้ การกำหนดค่ายังคงสามารถเผยแพร่ได้ แต่บริการที่เกี่ยวข้องอาจต้องรีสตาร์ทด้วยตนเองในภายหลังเพื่อใช้การตั้งค่าใหม่

ระหว่างการรีสตาร์ทบริการ ฟังก์ชันที่เกี่ยวข้องอาจมีความผันผวนชั่วคราว แนะนำให้ทำการเปลี่ยนแปลงการกำหนดค่าที่สำคัญในช่วงเวลานอกชั่วโมงพีค

## สถานการณ์ทั่วไป

- **ไม่พบแอปพลิเคชัน**: กรุณาล้างเกณฑ์การค้นหาหรือยืนยันว่าแอปพลิเคชันเป้าหมายได้รับการปรับใช้ถูกต้องแล้ว
- **: ไม่สามารถโหลดไฟล์การกำหนดค่าได้**: กรุณาตรวจสอบสถานะบริการและสิทธิ์ของบัญชีปัจจุบันก่อนลองใหม่
- **: ข้อผิดพลาดรูปแบบการกำหนดค่า**: กรุณาตรวจสอบการย่อหน้า วงเล็บ เครื่องหมายคำพูด และรูปแบบฟิลด์ JSON, YAML, หรือ TOML.
- **: ไม่มีการเปลี่ยนแปลงที่จะเผยแพร่**: เนื้อหาการกำหนดค่าจริงไม่ได้เปลี่ยนแปลงอย่างมีประสิทธิผล ไม่จำเป็นต้องเผยแพร่
- **: การเปลี่ยนแปลงไม่มีผลหลังจากการเผยแพร่**: กรุณายืนยันว่าบริการที่เกี่ยวข้องได้ถูกรีสตาร์ทแล้วหรือไม่ หากจำเป็นให้รีสตาร์ทด้วยตนเองและตรวจสอบอีกครั้ง
- **: การเผยแพร่ล้มเหลว**: กรุณาตรวจสอบเนื้อหาการกำหนดค่าหรือสถานะบริการตามคำแนะนำบนหน้า และเผยแพร่ใหม่หลังจากแก้ไข 

> : การเปลี่ยนแปลงการกำหนดค่าอาจส่งผลต่อการเริ่มต้นบริการและฟังก์ชันธุรกิจ กรุณาเผยแพร่เฉพาะหลังจากยืนยันการเปลี่ยนแปลงทั้งหมดแล้ว
