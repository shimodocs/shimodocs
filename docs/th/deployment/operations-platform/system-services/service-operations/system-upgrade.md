# การอัปเกรดระบบ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## ภาพรวมฟังก์ชัน

การอัปเกรดระบบใช้ในการอัปโหลดและประยุกต์ใช้แพ็กเกจการติดตั้งใหม่ MDP ก่อนการอัปเกรดอย่างเป็นทางการ ระบบจะตรวจสอบแพ็กเกจอัปเกรดและสภาพแวดล้อมปัจจุบันโดยอัตโนมัติ และแสดงการเปลี่ยนแปลงการกำหนดค่าและบริการที่เกี่ยวข้องกับการอัปเกรดนี้ ช่วยให้คุณทำการอัปเกรดเวอร์ชันหรือการบำรุงรักษาตามปกติ

หน้าจอนี้ยังเก็บประวัติการอัปเกรด ทำให้ง่ายต่อการดูบันทึกการอัปเกรดในอดีต สถานะการดำเนินการ และบันทึกที่เกี่ยวข้อง

**หมายเหตุ**: การอัปเกรดเวอร์ชันใหญ่ อาจมีการอัปเดตโครงสร้างฐานข้อมูล การอัปเกรดเกี่ยวข้องกับการเปลี่ยนแปลงการตั้งค่า การรีสตาร์ทบริการ และการเปลี่ยนแปลงอินเทอร์เฟซฟังก์ชัน ซึ่งอาจส่งผลต่อประสบการณ์ผู้ใช้ ควรทำในช่วงเวลานอกเวลาทำการยุ่ง

## เข้าสู่หน้า

หลังจากเข้าสู่ระบบด้านหลังการจัดการ ให้เลือก **การอัปเกรดระบบ** ในเมนูนำทางด้านซ้ายเพื่อเข้าสู่หน้า

การอัปเกรดระบบสามารถทำได้เฉพาะผู้ดูแลระบบเท่านั้น หากคุณไม่เห็นเมนูนี้ กรุณาติดต่อผู้ดูแลระบบเพื่อยืนยันสิทธิ์บัญชีปัจจุบัน

## การเตรียมความพร้อมก่อนการอัปเกรด

ก่อนเริ่มการอัปเกรด แนะนำให้ยืนยันรายการดังต่อไปนี้:

- ใช้แพ็กเกจอัปเกรดที่จัดเตรียมโดยทางการซึ่งตรงกับประเภทผลิตภัณฑ์และวิธีการติดตั้งปัจจุบัน
- แพ็กเกจอัปเกรดอยู่ใน `.tar.gz` รูปแบบ โปรดอย่าดึงออกหรือแก้ไขไฟล์ภายในแพ็กเกจ
- แนะนำให้ทำการอัปเกรดในช่วงเวลาที่ไม่ใช่ชั่วโมงทำงานหรือช่วงเวลาบำรุงรักษา
- ยืนยันว่าบริการปัจจุบันทำงานปกติ และแจ้งผู้ใช้ที่เกี่ยวข้องล่วงหน้า
- หากการอัปเกรดเกี่ยวข้องกับการเปลี่ยนแปลงใบอนุญาต โปรดเตรียมเนื้อหาใบอนุญาตใหม่ล่วงหน้า

## ขั้นตอนการอัปเกรด

### 1. อัปโหลดแพ็กเกจการอัปเกรด

คลิกที่พื้นที่อัปโหลดบนหน้าการอัปเกรดระบบ หรือ ลากแพ็กเกจการอัปเกรดไปยังพื้นที่อัปโหลด หลังจากการอัปโหลดเสร็จสิ้น ระบบจะทำการแยกวิเคราะห์และตรวจสอบแพ็กเกจการอัปเกรดโดยอัตโนมัติ

การตรวจสอบหลัก ๆ จะรวมถึง:

- รูปแบบและความสมบูรณ์ของเนื้อหาในแพ็กเกจติดตั้ง
- การตรวจสอบความถูกต้องของลายเซ็นแพ็กเกจติดตั้ง
- เวอร์ชันของแพ็กเกจอัปเกรดและแผนการอัปเกรด
- ประเภทผลิตภัณฑ์และสถาปัตยกรรมการปรับใช้งานตรงกันหรือไม่
- ใบอนุญาตปัจจุบันรองรับการอัปเกรดนี้หรือไม่

ผลการตรวจสอบจะแบ่งออกเป็นสถานะดังต่อไปนี้:

- **ผ่าน**: การตรวจสอบเป็นปกติ และคุณสามารถดำเนินการต่อได้
- **เปลี่ยนแปลง**: มีการเปลี่ยนแปลงที่คาดไว้ในอัปเกรดนี้ โปรดยืนยันเนื้อหาก่อนดำเนินการต่อ
- **ไม่ตรงกัน**: มีปัญหาที่ขัดขวางการอัปเกรด คุณต้องเปลี่ยนแพ็กเกจอัปเกรดหรือตั้งค่าที่เกี่ยวข้องก่อนทำการอัปโหลดใหม่

### 2. กรอกใบอนุญาต

หากระบบตรวจสอบแล้วว่าการอัปเกรดนี้ต้องใช้ใบอนุญาตที่อัปเดต หน้าเว็บจะแจ้งผลิตภัณฑ์ที่จำเป็นต้องอัปเดตและแสดงข้อมูลเช่นรหัสเครื่องเซิร์ฟเวอร์ปัจจุบัน

หลังจากวางเนื้อหาใบอนุญาตใหม่ คลิก **ยืนยันและบันทึกชั่วคราว**. การอัปเกรดสามารถดำเนินการต่อได้ก็ต่อเมื่อใบอนุญาตได้รับการยืนยันเรียบร้อยแล้ว ใบอนุญาตที่บันทึกชั่วคราวจะมีผลโดยอัตโนมัติหลังจากการอัปเดตสำเร็จ สำหรับข้อมูลใบอนุญาต โปรดดูที่ [การจัดการใบอนุญาต]

หากหน้าจอแสดงว่าไม่จำเป็นต้องอัปเดตใบอนุญาต คุณสามารถดำเนินการไปยังขั้นตอนถัดไปได้โดยตรง

### 3. ยืนยันเนื้อหาของแพ็กเกจอัปเกรด

หน้าจอจะแสดงไฟล์การกำหนดค่าและทรัพยากรบริการในแพ็กเกจอัปเกรด คุณสามารถเลือกไฟล์เฉพาะเพื่อดูเนื้อหาและยืนยันว่าแพ็กเกจอัปเกรดตรงกับเป้าหมายการอัปเกรดปัจจุบัน

### 4. ยืนยันการเปลี่ยนแปลง

ระบบจะเปรียบเทียบสภาพแวดล้อมปัจจุบันกับแพ็กเกจอัปเกรดและแสดงทรัพยากรที่จะถูกเพิ่ม แก้ไข ลบ หรือรีสตาร์ทในการอัปเกรดครั้งนี้

กรุณาให้ความสำคัญเป็นพิเศษในการยืนยัน: 

- ว่ามีการลบทรัพยากรโดยไม่คาดคิดหรือไม่ 
- ว่ามีบริการสำคัญใดที่จำเป็นต้องรีสตาร์ทหรือไม่ 
- ว่าการเปลี่ยนแปลงในไฟล์การกำหนดค่าตรงตามที่คาดหวังหรือไม่ 

### 5. ใช้อัปเดต 

หลังจากยืนยันว่าข้อมูลข้างต้นถูกต้อง ให้คลิก **ยืนยันเพื่อเริ่มอัปเดต**ระบบจะสร้างสแนปชอตก่อนอัปเกรดและเริ่มการใช้แพ็กเกจอัปเดต 

ระหว่างการอัปเกรด หน้าเว็บจะแสดงบันทึกการดำเนินงานอย่างต่อเนื่อง รวมถึงข้อมูลเช่น การอัปเดตทรัพยากร การรีสตาร์ทบริการ และการตรวจสอบสถานะการทำงาน เมื่อส่วนประกอบบางตัวรีสตาร์ท หน้าเว็บการจัดการอาจไม่สามารถเข้าถึงได้ชั่วขณะ กรุณารอสักครู่แล้วเปิดหน้าเว็บอีกครั้งเพื่อตรวจสอบความคืบหน้า 

หากการดำเนินการล้มเหลว คุณสามารถแก้ไขปัญหาตามบันทึกแล้วคลิก **นำมาใช้ใหม่**. 

### 6. เสร็จสิ้นการอัปเกรด 

หลังจากงานอัปเกรดดำเนินการสำเร็จ ให้คลิก **เสร็จสิ้น** เพื่อจบกระบวนการอัปเกรดนี้ 

หน้าการเสร็จสิ้นการอัปเกรดจะแสดงชื่อและเวอร์ชันของแพ็กเกจอัปเกรด พร้อมให้ดำเนินการดังต่อไปนี้: 

- **ดูบันทึกการดำเนินงาน**: ดูกระบวนการอัปเกรดทั้งหมด 
- **ย้อนกลับไปยังเวอร์ชันก่อนการอัปเกรด**: เข้าสู่ snapshot ก่อนการอัปเกรดและทำตามคำแนะนำบนหน้าเพื่อต้องการย้อนกลับ 
- **กลับไปยังการอัปเดตแอปพลิเคชัน**: กลับไปยังหน้าหลักการอัปเกรดระบบ 

## ประวัติการอัปเกรด 

ด้านล่างของหน้าหลักการอัปเกรดระบบจะแสดงประวัติการอัปเกรด รวมถึงชื่อแพ็กเกจอัปเกรด เวอร์ชัน เวลาที่สร้าง และสถานะการดำเนินการ 

คลิกที่บันทึกการอัปเกรดเพื่อเข้ากระบวนการที่เกี่ยวข้องอีกครั้งและดูความคืบหน้าในการอัปเกรดหรือผลลัพธ์การดำเนินการในอดีต

## สถานการณ์ทั่วไป

- **การตรวจสอบแพ็กเกจอัปเกรดล้มเหลว**: โปรดยืนยันแหล่งที่มาของแพ็กเกจอัปเกรด ความสมบูรณ์ของไฟล์ ประเภทผลิตภัณฑ์ และสถาปัตยกรรมการติดตั้งถูกต้อง
- **เวอร์ชันไม่ตรงกัน**: โปรดตรวจสอบเวอร์ชันของระบบปัจจุบันและเวอร์ชันของแพ็กเกจอัปเกรดเพื่อให้แน่ใจว่ากำลังใช้เส้นทางการอัปเกรดที่ถูกต้อง
- **จำเป็นต้องอัปเดตใบอนุญาต**: ขอใบอนุญาตใหม่ที่เข้ากันได้กับเวอร์ชันเป้าหมายและสภาพแวดล้อมการทำงานปัจจุบัน ตรวจสอบความถูกต้องและเก็บไว้ชั่วคราวก่อนดำเนินการต่อ
- **หน้ากระบวนการอัปเกรดไม่พร้อมใช้งานชั่วคราว**: การ MDP บริการอาจกำลังอัปเดตหรือรีสตาร์ท กรุณารอสักครู่แล้วรีเฟรชหน้า
- **งานอัปเกรดล้มเหลว**: ตรวจสอบบันทึกการทำงานเพื่อตรวจหาสาเหตุ; หลังจากแก้ไขปัญหาแล้ว ใช้ **นำมาใช้ใหม่**.
- **ความผิดปกติของบริการหลังการอัปเกรด**: ตรวจสอบบันทึกการทำงานและสถานะบริการก่อน; หากต้องการกู้คืน คุณสามารถย้อนกลับโดยใช้สแนปช็อตก่อนการอัปเกรด

> การอัปเกรดระบบจะปรับเปลี่ยนการตั้งค่าบริการและอาจทำให้บริการรีสตาร์ท กรุณาดำเนินการต่อหลังจากยืนยันว่าแพ็กเกจอัปเกรดและการเปลี่ยนแปลงถูกต้องแล้ว
