# บันทึกบริการ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## ภาพรวมคุณสมบัติ 
ฟีเจอร์บันทึกการให้บริการเป็นแพลตฟอร์มดึงบันทึกเหมือน Kibana ที่สามารถเก็บบันทึกของ Pod จากบริการต่าง ๆ ShimoDocs และมีความสามารถในการค้นหาบันทึก สืบค้น และวิเคราะห์สัดส่วน 

## การเข้าสู่ระบบและการนำทาง
เมนูด้านซ้าย: ระบบบริการ --> การดำเนินการบริการ --> บันทึกการให้บริการ

## SQL โหมด
กล่องป้อนข้อมูลรองรับการสืบค้นไวยากรณ์ ClickHouse SQL หลังจากป้อน SQLคุณสามารถรันคำสืบค้นในโหมด ClickHouse Raw

ดังที่แสดงในรูปด้านล่าง ให้ป้อน

``` sql
`_raw_log_` like '%access%'
```

สามารถใช้สืบค้นบันทึกทั้งหมดที่มีคำว่า access 

## การกรองตามเงื่อนไข
ดังที่แสดงในรูปด้านล่าง คลิกปุ่ม "เพิ่มเงื่อนไข" เพื่อเพิ่มเงื่อนไขตัวกรองใหม่

## การวิเคราะห์สัดส่วน
ดังที่แสดงในรูปด้านล่าง คลิกไอคอนถัดจากฟิลด์ในแถวบันทึกเพื่อเปิดเมนูแบบเลื่อนลง หลังจากเลือก "ค่าที่สูงที่สุด" คุณสามารถดูสัดส่วนของฟิลด์นั้นภายในช่วงเวลาปัจจุบันที่มุมบนขวา

## คำอธิบายฟิลด์

| ฟิลด์ในตัว | คำอธิบาย |
| --- | --- |
| lv | ระดับความผิดพลาดของบันทึก รวมถึง info, error, warn |
| container.name | CONTAINER_NAME |
| method | วิธีการในบันทึกการเข้าใช้งาน; gRPC พิมพ์ gRPC method, HTTP พิมพ์ API path |
| peerIP | IP ของเพียร์ |
| peerName | ชื่อของเพื่อนร่วมงาน เช่น ชื่อบริการ ฯลฯ |
| คอมพ์ | ส่วนประกอบในบันทึกการเข้าถึง เช่น server.begin |
| ค่าใช้จ่าย | เวลาที่ใช้ไปในบันทึกการเข้าถึง เป็นมิลลิวินาที |

## การวิเคราะห์กรณี
### สอบถามบันทึกข้อผิดพลาดทั้งหมดของวัน

ใน เพิ่มเงื่อนไข ให้เลือกฟิลด์ lv และเพิ่ม lv = error ดังที่แสดงในรูปด้านล่าง

### ดูบันทึกคำขอ

    1. ใช้ `msg`='access' เพื่อดูบันทึกคำขอทั้งหมด รวมถึง HTTP และ gRPC
    
2. ดู HTTP คำขอ

3. ดู gRPC คำขอ
