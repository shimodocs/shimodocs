# Kafka เครื่องมือ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

> [!TIP]
>
> ผู้ใช้ Kafka เครื่องมือช่วยให้คุณดู Kafka สถานะคลัสเตอร์ หัวข้อ ข้อความ กลุ่มผู้บริโภค และข้อมูลพาร์ติชันผ่าน Redpanda Console ซึ่งมักใช้เพื่อตรวจสอบการเขียนข้อความ ค้างผู้บริโภค และปัญหาเชื่อมต่อแบบไม่ซิงโครนัส
>
> เมื่อหน้าโหลดสำเร็จแล้ว คอนโซล Redpanda จะถูกฝังอยู่ภายใน MDP.

## 1. การเข้าถึง Kafka

1. เข้าสู่ระบบไปยัง **MDP แพลตฟอร์มปฏิบัติการ**.
2. เลือก **บริการระบบ** ที่ด้านบน
3. ขยาย **เครื่องมือ Middleware** ในแถบนำทางด้านซ้าย
4. เลือก **Kafka**.
5. รอให้คอนโซล Redpanda โหลดเสร็จ

หากคอนโซลยังไม่พร้อม หน้าเว็บจะแจ้งว่ากำลังเริ่มต้นหรือเริ่มต้นล้มเหลวและแสดงข้อมูลข้อผิดพลาด

## 2. ดูภาพรวมคลัสเตอร์

หลังจากเข้า Kafka, **ภาพรวม** จะแสดงโดยค่าเริ่มต้น

คุณสามารถดูข้อมูลดังต่อไปนี้:

| ข้อมูล | คำอธิบาย |
| --- | --- |
| สถานะคลัสเตอร์ | สถานะการทำงานของคลัสเตอร์ |
| ขนาดพื้นที่เก็บข้อมูลคลัสเตอร์ | ขนาดพื้นที่เก็บข้อมูลปัจจุบันของคลัสเตอร์ |
| เวอร์ชันคลัสเตอร์ | ข้อมูลเวอร์ชันของคลัสเตอร์ |
| โบรกเกอร์ที่ออนไลน์ | จำนวนโบรกเกอร์ที่ออนไลน์ |
| หัวข้อ | จำนวนหัวข้อ |
| สำเนา | จำนวนสำเนา |
| รายละเอียดโบรกเกอร์ | ID โบรกเกอร์ สถานะ และขนาด |

## 3. ดูหัวข้อ

1. ในเมนูนำทางด้านซ้ายของคอนโซล Redpanda เลือก **หัวข้อ**.
2. ค้นหาหัวข้อเป้าหมายในรายการหัวข้อ
3. คลิกที่หัวข้อเพื่อเข้าสู่หน้ารายละเอียด
4. ดูข้อมูลเช่น พาร์ทิชันของหัวข้อ ข้อความ และการตั้งค่า

การแก้ปัญหาหัวข้อมักมุ่งเน้นที่:

| ข้อมูล | คำอธิบาย |
| --- | --- |
| พาร์ติชัน | สถานะของพาร์ติชันของหัวข้อ |
| ข้อความ | รายการข้อความในหัวข้อ |
| การกำหนดค่า | การกำหนดค่าหัวข้อ เช่น นโยบายการเก็บรักษา |

## 4. การดูข้อความ

1. เข้าสู่หัวข้อเป้าหมาย
2. เปิดพื้นที่การดูข้อความ
3. เลือกพาร์ติชัน ตำแหน่ง หรือช่วงเวลาที่ต้องการโดยใช้ตัวกรองที่ให้ในหน้า
4. ดู Key ของข้อความ, Value, Headers, พาร์ติชัน, Offset และ Timestamp

> เนื้อหาของข้อความอาจมีฟิลด์ธุรกิจ เมื่อแก้ไขปัญหา ให้เน้นการค้นหาตาม Business ID, Key, Offset และ Timestamp

## 5. การดู Consumer Groups

1. ใน Redpanda Console ให้เลือก **Consumer Groups** จากเมนูนำทางด้านซ้าย
2. ค้นหาหรือเลือกกลุ่มผู้บริโภคเป้าหมาย
3. เข้าสู่รายละเอียดของกลุ่มผู้บริโภค
4. ดูหัวข้อ พาร์ติชัน Current Offset, Log End Offset และ Lag ที่เกี่ยวข้องกับกลุ่มผู้บริโภค

## 6. การตรวจสอบ Consumer Backlog

| สถานะ | คำอธิบาย |
| --- | --- |
| Lag คือ 0 | กลุ่มผู้บริโภคปัจจุบันไม่มีงานคงค้าง |
| Lag เพิ่มขึ้นอย่างต่อเนื่อง | ความเร็วในการบริโภคน้อยกว่าความเร็วในการผลิต |
| ความล่าช้าไม่เปลี่ยนแปลงแต่ไม่เป็น 0 | อาจมีผู้บริโภคหยุดทำงาน การอุดตันของพาร์ติชัน หรือความล้มเหลวในการบริโภค |
| ความล่าช้าของพาร์ติชันเดียวสูงมาก | อาจเกิดจากคีย์ร้อนหรือการบริโภคผิดปกติในพาร์ติชันนั้น |

## 7. การดู Brokers

1. ในหน้า Overview, ค้นหา **รายละเอียด Broker**.
2. ตรวจสอบ Broker ID, สถานะการทำงาน และขนาดการจัดเก็บ
3. คลิก **ดู** เพื่อดูรายละเอียดของ broker

## 8. สถานการณ์การแก้ไขปัญหาที่พบบ่อย

| สถานการณ์ | ข้อเสนอแนะด้านการดำเนินงาน |
| --- | --- |
| ยืนยันว่า Kafka กำลังทำงานเป็นปกติหรือไม่ | ตรวจสอบสถานะ Cluster และ Brokers ที่ออนไลน์ในหน้า Overview |
| ยืนยันว่าข้อความถูกเขียนหรือไม่ | ไปที่ Topic และตรวจสอบ Messages |
| แก้ไขปัญหาความล่าช้าของ consumer | ไปที่ Consumer Groups และตรวจสอบ Lag |
| ค้นหาข้อความเดียว | ค้นหาตาม Topic, Partition, Offset, Key, หรือ timestamp |
| ยืนยันการตั้งค่า Topic | ไปที่รายละเอียด Topic และตรวจสอบ Configuration |
