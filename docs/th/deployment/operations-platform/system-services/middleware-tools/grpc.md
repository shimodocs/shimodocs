# gRPC เครื่องมือ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

> [!TIP]
>
> ผู้ใช้ gRPC เครื่องมือใช้เชื่อมต่อกับ gRPC บริการภายใน, ดู Services และ Methods, และเริ่มต้นการเรียก debug วิธีแบบ Unary
>
> หน้าสนับสนุนสามวิธีในการเลือกเป้าหมาย: ป้อนที่อยู่ด้วยตนเอง, เลือกตาม Kubernetes บริการ หรือเลือกตาม Pod

## 1. การเข้าถึง gRPC

1. เข้าสู่ระบบไปยัง **MDP แพลตฟอร์มปฏิบัติการ**.
2. เลือก **บริการระบบ** ที่ด้านบน
3. ขยาย **เครื่องมือ Middleware** ในแถบนำทางด้านซ้าย
4. เลือก **gRPC**.

หน้าจอจะแสดงพื้นที่ "เป้าหมาย" สำหรับการเลือก gRPC บริการที่จะเชื่อมต่อเป็นครั้งแรก

## 2. วิธีการเลือกเป้าหมาย

หน้าจอมีสามโหมดเป้าหมาย:

| โหมด | คำอธิบาย |
| --- | --- |
| ด้วยตนเอง | กรอกที่อยู่ด้วยตนเอง, เช่น gRPC ตัวอย่างเช่น, `svc-user:50051`. |
| บริการ | เลือกเป้าหมายโดย Cluster, Namespace, Service และ Port |
| Pod | เลือกเป้าหมายโดย Cluster, Namespace, Pod และ Port |

## 3. การเชื่อมต่อด้วยตนเอง 

1. เลือก **คู่มือ**. 
2. ป้อน gRPC ที่อยู่บริการใน **ที่อยู่** กล่องป้อนข้อมูล 
3. คลิก **เชื่อมต่อ**. 
4. หลังจากการเชื่อมต่อสำเร็จ หน้าจะเข้าสู่พื้นที่ทำงานการดีบัก Service / Method 

## 4. เชื่อมต่อโดย Service

1. เลือก **บริการ**.
2. เลือกคลัสเตอร์เป้าหมายและ Namespace
3. ใน **Service / Port** เมนูดรอปดาวน์ เลือกบริการและพอร์ตเป้าหมาย
4. หากรายการบริการไม่ได้รับการอัปเดต คลิก **รีเฟรช**.
5. คลิก **เชื่อมต่อ**.

## 5. เชื่อมต่อโดย Pod

1. เลือก **พ็อด**.
2. เลือกคลัสเตอร์เป้าหมายและ Namespace
3. ใน **Pod / Port** ดรอปดาวน์ เลือก Pod และพอร์ตเป้าหมาย
4. หากรายการ Pod ไม่อัปเดต ให้คลิก **รีเฟรช**.
5. คลิก **เชื่อมต่อ**.

## 6. เลือกบริการและวิธีการ

หลังจากการเชื่อมต่อสำเร็จ หน้าจะถูกแบ่งออกเป็น รายการบริการ, รายการวิธีการ, พื้นที่คำขอ และพื้นที่การตอบกลับ

1. เลือกบริการเป้าหมายจากรายการบริการทางด้านซ้าย
2. คุณสามารถใช้ช่องค้นหาบริการเพื่อกรองบริการ
3. เลือกวิธีการเป้าหมายจากรายการวิธีการ
4. ตัวเลือกการกรองวิธีการที่สลับได้: `Unary`, `Streaming`, `All`.
5. คุณสามารถใช้ช่องค้นหาวิธีการเพื่อกรองวิธีการ

> หน้าปัจจุบันรองรับการเรียกวิธีการแบบ Unary เท่านั้น วิธีการแบบ Streaming จะปรากฏว่าไม่สามารถใช้งานได้

## 7. กรอกพารามิเตอร์ของคำขอ

พื้นที่คำขอรองรับสองวิธีในการกรอกข้อมูล:

| วิธีการ | คำอธิบาย |
| --- | --- |
| โหมดฟอร์ม | หน้าจะสร้างฟอร์มตามช่องป้อนข้อมูลของวิธีการ |
| JSON โหมด | เมื่อ **JSON โหมด** ถูกเปิดใช้งาน ทำการแก้ไขโดยตรงใน JSON ร่างคำขอทั้งหมด |

ขั้นตอนการใช้โหมดฟอร์ม:

1. เลือกวิธีการเป้าหมาย
2. กรอกพารามิเตอร์คำขอตามช่องแต่ละช่อง
3. ใช้เมนูแบบเลื่อนลงเพื่อเลือกฟิลด์ที่มีการนับจำนวน
4. เลือก `true` หรือ `false` สำหรับฟิลด์บูลีน
5. ใช้เครื่องหมายจุลภาคตามที่ระบุบนหน้าสำหรับฟิลด์ที่ซ้ำกัน

ขั้นตอนการใช้งาน JSON โหมด:

1. เปิด **JSON โหมด** สวิตช์
2. กรอกข้อมูลครบถ้วน JSON ในช่องข้อความ
3. ตรวจสอบให้แน่ใจว่า JSON รูปแบบถูกต้อง

## 8. กรอก Metadata

1. ขยาย **Metadata** ในพื้นที่คำร้อง
2. กรอกคีย์และค่า
3. เพื่อเพิ่ม Metadata หลายรายการ ให้คลิก **เพิ่ม**.
4. เพื่อ ลบ แถว ให้คลิกไอคอนลบ

Metadata มักใช้เพื่อถ่ายทอดข้อมูลการยืนยันตัวตน รหัสคำร้อง หรือบริบททางธุรกิจ

## 9. เริ่มการเรียกและดูการตอบสนอง

1. ยืนยันเป้าหมาย บริการ วิธีการ เนื้อหาคำร้อง และ Metadata
2. คลิก **เรียกใช้** ที่มุมบนขวาของหน้า
3. ดูสถานะ เวลาใช้ Metadata ตอบกลับ และการตอบสนอง JSON ในพื้นที่ตอบสนอง
4. หากการเรียกล้มเหลว พื้นที่ตอบสนองจะแสดงสถานะข้อผิดพลาดและเนื้อหาข้อผิดพลาด

## 10. สลับหรือเชื่อมต่อเป้าหมายอีกครั้ง

1. คลิก **เชื่อมต่อ** อยู่ด้านบนเพื่อโหลดนิยามบริการของเป้าหมายปัจจุบันใหม่
2. คลิก **เปลี่ยนเป้าหมาย** เพื่อกลับไปยังหน้าการเลือกเป้าหมาย
3. หลังจากเปลี่ยนเป้าหมาย คุณจะต้องเชื่อมต่อใหม่และเลือก บริการ / วิธีการ อีกครั้ง

## 11. สถานการณ์แก้ปัญหาทั่วไป

| สถานการณ์ | ข้อเสนอแนะการปฏิบัติ |
| --- | --- |
| ตรวจสอบว่าบริการสามารถเชื่อมต่อได้หรือไม่ | เลือกเป้าหมายและคลิก **เชื่อมต่อ** เพื่อดูว่ารายการบริการสามารถโหลดได้หรือไม่ |
| ค้นหาวิธีการอินเทอร์เฟซ | ใช้การค้นหาบริการและการกรองการค้นหาวิธีการ |
| ดีบักการสอบถามอินเทอร์เฟซ | เลือกวิธีแบบ Unary กรอกพารามิเตอร์คำขอ และคลิก **เรียกใช้**. |
| จำเป็นต้องผ่านบริบท | ขยาย Metadata และกรอก Key และ Value ที่สอดคล้องกัน |
| การตอบสนองว่างเปล่าหรือเกิดความล้มเหลว | ตรวจสอบสถานะการตอบสนอง เนื้อหาข้อผิดพลาด และ Metadata |
