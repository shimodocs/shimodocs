# Redis เครื่องมือ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

> [!TIP]
>
> Redis ถูกใช้ในแพลตฟอร์มปฏิบัติการเพื่อดู Redis อินสแตนซ์, DB, รายการของ Keys, และรายละเอียดของ Key ใช้ทั่วไปในการแก้ไขปัญหา cache, session, distributed lock, rate-limiting counter และสถานะระยะสั้น
>
> หน้าสนับสนุนการค้นหาตาม Key หรือ คำนำหน้า Key และแสดงประเภท Key, TTL, และค่าปัจจุบัน

## 1. การเข้าถึง Redis

1. เข้าสู่ระบบที่ **MDP แพลตฟอร์มปฏิบัติการ**.
2. เลือก **บริการระบบ** ที่ด้านบน
3. ขยาย **เครื่องมือ Middleware** ในแถบนำทางด้านซ้าย
4. เลือก **Redis**.

ด้านซ้ายของหน้าเป็นพื้นที่สอบถาม Key และด้านขวาเป็นพื้นที่รายละเอียด Key

## 2. การเลือก Redis อินสแตนซ์ และ DB

1. ในเมนูแบบเลื่อนลงแรกที่มุมบนซ้าย ให้เลือก Redis อินสแตนซ์
2. ในเมนูแบบเลื่อนลงที่สอง ให้เลือก DB ตัวอย่างเช่น `db0`.
3. หน้าจะโหลดรายการ Key ตามอินสแตนซ์และ DB ปัจจุบัน

หากรายการ DB ว่างหรือหน้ารายงานข้อผิดพลาด โปรดตรวจสอบก่อนว่า Redis การตั้งค่าอินสแตนซ์เป็นปกติหรือไม่

## 3. ค้นหา Key

1. ป้อนชื่อ Key หรือคำนำหน้า Key ในกล่องค้นหา
2. คลิกปุ่มค้นหาหรือกด Enter เพื่อดำเนินการค้นหา
3. ดูรายการ Key ทางด้านซ้าย
4. หากคุณต้องการโหลดรายการซ้ำภายใต้เงื่อนไขปัจจุบัน ให้คลิกไอคอนรีเฟรช

ข้อความแนะนำในกล่องค้นหาคือ "โปรดป้อนชื่อ Key รองรับการค้นหาแบบใกล้เคียง" หน้าจะแสดงประเภท Key ที่ตรงกันและ TTL.

## 4. ดูรายการ Key

รายการ Key ประกอบด้วยข้อมูลดังต่อไปนี้

| ข้อมูล | คำอธิบาย |
| --- | --- |
| ประเภท |  Redis ประเภทของ Key เช่น `string`, `hash`, `list`, `set`, `zset`. |
| ชื่อ Key | Key ฉบับเต็มที่ตรงกันในปัจจุบัน |
| TTL | เวลาที่เหลือก่อนหมดอายุของ Key; หน้าจะแสดง "ถาวร" หาก Key ปัจจุบันไม่มีวันหมดอายุ |

## 5. ดูรายละเอียด Key

1. คลิกที่คีย์เป้าหมายในรายการคีย์ทางด้านซ้าย
2. พื้นที่รายละเอียดทางด้านขวาจะแสดงชื่อคีย์ ประเภท TTLและค่าที่เฉพาะเจาะจง
3. เพื่อรีเฟรชรายละเอียดคีย์ปัจจุบัน ให้คลิกปุ่มรีเฟรชที่พื้นที่หัวข้อรายละเอียด

ประเภทวิธีการแสดงผลต่าง ๆ มีดังนี้:

| ประเภท | วิธีการแสดงผล |
| --- | --- |
| `string` | แสดงค่าครบถ้วนในกล่องข้อความ |
| `hash` | แสดงคีย์และค่าของฟิลด์ในตาราง |
| `list` / `set` | แสดงรายการขององค์ประกอบในตาราง |
| `zset` | แสดงคะแนนและสมาชิกในตาราง |

## 6. การคัดลอกค่าของฟิลด์

1. ค้นหาฟิลด์หรือค่าที่คุณต้องการคัดลอกในตารางรายละเอียดหลัก
2. คลิกที่เนื้อหาที่สอดคล้องกัน
3. หน้าจะคัดลอกเนื้อหานั้นไปยังคลิปบอร์ด

> `string` ประเภทจะปรากฏในกล่องข้อความและสามารถคัดลอกโดยตรงได้โดยการเลือกข้อความ; ประเภทตารางรองรับการคลิกที่ค่าเพื่อคัดลอก

## 7. สถานการณ์การแก้ปัญหาที่พบได้บ่อย

| สถานการณ์ | คำแนะนำในการดำเนินการ |
| --- | --- |
| ยืนยันว่ามีแคชหรือไม่ | หลังจากเลือกอินสแตนซ์และฐานข้อมูล ให้ค้นหาด้วยคีย์เต็มหรือคำนำหน้า |
| ตรวจสอบว่าแคชหมดอายุหรือไม่ | ตรวจสอบ TTL ในรายการคีย์หรือรายละเอียด |
| ดูฟิลด์แฮช | คลิกที่คีย์เพื่อดูช่องข้อมูลและค่าต่าง ๆ ในตารางด้านขวา |
| ดูข้อมูลที่จัดเรียงของ ZSet | คลิกที่ `zset` คีย์เพื่อดูคะแนนและสมาชิก |
| ตรวจสอบสถานะล่าสุดของคีย์เดียวกัน | คลิกปุ่มรีเฟรชในพื้นที่รายละเอียด |
