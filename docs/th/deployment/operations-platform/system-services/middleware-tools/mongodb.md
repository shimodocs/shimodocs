# MongoDB เครื่องมือ

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

> [!TIP]
>
> MongoDB ถูกใช้ในแพลตฟอร์มปฏิบัติการเพื่อดู MongoDB ฐานข้อมูล, คอลเลกชัน, และเนื้อหาเอกสาร เหมาะสำหรับการแก้ไขปัญหาข้อมูลแบบเอกสาร, สถานะระหว่างกลาง, บันทึกงาน, และข้อมูลธุรกิจที่มีโครงสร้างยืดหยุ่น
>
> หน้าหน้านี้รองรับการค้นหาตามฐานข้อมูลหรือคอลเลกชัน และหลังจากเลือกคอลเลกชันแล้ว MongoDB JSON สามารถใช้การสืบค้นตามเงื่อนไขได้

## 1. การเข้าถึง MongoDB

1. เข้าสู่ระบบที่ **MDP แพลตฟอร์มปฏิบัติการ**.
2. เลือก **บริการระบบ** ที่ด้านบน
3. ขยาย **เครื่องมือ Middleware** ในแถบนำทางด้านซ้าย
4. เลือก **MongoDB**.

ด้านซ้ายของหน้าแสดงโครงสร้างไม้ของฐานข้อมูลและคอลเลกชัน ส่วนด้านขวาจะแสดงเงื่อนไขการสืบค้นและผลลัพธ์การสืบค้น

## 2. การค้นหาฐานข้อมูลหรือคอลเลกชัน

1. ป้อน DATABASE_NAME หรือคีย์เวิร์ดชื่อคอลเลกชันในช่องค้นหาที่มุมบนซ้าย
2. ดูรายการโครงสร้างที่ถูกกรอง
3. ล้างช่องค้นหาเพื่อคืนการแสดงผลของฐานข้อมูลทั้งหมด

## 3. ขยายฐานข้อมูลและเลือกคอลเลกชัน

1. ค้นหาฐานข้อมูลเป้าหมายในโครงสร้างทางซ้าย
2. คลิกไอคอนขยายทางซ้ายของฐานข้อมูลเพื่อโหลดรายการคอลเลกชัน
3. เลือกคอลเลกชันเป้าหมาย
4. หน้าทางขวาจะทำการสืบค้นโดยอัตโนมัติครั้งหนึ่งด้วยเงื่อนไขเริ่มต้น `{}`.

> การเลือกเพียงฐานข้อมูลจะไม่ทำการเรียกค้นคอลเล็กชัน; คุณจำเป็นต้องเลือกคอลเล็กชันเฉพาะก่อน จากนั้นพื้นที่การค้นหาจะปรากฏทางด้านขวา

## 4. กรอกเงื่อนไขการค้นหา

1. กรอก MongoDB JSON กรอกเงื่อนไขการค้นหาในช่องป้อนข้อมูลทางด้านขวา
2. เลือกจำนวนผลลัพธ์ที่จะส่งกลับ รองรับ `limit: 10`, `limit: 20`, `limit: 50`.
3. คลิก **ค้นหา**.

ตัวอย่างการค้นหา: 

```json
{
  "_id": "task-123"
}
```

ตัวอย่างการค้นหาจากฟิลด์:

```json
{
  "status": "running"
}
```

## 5. การดูผลลัพธ์การค้นหา

1. หลังจากการค้นหาเสร็จสิ้น ตรวจสอบเอกสารที่ส่งกลับในพื้นที่ผลลัพธ์ทางด้านขวา
2. ค่าเริ่มต้นจะแสดงผลลัพธ์ใน JSON รูปแบบ
3. คลิก **ขยาย** เพื่อขยายเอกสารปัจจุบัน
4. คลิก **ย่อ** เพื่อย่อเอกสารปัจจุบัน
5. คลิก **คัดลอก** เพื่อคัดลอกเอกสารปัจจุบัน JSON.

## 6. สถานการณ์การแก้ไขปัญหาที่พบบ่อย

| สถานการณ์ | คำแนะนำในการปฏิบัติ |
| --- | --- |
| ยืนยันว่าเอกสารมีอยู่ | หลังจากเลือกคอลเล็กชันแล้ว ให้ค้นหาโดยใช้ `_id` หรือรหัสธุรกิจ |
| ตรวจสอบสถานะงาน | ค้นหาด้วยรหัสงานและตรวจสอบฟิลด์สถานะและฟิลด์เวลาที่อัปเดต |
| ค้นหาประเภทของระเบียน | ใช้การรวมของฟิลด์เช่น สถานะ ประเภท และเวลาสร้างเพื่อทำการค้นหา |
| ผลลัพธ์ว่างเปล่า | ตรวจสอบว่าฐานข้อมูล คอลเลกชัน ชื่อฟิลด์ และประเภทฟิลด์ที่ถูกต้องถูกเลือกแล้วหรือไม่ |
| จำเป็นต้องลบผลการแก้ไขปัญหาออก | คลิก **คัดลอก** บนผลลัพธ์เดียว |
