# การตั้งค่าขั้นสูง

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## ภาพรวมฟังก์ชัน

การตั้งค่าขั้นสูงใช้เพื่อจัดการการปรับแต่งของระบบ `pd-config` โดยตรงผ่าน YAMLเหมาะสำหรับการจัดการพารามิเตอร์ขั้นสูงที่ไม่ได้ให้ไว้ในหน้าการตั้งค่ามาตรฐานหรือสำหรับการกำหนดค่าจำนวนมาก

ระบบจะรวมการกำหนดค่าที่ปรับแต่งกับการกำหนดค่ามาตรฐานจากโรงงาน ค่าที่ปรับแต่งในเส้นทางเดียวกันจะเขียนทับค่ามาตรฐาน ในขณะที่การกำหนดค่าที่ไม่ได้กรอกจะยังคงใช้ค่ามาตรฐานจากโรงงาน

## การเข้าสู่หน้าต่าง

หลังจากเข้าสู่ระบบด้านหลังการจัดการ ให้เลือก **การตั้งค่าขั้นสูง** ในแถบนำทางด้านซ้ายเพื่อเข้าถึงหน้า

การตั้งค่าขั้นสูงสามารถใช้งานได้เฉพาะผู้ดูแลระบบเท่านั้น หน้าต่างนี้สามารถมีผลต่อทั้งระบบ ดังนั้นควรดำเนินการโดยบุคลากรที่คุ้นเคยกับ MDP โครงสร้างการกำหนดค่า

## คำอธิบายหน้า

หน้าถูกแบ่งออกเป็นสองส่วน:

- **การตั้งค่าเริ่มต้นของโรงงาน pd-config**: การตั้งค่าเริ่มต้นที่จัดเตรียมโดยแพ็กเกจการติดตั้ง, อ่านได้อย่างเดียว
- **การตั้งค่า pd-config ที่ปรับแต่งเอง**: การตั้งค่าที่ลูกค้าบันทึกไว้และสามารถแก้ไขได้

การตั้งค่าที่ปรับแต่งเองไม่จำเป็นต้องคัดลอกเนื้อหามาตรฐานทั้งหมด; โดยปกติจะเก็บเฉพาะรายการการตั้งค่าที่ต้องการแทนที่หรือเพิ่มใหม่

## การแก้ไขและเผยแพร่การตั้งค่า

ขอแนะนำให้ทำตามขั้นตอนเหล่านี้:

1. คลิก **รีเฟรช** เพื่อให้มั่นใจว่าการตั้งค่าที่กำหนดเองล่าสุดถูกโหลดแล้ว
2. เปรียบเทียบกับการตั้งค่าเริ่มต้นของโรงงานทางด้านซ้าย และแก้ไข YAML เนื้อหาทางด้านขวา
3. คลิก **เผยแพร่**.
4. ตรวจสอบเนื้อหาที่เพิ่ม ลบ และแก้ไขในหน้าต่างยืนยันความแตกต่าง
5. ใช้ปุ่มความแตกต่างก่อนหน้า/ถัดไปเพื่อตรวจสอบการเปลี่ยนแปลงทีละรายการ
6. หลังจากยืนยันว่าไม่มีข้อผิดพลาด คลิก **ยืนยันการเผยแพร่**.

หลังจากการเผยแพร่สำเร็จ ระบบจะสร้างงานแอปพลิเคชันการกำหนดค่าและเปิดบันทึกงานในหน้าต่างใหม่ ขึ้นอยู่กับการเปลี่ยนแปลงและการตั้งค่าของระบบ บริการที่เกี่ยวข้องอาจเริ่มทำงานใหม่โดยอัตโนมัติ

## ประวัติการกำหนดค่า

คลิก **ประวัติ** เพื่อดูการกำหนดค่าที่ปรับแต่งและเผยแพร่ก่อนหน้านี้ รวมถึงรหัสบันทึก เวลาสร้าง และ MD5.

- คลิก **ดู** เพื่อดูทั้งหมด YAML ของเวอร์ชันประวัติศาสตร์
- หลังจากเลือกบันทึกสองรายการแล้ว คุณสามารถทำการเปรียบเทียบความแตกต่างได้

หน้าปัจจุบันไม่มีปุ่มกู้คืนด้วยคลิกเดียว สำหรับการกู้คืนการกำหนดค่าในอดีต กรุณาตรวจสอบเวอร์ชันที่เกี่ยวข้อง ตรวจสอบเนื้อหา คัดลอกด้วยตนเองลงในพื้นที่แก้ไข และเผยแพร่ใหม่

## บันทึก

- YAML ต้องรักษาไวยากรณ์ให้ถูกต้อง; ให้สังเกตการเยื้อง วรรคสองจุด และประเภทข้อมูล
- อย่าลบรายการกำหนดค่าที่คุณไม่เข้าใจโดยไม่จำเป็น
- ก่อนการเผยแพร่ ตรวจสอบความแตกต่างอย่างเต็มที่เพื่อหลีกเลี่ยงการเขียนทับการเปลี่ยนแปลงที่ผู้ดูแลระบบคนอื่นเพิ่งส่ง
- แนะนำให้ดำเนินการเปลี่ยนแปลงที่สำคัญในช่วงเวลาที่ธุรกิจไม่คับคั่ง และควรบันทึกการตั้งค่าเดิมล่วงหน้า
- หลังจากเผยแพร่ ตรวจสอบบันทึกงานเพื่อให้แน่ใจว่าการนำการตั้งค่าไปใช้และการตรวจสอบสถานะบริการเสร็จสมบูรณ์

## สถานการณ์ทั่วไป

- **การเผยแพร่ล้มเหลว**: กรุณาตรวจสอบ YAML รูปแบบ ชื่อฟิลด์ และประเภทค่าการตั้งค่า
- **การรีสตาร์ทบริการหลังการเผยแพร่**: การเปลี่ยนแปลงการตั้งค่าอาจจำเป็นต้องรีสตาร์ทบริการที่เกี่ยวข้อง ซึ่งเป็นเรื่องปกติ
- **หน้าไม่สามารถเข้าถึงได้ชั่วคราวหลังการเผยแพร่**: MDP หรือบริการที่เกี่ยวข้องอาจกำลังรีสตาร์ท กรุณารีเฟรชหลังจากรอสักครู่
- **การตั้งค่าไม่เกิดผลตามที่คาดหวัง**: กรุณายืนยันว่าเส้นทางการตั้งค่าถูกต้อง และตรวจสอบผลลัพธ์รวมสุดท้ายและบันทึกงาน
- **การแก้ไขการตั้งค่าผิด**: ค้นหารุ่นที่ถูกต้องจากประวัติ คัดลอกเนื้อหา และเผยแพร่อีกครั้ง

> การตั้งค่าขั้นสูงจะส่งผลต่อการตั้งค่าระดับระบบและการทำงานของบริการ ห้ามเผยแพร่การตั้งค่าที่ไม่ได้ตรวจสอบโดยตรงในสภาพแวดล้อมการผลิต

## ตัวอย่างอินเทอร์เฟซการดำเนินงาน
