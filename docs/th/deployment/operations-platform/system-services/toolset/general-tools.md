# เครื่องมือทั่วไป

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## 1. ภาพรวมหน้าเพจ

หน้าของเครื่องมือทั่วไปมีฟังก์ชันที่ใช้บ่อย 7 ฟังก์ชันดังนี้: JSON การฟอร์แมต, การแปลงฟอร์แมต, JWT การถอดรหัส, การแปลงเวลา, การตรวจสอบเวลาเครื่อง, การวิเคราะห์ QR Code, และการเข้ารหัส/ถอดรหัส Base64

1. คลิกที่การ์ดฟังก์ชันใดก็ได้เพื่อเข้าสู่หน้าการดำเนินการ
2. หลังจากเข้าสู่หน้าแล้ว คุณสามารถสลับไปยังเครื่องมืออื่น ๆ โดยตรงจากรายการฟังก์ชันทางด้านซ้าย
3. คลิก 'กลับไปที่เมนูฟังก์ชัน' เพื่อกลับไปยังหน้าหลักของการ์ด

## 2. JSON การฟอร์แมต

ฟังก์ชันนี้ใช้สำหรับฟอร์แมต, การบีบอัด และการตรวจสอบความถูกต้อง JSON เนื้อหา.

1. คลิก "JSON การจัดรูปแบบ
2. ป้อนเนื้อหาที่ต้องการประมวลผลในพื้นที่ "ป้อนข้อมูล" JSONตัวอย่างเช่น:

   ```json
   {"name":"MDP","enabled":true,"items":[1,2]}
   ```

3. คลิก 'รูปแบบ' และจะมีการเยื้องทางด้านขวา JSON จะถูกสร้างขึ้นทางด้านขวา
4. คลิก 'บีบอัด' และแบบย่อ JSON โดยไม่มีช่องว่างและการขึ้นบรรทัดจะถูกสร้างทางด้านขวา
5. คลิก 'คัดลอก' เพื่อคัดลอกผลลัพธ์ที่ประมวลผลแล้ว
6. คลิก 'ล้าง' เพื่อลบเนื้อหาที่ป้อนเข้าและผลลัพธ์

ผลการทดสอบ: สตริง ค่าบูลีน และอาร์เรย์ทั้งหมดถูกเก็บรักษาไว้อย่างถูกต้อง และฟังก์ชันการจัดรูปแบบและการบีบอัดทำงานได้อย่างถูกต้อง

## 3. การแปลงรูปแบบ

ฟังก์ชันนี้รองรับการแปลงและการจัดรูปแบบระหว่าง JSON, YAML, และ TOML รูปแบบต่าง ๆ

1. คลิก "การแปลงรูปแบบ"
2. เลือกรูปแบบเนื้อเข้าที่ "รูปแบบต้นฉบับ"
3. เลือกรูปแบบผลลัพธ์ที่ต้องการใน "รูปแบบเป้าหมาย"
4. กรอกเนื้อหาที่ต้องการแปลงทางด้านซ้าย
5. คลิก "แปลง" และผลลัพธ์จะแสดงทางด้านขวา
6. คลิก "สลับรูปแบบ" เพื่อสลับรูปแบบต้นฉบับและรูปแบบเป้าหมาย
7. คลิก "จัดรูปแบบ" เพื่อปรับการเยื้องและการจัดวางของเนื้อหาปัจจุบัน
8. คลิก "คัดลอก" เพื่อคัดลอกผลลัพธ์

ครั้งนี้เราใช้ JSON เพื่อแปลงเป็น YAML, ป้อนข้อมูล:

```json
{"name":"MDP","ports":[80,443],"enabled":true}
```

ผลลัพธ์การแปลง: 

```yaml
name: MDP
ports:
  - 80
  - 443
enabled: true
```

ผลลัพธ์ที่วัดได้: ฟิลด์, อาร์เรย์, และค่าบูลีนถูกแปลงอย่างถูกต้อง

## 4. JWT ถอดรหัส

ฟีเจอร์นี้ใช้เพื่อวิเคราะห์ Header, Payload, และ Signature ของ JWT Token

1. คลิก "JWT ถอดรหัส
2. วาง JWT Token ลงในกล่องป้อนข้อมูล
3. คลิก "ถอดรหัส"
4. ดูอัลกอริทึมลายเซ็นและประเภท Token ในส่วน Header
5. ดูข้อมูลเช่น ผู้ใช้ บทบาท และเวลาหมดอายุในส่วน Payload
6. ดูเนื้อหาดิบของลายเซ็น
7. คลิกปุ่มคัดลอกในแต่ละส่วนเพื่อคัดลอกผลลัพธ์การแยกวิเคราะห์
8. คลิก "ล้าง" เพื่อลบ Token และผลลัพธ์การแยกวิเคราะห์ปัจจุบัน

ผลลัพธ์ทดสอบ: Token ทดสอบสามารถแยกวิเคราะห์ฟิลด์เช่น `HS256`, `JWT`ผู้ใช้ บทบาท และเวลาหมดอายุ

> JWT การถอดรหัสมีไว้เพื่อดูโครงสร้างของ Token เท่านั้นและไม่สามารถแทนการยืนยันความถูกต้องของลายเซ็นฝั่งเซิร์ฟเวอร์ได้

## 5. การแปลง Timestamp 

ฟีเจอร์นี้รองรับการแปลงสองทางระหว่าง Unix timestamp และวัน-เวลา 

### 5.1 การแปลง Timestamp เป็น วัน/เวลา 

1. คลิก "การแปลง Timestamp" 
2. กรอก timestamp 10 หลักสำหรับวินาทีหรือ 13 หลักสำหรับมิลลิวินาทีในช่อง "Timestamp (วินาทีหรือมิลลิวินาที)" 
3. คลิก "แปลง" ด้านบน 
4. ดูวันที่และเวลาใน "ผลลัพธ์การแปลง" 
5. คลิกปุ่มคัดลอกข้างผลลัพธ์เพื่อนำเนื้อหาไปใช้ 

### 5.2 การแปลงวันเวลาเป็น Timestamp 

1. กรอก 'YYYY-MM-DD HH:mm:ss' หรือ ISO ฟอร์แมตเวลาในช่อง "วันที่ เวลา" 
2. คลิก "แปลง" ด้านล่าง 
3. ดู Unix timestamp ใน "ผลการแปลง (วินาที)" 
4. คลิก "เวลาปัจจุบัน" เพื่อใส่เวลาปัจจุบันและวันที่อย่างรวดเร็ว 
5. คลิก "ล้าง" เพื่อล้างเนื้อหาทั้งหมด 

ผลการทดสอบ: '1704067200' ถูกแปลงเป็นวันที่-เวลาเรียบร้อยแล้ว และวันที่-เวลาก็สามารถแปลงกลับเป็น timestamp ระดับวินาทีได้ถูกต้องเช่นกัน 

> เมื่อทำการตรวจสอบข้อมูลข้ามโซนเวลา ให้ชี้แจงก่อนว่าเวลาธุรกิจใช้ UTC หรือเวลาโซนท้องถิ่น 

## 6. ตรวจสอบเวลาของเครื่อง

ฟังก์ชันนี้ใช้ตรวจสอบเวลาของ Pods ทั้งหมดที่มี `app=ws-gateway` ในปัจจุบัน NAMESPACE และเน้นไอเท็มที่มีความเบี่ยงเบนเวลามากกว่า 30 วินาที

1. คลิก "ตรวจสอบเวลาของเครื่อง"
2. คลิก "รีเฟรช" มุมขวาบน
3. ตรวจสอบปัจจุบัน NAMESPACE และค้นหาป้ายกำกับ
4. ดูเวลามาตรฐานระบบที่คำนวณโดยระบบ ซึ่งเป็นเวลากลางของ Pods ทั้งหมด
5. ดูโหนดที่แต่ละ Pod อยู่, Unix timestamp และเวลาแบบอ่านได้
6. ตรวจสอบ "ความแตกต่างจากมาตรฐาน" และ "สถานะ"
7. หากความคลาดเคลื่อนเกิน 30 วินาที ให้ตรวจสอบโหนด NTP/Chrony, เวลาเครื่องเสมือน และการตั้งค่าเขตเวลา

ผลการทดสอบ: 1 `ws-gateway` Pod ส่งกลับมาแล้ว โดยมีความเบี่ยงเบนจากเวลามาตรฐานที่ `0s` และสถานะ "ปกติ".

## 7. การวิเคราะห์ QR Code

ฟีเจอร์นี้ใช้สำหรับอัปโหลดรูปภาพ QR Code และดึงข้อความ ลิงก์ หรือเนื้อหาอื่น ๆ ที่อยู่ภายใน

1. คลิก "การวิเคราะห์ QR Code"
2. คลิก "เลือกไฟล์"
3. เลือกภาพ QR โค้ดที่ชัดเจนจากอุปกรณ์ในเครื่องของคุณ
4. หลังจากหน้าแสดงตัวอย่างภาพ ให้ตรวจสอบ "ผลการวิเคราะห์" ด้านล่าง
5. เปรียบเทียบผลลัพธ์กับเนื้อหาที่คาดหวังของ QR โค้ดเพื่อยืนยันความสอดคล้อง
6. คลิก "คัดลอก" เพื่อคัดลอกเนื้อหาที่วิเคราะห์ได้
7. คลิก "ล้าง" เพื่อลบภาพและผลการวิเคราะห์

ผลการทดสอบ: QR โค้ดตัวอย่างสามารถอัปโหลด แสดงตัวอย่าง และวิเคราะห์ได้ถูกต้อง

## 8. การเข้ารหัสและถอดรหัส Base64

คุณสมบัตินี้ใช้สำหรับการแปลงสองทางระหว่างข้อความธรรมดาและเนื้อหา Base64

### 8.1 การเข้ารหัส Base64

1. คลิก "การเข้ารหัสและถอดรหัส Base64"
2. ใส่ข้อความธรรมดาที่ด้านซ้าย
3. คลิก "เข้ารหัส"
4. ดูผลลัพธ์การเข้ารหัส Base64 ที่ด้านขวา

### 8.2 การถอดรหัส Base64

1. ใส่เนื้อหา Base64 ที่ด้านซ้าย
2. คลิก "ถอดรหัส"
3. ดูข้อความที่กู้คืนแล้วที่ด้านขวา
4. คลิก "คัดลอก" เพื่อคัดลอกผลลัพธ์
5. คลิก "ล้าง" เพื่อล้างข้อมูลเข้าและออก

ผลการทดสอบ:

```text
MDPTEST → TURQ5rWL6K+V
TURQ5rWL6K+V → MDPTEST
```

จีน UTF-8 เนื้อหาสามารถแปลงกลับไปกลับมาได้ตามปกติ
