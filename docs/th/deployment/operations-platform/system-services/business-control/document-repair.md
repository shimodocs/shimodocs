# การซ่อมแซมเอกสาร

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

อาการของไฟล์ที่เสียหายผิดปกติ ได้แก่ เอกสารไม่สามารถเปิดได้อย่างถูกต้อง ป๊อปอัพข้อผิดพลาดปรากฏระหว่างการโหลด และเนื้อหาไม่สามารถแสดงผล

เมื่อไม่สามารถเปิดเอกสารได้ ใช้ฟังก์ชันนี้เพื่อซ่อมแซมไฟล์

# ตัวอย่างการใช้งาน

มีวิธีซ่อมแซม 2 วิธี

## การเตรียมตัว

### เอกสารอ้างอิงด่วนสำหรับประเภทไฟล์

|**ประเภทไฟล์**|**ไฟล์ URL คุณสมบัติที่อยู่**|**หมายเหตุ**|
|:----|:----|:----|
|rdoc(เอกสารรวย)|/**เอกสาร**/{fileguid}|เอกสารเบา|
|mosheet(modoc)|/**แผ่นงาน**/{fileguid}|ตาราง|
|modoc(modoc)|/**docx**/{fileguid}|เอกสารมืออาชีพ|

### คำเตือนความเสี่ยงด้านการดำเนินงาน

การซ่อมล้มเหลวไม่มีความเสี่ยง

## การกู้คืนจากข้อมูลที่เข้ารหัส

รองรับเฉพาะการซ่อมไฟล์ประเภทตาราง สำหรับไฟล์ประเภทอื่น ให้เลือก [ซ่อมจากข้อมูลประวัติ]

นี่คือวิธีที่แนะนำ คุณสามารถป้อนไฟล์โดยตรง GUID เพื่อทำการซ่อมได้ วิธีนี้ GUID คือ ShimoDocs ไฟล์ GUID.

หลักการซ่อมคือการแปลงข้อมูลไฟล์เข้ารหัสในที่เก็บวัตถุเป็นข้อมูลเนื้อหาไฟล์ที่ไม่เข้ารหัส ซึ่งใช้ได้กับหลายสถานการณ์

หากวิธีนี้ซ่อมไม่ได้ ให้เลือกวิธีอื่น

### ไฟล์ GUID

1. เปิดเครื่องมือสำหรับนักพัฒนาของเบราว์เซอร์

2. กรองคำขอ pull

3. ในคำขอ ส่วน rp3OMYnMrdcQJZkm สตริง 16 ตัวนี้ คือ guid

## กู้คืนจากข้อมูลประวัติ

กู้คืนจากบันทึกประวัติ

1. รหัสไฟล์ลูกค้า

2. ประเภทไฟล์

   1. สำหรับเอกสาร/สเปรดชีท/งานนำเสนอแบบดั้งเดิม ให้เลือก modoc

   2. สำหรับเอกสารขนาดเบา ให้เลือก richdoc

1. เลือกแหล่งข้อมูล
