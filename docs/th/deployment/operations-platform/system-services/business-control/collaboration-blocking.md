# การบล็อกการทำงานร่วมกัน

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## คำอธิบายฟังก์ชัน

เมื่อเกิดงานค้างใน Kafka, และยืนยันแล้วว่างานค้างที่ผิดปกติเกิดจากไฟล์ใดไฟล์หนึ่ง คุณสามารถใช้ฟังก์ชันห้ามนี้เพื่อห้ามการแก้ไขไฟล์นั้น ซึ่งจะช่วยแก้ปัญหา Kafka งานค้าง

## ตัวอย่างการใช้งาน

1. เลือกการห้ามร่วมกัน 

2. ป้อน guid ของไฟล์ โดยเน้น: นี่หมายถึง guid ภายใน ShimoDocs, ไม่ใช่ id ไฟล์ของลูกค้า 

ป้อน ShimoDocs ไฟล์ GUID และคลิก 'เพิ่มเพื่อบล็อก'; ไฟล์จะถูกห้ามไม่ให้แก้ไขภายใน 3 นาที 

คลิกปุ่ม 'ยกเลิกการบล็อก' เพื่อคืนฟังก์ชันการแก้ไขไฟล์ 

### วิธีการรับ GUID 

1. เปิดเครื่องมือสำหรับนักพัฒนาในเบราว์เซอร์ 

2. กรองคำขอ Pull Request 

3. ในคำขอ สตริง 16 ตัวอักษรจาก rp3OMYnMrdcQJZkm คือ GUID 

### วิธีการกำหนดผลกระทบของการแบน

เอกสารไม่สามารถบันทึกได้สำเร็จ; หลังจากแก้ไขไฟล์ จะมีป๊อปอัพแบบออฟไลน์ปรากฏหลัง 2 นาที และข้อมูลจะสูญหายหลังจากรีเฟรชหน้า

### เมื่อใดควรยกเลิกการแบน

ไม่แนะนำให้ยกเลิกการแบน โดยทั่วไป เนื่องจากไฟล์มีขนาดใหญ่เกินกว่าที่เซิร์ฟเวอร์จะรองรับการแก้ไข หลังจากถูกแบน ไฟล์จะเป็นแบบอ่านอย่างเดียว แนะนำให้คัดลอกเนื้อหาไฟล์ด้วยตนเองไปยังไฟล์ใหม่
