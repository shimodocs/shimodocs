# การค้นหาข้อมูลไฟล์

[← ShimoDocs Suite เอกสารการติดตั้ง](../../../README.md)

## ภาพรวมฟังก์ชัน

การสืบค้นข้อมูลไฟล์ใช้สำหรับสืบค้นบันทึกพื้นฐานของไฟล์ในระบบตามไฟล์ภายใน GUID หรือรหัสไฟล์ฝั่งลูกค้า เพื่ออำนวยความสะดวกในการตรวจสอบรหัสไฟล์ แอปพลิเคชันที่เกี่ยวข้อง ประเภทไฟล์ สถานะ และขนาดเนื้อหา

หน้าหน้านี้เป็นแบบอ่านอย่างเดียวและจะไม่แก้ไขเนื้อหาไฟล์หรือสถานะ

## การเข้าถึงหน้า

หลังจากเข้าสู่ระบบด้านหลังการจัดการ ให้เลือก **File Information Query** ในเมนูนำทางด้านซ้ายเพื่อเข้าถึงหน้า

## การสืบค้นไฟล์

หน้าหน้านี้รองรับเงื่อนไขการสืบค้นดังต่อไปนี้:

- **ไฟล์ภายใน GUID**: ของไฟล์ `history_guid`.
- **ผู้ให้บริการไฟล์ของลูกค้า GUID**: ฝั่งลูกค้า `provider_file_id`.
- **รหัสแอป**: เป็นค่าเลือกได้ แนะนำให้กรอกพร้อมกับผู้ให้บริการ GUID เพื่อระบุแอปพลิเคชันที่เกี่ยวข้อง

ต้องกรอกอย่างน้อยหนึ่งรายการระหว่างไฟล์ภายใน GUID หรือไฟล์ผู้ให้บริการลูกค้า GUID แล้วคลิก **ค้นหา**.

หากกรอกเฉพาะผู้ให้บริการ GUID และไม่ได้กรอกรหัสแอป ระบบจะแสดงผลบันทึกทั้งหมดที่ตรงกับผู้ให้บริการ GUIDดังนั้นอาจปรากฏผลลัพธ์หลายรายการ 

### การดึงไฟล์ GUID 
1. ในกรณีของ ShimoDocs Suiteเพียงใช้ที่อยู่ชุดโปรแกรมในเบราว์เซอร์เป็น **ผู้ให้บริการไฟล์ของลูกค้า GUID**. 

## ผลการค้นหา

ผลการค้นหาหลักประกอบด้วย:

- **id**: รหัสหลักของบันทึกไฟล์
- **แอป_id**: รหัสแอปพลิเคชันที่เกี่ยวข้อง
- **ผู้ให้บริการ_ไฟล์_id**: รหัสไฟล์ฝั่งลูกค้า
- **ประวัติ_guid**: ไฟล์ประวัติในระบบภายใน GUID.
- **สร้าง_เมื่อ**: เวลาสร้างบันทึก
- **ประเภท**: ประเภทไฟล์ เช่น เอกสาร สเปรดชีต งานนำเสนอ PDF, รูปภาพ หรือวิดีโอ
- **สร้าง_โดย**: รหัสผู้ใช้ผู้สร้าง
- **สถานะ**: ค่าปัจจุบันของสถานะไฟล์
- **ไฟล์_เนื้อหา_ขนาด**: ขนาดของเนื้อหาไฟล์ เป็นไบต์

ประเภทไฟล์ในผลลัพธ์จะแสดงทั้งหมายเลขประเภทและชื่อที่สอดคล้องกันเพื่อความสะดวกในการระบุ

## สถานการณ์ทั่วไป

- **ข้อความแจ้ง: ต้องป้อนเงื่อนไขการค้นหา**: กรุณากรอกไฟล์ภายในอย่างน้อย GUID หรือผู้ให้บริการ GUID.
- **ไม่พบไฟล์**: กรุณาตรวจสอบว่าไอดีสมบูรณ์หรือยืนยันว่าไฟล์เป็นของสภาพแวดล้อมปัจจุบันหรือไม่
- **มีหลายระเบียนที่ส่งกลับ**: ผู้ให้บริการ GUID อาจซ้ำกันในหลายแอปพลิเคชัน; กรุณาเพิ่ม App ID แล้วค้นหาอีกครั้ง
- **ประเภทไฟล์แสดงเป็นไม่ทราบ**: หมายเลขประเภทของระเบียนปัจจุบันอาจยังไม่มีชื่อที่ตรงกันถูกกำหนดค่า คุณสามารถให้หมายเลขแก่ฝ่ายสนับสนุนทางเทคนิคเพื่อยืนยัน
- **ไม่สามารถระบุค่าของสถานะได้**: ฟิลด์สถานะเป็นค่าระเบียนพื้นฐานและต้องการการวิเคราะห์เพิ่มเติมร่วมกับปรากฏการณ์ทางธุรกิจและบันทึกเฉพาะ

> ตัวระบุไฟล์เป็นข้อมูลธุรกิจ; กรุณาอย่าแชร์โดยตรงในแชทสาธารณะหรือบัตรแจ้งปัญหาภายนอก
