# การแก้ไขปัญหาการติดตั้ง

[← ShimoDocs Suite เอกสารการติดตั้ง](../README.md)

> [!TIP]
>
> ปัญหาที่พบบ่อยในระหว่างขั้นตอนการติดตั้งมักจะอยู่ในหมวดหมู่ต่อไปนี้

## 1 การไม่ตรงกันของเวลา

อาการปัญหา:

* ไม่สามารถเข้าสู่ระบบได้

* ข้อผิดพลาดในการตรวจสอบสิทธิ์

* ข้อยกเว้นในการเรียกบริการ

ข้อกำหนดในการจัดการ:

* ตรวจสอบการเบี่ยงเบนของเวลาของทุกโหนดก่อนเป็นอันดับแรก

* หลังจากแก้ไข NTP/บริการซิงโครไนซ์เวลา, ดำเนินการติดตั้งหรือการรับรองต่อไป

คำสั่งตรวจสอบ:

```plain
timedatectl status
date
```


## 2 ข้อผิดพลาดในการกำหนดค่าพาธดิสก์ข้อมูล

ปรากฏการณ์:

* หลังการติดตั้ง, ดิสก์เต็มอย่างรวดเร็ว

* การเขียนข้อมูลล้มเหลว

* ไดเรกทอรีคงที่ตั้งอยู่บนไดรฟ์ระบบ

ข้อกำหนดในการประมวลผล:

* ไดเรกทอรีคงที่ต้องระบุชัดเจนไปยังดิสก์ข้อมูล

* ข้อมูลธุรกิจไม่ถูกเก็บในไดเรกทอรีของดิสก์ระบบ

คำสั่งแก้ไขปัญหา:

```plain
findmnt -n -o TARGET -T /data
df -Th|egrep -v "overlay|tmpfs"
```


## 3 การเชื่อมต่อบริการที่พึ่งพาล้มเหลว

ปรากฏการณ์:

* การตรวจสอบบริการล้มเหลวระหว่างการติดตั้ง

* การเชื่อมต่อกับฐานข้อมูล แคช คิวข้อความ หรือที่เก็บวัตถุล้มเหลว

ข้อกำหนดในการจัดการ:

* ตรวจสอบก่อนว่าที่อยู่ พอร์ต บัญชี และ PASSWORD ถูกป้อนอย่างถูกต้องหรือไม่

* ตรวจสอบการเชื่อมต่อเครือข่ายและนโยบายความปลอดภัย

* สุดท้าย ตรวจสอบว่าบริการเป้าหมายเองสามารถใช้งานได้หรือไม่

คำสั่งแก้ไขปัญหา:

```plain
nc -zv <MYSQL_HOST> 3306
nc -zv <REDIS_HOST> 6379
nc -zv <MONGO_HOST> 27017
nc -zv <KAFKA_HOST> 9092
```


## 4 แพ็กเกจออฟไลน์ไม่ตรงกัน

ปรากฏการณ์:

* การโหลดกระจกล้มเหลว

* กระบวนการติดตั้งรายงานว่าบริการไม่สามารถเริ่มทำงานและรุ่นไม่ตรงกัน

* แพ็กเกจติดตั้งไม่ตรงกับแพ็กเกจออฟไลน์มิร์เรอร์

ข้อกำหนดในการประมวลผล:

* ยืนยันว่าแพ็กเกจติดตั้ง แพ็กเกจภาพออฟไลน์ และเวอร์ชันผลิตภัณฑ์สอดคล้องกัน

* ยืนยันว่าสำหรับแพ็กเกจติดตั้งตรงกับ CPU สถาปัตยกรรม

* ยืนยันว่าวัสดุจากโครงการต่าง ๆ หรือวันที่ต่างกันไม่ได้ถูกผสมกัน

## หน้า Installer เปิดไม่ได้

ปรากฏการณ์:

* หน้า Web UI เข้าใช้งานไม่ได้

* Port 18080 ไม่ได้ฟังอยู่

* กระบวนการติดตั้งได้หยุดทำงานแล้ว

คำสั่งแก้ไขปัญหา:

```plain
ps -ef | grep mdp | grep -v grep
ss -lntp | grep 18080
tail -n 100 /root/nohup.out
```


## 6. ลำดับการแก้ไขปัญหาที่แนะนำ

แก้ไขปัญหาการติดตั้งตามลำดับต่อไปนี้:

1. ขั้นแรก ยืนยันว่าปัญหาเป็นปัญหาสภาพแวดล้อมหรือไม่: ระบบ, เวลา, ดิสก์, พอร์ต, เครือข่าย

2. ยืนยันอีกครั้งว่าปัญหาเป็นปัญหาการตั้งค่าหรือไม่: ชื่อโดเมน, ไดเรกทอรี, ที่อยู่การพึ่งพา, บัญชี PASSWORD

3. ยืนยันอีกครั้งว่าปัญหาเป็นปัญหาวัสดุหรือไม่: แพ็กเกจติดตั้ง, แพ็กเกจออฟไลน์, ความเข้ากันได้ของสถาปัตยกรรม

4. สุดท้าย ตรวจสอบบันทึกการติดตั้งและสถานะการทำงานของบริการ

คำอธิบาย:

* ห้ามติดตั้งซ้ำหากยังไม่ตรงตามข้อกำหนดเบื้องต้น

* ห้ามรันคำสั่งซ้ำด้วยเหตุผลล้มเหลวเดิมอย่างชัดเจน

## 7. เมื่อใดควรหยุดการติดตั้ง

หากเกิดสถานการณ์ดังต่อไปนี้ ให้หยุดการติดตั้งก่อนและดำเนินการต่อหลังแก้ไขปัญหาพื้นฐานแล้วเท่านั้น:

* เวลาของทุกโหนดไม่ตรงกัน

* ดิสก์ข้อมูลไม่ได้ติดตั้งโดยอิสระ

* บริการภายนอกที่ต้องพึ่งพาไม่สามารถเข้าถึงได้

* เวอร์ชันวัสดุออฟไลน์ไม่ตรงกัน

* บริการติดตั้งไม่ได้เริ่มทำงานอย่างถูกต้อง
