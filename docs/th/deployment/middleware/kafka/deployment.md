# ปรับใช้ด้วย Kafka

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

บทความนี้อธิบายวิธีปิดตัวติดตั้งในตัว Kafka ใน ShimoDocs และกำหนดค่า Kafka ของลูกค้าเองเป็นคิวข้อความของบุคคลที่สาม หลังจากการกำหนดค่า ตัวติดตั้งจะตรวจสอบ Kafkaการเชื่อมต่อเครือข่ายและสิทธิ์ในการสร้างหัวข้อ เมื่อทำการตรวจสอบแล้ว สามารถดำเนินการปรับใช้งานต่อได้ 

# 1. การเตรียมการก่อนการกำหนดค่า 
ก่อนเริ่มโปรดยืนยันว่า: 
- Kafka เซิร์ฟเวอร์ถูกติดตั้งและทำงานอย่างปกติ 
- โหนดปรับใช้สามารถเข้าถึง Kafka โฮสต์และพอร์ตของเซิร์ฟเวอร์ 
- ข้อมูลผู้ใช้สำหรับการตรวจสอบสิทธิ์และ PASSWORD สำหรับการเชื่อมต่อไปยัง Kafka หัวข้อเซิร์ฟเวอร์ (หากคลัสเตอร์ภายนอก Kafka เปิดใช้งานการตรวจสอบสิทธิ์ที่ปลอดภัย) 
- บัญชีที่ตรวจสอบสิทธิ์ต้องใช้ผู้ดูแลระบบและมีสิทธิ์สร้าง ลบ ให้สิทธิ์ และอ่านเขียนหัวข้อ (หากเป็นคลัสเตอร์ภายนอก) Kafka เปิดใช้งานการตรวจสอบสิทธิ์ที่ปลอดภัย) 

> [!TIP]
>
> IP พอร์ต และบัญชีในบทความนี้เป็นตัวอย่าง โปรดกำหนดค่าโดยใช้ข้อมูลสภาพแวดล้อมจริงของคุณ; อย่าบันทึก PASSWORD ไปยังเอกสารภายนอกหรือภาพหน้าจอ 
>

# 2. เข้าสู่การกำหนดค่าขั้นสูง 
ในขั้นตอน "Configuration" ของตัวติดตั้ง หลังจากทำการกำหนดค่าเครือข่าย สภาพแวดล้อมเป้าหมาย และข้อมูลโหนดเรียบร้อยแล้ว ให้ขยายส่วน "Advanced Configuration" ที่ด้านล่างของหน้า 

# 3. ยกเลิกการติดตั้งในตัว Kafka
ในพื้นที่ 'Middleware Services' ยกเลิกการเลือก Kafka.

หลังจากยกเลิกการเลือก ตัวติดตั้งจะไม่ติดตั้ง Kafkaในตัวอีกต่อไป และจะเป็นภายนอก Kafka ซึ่งได้เตรียมไว้จะถูกใช้ในภายหลัง สำหรับซอฟต์แวร์กลางอื่น ๆ ว่าจะใช้บริการที่มีอยู่หรือไม่ควรเลือกตามแผนการติดตั้งจริง

# 4. เปิดการตั้งค่า Middleware ของบุคคลที่สาม
ในพื้นที่ "ซอฟต์แวร์กลางบุคคลที่สาม" คลิก "กำหนดค่า"

# 5. กำหนดค่า Kafka ซอฟต์แวร์กลางการส่งข้อความ
## Kafka เซิร์ฟเวอร์ SASL ไม่ได้เปิดใช้งานการตรวจสอบสิทธิ์
1. เลือก "Kafka คิวข้อความ" ทางด้านซ้าย
2. เปิดใช้งาน "ใช้ซอฟต์แวร์กลางบุคคลที่สาม Kafka คิวข้อความ"
3. กรอก Kafka ข้อมูลการเชื่อมต่อเซิร์ฟเวอร์
5. ตรวจสอบและบันทึก

## การเปิดใช้งาน SASL การตรวจสอบสิทธิ์บน Kafka เซิร์ฟเวอร์ 
ถ้า Kafka เซิร์ฟเวอร์มี SASL การตรวจสอบสิทธิ์เปิดใช้งาน ต้องเปิดใช้งานพร้อมกันใน Web UI: เปิดใช้งานก็ต่อเมื่อโบรกเกอร์ต้องการการเข้าถึงที่ตรวจสอบสิทธิ์ ปุ่ม 
1. เปิดใช้งาน SASL การตรวจสอบสิทธิ์ 
2. ตรวจสอบกลไก 
3. ป้อน USERNAME และ PASSWORD 
4. ตรวจสอบและบันทึก 

# 6. ยืนยันผลการตรวจสอบ
โปรแกรมติดตั้งจะตรวจสอบสิ่งต่อไปนี้:
- เข้าสู่ระบบ: บัญชีสามารถยืนยันตัวตนได้ตามปกติ (หาก SASL ถูกเปิดใช้งาน)
- การเชื่อมต่อ: สภาพแวดล้อมการปรับใช้สามารถเข้าถึงได้ Kafka.
- สิทธิ์การสร้างหัวข้อ: บัญชีมีสิทธิ์ในการสร้างหัวข้อ อนุญาต และอ่าน/เขียน

หลังจากรายการตรวจสอบทั้งหมดแสดงว่า 'สำเร็จ' ปิดหน้าต่างการกำหนดค่าและกลับไปที่หน้าการกำหนดค่า 'Configuration' ของโปรแกรมติดตั้ง

หากพบข้อผิดพลาดใด ๆ กรุณาตรวจสอบตามข้อความแนะนำบนหน้าเพจ:
- ตรวจสอบว่ากรอกโฮสต์และพอร์ตถูกต้องหรือไม่
- เครือข่ายระหว่างโหนดการปรับใช้งานและ Kafka เซิร์ฟเวอร์เชื่อมต่ออยู่หรือไม่
- ว่า USERNAME และ PASSWORD ถูกต้อง (Kafka เซิร์ฟเวอร์ได้เปิดใช้งาน SASL การตรวจสอบสิทธิ์)
- บัญชีมีสิทธิ์ที่ต้องการหรือไม่ (Kafka เซิร์ฟเวอร์มี SASL เปิดใช้งานการตรวจสอบสิทธิ์)

# 7. ดำเนินการเริ่มต้นการปรับใช้งานต่อ
หลังจากกลับไปที่หน้า 'การกำหนดค่า' ให้แน่ใจว่า Kafka ยังไม่ได้ตรวจสอบ ให้คลิก 'เริ่มต้นการปรับใช้งาน' เพื่อดำเนินการต่อกับภาพรวมการปรับใช้งาน ตรวจสอบ และขั้นตอนการดำเนินการ

> [!TIP]
>
> ก่อนเริ่มต้นการปรับใช้งาน กรุณายืนยันอีกครั้งว่า Kafka การกำหนดค่าถูกบันทึกแล้วและรายการตรวจสอบทั้งหมดผ่านเรียบร้อย
