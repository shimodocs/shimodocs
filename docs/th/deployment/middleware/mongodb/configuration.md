# MongoDB การกำหนดค่า

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

บทความนี้มีวัตถุประสงค์เพื่อแนะนำเจ้าหน้าที่ด้านการดำเนินงาน การปฏิบัติ หรือการรวมระบบให้เสร็จสิ้นการรวม ShimoDocs กับภายนอก MongoDB ทีละขั้นตอน

## 1. การยืนยันก่อนการดำเนินงาน

## MongoDB ข้อกำหนดของอินสแตนซ์


| ซอฟต์แวร์ตัวกลาง | เวอร์ชันที่แนะนำ | ผู้ใช้ต่ำกว่า 3000 คน | ผู้ใช้มากกว่า 3000 คน |
| --- | --- | --- | --- |
| MongoDB | MongoDB 4.4 | 2C 8G 100G SSD | 4C 16G 100G SSD |


## ข้อกำหนดการตั้งค่าคลัสเตอร์
- รองรับคลัสเตอร์ความพร้อมใช้งานสูงแบบ replica set ต้องมีอย่างน้อย 3 โหนดในสภาพแวดล้อมการผลิต
- แนะนำให้เปิดใช้งาน SCRAM-SHA-256 การตรวจสอบสิทธิ์





## การเชื่อมต่อเครือข่าย

พอร์ตสำหรับ K8s คลัสเตอร์ธุรกิจในการเข้าถึง MongoDB ต้องเปิด

```js
telnet IP 27017
```

## การตรวจสอบสิทธิ์และการอนุญาต
- ในสภาพแวดล้อมการผลิต แนะนำให้บังคับใช้ SCRAM-SHAการตรวจสอบสิทธิ์แบบ -256


## ความต้องการอื่น ๆ
- เครือข่ายภายใน P99 ความล่าช้าในการอ่าน < 5ms, ความล่าช้าในการเขียน < 10ms
- ดิสก์ IOPS ต้องสามารถรองรับความต้องการการเขียนสูงสุด; SSD เป็นข้อบังคับ
- การซิงโครไนซ์นาฬิกา: MongoDB โหนดคลัสเตอร์และ ShimoDocs เซิร์ฟเวอร์แอปพลิเคชันต้อง NTP ซิงโครไนซ์กัน
- ทำสำรองข้อมูลเต็มรูปแบบเป็นประจำและสำรอง Oplog ต่อเนื่อง
