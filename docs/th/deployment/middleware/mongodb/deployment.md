# ปรับใช้ด้วย MongoDB

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

บทความนี้อธิบายวิธีปิดเครื่องมือในตัว MongoDB ใน ShimoDocs และกำหนดค่า MongoDB ในฐานะฐานข้อมูลเอกสารของบุคคลที่สาม MongoDB หลังการกำหนดค่า ตัวติดตั้งจะตรวจสอบ MongoDB การเชื่อมต่อเครือข่ายและสิทธิ์ เช่น การเชื่อมต่อและการตรวจสอบสิทธิ์ เมื่อการตรวจสอบผ่าน การปรับใช้งานสามารถดำเนินต่อไปได้ 

# 1. การเตรียมการก่อนการกำหนดค่า 
ก่อนเริ่มโปรดยืนยันว่า: 
- MongoDB เซิร์ฟเวอร์ถูกติดตั้งและทำงานอย่างปกติ 
- โหนดการติดตั้งสามารถเข้าถึงโฮสต์และพอร์ตของ MongoDB เซิร์ฟเวอร์ 
- ข้อมูลการเชื่อมต่อและ PASSWORD สำหรับการตรวจสอบสิทธิ์กับ MongoDB เซิร์ฟเวอร์ได้ถูกเตรียมไว้แล้ว 

> [!TIP] 
> 
> IP, พอร์ต, และบัญชีในบทความนี้เป็นเพียงตัวอย่าง โปรดใช้ข้อมูลสภาพแวดล้อมจริงในการกำหนดค่า และอย่าบันทึกข้อมูลจริง PASSWORD ในเอกสารสาธารณะหรือภาพหน้าจอ 
> 

# 2. เข้าสู่การกำหนดค่าขั้นสูง 
ในขั้นตอน 'การกำหนดค่า' ของตัวติดตั้ง หลังจากทำการกำหนดค่าเครือข่าย, สภาพแวดล้อมเป้าหมาย, และข้อมูลโหนดเสร็จสิ้น ให้ขยาย 'การกำหนดค่าขั้นสูง' ที่ด้านล่างของหน้า 

# 3. ยกเลิกการติดตั้ง MongoDB
ในพื้นที่ 'Middleware Services' ยกเลิกการเลือก MongoDB

หลังจากยกเลิกการเลือก ตัวติดตั้งจะไม่ติดตั้ง MongoDBในตัว และจะใช้ MongoDB ที่เตรียมจากภายนอกแทน สำหรับซอฟต์แวร์ประสานงานอื่น ๆ ว่าจะใช้บริการในตัวหรือไม่นั้นควรเลือกตามแผนการปรับใช้จริง

# 4. เปิดการตั้งค่า Middleware ของบุคคลที่สาม
ในพื้นที่ "ซอฟต์แวร์กลางบุคคลที่สาม" คลิก "กำหนดค่า"

# 5. กำหนดค่า MongoDB ฐานข้อมูลเอกสาร
1. เลือก "MongoDB ฐานข้อมูลเอกสาร" ทางด้านซ้าย
2. เปิดใช้งาน "ใช้ซอฟต์แวร์กลางบุคคลที่สาม MongoDB ฐานข้อมูลเอกสาร
3. ป้อน Host, Port, USERNAME, PASSWORD, การแทนที่ Connection String
4. ตรวจสอบและบันทึก

> [!WARNING]
>
> ข้อควรระวัง: หากผู้ให้บริการภายนอก MongoDB สร้างบัญชีเฉพาะสำหรับแอปพลิเคชันและปฏิบัติตาม 'หลักการสิทธิ์ขั้นต่ำ' โดยบัญชีจะมีสิทธิ์เข้าถึงเฉพาะฐานข้อมูลที่กำหนด จำเป็นต้องกำหนดผู้ใช้และ PASSWORD สำหรับแต่ละฐานข้อมูลธุรกิจ

# 6. ยืนยันผลการตรวจสอบ
โปรแกรมติดตั้งจะตรวจสอบสิ่งต่อไปนี้:
- การเข้าสู่ระบบ: บัญชีสามารถรับรองความถูกต้องได้ตามปกติ
- การเชื่อมต่อ: สภาพแวดล้อมการปรับใช้สามารถเข้าถึงได้ MongoDB
- สิทธิ์: บัญชีมีสิทธิ์สำหรับการเชื่อมต่อ, การตรวจสอบสิทธิ์, การรันคำสั่ง เป็นต้น

หลังจากรายการตรวจสอบทั้งหมดแสดงว่า 'สำเร็จ' ปิดหน้าต่างการกำหนดค่าและกลับไปที่หน้าการกำหนดค่า 'Configuration' ของโปรแกรมติดตั้ง

หากพบข้อผิดพลาดใด ๆ กรุณาตรวจสอบตามข้อความแนะนำบนหน้าเพจ:
- ตรวจสอบว่ากรอกโฮสต์และพอร์ตถูกต้องหรือไม่
- เครือข่ายระหว่างโหนดการปรับใช้งานและ MongoDB เซิร์ฟเวอร์เชื่อมต่อแล้ว
- ว่า USERNAME และ PASSWORD ถูกต้องหรือไม่
- บัญชีมีสิทธิ์ที่ต้องการหรือไม่ (การเชื่อมต่อและตรวจสอบสิทธิ์, สิทธิ์คำสั่ง ฯลฯ)

# 7. ดำเนินการเริ่มต้นการปรับใช้งานต่อ
หลังจากกลับไปที่หน้า 'การกำหนดค่า' ให้แน่ใจว่า MongoDB ยังไม่ได้ถูกเลือก จากนั้นคลิก 'เริ่มต้นการปรับใช้' เพื่อดำเนินการต่อในการทำภาพรวมการปรับใช้, การตรวจสอบ และขั้นตอนการดำเนินการ

> [!TIP]
>
> ก่อนเริ่มต้นการปรับใช้งาน กรุณายืนยันอีกครั้งว่า MongoDB การกำหนดค่าได้ถูกบันทึกไว้แล้วและตรวจสอบผ่านทุกข้อ
