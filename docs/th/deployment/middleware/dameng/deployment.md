# ปรับใช้ด้วย Dameng V8

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

บทความนี้อธิบายวิธีปิดการใช้งานในตัว MySQL ใน ShimoDocs ตัวติดตั้งและกำหนดค่า Dameng DM8 เป็นฐานข้อมูลเชิงสัมพันธ์ของบุคคลที่สาม หลังจากการกำหนดค่าเสร็จสิ้น ตัวติดตั้งจะตรวจสอบการเข้าสู่ระบบฐานข้อมูล การเชื่อมต่อเครือข่าย และสิทธิ์การสร้างตาราง เมื่อการตรวจสอบผ่านแล้ว การติดตั้งสามารถดำเนินต่อได้

## 1. การเตรียมก่อนการกำหนดค่า

ก่อนเริ่ม โปรดยืนยันว่า:

- Dameng DM8 ถูกติดตั้งและทำงานได้ตามปกติ
- โหนดการติดตั้งสามารถเข้าถึงโฮสต์และพอร์ตของ Dameng ฐานข้อมูล.
- โฮสต์ฐานข้อมูล, พอร์ต, USERNAME, และ PASSWORD พร้อมใช้งานแล้ว
- บัญชีฐานข้อมูลมีสิทธิ์ในการเข้าสู่ระบบ, เชื่อมต่อ, สร้างตาราง และลบตาราง
- Dameng ฐานข้อมูลได้ดำเนินการตั้งค่าโหมดความเข้ากันได้ MySQL ตามที่ต้องการแล้ว สำหรับคำแนะนำโดยละเอียด โปรดดูที่ ["Dameng คู่มือการตั้งค่าการรวมฐานข้อมูล](requirements.md).

> [!TIP]
>
> ที่อยู่ IP, พอร์ต, และบัญชีในบทความนี้เป็นเพียงตัวอย่างเท่านั้น โปรดใช้ข้อมูลจากสภาพแวดล้อมจริงในการตั้งค่า และอย่าบันทึก PASSWORD ข้อมูลจริงลงในเอกสารหรือตัวอย่างหน้าจอภายนอก

## 2. เข้าสู่การตั้งค่าขั้นสูง

ในขั้นตอน 'การกำหนดค่า' ของตัวติดตั้ง หลังจากตั้งค่าเครือข่าย, สภาพแวดล้อมเป้าหมาย และข้อมูลโหนดเรียบร้อยแล้ว ให้ขยาย 'การตั้งค่าขั้นสูง' ที่ด้านล่างของหน้า

## 3. ยกเลิกการติดตั้งในตัว MySQL

ในส่วน 'บริการ Middleware' ให้ยกเลิกการเลือก **MySQL**.

หลังจากยกเลิกการเลือก ตัวติดตั้งจะไม่ติดตั้ง MySQLในตัวอีกต่อไป และจะใช้ฐานข้อมูลที่เตรียมไว้ Dameng สำหรับ middleware ตัวอื่นว่าควรใช้บริการในตัวหรือไม่ ควรเลือกตามแผนการปรับใช้งานจริง

## 4. เปิดการตั้งค่า Middleware ของบุคคลที่สาม

ในพื้นที่ 'Third-Party Middleware' คลิก 'Configure'

## 5. กำหนดค่า Dameng ฐานข้อมูล

1. เลือก "RDB ฐานข้อมูลเชิงสัมพันธ์" ทางด้านซ้าย
2. เปิดใช้งาน "ใช้ฐานข้อมูลเชิงสัมพันธ์ของบุคคลที่สาม"
3. ในส่วน 'Dialect' ให้เลือก **DM (Dameng)**.
4. กรอกข้อมูลการเชื่อมต่อฐานข้อมูล

| รายการการกำหนดค่า | คำอธิบาย |
| --- | --- |
| โฮสต์ | ที่อยู่ IP หรือชื่อโฮสต์ที่เข้าถึงได้ของ Dameng ฐานข้อมูล |
| พอร์ต | พอร์ตที่ฐานข้อมูลฟังอยู่ Dameng ฐานข้อมูล โดยทั่วไปคือ 5236 ตามค่าเริ่มต้น ขึ้นอยู่กับการกำหนดค่าที่แท้จริง |
| USERNAME | บัญชีที่ใช้ในการเชื่อมต่อกับฐานข้อมูล |
| PASSWORD |  PASSWORD ที่สอดคล้องกับบัญชีฐานข้อมูล |
| DSN | สร้างโดยอัตโนมัติจากตัวติดตั้งตามข้อมูลด้านบน ไม่ต้องป้อนด้วยตนเอง |

5. หลังจากยืนยันว่าข้อมูลถูกต้อง คลิก "ตรวจสอบและบันทึก"

## 6. ยืนยันผลการตรวจสอบ

ตัวติดตั้งจะตรวจสอบรายการต่อไปนี้:

- **การเข้าสู่ระบบ**: บัญชีฐานข้อมูลสามารถเข้าสู่ระบบได้ตามปกติ
- **การเชื่อมต่อ**: สภาพแวดล้อมการปรับใช้สามารถเข้าถึงฐานข้อมูลได้
- **สร้างตารางสิทธิ์**: บัญชีฐานข้อมูลมีสิทธิ์ในการสร้างและลบตาราง

หลังจากการตรวจสอบทั้งหมดแสดง "สำเร็จ" ให้ปิดหน้าต่างการกำหนดค่าและกลับไปที่หน้า "การกำหนดค่า" ของโปรแกรมติดตั้ง

หากมีรายการใดล้มเหลว โปรดตรวจสอบตามคำแนะนำบนหน้า:

- ตรวจสอบว่ากรอกโฮสต์และพอร์ตถูกต้องหรือไม่
- ตรวจสอบว่าเครือข่ายระหว่างโหนดการปรับใช้งานและฐานข้อมูลเชื่อมต่อได้หรือไม่
- ว่าหน่วยความจำ, และดิสก์ตรงตามข้อกำหนดหรือไม่ USERNAME และ PASSWORD ถูกต้องหรือไม่
- ตรวจสอบว่าบัญชีฐานข้อมูลมีสิทธิ์ที่จำเป็นหรือไม่
- ว่าหน่วยความจำ, และดิสก์ตรงตามข้อกำหนดหรือไม่ Dameng บริการฐานข้อมูลและ MySQL การกำหนดค่าความเข้ากันได้มีผลตามปกติหรือไม่

## 7. ดำเนินการเริ่มต้นการปรับใช้งานต่อ

หลังจากกลับไปที่หน้า "การกำหนดค่า" ให้ยืนยันว่า MySQL ยังไม่ถูกเลือก จากนั้นคลิก "เริ่มต้นการปรับใช้งาน" เพื่อดำเนินการต่อและทำขั้นตอนภาพรวม การตรวจสอบ และการดำเนินการให้ครบถ้วน

> [!TIP]
>
> ก่อนเริ่มต้นการปรับใช้งาน โปรดยืนยันอีกครั้งว่า Dameng การกำหนดค่าได้ถูกบันทึกแล้ว และรายการตรวจสอบทั้งหมดผ่านแล้ว
