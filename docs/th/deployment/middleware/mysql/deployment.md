# ปรับใช้ด้วย MySQL 8

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

บทความนี้อธิบายวิธีปิดตัวติดตั้งในตัว MySQL ใน ShimoDocs ตัวติดตั้งและกำหนดค่าของคุณเอง MySQL เป็นฐานข้อมูลเชิงสัมพันธ์ของบุคคลที่สาม หลังการกำหนดค่า ตัวติดตั้งจะตรวจสอบการเข้าสู่ระบบฐานข้อมูล การเชื่อมต่อเครือข่าย และสิทธิ์ในการสร้างตาราง เมื่อทำการตรวจสอบแล้ว การปรับใช้สามารถดำเนินต่อได้ 

# 1. การเตรียมความพร้อมก่อนการกำหนดค่า 
ก่อนเริ่มโปรดยืนยันว่า: 
- MySQL 8.0 ได้ติดตั้งและทำงานปกติ 
- โหนดปรับใช้สามารถเข้าถึง MySQL โฮสต์และพอร์ตของฐานข้อมูล 
- โฮสต์ฐานข้อมูล, พอร์ต, USERNAME, และ PASSWORD ได้รับการเตรียมเรียบร้อย 
- บัญชีฐานข้อมูลมีสิทธิ์ในการเข้าสู่ระบบ การเชื่อมต่อ การสร้างตาราง และการลบตาราง 

> [!TIP]
>
> IP พอร์ต และบัญชีในบทความนี้เป็นตัวอย่าง โปรดกำหนดค่าโดยใช้ข้อมูลสภาพแวดล้อมจริงของคุณ; อย่าบันทึก PASSWORD ไปยังเอกสารภายนอกหรือภาพหน้าจอ 
>

# 2. เข้าสู่การกำหนดค่าขั้นสูง 
ในขั้นตอน "Configuration" ของตัวติดตั้ง หลังจากทำการกำหนดค่าเครือข่าย สภาพแวดล้อมเป้าหมาย และข้อมูลโหนดเรียบร้อยแล้ว ให้ขยายส่วน "Advanced Configuration" ที่ด้านล่างของหน้า 

# 3. ยกเลิกการติดตั้ง MySQL
ในพื้นที่ 'Middleware Services' ยกเลิกการเลือก MySQL.

หลังจากยกเลิกการเลือก ตัวติดตั้งจะไม่ติดตั้ง MySQLในตัวอีกต่อไป และจะเป็นภายนอก MySQL 8.0 ที่เตรียมไว้แล้วจะถูกใช้ในภายหลัง การใช้บริการในตัวอื่นของมิดเดิ้ลแวร์ควรเลือกตามแผนการปรับใช้จริง

# 4. เปิดการตั้งค่า Middleware ของบุคคลที่สาม
ในส่วน "มิดเดิ้ลแวร์บุคคลที่สาม" คลิก "กำหนดค่า"

# 5. กำหนดค่า MySQL ฐานข้อมูล
1. เลือก 'RDB ฐานข้อมูลเชิงสัมพันธ์' ทางด้านซ้าย
2. เปิดใช้งาน 'ใช้ฐานข้อมูลเชิงสัมพันธ์บุคคลที่สาม'
3. เลือกมาตรฐาน MySQL ภายใต้ 'สำเนียง'
4. กรอกข้อมูลการเชื่อมต่อฐานข้อมูล
5. ตรวจสอบและบันทึก

# 6. ยืนยันผลการตรวจสอบ
โปรแกรมติดตั้งจะตรวจสอบสิ่งต่อไปนี้:

- การเข้าสู่ระบบ: ว่าบัญชีฐานข้อมูลสามารถเข้าสู่ระบบได้ตามปกติ
- การเชื่อมต่อ: ว่าสภาพแวดล้อมการปรับใช้สามารถเข้าถึงฐานข้อมูลได้
- สิทธิ์สร้างตาราง: ว่าบัญชีฐานข้อมูลมีสิทธิ์ในการสร้างและลบตารางหรือไม่

หลังจากรายการตรวจสอบทั้งหมดแสดงว่า 'สำเร็จ' ปิดหน้าต่างการกำหนดค่าและกลับไปที่หน้าการกำหนดค่า 'Configuration' ของโปรแกรมติดตั้ง

หากพบข้อผิดพลาดใด ๆ กรุณาตรวจสอบตามข้อความแนะนำบนหน้าเพจ:
- ตรวจสอบว่ากรอกโฮสต์และพอร์ตถูกต้องหรือไม่
- เครือข่ายระหว่างโหนดการปรับใช้กับฐานข้อมูลเชื่อมต่อหรือไม่
- ว่า USERNAME และ PASSWORD ถูกต้องหรือไม่
- ตรวจสอบว่าบัญชีฐานข้อมูลมีสิทธิ์ที่จำเป็นหรือไม่

# 7. ดำเนินการเริ่มต้นการปรับใช้งานต่อ
หลังจากกลับไปที่หน้า 'การกำหนดค่า' ให้แน่ใจว่า MySQL ยังไม่ได้ตรวจสอบ จากนั้นคลิก 'เริ่มต้นการปรับใช้' เพื่อดำเนินการตรวจสอบภาพรวมการปรับใช้และขั้นตอนการดำเนินการต่อ

> [!TIP]
>
> ก่อนเริ่มต้นการปรับใช้ โปรดยืนยันอีกครั้งว่า MySQL การกำหนดค่า 8.0 ได้บันทึกแล้วและรายการการตรวจสอบทั้งหมดผ่านเรียบร้อย
