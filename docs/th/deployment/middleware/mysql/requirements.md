เอกสารฉบับนี้มีวัตถุประสงค์เพื่อชี้แนะแก่บุคลากรที่เกี่ยวข้องกับการดำเนินการ การปฏิบัติงาน หรือการบูรณาการให้สามารถดำเนินการให้เสร็จสมบูรณ์ ShimoDocs การเชื่อมต่อกับ MySQL การเริ่มต้นฐานข้อมูล รวมถึงการเริ่มต้นบริการและการตรวจสอบการเชื่อมต่อทีละขั้นตอน


## 1. การยืนยันก่อนการปฏิบัติการ

| MySQL 8.0 | 4C 8G 200G SSD | 8C 16G 200G SSD | 

## MySQL ข้อกำหนดการกำหนดค่าและความพร้อมใช้งานสูง
รองรับการสลับความพร้อมใช้งานสูงแบบมาสเตอร์-สเลฟ
ชุดอักขระ: utf8mb4 
เขตเวลา: Asia/Shanghai หรือ UTC 
การเชื่อมต่อ: สูงสุด_การเชื่อมต่อ ≥ 1000
ผู้ใช้การเชื่อมต่อ: สิทธิเข้าถึงระดับแอดมิน

> [!TIP]
>
> ต้องกำหนดค่าอินสแตนซ์แยกต่างหาก MySQL 
> 1. เพื่อให้สามารถแยกความผิดพลาด ความปลอดภัยของสิทธิ์ และการสำรองและกู้คืนข้อมูลอย่างอิสระ เพื่อให้มั่นใจว่าระบบเอกสารทำงานอย่างมั่นคงและมีประสิทธิภาพ
> 2. ระบบในปัจจุบันยังไม่รองรับชื่อฐานข้อมูลและคำนำหน้าตารางที่กำหนดเอง ดังนั้นการวางแผนและการเตรียมอินสแตนซ์แยกต่างหากต้องเสร็จสิ้นก่อนการปรับใช้งาน





## การเชื่อมต่อเครือข่าย 
พอร์ตสำหรับเชื่อมต่อเครือข่ายคลัสเตอร์ธุรกิจ k8s กับ MySQL อินสแตนซ์ต้องเปิด 

```js
telnet IP 3306
```
## การตรวจสอบผู้ใช้
ผู้ใช้ MySQL ผู้ใช้ที่ให้มาต้องได้รับการตรวจสอบเมื่อเชื่อมต่อกับ MySQL เซิร์ฟเวอร์

# คำอธิบาย: 
- ผู้ใช้ MySQL การตั้งค่าในเอกสารนี้เป็นการตั้งค่าที่แนะนำทั้งหมด ใช้สำหรับการประเมินความสามารถของโครงการในระยะเริ่มต้นและการวางแผนทรัพยากร และไม่ใช่การตั้งค่าสุดท้ายสำหรับการผลิต การตั้งค่าจริงสุดท้ายจะถูกกำหนดหลังจากการประเมินก่อนการขาย
- เมื่อใช้เซิร์ฟเวอร์ที่มีสถาปัตยกรรมภายในประเทศ CPU ขอแนะนำให้ประเมินทรัพยากรโดยรวมเป็นสองเท่าของสเปคมาตรฐาน
- ขอแนะนำให้สำรองความจุสำหรับการขยายในสภาพแวดล้อมการผลิตที่เป็นทางการและให้ความสำคัญกับการปรับใช้ที่มีความพร้อมใช้งานสูง
