# ปรับใช้ด้วย Redis

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

บทความนี้อธิบายวิธีปิดการใช้งานในตัว Redis ใน ShimoDocs และกำหนดค่า Redis เป็นฐานข้อมูลแคชจากบุคคลที่สาม หลังการกำหนดค่า ตัวติดตั้งจะตรวจสอบ Redis การเชื่อมต่อเครือข่าย, การเชื่อมต่อ, การตรวจสอบสิทธิ์, การทำงานของคำสั่ง, สิทธิ์ publish/subscribe ฯลฯ เมื่อการตรวจสอบผ่านแล้ว สามารถดำเนินการติดตั้งต่อได้ 

# 1. การเตรียมความพร้อมก่อนการกำหนดค่า 
ก่อนเริ่มโปรดยืนยันว่า: 
- ผู้ใช้ Redis เซิร์ฟเวอร์ถูกติดตั้งและทำงานอย่างปกติ 
- โหนดที่ติดตั้งสามารถเข้าถึง Redis โฮสต์และพอร์ตของเซิร์ฟเวอร์ 
- ข้อมูลผู้ใช้งานสำหรับการตรวจสอบสิทธิ์ และ PASSWORD สำหรับการเชื่อมต่อกับ Redis เซิร์ฟเวอร์ได้ถูกเตรียมไว้แล้ว 

> [!TIP] 
> 
> ที่อยู่ IP, พอร์ต และบัญชีในบทความนี้เป็นเพียงตัวอย่าง กรุณาใช้ข้อมูลสภาพแวดล้อมจริงสำหรับการกำหนดค่า และอย่าบันทึกรหัสผ่านจริงในเอกสารสาธารณะหรือภาพหน้าจอ 
> 

# 2. เข้าสู่การกำหนดค่าขั้นสูง 
ในขั้นตอน "การกำหนดค่า" ของตัวติดตั้ง หลังจากตั้งค่าเครือข่าย สภาพแวดล้อมเป้าหมาย และข้อมูลโหนดเรียบร้อยแล้ว ให้ขยาย "การกำหนดค่าขั้นสูง" ที่ด้านล่างของหน้า 

# 3. ยกเลิกการติดตั้ง Built-in Redis
ในส่วน 'บริการตัวกลาง' ยกเลิกการทำเครื่องหมาย Redis

หลังจากยกเลิกการเลือก ตัวติดตั้งจะไม่ติดตั้ง Redisและจะใช้ตัวกลางภายนอกที่เตรียมไว้แทน Redis ไม่ว่าตัวกลางอื่นจะใช้บริการแบบ Built-in หรือไม่ควรเลือกตามแผนการติดตั้งจริง

# 4. เปิดการตั้งค่า Middleware ของบุคคลที่สาม
ในพื้นที่ 'Third-Party Middleware' คลิก 'Configure'

# 5. กำหนดค่า Redis ตัวกลาง Cache
## Redis เซิร์ฟเวอร์โหนดเดียว
1. เลือก "Redis "Cache" ด้านซ้าย
2. เปิดใช้งาน "ใช้ซอฟต์แวร์กลางบุคคลที่สาม Redis".
3. คลิก "Single Node"
4. ป้อน Host, Port, PASSWORD
5. ตรวจสอบและบันทึก

## Redis เซิร์ฟเวอร์ Sentinel Cluster
1. ทางด้านซ้าย เลือก 'Redis Cache'
2. เปิดใช้งาน 'ใช้ของบุคคลที่สาม Redis'.
3. คลิก 'Sentinel Cluster'
4. ใส่ 'Master Name, SENTINEL PASSWORD, SENTINEL โหนด'
5. ตรวจสอบและบันทึก

# 6. ยืนยันผลการตรวจสอบ
โปรแกรมติดตั้งจะตรวจสอบสิ่งต่อไปนี้:
- การเข้าสู่ระบบ: บัญชีสามารถรับรองความถูกต้องได้ตามปกติ
- การเชื่อมต่อ: สภาพแวดล้อมการปรับใช้สามารถเข้าถึงได้ Redis
- สิทธิ์: บัญชีมีสิทธิ์ในการเชื่อมต่อ การยืนยันตัวตน การสั่งงาน การเผยแพร่/สมัครรับข่าวสาร เป็นต้น

หลังจากรายการตรวจสอบทั้งหมดแสดงว่า 'สำเร็จ' ปิดหน้าต่างการกำหนดค่าและกลับไปที่หน้าการกำหนดค่า 'Configuration' ของโปรแกรมติดตั้ง

หากพบข้อผิดพลาดใด ๆ กรุณาตรวจสอบตามข้อความแนะนำบนหน้าเพจ:
- ตรวจสอบว่ากรอกโฮสต์และพอร์ตถูกต้องหรือไม่
- เครือข่ายระหว่างโหนดการปรับใช้งานและ Redis เซิร์ฟเวอร์เชื่อมต่ออยู่หรือไม่
- ว่า USERNAME และ PASSWORD ถูกต้องหรือไม่
- ว่าบัญชีมีสิทธิ์ที่ต้องการหรือไม่ (การเชื่อมต่อและการตรวจสอบสิทธิ์, สิทธิ์ของคำสั่ง, สิทธิ์การเผยแพร่/สมัครรับ ฯลฯ)

# 7. ดำเนินการเริ่มต้นการปรับใช้งานต่อ
หลังจากกลับไปที่หน้า 'การกำหนดค่า' ให้แน่ใจว่า Redis ยังไม่ได้ตรวจสอบ ให้คลิก 'เริ่มต้นการปรับใช้งาน' เพื่อดำเนินการต่อกับภาพรวมการปรับใช้งาน ตรวจสอบ และขั้นตอนการดำเนินการ

> [!TIP]
>
> ก่อนเริ่มต้นการปรับใช้ โปรดยืนยันอีกครั้งว่า Redis การตั้งค่าได้ถูกบันทึกแล้วและผ่านการตรวจสอบทั้งหมด
