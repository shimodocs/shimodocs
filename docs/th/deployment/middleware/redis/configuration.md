# Redis การกำหนดค่า

[← ShimoDocs Suite เอกสารการติดตั้ง](../../README.md)

เอกสารนี้มีวัตถุประสงค์เพื่อแนะนำผู้ปฏิบัติการ พนักงานปฏิบัติการ หรือผู้รวมระบบในการดำเนินการบูรณาการ ShimoDocs กับภายนอก Redis ทีละขั้นตอน โดยทั่วไปจะใช้ในสถานการณ์หลัก เช่น การจัดการเซสชัน, การล็อกแบบกระจาย, ตัวนับจำกัดอัตรา, และคิวข้อความ

## 1. การยืนยันก่อนการปฏิบัติการ

## Redis ข้อกำหนดของอินสแตนซ์


| ซอฟต์แวร์ตัวกลาง | เวอร์ชันที่แนะนำ | สำหรับผู้ใช้ต่ำกว่า 3000 คน | สำหรับผู้ใช้มากกว่า 3000 คน |
| --- | --- | --- | --- |
| Redis | Redis 6.2.21 | 2C 4G 100G SSD | 2C 8G 100G SSD |


## ข้อกำหนดการตั้งค่าคลัสเตอร์
- รองรับความพร้อมใช้งานสูงแบบ master-slave/sentinel
- ความคงทนของข้อมูล
- ไม่รองรับโหมดคลัสเตอร์
- จำนวน DB ต้องมากกว่าหรือเท่ากับ 64





## การเชื่อมต่อเครือข่าย

พอร์ตสำหรับการเชื่อมต่อ K8s เครือข่ายคลัสเตอร์ธุรกิจกับ Redis อินสแตนซ์ต้องเปิดอยู่

```js
telnet IP 6379
```

## การตรวจสอบสิทธิ์และการอนุญาต
- ในสภาพแวดล้อมการผลิต แนะนำให้เปิดใช้งาน PASSWORD การตรวจสอบสิทธิ์ (requirepass / ACL).


## ความต้องการอื่น ๆ
- เครือข่ายภายใน P99 ความหน่วงควรน้อยกว่า 10ms
- การซิงโครไนซ์นาฬิกา: Redis โหนดคลัสเตอร์และ ShimoDocs เซิร์ฟเวอร์แอปพลิเคชันต้อง NTP ซิงโครไนซ์กัน
- สำรองข้อมูลเต็มตามปกติ
