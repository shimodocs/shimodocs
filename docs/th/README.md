# เอกสาร ShimoDocs

ShimoDocs คือชุดเครื่องมือทำงานร่วมกันบนเอกสารแบบโฮสต์ด้วยตนเองสำหรับเอกสาร โปรแกรมประมวลผลคำ สเปรดชีต งานนำเสนอ แบบฟอร์ม และตารางในไพรเวตคลาวด์ พร้อม AI Agent ที่กำหนดค่าแบบส่วนตัวได้ในทุกผลิตภัณฑ์
