# Gestion des licences

[← ShimoDocs Suite documentation de déploiement](../../README.md)

> [!TIP]
>
> La gestion des licences est utilisée pour obtenir le code machine du serveur pour ShimoDocs Suite, écrire et publier des licences, et voir le statut actuel de la licence, la portée de la licence et les informations sur la machine en cours d’exécution. Pour une première activation, 
> le renouvellement de licence à l’expiration, ou lorsque les nœuds du serveur changent, vous pouvez mettre à jour la ShimoDocs Suite licence via cette page.

> Après avoir écrit la licence, vous devez vérifier les résultats de la vérification avant de publier la licence. Le simple fait d’écrire ou de sauvegarder temporairement ne rend pas la licence officiellement effective.
- Si vous êtes un client payant, veuillez envoyer le code machine copié à l’équipe de ShimoDocs support technique. Nous générerons la licence correspondante en fonction du code machine et vous enverrons les informations de licence.
- Si vous souhaitez un essai gratuit, veuillez aller sur **ShimoDocs Demande de licence sur le site officiel**: https://shimo.net/license pour remplir les informations de la demande et coller le code machine.
- Après soumission, le système générera automatiquement une licence d’essai. Veuillez copier et compléter l’écriture dans les 10 minutes suivant sa génération. Si elle expire, veuillez refaire la demande.
## 1. Accéder à la gestion des licences

1. Connectez-vous à la **MDP Plateforme d'Opérations**.
2. Sélectionner **ShimoDocs Suite** en haut.
3. Sélectionner **Gestion des licences** dans la barre de navigation gauche.

La page contient des zones pour l'activation de la licence, les informations sur la licence, la comparaison des codes machine et les informations sur la machine.

## 2. Demander ShimoDocs Suite Licence

Avant de demander l’autorisation, veuillez d’abord vous assurer que le ShimoDocs Suite les nœuds du serveur sont stables et qu'aucun nœud ne sera ajouté, supprimé ou remplacé temporairement. 

### 1. Copier tous les codes machines 

1. Dans la zone 'Activation d'autorisation', cliquez sur 'Copier tous les codes machines en un clic'. 
2. Confirmez que la page affiche une invite de copie réussie. 
3. Enregistrez les codes machines dans les documents de demande d'autorisation. 

### 2. Soumettre les informations de demande d'autorisation

Soumettez tous les codes machines et les exigences d'autorisation au ShimoDocs personnel de service pour générer la ShimoDocs Suite licence.

Il est recommandé de confirmer les informations suivantes lors de la demande :

| Informations | Description |
| --- | --- |
| Produit autorisé | ShimoDocs Suite. |
| Nom et société de la licence | Le nom de la licence et la société à afficher sur la licence. |
| Nombre de postes | Le nombre maximum de postes pouvant utiliser la licence. |
| Période d'utilisation | La date de début et d'expiration de la licence produit. |
| Période de service après-vente | La date de début et d'expiration du service après-vente. |
| Suite disponible | Les types de documents ou de suites de fonctionnalités à activer. |
| Capacités AI | Si les capacités AI doivent être activées. |
| Codes machines | Tous les codes machines des serveurs en cours d'exécution ShimoDocs Suite. |

## 3. Écrire et vérifier l'autorisation

Après avoir reçu la nouvelle licence, veuillez suivre les étapes ci-dessous pour l'écrire dans le système.

### 1. Écrire la licence

1. Cliquez sur 'Écrire l'autorisation' dans la zone 'Activation d'autorisation'.
2. Collez le contenu complet de la licence reçue dans la zone de saisie.
3. Assurez-vous que le contenu de la licence est complet, sans caractères manquants ni espaces supplémentaires.
4. Cliquez sur 'Enregistrer temporairement'.

### 2. Vérifiez les résultats de la vérification de la licence

Après un stockage temporaire, le système vérifiera la nouvelle licence et affichera les résultats suivants :

| Résultat de la vérification | Description | Action suggérée |
| --- | --- | --- |
| Non concordance | Les informations clés de la nouvelle licence ne correspondent pas à l'environnement actuel. | Vérifiez le code machine, le type d'application, la version et la portée de l'autorisation. Après avoir confirmé qu'ils sont corrects, obtenez de nouveau la licence. |
| Modifié | Certaines informations dans la nouvelle licence diffèrent de la licence actuelle. | Vérifiez la valeur originale, la nouvelle valeur et le résultat de la détermination sur la page pour confirmer que les changements correspondent à cette application. |
| Réussi | L'élément de vérification correspondant a été réussi. | Continuez à vérifier les autres informations d'autorisation. |

S'il y a des éléments "Modifié" sur la page et que les changements sont conformes à cette demande d'autorisation, cliquez sur "Confirmer le stockage temporaire".

> En cas de "non concordance" ou de "modification" inattendue, veuillez arrêter d'abord la publication et revérifier les informations de l'application et l'environnement opérationnel actuel.

## 4. Publication de l'autorisation

Après la vérification et le stockage temporaire, la page affichera les informations sur la licence à publier.

### Vérification préalable à la publication

Vérifiez attentivement les éléments suivants :

- Nom de la licence.
- Limitations des postes.
- Heure de début et date d'expiration.
- ID de l'application.
- Code machine du serveur.

Après avoir confirmé que les informations sont correctes, cliquez sur "Publier la licence".

Après la publication, actualisez la page pour voir l'état de l'autorisation mis à jour et les informations d'autorisation.

## 5. Consultation des informations d'autorisation

La section 'Informations d'autorisation' affiche le contenu de licence actuellement actif.

### Description des champs des informations d'autorisation

| Champ | Description |
| --- | --- |
| Nom de l'autorisation | Le nom de l'autorisation pour la licence actuelle. |
| Entreprise autorisée | L'entreprise à laquelle appartient la licence. |
| Version du produit | La version du produit applicable à l'autorisation actuelle. |
| Version de publication | Le type de publication de l'autorisation actuelle. |
| Type d'application | Le type de produit applicable à la licence actuelle. |
| Nombre de locataires | Le nombre maximum de locataires autorisé par la licence actuelle. |
| Nombre de postes | Le nombre maximum de postes autorisés par la licence actuelle. |
| Période d'utilisation du produit | La date de début et la date d'expiration de l'autorisation du produit. |
| Période de service après-vente | La date de début et la date d'expiration du service après-vente. |
| Nombre de machines | Le nombre de serveurs liés dans la licence. |
| Capacité IA | Si la licence actuelle a la capacité IA activée. |
| Suites disponibles | Les types de documents ou de suites autorisés par la licence actuelle. |

## 6. Vérification des résultats de comparaison du code machine

Sous les informations d'autorisation, les résultats de la comparaison entre les codes machine dans la licence et les serveurs en cours d'exécution seront affichés.

| Résultat | Description |
| --- | --- |
| Machines dans le certificat | Le nombre de serveurs déjà liés dans la licence actuelle. |
| Machines réelles | Le nombre de serveurs en cours d'exécution détectés par le système actuel. |
| Correspondance | Le code machine dans la licence correspond au serveur actuel. |
| Non concordance | Il existe actuellement un serveur non lié à une licence, ou la machine dans la licence a changé. |
| Manquant | La machine liée dans la licence n'est actuellement pas détectée par le système. |

Si le nombre de machines dans le certificat ne correspond pas au nombre réel de machines, ou si la page affiche 'Incompatibilité' ou 'Manquant', veuillez cliquer sur 'Copier le code machine' et refaire la demande de licence en utilisant le code machine actuel.

> Si une invite de compte à rebours indiquant des codes machine incohérents apparaît en haut de la page, veuillez compléter la vérification des informations du serveur ou le remplacement de la licence dans la période d'invite pour assurer l'autorisation continue.

## 7. Voir les informations de la machine

La section 'Informations sur la machine' affiche les nœuds de serveur actuellement en fonctionnement.

### Description des champs d'informations de la machine

| Champ | Description |
| --- | --- |
| Serveur | Le nom ou l'adresse du nœud de serveur actuel. |
| Système d'exploitation | Le système d'exploitation actuellement utilisé par le serveur. |
| CPU | Le modèle de processeur du serveur. |
| Cœurs | Le nombre de CPU cœurs du serveur. |
| Mémoire | La quantité de mémoire actuellement reconnue par le serveur. |
| Architecture | L'architecture système du serveur. |
| Code machine | L'identifiant unique du serveur utilisé pour générer et lier les licences. |

## 8. Vérifier les résultats de la mise à jour de l'autorisation

Après avoir effectué la libération de la licence, il est recommandé de vérifier dans l'ordre suivant :

1. Actualiser la page de gestion des autorisations pour confirmer que le statut de l'autorisation est normal.
2. Vérifier le nom de l'autorisation, le nombre de postes, la période d'utilisation, les suites disponibles et les capacités d'IA.
3. Confirmer que le nombre de machines dans le certificat correspond au nombre réel de machines.
4. Confirmez qu'il n'y a pas de résultats de "non-concordance" ou "manquants" inattendus dans la comparaison du code machine.
5. Connectez-vous à ShimoDocs Suite pour vérifier que les types et fonctions de documents autorisés peuvent être utilisés normalement.

> Après avoir remplacé, ajouté ou supprimé des nœuds de serveur, il est recommandé de revenir rapidement sur cette page pour vérifier les résultats de la comparaison du code machine. Si le code machine change, il est nécessaire de redemander et de publier la licence en utilisant tous les nouveaux codes machine.
