# Tài liệu ShimoDocs

ShimoDocs là bộ công cụ cộng tác tài liệu tự lưu trữ cho tài liệu, trình soạn thảo, bảng tính, bản trình bày, biểu mẫu và bảng trong đám mây riêng, với AI Agent có thể cấu hình riêng được tích hợp trong mọi sản phẩm.

## Tài liệu

- [Triển khai và vận hành ShimoDocs Suite](deployment/README.md)

Kho lưu trữ này chứa tài liệu về ShimoDocs Suite. Tài liệu tích hợp nền tảng dành cho nhà phát triển không được bao gồm.
