<h1>ShimoDocs</h1>

<h3>あなたのクラウド。あなたのドキュメント。あなたのコントロール。</h3>

<p><strong>ShimoDocs</strong> は、プライベートクラウドでリアルタイムのドキュメント、文書作成、スプレッドシート、プレゼンテーション、フォーム、テーブルを提供するセルフホスト型文書コラボレーションスイートです。</p>

<p><strong>プライベートクラウド</strong>で使える、より優れた Google Docs。</p>

自社サーバーやプライベートクラウドで、使い慣れたスムーズなリアルタイム文書コラボレーションを実現します。

## コラボレーションのために。データ管理のために。

ShimoDocs は、Google Docs のようなリアルタイムコラボレーションと、プライベート導入、企業向け権限管理、ビジネスデータのコントロールを組み合わせたプラットフォームです。添付ファイルを送り合ったり複数のファイル版を管理したりすることなく、1つのワークスペースで作成、編集、コメント、レビュー、共有を行えます。

<table><tr><td width="50%" valign="top">

### 🔒 データを自社環境に保持

自社サーバー、プライベートクラウド、データセンターに導入できます。文書とコラボレーションデータは、組織のポリシーに沿って管理できます。

</td><td width="50%" valign="top">

### ✍️ 使い慣れたリアルタイム共同編集

複数人で同時に編集し、コメント、返信、提案、変更履歴、権限付き共有を使って作業を進められます。

</td></tr><tr><td width="50%" valign="top">

### 🛡️ 企業向け管理と監査

部門、ユーザー、ロールを一元管理し、きめ細かな権限、共有制御、監査ログを利用できます。

</td><td width="50%" valign="top">

### 🔌 オープンで拡張可能

SSO、LDAP、Active Directory と連携し、オープン API で既存のツール、ワークフロー、社内システムを統合できます。

</td></tr></table>

## ShimoDocs と Google Docs の比較

> Google Docs の使い慣れたコラボレーション体験に、プライベート導入のセキュリティ、コントロール、柔軟性を。

### より高いコントロール。より強いセキュリティ。Shimo だから実現。

| 機能 | ShimoDocs | Google Docs |
| --- | :---: | :---: |
| **プライベート導入**<br><sub>自社サーバーやプライベートクラウドに導入。</sub> | ✅ 対応 | パブリッククラウドのみ |
| **完全なデータ所有権**<br><sub>データを自社環境に保持。</sub> | ✅ 対応 | Google が管理 |
| **SSO・企業ディレクトリ**<br><sub>SSO、LDAP、AD などと連携。</sub> | ✅ 対応 | 制限あり |
| **監査ログ・コンプライアンス**<br><sub>セキュリティとコンプライアンス向けの詳細ログ。</sub> | ✅ 対応 | 制限あり |
| **高度な管理者制御**<br><sub>きめ細かな管理ポリシーと制御。</sub> | ✅ 対応 | 基本機能のみ |
| **オープン API・拡張性**<br><sub>独自連携や自動化のための API。</sub> | ✅ 対応 | 制限あり |

### すでに使い慣れたコラボレーション体験。

| 機能 | ShimoDocs | Google Docs |
| --- | :---: | :---: |
| **リアルタイム共同編集**<br><sub>複数人で同時に編集。</sub> | ✅ 対応 | ✅ 対応 |
| **使い慣れた文書編集**<br><sub>Docs のような編集体験。</sub> | ✅ 対応 | ✅ 対応 |
| **コメント・提案**<br><sub>コメント、返信、変更提案。</sub> | ✅ 対応 | ✅ 対応 |
| **共有・権限**<br><sub>閲覧、編集、コメント権限で安全に共有。</sub> | ✅ 対応<br><sub>高度な制御</sub> | ✅ 対応<br><sub>基本的な制御</sub> |

ShimoDocs は、使い慣れたコラボレーション体験に加え、導入、データ、権限、連携をより柔軟にコントロールできます。

## ShimoDocs が適しているチーム

- **スタートアップ・小規模チーム：** 低い初期コストで共有ワークスペースを構築。
- **オープンソースプロジェクト・技術チーム：** ロードマップ、設計文書、リリース計画、プロジェクト知識を共同管理。
- **プライバシーを重視する組織：** データの保存場所とアクセスを管理しながらコラボレーションを改善。
- **規制業界・大企業：** プライベート導入、ID 連携、詳細な権限、監査機能を活用。
- **分散・国際チーム：** 常に最新の1つの版でコミュニケーション、レビュー、作業を進行。

## よくある質問

<details><summary><strong>ShimoDocs は本当に無料ですか？</strong></summary>

はい。5ユーザーまでのチームは [support.global@shimo.im](mailto:support.global@shimo.im) へメールを送り、クレジットカードなしで無料ライセンスを申請できます。6ユーザー以上のチームは人数に応じた有料プランを選択できます。

</details>

<details><summary><strong>自社サーバーは必要ですか？</strong></summary>

はい。ShimoDocs はプライベート環境で動作するため、組織がサーバー、プライベートクラウド、その他のインフラを用意して管理します。まだ導入しない場合は、[オンライン試用](https://shimodocs.com/#online-trial)をご利用ください。

</details>

<details><summary><strong>Google Docs との違いは何ですか？</strong></summary>

ShimoDocs は、使い慣れたリアルタイム編集を自社のプライベート環境で提供します。データの保存場所、ID システム、アクセス権限、監査ログ、システム連携をより細かく管理できます。

</details>

<details><summary><strong>既存の AI サービスを接続できますか？</strong></summary>

はい。組織が選択した AI サービスを接続し、下書き、要約、書き換え、翻訳に利用できます。AI の使い方は自社のポリシーに沿って管理できます。

</details>
