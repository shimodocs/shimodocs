## ShimoDocs vs Google Docs

> Get the familiar collaboration experience of Google Docs, with the security, control, and flexibility of private deployment.

### More control. More security. Only with Shimo.

| Feature | ShimoDocs | Google Docs |
| --- | :---: | :---: |
| **Private deployment**<br><sub>Deploy on your own servers or private cloud.</sub> | ✅ Yes | Public cloud only |

| **SSO & enterprise directory**<br><sub>Integrate with SSO, LDAP, AD, and more.</sub> | ✅ Yes | Limited |

| **Open API & extensibility**<br><sub>Open API for custom integrations and automation.</sub> | ✅ Yes | Limited |

| Feature | ShimoDocs | Google Docs |

## 常见问题

<details>
<summary><strong>ShimoDocs 真的可以免费使用吗？</strong></summary>

可以。团队人数不超过 5 人时，可以发送邮件至 [support.global@shimo.im](mailto:support.global@shimo.im) 申请免费 License，无需信用卡。超过 5 人后，可以根据实际人数选择付费方案。

</details>

<details>
<summary><strong>使用 ShimoDocs 是否需要自己的服务器？</strong></summary>

需要。ShimoDocs 安装在你的私有环境中，因此需要由你的组织提供和管理服务器、私有云或其他基础设施。暂时没有部署环境时，可以先申请 [在线试用](https://shimodocs.com/#online-trial)。

</details>

<details>
<summary><strong>它与 Google Docs 有什么不同？</strong></summary>

ShimoDocs 提供类似 Google Docs 的实时编辑体验，但可以部署在自己的私有环境中。组织能够对数据位置、身份系统、访问权限、审计记录和系统集成保留更多控制权。

</details>

<details>
<summary><strong>可以接入我们现有的 AI 服务吗？</strong></summary>

可以。ShimoDocs 支持连接组织选择的 AI 服务，将起草、总结、改写和翻译等能力带入文档，同时让团队按照自身策略管理 AI 的使用方式。

</details>
