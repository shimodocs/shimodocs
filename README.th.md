## ShimoDocs คืออะไร

ShimoDocs คือชุดเครื่องมือทำงานร่วมกันบนเอกสารแบบโฮสต์ด้วยตนเอง ซึ่งรวมเอกสารร่วมกัน การประมวลผลคำระดับมืออาชีพ สเปรดชีต งานนำเสนอ แบบฟอร์ม และตารางแบบมีโครงสร้างไว้ในไพรเวตคลาวด์ มอบประสบการณ์ทำงานร่วมกันแบบเรียลไทม์ที่คุ้นเคยคล้าย Google Docs พร้อมให้องค์กรควบคุมข้อมูลธุรกิจ การเข้าถึงของผู้ใช้ และการติดตั้งได้เอง

สร้าง แก้ไข แสดงความคิดเห็น ตรวจทาน และแชร์ในพื้นที่ทำงานเดียว โดยไม่ต้องส่งไฟล์แนบ ดูแลหลายเวอร์ชัน หรือส่งเนื้อหาที่ละเอียดอ่อนไปยังบริการพับลิกคลาวด์

## AI Agent ในทุกผลิตภัณฑ์

ผลิตภัณฑ์ ShimoDocs ทุกตัวมีแถบด้านข้าง AI Agent ในตัว AI ทำงานภายในเอกสาร สเปรดชีต งานนำเสนอ แบบฟอร์ม หรือตารางที่กำลังใช้งาน จึงไม่ต้องย้ายไปยังเครื่องมือแยกที่สูญเสียบริบทปัจจุบัน

องค์กรสามารถกำหนดค่า AI Agent โมเดล เครื่องมือ และแหล่งความรู้ที่ได้รับอนุมัติได้แบบส่วนตัว พร้อมควบคุมสิทธิ์เข้าถึงและขอบเขตข้อมูล ทีมจึงเลือกบริการ AI ที่ตรงกับข้อกำหนดด้านความปลอดภัย การปฏิบัติตามกฎ และการติดตั้ง โดยไม่ผูกติดกับผู้ให้บริการ AI สาธารณะรายเดียว

<table>
<tr>
<td width="33%" valign="top">

### 🤖 ครบทุกผลิตภัณฑ์

Document, Writer, Sheet, Presentation, Form และ Table มีแถบด้านข้าง AI Agent แบบเดียวกัน

</td>
<td width="33%" valign="top">

### 🔐 กำหนดค่าแบบส่วนตัว

เชื่อมต่อ AI Agent โมเดล เครื่องมือ และความรู้ที่องค์กรอนุมัติด้วยนโยบายการเข้าถึงและการควบคุมข้อมูลของคุณเอง

</td>
<td width="33%" valign="top">

### ⚡ Responses ไม่ใช่แค่แชต

ShimoDocs ใช้ **โหมด Responses** แบบ Agent ไม่ใช่กล่องแชตสไตล์ Copilot ทั่วไป Agent เข้าใจเนื้อหาปัจจุบัน จัดการคำขอหลายขั้นตอน ใช้เครื่องมือและบริบทที่กำหนดค่าไว้ และส่งผลลัพธ์ที่สมบูรณ์แบบมีโครงสร้างภายในเวิร์กโฟลว์

</td>
</tr>
</table>

## ติดตั้งแบบส่วนตัวในสี่ขั้นตอน

<p align="center"><img src="./assets/readme/get-started.svg" alt="ดาวน์โหลด ติดตั้งแบบส่วนตัว ขอไลเซนส์ และเริ่มทำงานร่วมกัน" width="100%" /></p>

4. เปิดใช้งานไลเซนส์ สร้างพื้นที่ทำงาน และเชิญทีมของคุณ

## ShimoDocs เทียบกับ Google Docs

> ประสบการณ์ทำงานร่วมกันที่คุ้นเคยของ Google Docs พร้อมความปลอดภัย การควบคุม และความยืดหยุ่นของการติดตั้งแบบส่วนตัว

### ควบคุมได้มากกว่า ปลอดภัยยิ่งกว่า มีเฉพาะใน Shimo

| ฟีเจอร์ | ShimoDocs | Google Docs |
| --- | :---: | :---: |
| **การติดตั้งแบบส่วนตัว**<br><sub>ติดตั้งบนเซิร์ฟเวอร์หรือไพรเวตคลาวด์ของคุณ</sub> | ✅ รองรับ | เฉพาะพับลิกคลาวด์ |
| **ความเป็นเจ้าของข้อมูลเต็มรูปแบบ**<br><sub>ข้อมูลอยู่ในสภาพแวดล้อมของคุณ</sub> | ✅ รองรับ | จัดการโดย Google |
| **SSO และไดเรกทอรีองค์กร**<br><sub>เชื่อมต่อ SSO, LDAP, AD และอื่น ๆ</sub> | ✅ รองรับ | จำกัด |
| **บันทึกการตรวจสอบและการปฏิบัติตามข้อกำหนด**<br><sub>บันทึกรายละเอียดเพื่อความปลอดภัยและการกำกับดูแล</sub> | ✅ รองรับ | จำกัด |
| **การควบคุมผู้ดูแลขั้นสูง**<br><sub>นโยบายและการควบคุมแบบละเอียด</sub> | ✅ รองรับ | การควบคุมพื้นฐาน |
| **Open API และการขยายระบบ**<br><sub>API สำหรับการผสานรวมและระบบอัตโนมัติ</sub> | ✅ รองรับ | จำกัด |

### ประสบการณ์ทำงานร่วมกันที่คุณคุ้นเคยอยู่แล้ว

| ฟีเจอร์ | ShimoDocs | Google Docs |
| --- | :---: | :---: |
| **การทำงานร่วมกันแบบเรียลไทม์**<br><sub>แก้ไขร่วมกันแบบเรียลไทม์</sub> | ✅ รองรับ | ✅ รองรับ |
| **การแก้ไขเอกสารที่คุ้นเคย**<br><sub>ประสบการณ์การแก้ไขคล้าย Docs</sub> | ✅ รองรับ | ✅ รองรับ |
| **ความคิดเห็นและคำแนะนำ**<br><sub>แสดงความคิดเห็น ตอบกลับ และเสนอการเปลี่ยนแปลง</sub> | ✅ รองรับ | ✅ รองรับ |
| **การแชร์และสิทธิ์**<br><sub>แชร์อย่างปลอดภัยด้วยสิทธิ์ดู แก้ไข หรือแสดงความคิดเห็น</sub> | ✅ รองรับ<br><sub>การควบคุมขั้นสูง</sub> | ✅ รองรับ<br><sub>การควบคุมพื้นฐาน</sub> |

ShimoDocs มอบประสบการณ์ทำงานร่วมกันที่คุ้นเคย พร้อมการควบคุมการติดตั้ง ข้อมูล สิทธิ์ และการผสานรวมที่มากกว่า

## ShimoDocs เหมาะกับใคร

- **สตาร์ทอัพและทีมขนาดเล็ก:** สร้างพื้นที่ทำงานร่วมกันด้วยต้นทุนเริ่มต้นที่ต่ำกว่า
- **โครงการโอเพนซอร์สและทีมเทคนิค:** ดูแลโรดแมป เอกสารออกแบบ แผนการเผยแพร่ และความรู้ของโครงการร่วมกัน
- **องค์กรที่ให้ความสำคัญกับความเป็นส่วนตัว:** เพิ่มประสิทธิภาพการทำงานร่วมกันพร้อมควบคุมตำแหน่งและการเข้าถึงข้อมูล
- **อุตสาหกรรมที่มีข้อกำกับและองค์กรขนาดใหญ่:** ใช้การติดตั้งแบบส่วนตัว การเชื่อมต่อระบบยืนยันตัวตน สิทธิ์ละเอียด และการตรวจสอบ
- **ทีมแบบกระจายและนานาชาติ:** สื่อสาร ตรวจทาน และทำงานต่อบนเวอร์ชันล่าสุดเดียวกัน
