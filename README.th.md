## สร้างมาเพื่อการทำงานร่วมกัน ออกแบบมาเพื่อการควบคุม

ShimoDocs ผสานประสบการณ์ทำงานร่วมกันแบบเรียลไทม์ที่คล้าย Google Docs เข้ากับการติดตั้งแบบส่วนตัว สิทธิ์ระดับองค์กร และการควบคุมข้อมูลที่มากขึ้น ทีมสามารถสร้าง แก้ไข แสดงความคิดเห็น ตรวจทาน และแชร์เนื้อหาในพื้นที่ทำงานเดียว โดยไม่ต้องส่งไฟล์แนบหรือดูแลไฟล์หลายเวอร์ชัน

## ShimoDocs เทียบกับ Google Docs

> ประสบการณ์ทำงานร่วมกันที่คุ้นเคยของ Google Docs พร้อมความปลอดภัย การควบคุม และความยืดหยุ่นของการติดตั้งแบบส่วนตัว

### ควบคุมได้มากกว่า ปลอดภัยยิ่งกว่า มีเฉพาะใน Shimo

| ฟีเจอร์ | ShimoDocs | Google Docs |
| --- | :---: | :---: |
| **การติดตั้งแบบส่วนตัว**<br><sub>ติดตั้งบนเซิร์ฟเวอร์หรือไพรเวตคลาวด์ของคุณ</sub> | ✅ รองรับ | เฉพาะพับลิกคลาวด์ |
| **ความเป็นเจ้าของข้อมูลเต็มรูปแบบ**<br><sub>ข้อมูลอยู่ในสภาพแวดล้อมของคุณ</sub> | ✅ รองรับ | จัดการโดย Google |
| **SSO และไดเรกทอรีองค์กร**<br><sub>เชื่อมต่อ SSO, LDAP, AD และอื่น ๆ</sub> | ✅ รองรับ | จำกัด |
| **บันทึกการตรวจสอบและการปฏิบัติตามข้อกำหนด**<br><sub>บันทึกรายละเอียดเพื่อความปลอดภัยและการกำกับดูแล</sub> | ✅ รองรับ | จำกัด |

ShimoDocs มอบประสบการณ์ทำงานร่วมกันที่คุ้นเคย พร้อมการควบคุมการติดตั้ง ข้อมูล สิทธิ์ และการผสานรวมที่มากกว่า

## ShimoDocs เหมาะกับใคร

- **สตาร์ทอัพและทีมขนาดเล็ก:** สร้างพื้นที่ทำงานร่วมกันด้วยต้นทุนเริ่มต้นที่ต่ำกว่า
- **โครงการโอเพนซอร์สและทีมเทคนิค:** ดูแลโรดแมป เอกสารออกแบบ แผนการเผยแพร่ และความรู้ของโครงการร่วมกัน
- **องค์กรที่ให้ความสำคัญกับความเป็นส่วนตัว:** เพิ่มประสิทธิภาพการทำงานร่วมกันพร้อมควบคุมตำแหน่งและการเข้าถึงข้อมูล
- **อุตสาหกรรมที่มีข้อกำกับและองค์กรขนาดใหญ่:** ใช้การติดตั้งแบบส่วนตัว การเชื่อมต่อระบบยืนยันตัวตน สิทธิ์ละเอียด และการตรวจสอบ
- **ทีมแบบกระจายและนานาชาติ:** สื่อสาร ตรวจทาน และทำงานต่อบนเวอร์ชันล่าสุดเดียวกัน
